  <action>
**App.tsx changes — complete rewrite of AppContent and App routing:**

1. **Remove old imports no longer needed at App.tsx level:**
   - Remove: `DAODashboard`, `StrategicDashboard`, `StrategicValidityDashboard`, `MissionList`, `MissionDetail`, `MissionWizard`, `LoginButton`
   - Keep: `AuthWrapper`, `UserStatusBar`, `LoginPage`, `RegisterPage`, `MagicLinkVerify`, `useUser`

2. **Add new imports:**
   - `import { Navigate, useNavigate, useLocation } from 'react-router-dom'`
   - `import { DecideTab } from './components/tabs/DecideTab'`
   - `import { DesignTab } from './components/tabs/DesignTab'`
   - `import { CampaignTab } from './components/tabs/CampaignTab'`
   - `import { MonitorTab } from './components/tabs/MonitorTab'`
   - `import { AdminDashboard } from './components/admin'`

3. **Remove the `View` type and `initialView` prop pattern entirely.** Active tab is derived from URL.

4. **Define tab constants:**
   ```typescript
   const MAIN_TABS = ['decide', 'design', 'campaign', 'monitor'] as const;
   type MainTab = typeof MAIN_TABS[number];
   ```

5. **Rewrite AppContent (no props needed):**
   - Use `useNavigate()` and `useLocation()` from react-router-dom
   - Derive `activeTab` from `location.pathname`: check if pathname starts with each tab name, fallback to `'monitor'`. Also check for `'/admin'`.
   - Determine `isAdmin = location.pathname.startsWith('/admin')`
   - Render header:
     - `<h1>` with BASTION — clicking navigates to `/monitor` (not home — home is removed per user decision)
     - `<nav className="app-nav">` with:
       - 4 main tab buttons (Decide, Design, Campaign, Monitor) — text labels only, no icons, uppercase per existing CSS. Each button: `className="nav-button"` + `active` class when matching. `onClick={() => navigate('/{tab}')}`
       - `<div className="nav-spacer" />` — flex spacer to push Admin right
       - Admin button: `className="nav-button nav-button--admin"` + `active` class. `onClick={() => navigate('/admin')}`
     - `<UserStatusBar />`
   - Render main content area `.app-main`:
     - Conditional render based on `activeTab`:
       - `'decide'` → `<DecideTab />`
       - `'design'` → `<DesignTab />`
       - `'campaign'` → `<CampaignTab />`
       - `'monitor'` → `<MonitorTab />`
     - If `isAdmin` → `<AdminDashboard onBack={() => navigate('/monitor')} />`

6. **Rewrite App() Routes:**
   ```
   Auth routes (outside AuthWrapper) — UNCHANGED:
   /login → LoginPage
   /register → RegisterPage
   /auth/verify → MagicLinkVerify
   /auth/recover → LoginPage

   Legacy redirects (outside AuthWrapper — these fire before auth check):
   / → <Navigate to="/monitor" replace />
   /governance → <Navigate to="/decide" replace />
   /strategic → <Navigate to="/design" replace />
   /validity → <Navigate to="/monitor" replace />
   /missions → <Navigate to="/campaign" replace />

   Main app routes (inside AuthWrapper):
   /decide → <AuthWrapper><AppContent /></AuthWrapper>
   /design → <AuthWrapper><AppContent /></AuthWrapper>
   /campaign → <AuthWrapper><AppContent /></AuthWrapper>
   /monitor → <AuthWrapper><AppContent /></AuthWrapper>
   /admin/* → <AuthWrapper><AppContent /></AuthWrapper>

   404:
   * → NotFound
   ```

7. **Keep NotFound component** — update the "Return to Home" link to point to `/monitor` instead of `/`.

**App.css changes:**

1. **Add `.nav-spacer` class:**
   ```css
   .nav-spacer {
     flex: 1;
   }
   ```

2. **Remove `justify-content: center` from `.app-nav`** — the spacer handles alignment now. The 4 main tabs will cluster left-center, Admin floats right.

3. **Ensure `.app-main` supports the sidebar layout:**
   - `.app-main` should have `overflow: hidden` (not `auto`) so the sidebar's own overflow-y works correctly
   - Ensure flex: 1 and min-height: 0 are present (they already are)

4. **Remove `.content-container` and `.login-container` styles** that were only used by the Home view. Actually, keep them — `NotFound` still uses `content-container`, and they're harmless.

5. **Responsive 768px breakpoint:** Keep existing mobile responsive rules. The tab buttons will wrap naturally on small screens.

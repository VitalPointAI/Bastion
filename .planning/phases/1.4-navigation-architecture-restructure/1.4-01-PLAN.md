  - A flex container div `.tab-layout` (horizontal: sidebar + content)

  - When open: a `<nav>` with `.sidebar-nav` containing buttons for each item
  - Each sidebar button: `.sidebar-item` class, `.active` when selected, `title={item.tooltip}` for tooltip, `onClick` calls `onSelectItem(item.id)`
  - A `<main>` with class `.tab-content` that renders `{children}`
- Use React 19 import style (`import { useState } from 'react'`)
- Import `./TabLayout.css`

**TabLayout.css:**
- Follow the CSS pattern from the RESEARCH.md code example exactly (`.tab-layout`, `.tab-sidebar`, `.tab-sidebar.collapsed`, `.sidebar-toggle`, `.sidebar-nav`, `.sidebar-item`, `.sidebar-item.active`, `.tab-content`)

- Sidebar open width: 220px. Collapsed width: 40px (enough for toggle button)
- CSS `transition` on sidebar width for smooth collapse animation
- Active sidebar item: left blue border + blue text (per research pattern)
- Add responsive breakpoint at 768px: sidebar collapsed by default on mobile

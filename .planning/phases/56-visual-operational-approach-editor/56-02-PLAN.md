Create `OperationalApproachMapEditor.tsx` with these capabilities:

**Props interface:**
```typescript
interface OperationalApproachMapEditorProps {
  problemSetId: string;
  mapOverlay: MapOverlay;
  onOverlayChange: (overlay: MapOverlay) => void;
  aoBounds?: { southwest: { lat: number; lng: number }; northeast: { lat: number; lng: number } };
}
```

**Map setup:**
- Use `<MapContainer>` from react-leaflet with OpenStreetMap tile layer
- Center on `aoBounds` if provided (use `L.latLngBounds` to fit), otherwise default to world view
- Set a stable `key` prop to prevent remounting (use `problemSetId`)
- Import `leaflet/dist/leaflet.css` and `leaflet-draw/dist/leaflet.draw.css`

**Symbol rendering (L.Marker with milsymbol DivIcon):**
- For each symbol in `mapOverlay.symbols`, render a `<Marker>` with:
  - DivIcon created from milsymbol: `new ms.Symbol(symbol.sidc, { size: 30, uniqueDesignation: symbol.designation }).asSVG()`
  - Memoize icon creation using a `Map<string, L.DivIcon>` cache keyed by `${sidc}-${designation}-${echelon}`
  - `draggable={true}`
  - `dragend` handler: calls `mapOverlayService.moveSymbol(problemSetId, symbol.id, newLat, newLng)` then updates local state via `onOverlayChange`
  - `click` handler: opens inline edit panel (simple state toggle showing MapSymbolEditPanel below the map)
  - Tooltip showing designation and MGRS coordinate (use `latLngToMGRS` from `mgrs-coordinator.ts`)

**Control measure rendering:**
- For each control measure, render as `<Polyline>` (for line type) or `<Polygon>` (for polygon type) from react-leaflet
- Color by affiliation: friendly=#0066cc, enemy=#cc0000, neutral=#00cc00
- Label via `<Tooltip permanent>` with the measure's label text

**Drawing new control measures (leaflet-draw):**
- Wrap in `<FeatureGroup>` with `<EditControl>` (follow AreaStep.tsx pattern exactly)
- Enable polyline and polygon drawing only (disable rectangle, circle, circlemarker, marker)
- `onCreated`: prompt for label and type via a small modal/form, then call `mapOverlayService.addControlMeasure()` and update state
- `onDeleted`: call `mapOverlayService.removeControlMeasure()` for each deleted layer

**Inline symbol edit panel:**
- When a symbol is clicked, show a small panel below the map (not a modal) with:
  - Text input for designation
  - Text input for SIDC (with live milsymbol preview)
  - Affiliation dropdown (friendly/enemy/neutral/unknown)
  - Delete button (calls `mapOverlayService.removeSymbol()`)
  - Save button (calls `mapOverlayService.updateSymbol()`)
- Clicking another symbol or the map background closes the panel

**CSS file (`OperationalApproachMapEditor.css`):**
- `.map-editor-container` — height: 500px, width: 100%, border: 1px solid var(--border), border-radius: 8px, overflow: hidden
- `.map-editor-panel` — padding: 12px, background: var(--bg-secondary), border-top: 1px solid var(--border)
- `.symbol-edit-row` — display: flex, gap: 8px, align-items: center
- Ensure leaflet container gets `z-index: 1` (prevent stacking issues with other UI)

**Anti-patterns to avoid (from research):**
- Do NOT use SVG overlay for editable symbols — use L.Marker with DivIcon
- Do NOT implement custom drag — use Leaflet's built-in `draggable={true}`
- Memoize milsymbol icon creation to avoid performance issues with 50+ symbols

1. Add map overlay CRUD methods to `backend/src/design/design-store.ts`:
   - `getMapOverlay(problemSetId: string): Promise<MapOverlay>` — reads `map_overlay` JSONB from operational_designs where problem_set_id matches
   - `setMapOverlay(problemSetId: string, overlay: MapOverlay): Promise<void>` — full replacement of map_overlay column
   - `addMapSymbol(problemSetId: string, symbol: MapSymbol): Promise<void>` — JSONB append: `UPDATE operational_designs SET map_overlay = jsonb_set(map_overlay, '{symbols}', (map_overlay->'symbols') || $2::jsonb) WHERE problem_set_id = $1`
   - `moveMapSymbol(problemSetId: string, symbolId: string, lat: number, lng: number): Promise<void>` — read overlay, find symbol by id, update lat/lng, write back
   - `removeMapSymbol(problemSetId: string, symbolId: string): Promise<void>` — read overlay, filter out symbol, write back
   - `updateMapSymbol(problemSetId: string, symbolId: string, updates: Partial<MapSymbol>): Promise<void>` — read overlay, merge updates into matching symbol, write back
   - `addControlMeasure(problemSetId: string, measure: ControlMeasure): Promise<void>` — JSONB append to controlMeasures array
   - `removeControlMeasure(problemSetId: string, measureId: string): Promise<void>` — read, filter, write back

   All write methods must also set `map_overlay->'lastUpdatedAt'` and `map_overlay->'lastUpdatedBy'`, and set `updated_at = NOW()` on the row.

2. Add PATCH endpoint in `backend/src/api/design.ts`:
   Route: `PATCH /api/design/:problemSetId/map-overlay`
   Body: `{ action: 'add_symbol' | 'move_symbol' | 'remove_symbol' | 'update_symbol' | 'add_control_measure' | 'remove_control_measure' | 'set_overlay', data: object }`
   Each action delegates to the corresponding store method. Returns the updated MapOverlay. Use the same router pattern already in design.ts.

   Also add `GET /api/design/:problemSetId/map-overlay` that returns the current MapOverlay JSON.

**Common symbols catalog (hardcoded ~20 entries):**
Organize into categories:
- **Land Units** (Friendly): Infantry (SFGPUCI----E), Armor (SFGPUCA----E), Artillery (SFGPUCF----E), Aviation (SFGPUCRVA--E), Reconnaissance (SFGPUCRR---E), Engineer (SFGPUCE----E), Signal (SFGPUCS----E), Logistics (SFGPUUS----E)
- **Land Units** (Enemy): Infantry (SHGPUCI----E), Armor (SHGPUCA----E), Artillery (SHGPUCF----E), Air Defense (SHGPUCD----E)
- **Air** (Friendly): Fixed Wing (SFAPMFF----E), Rotary Wing (SFAPMHR----E)
- **Control Measures**: Objective, Assembly Area, Checkpoint (use appropriate SIDCs for tactical graphics)

Each entry: `{ sidc: string, label: string, category: string }`

**UI layout:**
- Collapsible side panel (absolute positioned on the right side of the map container, 280px wide)
- Category headers (Land - Friendly, Land - Enemy, Air, Control Measures)
- Grid of symbol cards (2 columns): each card shows milsymbol SVG preview (32px) + label text
- Affiliation filter buttons at top: All / Friendly / Enemy / Neutral
- Text filter input for searching by label
- "Custom SIDC" section at bottom: text input for entering raw SIDC code with live milsymbol preview and "Add" button
- Clicking a catalog symbol → calls `onSelectSymbol(sidc, label, affiliation)` → closes picker

**milsymbol preview rendering:**
- For each visible symbol in the catalog, render: `new ms.Symbol(sidc, { size: 32 }).toDataURL()` as an `<img>` src
- Memoize the data URLs — compute once per SIDC, not on every render
- For the custom SIDC input: render live preview as user types (debounce 300ms)

3. On mount, seed the Y.Maps from the initial `mapOverlay` prop if they are empty (first client to connect populates from DB state):
   ```typescript
   useEffect(() => {
     if (!symbolsMap || symbolsMap.size > 0) return;
     // Seed from initial mapOverlay
     for (const sym of mapOverlay.symbols) {
       symbolsMap.set(sym.id, sym);
     }
     for (const cm of mapOverlay.controlMeasures) {
       measuresMap?.set(cm.id, cm);
     }
   }, [symbolsMap, measuresMap]);
   ```

4. Observe Y.Maps for changes and update local React state:
   ```typescript
   const [symbols, setSymbols] = useState<MapSymbol[]>(mapOverlay.symbols);
   const [controlMeasures, setControlMeasures] = useState<ControlMeasure[]>(mapOverlay.controlMeasures);

   useEffect(() => {
     if (!symbolsMap) return;
     const handler = () => setSymbols(Array.from(symbolsMap.values()));
     symbolsMap.observe(handler);
     // Initial sync
     handler();
     return () => symbolsMap.unobserve(handler);
   }, [symbolsMap]);

   // Same pattern for measuresMap -> setControlMeasures
   ```

5. Update all mutation callbacks to write to Yjs FIRST, then API:
   - **moveSymbol**: `symbolsMap.set(id, { ...existing, lat, lng })` then `mapOverlayService.moveSymbol(...)` in background (API is persistence, Yjs is real-time)
   - **addSymbol** (from draw or external): `symbolsMap.set(newSymbol.id, newSymbol)` then API call
   - **removeSymbol**: `symbolsMap.delete(id)` then API call
   - **updateSymbol**: `symbolsMap.set(id, { ...existing, ...updates })` then API call
   - **addControlMeasure**: `measuresMap.set(measure.id, measure)` then API call
   - **removeControlMeasure**: `measuresMap.delete(id)` then API call

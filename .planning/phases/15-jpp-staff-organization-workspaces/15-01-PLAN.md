   - `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

**StaffProductStore** (`backend/src/exercise/staff-product-store.ts`):
Follow the exact same pattern as existing stores in `backend/src/exercise/` (e.g., ipb-store.ts, coa-store.ts):
- Constructor takes `pool: Pool`
- `create(input: CreateStaffProductInput): Promise<StaffProduct>` — INSERT with crypto.randomUUID() id
- `findByRole(scenarioId: string, roleKey: string): Promise<StaffProduct[]>` — SELECT WHERE scenario_id=$1 AND role_key=$2 ORDER BY created_at
- `findById(id: string): Promise<StaffProduct | null>`
- `findOne(scenarioId: string, roleKey: string, productType: string): Promise<StaffProduct | null>` — for upsert patterns (strategic import)
- `update(id: string, input: UpdateStaffProductInput): Promise<StaffProduct>` — UPDATE with updated_at=NOW()
- `publish(id: string, publishedBy: string): Promise<StaffProduct>` — SET status='published', published_at=NOW(), published_by, version=version+1, return full row
- `findPublishedForScenario(scenarioId: string): Promise<StaffProduct[]>` — all published products across roles (for Commander overview)
- `delete(id: string): Promise<void>`

**StaffNotificationService** (`backend/src/exercise/staff-notification-service.ts`):
- Constructor takes `pool: Pool`
- `publishProduct(productId: string, publishedBy: string, enabledRoles: string[]): Promise<void>`:
  1. Call staffProductStore.publish(productId, publishedBy)
  2. Compute diff: query previous version from staff_products (by scenario_id + role_key + product_type + version < current), do shallow field-by-field JSON compare on `structured`, flag `contentChanged` boolean for `content` field
  3. INSERT staff_notifications row for each role in enabledRoles (excluding source role)
  4. Call MessageBus.publish() with channel `exercise.staff.${scenarioId}`, messageType `staff.product.published`, payload includes productId, sourceRole, title, diff. Use the existing `getMessageBus()` import pattern from PlanningBoardService.
- `getNotifications(scenarioId: string, targetRole: string): Promise<StaffNotification[]>` — SELECT from staff_notifications WHERE scenario_id AND target_role ORDER BY created_at DESC
- `getUnreadCount(scenarioId: string, targetRole: string): Promise<number>` — COUNT WHERE is_read=false
- `markRead(notificationId: string): Promise<void>` — UPDATE is_read=true
- `markIntegrated(notificationId: string): Promise<void>` — UPDATE is_integrated=true
- `getAllNotifications(scenarioId: string): Promise<StaffNotification[]>` — all notifications for global bell icon (no role filter)

**StrategicImportService** (`backend/src/exercise/strategic-import-service.ts`):
- Import `objectiveStore` from `../strategic/objectives/index.js` and `intentStore` from `../strategic/intent/index.js` (NOT HTTP calls — direct store imports per research pitfall #6)
- `importToCommanderWorkspace(scenarioId: string, importedBy: string): Promise<StaffProduct>`:
  1. Query objectiveStore for approved objectives
  2. Query intentStore for latest commander's intent
  3. Build structured JSON: `{ objectiveCount, objectives: [{id, description, priority}], intentId }`
  4. Build content narrative string: formatted markdown with objectives list and intent text
  5. Upsert: check staffProductStore.findOne(scenarioId, 'commander', 'strategic_guidance'), update if exists, create if not

**REST Routes** in `backend/src/api/exercise.ts`:
Add these routes (follow the exact existing pattern in exercise.ts — try/catch, req.headers['x-did'], res.status().json()):

Staff product routes:
- `GET /scenarios/:id/staff-products` — query param `roleKey` optional; if provided, return products for that role; if omitted, return all products for scenario
- `GET /scenarios/:id/staff-products/:productId` — single product by ID
- `POST /scenarios/:id/staff-products` — body: { roleKey, productType, title, structured?, content? }

- `POST /scenarios/:id/staff-products/:productId/publish` — triggers notification pipeline
- `DELETE /scenarios/:id/staff-products/:productId`

Staff notification routes:
- `GET /scenarios/:id/staff-notifications` — query param `roleKey` optional (filter) + `unreadOnly` boolean
- `GET /scenarios/:id/staff-notifications/count` — query param `roleKey` required, returns { count: N }
- `PUT /scenarios/:id/staff-notifications/:notificationId/read` — mark read
- `PUT /scenarios/:id/staff-notifications/:notificationId/integrate` — mark integrated

Strategic import route:

**Create ProductDiffView component** (`ProductDiffView.tsx`):

Props:
- `notification: StaffNotification` — contains the diff_snapshot and source product reference
- `scenarioId: string`
- `targetRoleKey: string` — the current user's role
- `onIntegrate: () => void` — callback after integration
- `onClose: () => void` — close diff view

Structure:

1. **Header**: "Changes from {sourceRole} — {product title}" with close button (X)

2. **Structured field changes section**:
   - Iterate over `notification.diffSnapshot.structuredChanges[]`
   - For each change, render a row showing:
     - Field name (left)
     - Old value with red/strikethrough styling (middle)
     - New value with green/highlight styling (right)
   - If `structuredChanges` is empty, show "No structured field changes"

3. **Content changes section**:
   - If `notification.diffSnapshot.contentChanged` is true:
     - Show the `contentSummary` text (AI-generated one-line summary of what changed in the narrative)
     - If no contentSummary, show "Narrative content was updated"
   - If contentChanged is false, show "No narrative changes"

4. **Action buttons**:
   - "Integrate" button — calls `exerciseService.markNotificationIntegrated(scenarioId, notification.id)`, then calls `onIntegrate()`. This marks the notification as integrated so it shows a check mark in the notification list.
   - "Dismiss" button — calls `exerciseService.markNotificationRead(scenarioId, notification.id)` without integrating, then calls `onClose()`
   - "View Full Product" button — opens the source product in read-only mode (link to the source role workspace or a modal showing the product content)

Per research recommendation: For content changes, show a summary rather than line-level diff. The structured changes are field-level which is straightforward to render. No external diff library needed.

**ProductDiffView.css**:
- Modal/overlay layout (centered, semi-transparent backdrop)
- Change rows: red background/strikethrough for old values, green background for new values
- Responsive: scrollable on small screens
- Use project color variables

**Update NotificationPanel** (`NotificationPanel.tsx`):

1. Add state: `selectedNotification: StaffNotification | null`
2. When user clicks a notification item, set `selectedNotification` to that notification
3. If `selectedNotification` is set, render `<ProductDiffView notification={selectedNotification} scenarioId={...} targetRoleKey={...} onIntegrate={handleIntegrate} onClose={() => setSelectedNotification(null)} />`
4. After integration, refresh notifications and reset selectedNotification
5. In the notification list, show a check icon for notifications where `isIntegrated === true`

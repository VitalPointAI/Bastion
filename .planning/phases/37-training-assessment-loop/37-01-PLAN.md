  <name>Task 1: Assessment type definitions</name>
  <files>backend/src/assessment/types.ts</files>
  <action>
Create backend/src/assessment/types.ts with all assessment type definitions. Use const objects (not enums) per project convention.

**AAR Types:**
- AARStatus: const object with 'draft' | 'in_review' | 'finalized' values
- StructuredAAR: { id (AAR-uuid), problemSetId, trainingEventName, initiatedBy (DID), status, whatWasPlanned, whatHappened, why, finalizedAt?, finalizedBy?, createdAt, updatedAt }
- CreateAARInput: Pick fields for creation (problemSetId, trainingEventName, initiatedBy)
- UpdateAARInput: Partial of the 4 doctrinal text sections + status
- AARObservation: { id (AARO-uuid), aarId, observationType ('sustain'|'improve'), content, metlTaskId?, suggestedByAi, aiAccepted?, createdBy, createdAt }
- CreateObservationInput: { aarId, observationType, content, metlTaskId?, suggestedByAi?, createdBy }

**METL Types:**
- METLRating: const object with 'T' | 'P' | 'U' values (Trained/Practiced/Untrained)
- METLTask: { id (METL-uuid), problemSetId, sourceProblemSetId?, taskName, taskDescription?, competencyArea?, isSupplemental, promotedToStrategic, decayDays (default 90), createdAt }
- CreateMETLTaskInput: { problemSetId, sourceProblemSetId?, taskName, taskDescription?, competencyArea?, isSupplemental?, decayDays? }
- METLAssessment: { id (METLA-uuid), metlTaskId, problemSetId, aarId?, rating ('T'|'P'|'U'), assessedBy, aiSuggestedRating?, commanderOverride, assessedAt, notes? }
- CreateMETLAssessmentInput: { metlTaskId, problemSetId, aarId?, rating, assessedBy, aiSuggestedRating?, commanderOverride?, notes? }
- DecayStatus: 'current' | 'warning' | 'expired'
- METLProficiencySummary: { metlTaskId, taskName, competencyArea?, decayDays, rating?, assessedAt?, assessedBy?, commanderOverride?, decayStatus }

**MOE/MOP Types:**
- AssessmentStatus: const object with 'green' | 'yellow' | 'red'
- AssessmentTrend: const object with 'improving' | 'stable' | 'declining'
- AssessmentMOE: { id (MOE-uuid), problemSetId, objectiveId?, objectiveSnapshot, name, description?, status, trend, createdBy, createdAt, updatedAt }
- CreateMOEInput: { problemSetId, objectiveId?, objectiveSnapshot, name, description?, createdBy }
- AssessmentMOP: { id (MOP-uuid), problemSetId, taskId?, taskSnapshot, name, description?, standard?, status, trend, createdBy, createdAt, updatedAt }
- CreateMOPInput: { problemSetId, taskId?, taskSnapshot, name, description?, standard?, createdBy }
- AssessmentObservation: { id (AOBS-uuid), targetType ('moe'|'mop'), targetId, content, source ('manual'|'ai_suggestion'|'osint'), statusUpdate?, trendUpdate?, approvedBy?, approvedAt?, createdBy, createdAt }
- CreateObservationInput (for MOE/MOP -- use a different name, e.g., CreateAssessmentObservationInput): { targetType, targetId, content, source?, statusUpdate?, trendUpdate?, createdBy }

  <action>
Create 4 store files following the existing store pattern (init() with table creation, getPool(), singleton export).

**aar-structured-store.ts:**
- initAARTables(): CREATE TABLE IF NOT EXISTS structured_aars (schema from RESEARCH.md) + aar_observations + indexes
- aarStructuredStore singleton with methods:
  - create(input: CreateAARInput): Promise<StructuredAAR> -- generates AAR-{uuid} id, defaults draft
  - getById(id: string): Promise<StructuredAAR | null>
  - listByProblemSet(problemSetId: string): Promise<StructuredAAR[]> -- ordered by created_at DESC
  - update(id: string, input: UpdateAARInput): Promise<StructuredAAR> -- only if status != 'finalized'
  - finalize(id: string, finalizedBy: string): Promise<StructuredAAR> -- sets status='finalized', finalizedAt=NOW(), finalizedBy
  - addObservation(input: CreateObservationInput): Promise<AARObservation> -- generates AARO-{uuid}
  - listObservations(aarId: string): Promise<AARObservation[]>
  - updateObservation(id: string, updates: { aiAccepted?: boolean; content?: string }): Promise<AARObservation>

**metl-store.ts:**
- initMETLTables(): CREATE TABLE IF NOT EXISTS metl_tasks + metl_assessments + indexes (schema from RESEARCH.md)
- metlStore singleton with methods:
  - createTask(input: CreateMETLTaskInput): Promise<METLTask> -- generates METL-{uuid}
  - getTasksByProblemSet(problemSetId: string): Promise<METLTask[]>
  - getInheritedTasks(problemSetId: string, sourceProblemSetId: string): Promise<METLTask[]> -- tasks inherited from strategic
  - promoteTask(taskId: string): Promise<METLTask> -- sets promotedToStrategic=true
  - createAssessment(input: CreateMETLAssessmentInput): Promise<METLAssessment> -- generates METLA-{uuid}
  - getAssessmentsByAAR(aarId: string): Promise<METLAssessment[]>
  - getLatestProficiency(sourceProblemSetId: string): Promise<METLProficiencySummary[]> -- uses DISTINCT ON query with decay_status calculation from RESEARCH.md
  - getAssessmentHistory(metlTaskId: string): Promise<METLAssessment[]> -- ordered by assessed_at DESC

**moe-store.ts:**
- initMOETables(): CREATE TABLE IF NOT EXISTS assessment_moes + assessment_observations (shared) + indexes
- moeStore singleton with methods:
  - create(input: CreateMOEInput): Promise<AssessmentMOE> -- generates MOE-{uuid}
  - getById(id: string): Promise<AssessmentMOE | null>
  - listByProblemSet(problemSetId: string): Promise<AssessmentMOE[]>
  - updateStatus(id: string, status: string, trend: string): Promise<AssessmentMOE>
  - addObservation(input: CreateAssessmentObservationInput): Promise<AssessmentObservation>
  - listObservations(targetId: string): Promise<AssessmentObservation[]>
  - approveObservation(id: string, approvedBy: string): Promise<AssessmentObservation> -- sets approvedBy + approvedAt, applies statusUpdate/trendUpdate to parent MOE

**mop-store.ts:**
- initMOPTables(): CREATE TABLE IF NOT EXISTS assessment_mops + reuses assessment_observations table from moe-store
- mopStore singleton with methods: same pattern as moeStore but for MOPs (create, getById, listByProblemSet, updateStatus, addObservation, listObservations, approveObservation)
- NOTE: assessment_observations table is shared -- moe-store creates it, mop-store just uses it. Add IF NOT EXISTS for safety.

All stores use `import { getPool } from '../db.js';` and `import { randomUUID } from 'crypto';`. Map snake_case DB columns to camelCase TypeScript in row mapping helpers.

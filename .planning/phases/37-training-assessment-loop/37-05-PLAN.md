Props: { problemSetId: string; proficiencyData: METLProficiencySummary[] }

Heat map matrix (CSS Grid, no charting library needed):
- Rows: METL tasks grouped by competencyArea
- Columns: the current proficiency rating (single column for latest state -- expand to time-based columns in future)
- Each cell: colored box showing T (green), P (yellow), U (red), or empty (gray)
- Decay warnings: if decayStatus === 'warning', cell has amber border with pulsing animation; if 'expired', cell has red dashed border with "(Decayed)" label
- Competency area group headers as row spans
- Legend at bottom: T=Trained (green), P=Practiced (yellow), U=Untrained (red), border styles for decay warnings

Implementation: pure CSS grid with conditional class names. Each cell is a div with classes like `metl-cell rating-T`, `metl-cell rating-U decay-warning`, etc.

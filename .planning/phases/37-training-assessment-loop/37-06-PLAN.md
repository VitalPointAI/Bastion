**ai-suggestion-service.ts:**
Create a service for generating AI-assisted assessment suggestions. Use a simple inline LLM call approach (per RESEARCH.md recommendation -- simpler than full staff agent pipeline).

- suggestObservations(aar: StructuredAAR, metlTasks: METLTask[]): Promise<Array<{ observationType: 'sustain'|'improve'; content: string; metlTaskId: string }>>
  1. Build prompt with AAR context: whatWasPlanned, whatHappened, why sections
  2. Include list of METL tasks with IDs and names
  3. System prompt: "You are a military Observer/Controller analyzing an After-Action Review. Based on the planned vs actual outcomes, generate sustain and improve observations. Each observation MUST be linked to a specific METL task ID. Format as JSON array."
  4. Call LLM via createLLMForAgent('assessment-observer') -- if this agent doesn't exist in the agent config, fall back to a direct ChatOpenAI instantiation with reasonable defaults
  5. Parse JSON response, validate each suggestion has required fields
  6. Return array of suggestions (frontend will display as AI-suggested observations for O/C review)

- suggestRatings(metlTasks: METLTask[], observations: AARObservation[]): Promise<Array<{ metlTaskId: string; suggestedRating: 'T'|'P'|'U'; rationale: string }>>
  1. Build prompt with METL tasks and their linked observations
  2. System prompt: "Based on these AAR observations linked to METL tasks, suggest a proficiency rating (T=Trained/fully meets standard, P=Practiced/partially meets standard, U=Untrained/does not meet standard) for each task. Provide brief rationale."
  3. Call LLM, parse response
  4. Return suggestions

Export as singleton `aiSuggestionService`.

**assessment-routes.ts -- add 2 new endpoints:**
- POST /aars/:id/ai-suggestions -- generates AI observation suggestions for an AAR
  1. Get AAR by id + METL tasks for the problem set
  2. Call aiSuggestionService.suggestObservations
  3. For each suggestion, call aarStructuredStore.addObservation with suggestedByAi=true
  4. Return the created observations

- POST /metl/assessments/ai-suggestions -- generates AI rating suggestions
  1. Body: { aarId }
  2. Get METL tasks and observations for the AAR
  3. Call aiSuggestionService.suggestRatings
  4. Return suggestions (NOT auto-created -- O/C reviews and submits manually)

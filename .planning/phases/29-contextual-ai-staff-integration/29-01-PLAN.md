  <action>
Create `frontend/src/context/AIStaffContext.tsx` following the split context pattern from RESEARCH.md pitfall 2 (prevents excessive re-renders):

1. Define `AIStaffStateContext` (read-only state) and `AIStaffDispatchContext` (actions) as two separate React contexts.

2. `AIStaffProvider` component props: `problemSetId: string`, `activeTab: string`, `children: ReactNode`
   - Maintains state: feedItems (AIFeedItem[]), annotations (AIAnnotation[]), isOpen (boolean, default true for process tabs, false for watch tabs), unreadCount (number), chatHistory (ChatMessage[])
   - On activeTab change: auto-set isOpen based on PROCESS_TABS (open) vs WATCH_TABS (closed/floating)
   - Feed items sorted by priority (critical > high > medium > low), then by timestamp descending
   - unreadCount derived from feedItems.filter(i => !i.isRead).length

3. Dispatch actions (via `useAIStaffDispatch` hook):
   - `addFeedItem(item: AIFeedItem)` -- prepend to feedItems, increment unreadCount
   - `markRead(itemId: string)` -- optimistic isRead=true
   - `markAllRead()` -- mark all as read
   - `togglePanel()` -- toggle isOpen
   - `setOpen(open: boolean)` -- explicit open/close
   - `addAnnotation(annotation: AIAnnotation)` -- add to annotations
   - `updateAnnotationStatus(annotationId: string, status: AIAnnotation['status'])` -- update status
   - `addChatMessage(message: ChatMessage)` -- append to chatHistory
   - `clearFeed()` -- reset feedItems

4. Export hooks:
   - `useAIStaff()` -- returns state context (feedItems, annotations, isOpen, activeTab, unreadCount, chatHistory)
   - `useAIStaffDispatch()` -- returns dispatch actions

Use `useReducer` for state management. Memoize state and dispatch objects with `useMemo` to prevent unnecessary re-renders.

Follow the same provider pattern as DecisionGateContext.tsx -- wrap children, throw if used outside provider.

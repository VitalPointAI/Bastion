**ai-staff-service.ts** -- REST API client following existing service patterns (cop-service.ts):
- Class `AIStaffService` with private `fetch` method wrapping window.fetch with credentials: 'include' and JSON content-type
- Methods matching all backend endpoints:
  - `getFeed(problemSetId, opts?)` -- GET /api/ai-staff/:id/feed
  - `createFeedItem(problemSetId, item)` -- POST
  - `markRead(problemSetId, itemId)` -- PATCH
  - `markAllRead(problemSetId)` -- POST
  - `getAnnotations(problemSetId)` -- GET
  - `createAnnotation(problemSetId, annotation)` -- POST
  - `updateAnnotation(problemSetId, annotationId, status)` -- PATCH
  - `getChatHistory(problemSetId, limit?)` -- GET
  - `sendChat(problemSetId, message)` -- POST
  - `getRouting(problemSetId)` -- GET
  - `updateRouting(problemSetId, tabId, agentIds)` -- PUT
- Export singleton: `export const aiStaffService = new AIStaffService()`

**useAIStaffFeed.ts** -- WebSocket subscription hook following useStaffNotifications pattern EXACTLY:
- Args: `problemSetId: string | null`
- On mount: fetch initial feed via `aiStaffService.getFeed(problemSetId)`; dispatch items into AIStaffContext via `useAIStaffDispatch().addFeedItem`
- WebSocket: connect to same WS_BASE_URL as useStaffNotifications. Subscribe to channel `ai.staff.${problemSetId}`.
- On message types `ai.feed.new`, `ai.feed.update`, `ai.annotation.new`: dispatch into context
- Use requestAnimationFrame batching: queue incoming messages, process max 5 per frame (per RESEARCH.md pitfall 4)
- Exponential backoff reconnect (1s base, 30s max) -- same constants as useStaffNotifications
- Cleanup on unmount: unsubscribe + close WebSocket
- Return: { loading, refresh }

**useAgentRouting.ts** -- Tab-aware agent routing:
- Args: `problemSetId: string | null`, `activeTab: string`
- Fetches routing config from backend on mount via aiStaffService.getRouting
- Merges backend config with DEFAULT_TAB_AGENTS (backend overrides defaults if user has customized)
- Returns: `{ agents: string[], isCustomized: boolean, updateRouting: (agentIds: string[]) => Promise<void> }`
- updateRouting calls aiStaffService.updateRouting and updates local state

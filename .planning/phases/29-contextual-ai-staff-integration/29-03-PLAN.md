**AIStaffPanel.tsx** -- Mode-switching shell:
- Reads `activeTab` and `isOpen` from `useAIStaff()`
- If not open and isProcessTab: return null (panel hidden)
- If isProcessTab: render `<AIStaffDocked />`
- If isWatchTab: render `<AIStaffFloating />`
- Import AIStaffPanel.css

**AIStaffPanel.css** -- Shared styles for the panel system (urgency badge colors, common typography).

**AIStaffDocked.tsx** -- Right sidebar panel for process tabs (Design, Plan, Understand):
- Fixed-width right panel (default 360px, min 280px, max 600px)
- Left-edge resize handle (4px drag zone, cursor: col-resize). Use native mousedown/mousemove/mouseup for resize -- do NOT use a drag library.
- Persist user's preferred width to localStorage key 'bastion-ai-panel-width'
- Header: "AI Staff" title + close button (calls dispatch.setOpen(false))
- Body: scrollable feed list rendering AIStaffFeedItem for each item from useAIStaff().feedItems
- Feed items sorted by priority (already sorted in context), with "Other tabs" collapsible group for non-active-tab items below active-tab items
- Footer: slot for AIStaffChatInput (rendered in Plan 04)
- CSS: position as flex sibling next to tab content (NOT inside TabLayout -- per RESEARCH.md pitfall 1). Uses CSS vars --bg-secondary, --border-subtle, --text-primary, --text-secondary.

**AIStaffFloating.tsx** -- Floating overlay for watch tabs (COP, Assess, Direct):
- When collapsed: circular floating button (48px) with notification badge showing unreadCount. Color-coded: green border if all info, amber if attention items, red if action_required items.
- When expanded: floating panel (360x500px default) rendered via `createPortal` to document.body (per RESEARCH.md pitfall 3). z-index: 900 (above map ~400-600, below modals 1000+).
- Draggable via native mousedown/mousemove/mouseup on header bar. Position stored as CSS transform: translate(x, y). Initial position: bottom-right corner, 20px from edges.
- Persist position to localStorage key 'bastion-ai-floating-pos'
- Same feed content as docked mode, just in floating container
- Close button minimizes to floating icon (does not destroy)

**AIStaffFloating.css** -- Floating-specific styles.

All components use project CSS convention (custom properties, no Tailwind in component CSS files, Tailwind-style utility classes only in JSX className strings where consistent with existing code).

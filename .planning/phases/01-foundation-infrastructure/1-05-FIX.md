  <action>
    Fix UAT-001: NEAR contract fails to build with WASM bulk memory errors

    **Root Cause:** Rust 1.88.0 generates bulk memory WASM instructions by default, but NEAR's WASM validator doesn't support the bulk memory proposal.

    **Solution Options (try in order):**

    1. **Option A: Downgrade Rust toolchain** (most reliable)
       - Change rust-toolchain.toml to use Rust 1.82.0 (commonly used for NEAR contracts)
       - This is the toolchain version used by cargo-near's Docker images

    2. **Option B: Add RUSTFLAGS to disable bulk memory** (if downgrade causes issues)
       - Create/modify .cargo/config.toml
       - Add: `[target.wasm32-unknown-unknown]`
       - Add: `rustflags = ["-C", "target-feature=-bulk-memory"]`

    **Implementation:**

    1. First, try Option A - downgrade toolchain:
       - Edit rust-toolchain.toml
       - Change channel from "1.88.0" to "1.82.0"

    2. Run `cargo near build non-reproducible-wasm` to verify

    3. If Option A fails or causes other issues, try Option B:
       - Create .cargo/config.toml (if doesn't exist)
       - Add RUSTFLAGS to disable bulk memory

    4. Run `cargo test` to verify unit tests still pass

    **Do not:**
    - Upgrade near-sdk (current version 5.9 is recent)
    - Modify contract code (the issue is toolchain, not code)
    - Use nightly Rust (stability matters)
  </action>
  <verify>

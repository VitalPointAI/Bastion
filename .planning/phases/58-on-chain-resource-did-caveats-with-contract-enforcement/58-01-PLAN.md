    CRITICAL SCHEMA SAFETY: Caveats MUST use a SEPARATE LookupMap keyed by blinded_key hex -- NOT an Option field on DIDEntry. This avoids Borsh schema invalidation for existing on-chain entries (see Pitfall 1 in research).

    New structs (all with BorshSerialize, BorshDeserialize, Serialize, Deserialize, Clone, JsonSchema derives):

    ResourceCaveats:
      - classification: String ("UNCLASSIFIED" | "SECRET" | "TOPSECRET" | "TS_SCI")
      - releasability: Vec<String> (nation codes, empty = unrestricted)
      - geo_bounds: Option<GeoBounds>
      - roe_tier: u8 (1-5)
      - time_windows: Vec<TimeWindow>
      - employment_constraints: Vec<String>
      - updated_by: AccountId
      - updated_at: u64

      - north: i64, south: i64, east: i64, west: i64 (degrees * 1_000_000, NO floats)

    TimeWindow:
      - start_ms: u64, end_ms: u64

    EmploymentContext (serde only, not borsh -- used as JSON input):
      - requesting_account: String
      - location: Option<GeoBounds>
      - timestamp_ms: u64
      - roe_tier_required: u8
      - nation_code: Option<String>

    EmploymentAuthResult (serde only):
      - authorized: bool
      - reasons: Vec<String>

    Add StorageKey::Caveats variant.

    Add `caveats: LookupMap<String, ResourceCaveats>` to DIDRegistry struct.

    Update DIDRegistry::new() to initialize caveats map with StorageKey::Caveats.

    MIGRATION METHOD (required for testnet upgrade with existing state):

    Add a `#[private] pub fn migrate(&mut self)` method OR a standalone migration function using the old-state pattern. The existing on-chain state is serialized as `{ dids, admin, paused }` (3 Borsh fields). The new struct expects `{ dids, caveats, admin, paused }` (4 fields). Without migration, Borsh deserialization will fail because it reads fields in order -- it will try to deserialize `admin: AccountId` bytes as `caveats: LookupMap` and panic.

    Recommended approach -- define an `OldDIDRegistry` struct for migration:
    ```rust
    #[derive(BorshDeserialize)]
    pub struct OldDIDRegistry {
        dids: LookupMap<String, DIDEntry>,
        admin: AccountId,
        paused: bool,
    }

    #[near]
    impl DIDRegistry {
        #[init(ignore_state)]
        pub fn migrate() -> Self {
            let old: OldDIDRegistry = env::state_read().expect("Old state exists");
            Self {
                dids: old.dids,
                caveats: LookupMap::new(StorageKey::Caveats),
                admin: old.admin,
                paused: old.paused,
            }
        }
    }
    ```

    This is called ONCE after contract deploy: `near contract call-function as-transaction $CONTRACT_ID migrate json-args '{}' ...`

    After migrate() succeeds, the contract state is in the new 4-field format and all methods work normally. Plan 03 Task 2 (testnet deploy) will call migrate() after deploying the WASM.

    NOTE: If testnet has no valuable state (expendable), the clean redeploy path (delete account + recreate + deploy with `new()`) is also acceptable. Plan 03 Task 2 specifies both paths. The migrate() method is provided as the SAFE path that preserves existing DIDs.

    New methods on DIDRegistry:

    1. update_resource_caveats(blinded_key: Vec<u8>, caveats: ResourceCaveats) -- #[payable], write
       - assert_not_paused
       - Convert blinded_key to hex
       - Verify DID exists in self.dids
       - Verify caller is DID owner OR admin
       - Store in self.caveats (NOT self.dids)
       - Handle storage deposit refund (same pattern as store_did)

    2. check_employment_authorized(blinded_key: Vec<u8>, context: EmploymentContext) -> EmploymentAuthResult -- view
       - If DID not found or inactive: authorized=false
       - If no caveats stored: authorized=true (permissive default)
       - Check releasability: if caveats.releasability non-empty and context.nation_code not in list, add reason
       - Check ROE tier: if context.roe_tier_required > caveats.roe_tier, add reason
       - Check time windows: if caveats.time_windows non-empty and context.timestamp_ms not in any window, add reason
       - Check geo bounds: if both geo_bounds and context.location present, check containment, add reason if outside
       - authorized = reasons.is_empty()

    3. get_caveats(blinded_key: Vec<u8>) -> Option<ResourceCaveats> -- view
       - Simple lookup from self.caveats

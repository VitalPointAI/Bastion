  <name>Task 1: COP API routes and handlers</name>
  <files>backend/src/cop/api/cop-routes.ts, backend/src/cop/api/cop-handlers.ts</files>
  <action>
Create `backend/src/cop/api/cop-handlers.ts` with handler groups:

**Layer Handlers:**
- `POST /cop/layers` -- createLayer: body { workspaceId, sectionId, layerType, spec? }. If spec provided, create with spec. If not, trigger generation via runCOPGeneration and return the draft layer.
- `GET /cop/layers` -- queryLayers: query params workspaceId, sectionId?, state?, layerType?
- `GET /cop/layers/:id` -- getLayer: returns full layer with spec
- `PUT /cop/layers/:id/spec` -- updateLayerSpec: body { spec }
- `POST /cop/layers/:id/transition` -- transitionLayer: body { targetState, reason? }. Calls layerStore.transitionLayer. On COP transition, also runs detectConflicts and returns conflicts.
- `POST /cop/layers/:id/feedback` -- addReviewFeedback: body { type, content, position?, entityId? }
- `POST /cop/layers/:id/recall` -- recallLayer: body { reason }. Transitions from COP to review with reason.

**Version Handlers:**
- `GET /cop/layers/:id/versions` -- listSnapshots for layer
- `GET /cop/layers/:id/versions/:version` -- getSnapshot or reconstructAtVersion
- `GET /cop/layers/:id/versions/:version/spec` -- returns just the spec at that version

**Agent Handlers:**
- `POST /cop/agents/trigger` -- body { workspaceId, sectionId, triggeredBy: 'manual' }. Calls triggerHandler.handleManualTrigger.
- `POST /cop/agents/polling/start` -- body { workspaceId, sectionId, intervalMs? }. Calls triggerHandler.startPolling.
- `POST /cop/agents/polling/stop` -- body { workspaceId, sectionId }. Calls triggerHandler.stopPolling.
- `GET /cop/agents/activity` -- query params workspaceId, limit?. Returns activityBridge.getActivities.

**Linkage Handlers:**
- `GET /cop/linkages/pending` -- query params workspaceId?. Returns linkageStore.getPendingReviews.
- `POST /cop/linkages/:id/review` -- body { approved }. Calls linkageStore.reviewLinkage.
- `GET /cop/linkages/entity/:entityId` -- returns linkageStore.getLinkagesForEntity.

**Conflict Handlers:**
- `GET /cop/conflicts` -- query params workspaceId. Queries all COP-state layers for workspace, runs detectConflicts pairwise, returns aggregated conflicts.

Create `backend/src/cop/api/cop-routes.ts`:
- Express Router mounting all handlers above
- Use existing auth middleware pattern from strategic.ts
- Input validation with zod schemas for all request bodies
- Error handling: wrap handlers in try/catch, return appropriate HTTP status codes (400 for validation, 404 for not found, 409 for invalid transitions, 500 for server errors)

All endpoints scoped by workspaceId. Follow the existing strategic.ts pattern for route structure and middleware.

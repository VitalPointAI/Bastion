Create `frontend/src/components/cop/COPReviewPanel.tsx`:
- Props: { layer: COPLayer, onFeedbackSubmitted, onTransition }
- Two feedback modes:
  1. **Spatial Annotation**: Staff clicks on map to place annotation at specific position/entity. Form: position (from map click), optional entityId (if clicked on symbol), comment text. Submits as ReviewFeedback with type='spatial_annotation'.
  2. **General Comment**: Free-text comment about the layer overall. Submits with type='general_comment'.
- Existing feedback display: list of prior ReviewFeedback entries with author, timestamp, spatial indicator if applicable
- Action buttons: "Request Revision" (transitions to draft), "Approve for Publish" (transitions to published)
- When submitting: calls copService.addFeedback then onFeedbackSubmitted callback

Create `frontend/src/components/cop/COPLayerLifecycle.tsx`:
- Props: { layer: COPLayer, onTransition, canPromote: boolean }
- Displays current state as a progress indicator: Draft -> Review -> Published -> COP (active state highlighted)
- Shows state badge with color: draft=gray, review=yellow, published=blue, cop=green
- Transition buttons based on current state:
  - Draft: "Submit for Review" button
  - Review: "Approve" / "Request Revision" buttons
  - Published: "Promote to COP" button (only if canPromote=true, per user's publish permission)
  - COP: "Recall" button (opens modal for reason input)
- Recall modal: text area for reason (required), confirm/cancel buttons
- Shows promotedBy/promotedAt if in COP state
- Shows recallReason if previously recalled
- All transitions call copService.transitionLayer or copService.recallLayer

Create `frontend/src/components/cop/COPConflictBanner.tsx`:
- Props: { conflicts: COPConflict[], onConflictClick }
- Displayed as a dismissible alert banner above the map when conflicts exist
- Shows conflict count: "3 conflicts detected across sections"
- Expandable list of conflicts:

  - "Resolve" button per conflict that calls onConflictClick to navigate to the conflicting entities
- Source authority ranking display: show which source is more authoritative per the ranking (SIGINT > HUMINT > IMINT > OSINT)
- Visual priority: affiliation conflicts highlighted red (most dangerous), position orange, designation yellow

CSS: Review panel as side panel. Lifecycle as horizontal progress bar. Conflict banner as top-of-map overlay with military alert styling.

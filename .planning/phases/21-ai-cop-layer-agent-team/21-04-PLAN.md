Create `backend/src/cop/svg/sidc-builder.ts`:

Implement full MIL-STD-2525D 20-character SIDC builder. The 20 digits are structured as:
- Positions 1-2: Version (always '10' for 2525D)
- Positions 3-4: Standard Identity (03=friendly, 06=hostile, 04=neutral, 01=unknown, 02=assumed_friendly, 05=suspect)
- Positions 5-6: Symbol Set (10=land_unit, 01=air, 30=sea_surface, 15=land_equipment, 20=land_installation, 05=space, 35=subsurface, 25=sea_mine, 40=activity)
- Position 7: Status (0=present, 1=planned, 2=anticipated/suspected, 3=present_fully_capable)
- Position 8: HQ/TF/FD (0=none, 1=hq, 2=task_force, 3=feint_dummy, 4=hq_task_force)
- Positions 9-10: Echelon/Amplifier (00=unspecified, 11=team, 12=squad, 13=section, 14=platoon, 15=company, 16=battalion, 17=regiment, 18=brigade, 19=division, 20=corps, 21=army)
- Positions 11-16: Entity code (6 digits, from MIL-STD-2525D lookup tables)
- Positions 17-18: Modifier 1 (2 digits, default '00')
- Positions 19-20: Modifier 2 (2 digits, default '00')

Define lookup maps:
- IDENTITY_MAP: friendly='03', hostile='06', neutral='04', unknown='01', assumed_friendly='02', suspect='05'
- SYMBOL_SET_MAP: land_unit='10', air='01', sea_surface='30', land_equipment='15', land_installation='20', space='05', subsurface='35', activity='40'
- STATUS_MAP: present='0', planned='1', anticipated='2', fully_capable='3'
- HQ_TF_FD_MAP: none='0', hq='1', task_force='2', feint_dummy='3', hq_task_force='4'
- ECHELON_MAP: unspecified='00', team='11', squad='12', section='13', platoon='14', company='15', battalion='16', regiment='17', brigade='18', division='19', corps='20', army='21'
- ENTITY_CODE_MAP: common military entity codes for infantry='110100', armor='110200', artillery='110300', air_defense='110400', engineer='110500', signal='110600', logistics='110700', medical='110800', military_intel='110900', headquarters='110000', etc.

`buildSIDC(params: SIDCParams): string` -- concatenate mapped values, pad entity code to 6 digits, modifiers to 2 digits each. Validate result is exactly 20 digits.

`buildSIDCFromEntity(entity: { type: string; affiliation: string; echelon?: string; functionCode?: string; status?: string }): string` -- convenience function that maps high-level entity attributes to SIDCParams and calls buildSIDC. Uses sensible defaults (status='present', hqTfFd='none', echelon='unspecified', entity='110000' for unknown).

- `generateAnnotationSVG(request: AnnotationRequest): Promise<COPAnnotationSpec>`:

  - Return COPAnnotationSpec with the sanitized svgFragment, position, bounds, generatedBy='llm', description

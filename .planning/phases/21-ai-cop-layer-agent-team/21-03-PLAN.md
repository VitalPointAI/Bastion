  <behavior>
    - createLayer(input) returns a new COPLayer in 'draft' state with version 1
    - getLayer(id) returns the layer or null
    - queryLayers(filters) returns layers matching workspace/section/state/type filters
    - transitionLayer from 'draft' to 'review' succeeds
    - transitionLayer from 'draft' to 'published' fails (must go through review)
    - transitionLayer from 'review' to 'published' succeeds
    - transitionLayer from 'published' to 'cop' succeeds (promote)
    - transitionLayer from 'cop' to 'review' succeeds only with reason (recall)
    - Each transition creates an AuditEntry
    - updateLayerSpec updates the spec and increments version
    - addReviewFeedback appends feedback to layer
  </behavior>

Create `backend/src/cop/layers/version-store.ts`:
- SQL table: `cop_layer_snapshots` with columns: id (UUID), layer_id, version, state, is_full_snapshot (boolean), spec_or_patch (JSONB), transitioned_by, transitioned_at, previous_state, created_at.
- `createSnapshot(layer: COPLayer, previousSpec: COPLayerSpec | null)`:
  - If layer.state === 'cop' OR previousSpec is null: store full spec (is_full_snapshot=true)
  - Otherwise: compute JSON diff (use simple object comparison -- not a library; just store the changed fields) and store as patch (is_full_snapshot=false)
- `getSnapshot(layerId: string, version: number): Promise<LayerSnapshot | null>`
- `listSnapshots(layerId: string): Promise<LayerSnapshot[]>` -- ordered by version
- `reconstructAtVersion(layerId: string, version: number): Promise<COPLayerSpec>` -- find nearest full snapshot, apply patches forward
- `ensureTable(): Promise<void>`

Create `backend/src/cop/layers/layer-assembler.ts`:
- `assemble(subAgentSpecs: COPLayerSpec[]): COPLayerSpec` -- merges multiple sub-agent layer specs:
  - Concatenate symbols arrays, deduplicate by entityId (keep highest confidence)
  - Concatenate controlMeasures arrays (no dedup needed -- different types)
  - Concatenate customAnnotations arrays
  - Merge temporalPhases by phaseNumber (union of phases across sub-agents)
  - Set metadata.generatedBy to 'cop-coordinator-001', generatedAt to now, sourceDocumentIds as union

Create `backend/src/cop/layers/conflict-detector.ts`:
- `detectConflicts(targetLayer: COPLayer, existingCOPLayers: COPLayer[]): COPConflict[]`
  - For each symbol in targetLayer.spec.symbols, check all symbols in existingCOPLayers:
    - Same entityId + different position (distance > threshold, e.g. 100m) = position conflict
    - Same entityId + different affiliation = affiliation conflict
    - Same entityId + different designation = designation conflict
  - For each conflict, include sourceAuthority from both symbols for ranking
  - Sort conflicts by severity: affiliation > position > designation
- Source authority ranking helper: SIGINT > HUMINT > IMINT > OSINT > default (configurable)

Tests in `backend/src/cop/layers/version-store.test.ts` covering snapshot creation (full vs patch), reconstruction, assembler merging, conflict detection.

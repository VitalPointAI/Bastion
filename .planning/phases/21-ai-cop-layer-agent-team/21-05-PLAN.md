  <name>Task 2: Hybrid entity linker</name>

  <action>
Create `backend/src/cop/linkage/entity-linker.ts`:
- `LinkageResult` interface: { entityId, linkedEntityId, confidence, method: 'graph_traversal' | 'embedding_similarity', description }
- `EntityLinker` class:
  - Constructor takes: neo4j driver (from existing neo4j-client.ts), OpenAI embeddings instance, linkageStore, confidenceConfig
  - `discoverLinkages(workspaceId: string, symbolSpecs: COPSymbolSpec[]): Promise<LinkageResult[]>`:
    1. **Graph traversal phase**: For each symbol, query Neo4j RAFT graph for the entity by entityId. If found, traverse relationships (1-2 hops) to discover linked entities. These get confidence=1.0 (known relationships). Use existing workspace-scoped graph queries.
    2. **Embedding similarity phase**: For entities not found in graph or with few relationships, generate embedding via text-embedding-3-large (using OpenAIEmbeddings from @langchain/openai). Compare against embeddings of other entities in the workspace. Use cosine similarity. Threshold for candidate: > 0.7 similarity. Final confidence = similarity score.
    3. Combine results, deduplicate by entityId pair
    4. For each result, call evaluateConfidence to determine auto-commit
    5. Persist all linkages via linkageStore.createLinkage
    6. Emit 'linkage:discovered' events via copEventBus for each new linkage
    7. Return all LinkageResults

  - `getEntityContext(entityId: string, workspaceId: string): Promise<EntityContext>` -- retrieves entity from RAFT graph with its immediate relationships, functions, tensions. Returns data suitable for hover tooltip (name, affiliation, key linked entities).

  - Private `generateEmbedding(text: string): Promise<number[]>` -- uses OpenAIEmbeddings.embedQuery(text)
  - Private `computeSimilarity(a: number[], b: number[]): number` -- cosine similarity

Note: The embedding storage strategy (per RESEARCH open question) -- store embeddings as a property on entities in Neo4j. If Neo4j vector index is available, use it. Otherwise fall back to in-memory comparison (acceptable for v1 scale).

Import and use existing modules:
- neo4j-client.ts for Neo4j driver
- resolution-service.ts for entity resolution if needed
- @langchain/openai for OpenAIEmbeddings

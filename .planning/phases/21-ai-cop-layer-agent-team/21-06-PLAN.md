Each sub-agent follows the same pattern -- a function that takes workspace context and returns a COPLayerSpec fragment for its domain. Use ChatAnthropic for entity extraction from documents, but SIDC codes are always generated via buildSIDCFromEntity (never by LLM).

Common pattern for all sub-agents:
```typescript
interface SubAgentInput {
  workspaceId: string;
  sectionId: string;
  documents: Array<{ id: string; content: string; type: string }>;
  graphEntities: Array<{ id: string; name: string; type: string; properties: Record<string, unknown> }>;
  existingSymbols?: COPSymbolSpec[]; // From other sub-agents if sequential
}

async function [agentName](input: SubAgentInput): Promise<COPLayerSpec>
```

Each sub-agent:
1. Filters input documents and graph entities relevant to its domain
2. Uses ChatAnthropic to extract structured entity data from documents (position, designation, type, affiliation)
3. Generates SIDC codes via buildSIDCFromEntity for each extracted entity
4. Validates CCO class for each entity via suggestCCOClass
5. Emits agent:activity events via copEventBus
6. Returns a COPLayerSpec with its domain's symbols, control measures, and/or annotations

- Extracts: unit positions, task organizations, movement plans from OPORDs/FRAGOs

**objectives-overlay.ts** (J35):

**control-measures.ts** (J3):
- Extracts: boundaries, phase lines, axes of advance, routes, fire support coordination measures
- Control measures: polylines/polygons with labels and phase ranges
- No symbols typically -- pure control measures

Each sub-agent has a 30-second timeout. If extraction fails, return an empty COPLayerSpec with metadata indicating the failure.

Then create `backend/src/cop/agents/cop-coordinator.ts` following the existing StrategyReviewerState LangGraph pattern from backend/src/agents/langgraph/state.ts:

Define COPCoordinatorState using Annotation.Root:
```
workspaceId: Annotation<string>
sectionId: Annotation<string>
triggeredBy: Annotation<'commit' | 'manual' | 'polling'>
triggerContext: Annotation<Record<string, unknown>> (reducer: replace)
messages: Annotation<BaseMessage[]> (reducer: append)
layerSpecs: Annotation<COPLayerSpec[]> (reducer: append)
assembledLayer: Annotation<COPLayer | null> (reducer: replace)
status: Annotation<'routing' | 'generating' | 'assembling' | 'validating' | 'complete' | 'error'> (reducer: replace)
errors: Annotation<string[]> (reducer: append)
```

Build StateGraph with nodes:
1. **route** -- Determines which sub-agents to invoke based on trigger context. For a full generation, routes to all 6. For a targeted update (e.g., only intel changed), routes to relevant sub-agent(s). Emits agent:activity. Sets status='routing'.

2. **generate_layers** -- Invokes sub-agents in parallel (no inter-agent dependencies for initial generation). Uses Promise.allSettled with 30s timeout per agent. Collects COPLayerSpec results into layerSpecs. Logs errors for failed agents but continues. Sets status='generating'. Emits agent:activity for each sub-agent start/complete.

3. **assemble** -- Calls LayerAssembler.assemble(layerSpecs) to merge all sub-agent outputs. Deduplicates symbols by entityId. Sets status='assembling'.

4. **validate_cco** -- For each symbol in assembled spec, validates CCO class via validateCCOClass. If invalid, attempts suggestCCOClass and updates. Logs validation failures. Sets status='validating'.

5. **persist** -- Creates layer via layerStore.createLayer in 'draft' state. Runs entity linker discoverLinkages for all symbols. Emits layer:generation:complete event. Sets assembledLayer and status='complete'.

Edge configuration:
- __start__ -> route -> generate_layers -> assemble -> validate_cco -> persist -> END
- Add error handling: if generate_layers produces zero specs, skip to persist with error status

Export `copCoordinatorGraph` as the compiled StateGraph.

Also export a convenience function:
```typescript
export async function runCOPGeneration(workspaceId: string, sectionId: string, triggeredBy: TriggerType, context?: Record<string, unknown>): Promise<COPLayer | null>
```
This invokes the graph with initial state and returns the assembled layer.

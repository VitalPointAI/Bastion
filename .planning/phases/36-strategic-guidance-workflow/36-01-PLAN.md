**store.ts** — Create `StrategicGuidanceStore` class following jpp-store.ts pattern:
- Constructor takes Pool, calls ensureTable()
- ensureTable() creates 4 tables via CREATE TABLE IF NOT EXISTS:
  - strategic_guidance_instances (id TEXT PK, problem_set_id TEXT NOT NULL UNIQUE, step_statuses JSONB DEFAULT '{}', current_directive_version INT DEFAULT 0, status TEXT DEFAULT 'active', created_by TEXT NOT NULL, created_at/updated_at TIMESTAMPTZ)
  - strategic_guidance_step_products (id TEXT PK, instance_id TEXT NOT NULL REF instances, step TEXT NOT NULL, content JSONB DEFAULT '{}', updated_by TEXT NOT NULL, created_at/updated_at TIMESTAMPTZ, UNIQUE(instance_id, step))
  - strategic_directive_versions (id TEXT PK, instance_id TEXT NOT NULL REF instances, version INT NOT NULL, content JSONB, constraints JSONB DEFAULT '[]', assumptions JSONB DEFAULT '[]', force_apportionment JSONB DEFAULT '[]', changelog TEXT, created_by TEXT NOT NULL, created_at TIMESTAMPTZ, UNIQUE(instance_id, version))
  - strategic_force_allocations (id TEXT PK, instance_id TEXT NOT NULL REF instances, force_id TEXT, force_name TEXT NOT NULL, force_type TEXT NOT NULL, is_registered BOOLEAN DEFAULT false, line_of_effort_id TEXT NOT NULL, priority TEXT NOT NULL, allocation_pct INT DEFAULT 0, notes TEXT, created_at/updated_at TIMESTAMPTZ)
  - Create indexes: idx_sg_instances_problem_set, idx_sg_step_products_instance, idx_sg_directive_versions_instance, idx_sg_force_allocations_instance
- Methods: createInstance, getInstanceByProblemSetId, getInstanceById, updateStepStatus, getStepProduct, upsertStepProduct, getForceAllocations, upsertForceAllocation, deleteForceAllocation, createDirectiveVersion, getDirectiveVersions, getLatestDirectiveVersion
- Use ON CONFLICT upsert for step products (per instance_id + step)
- Generate IDs with crypto.randomUUID(): SG-{uuid}, SGSP-{uuid}, SGDV-{uuid}

**service.ts** — Create `StrategicGuidanceService` class:
- Constructor takes StrategicGuidanceStore
- Methods:
  - createInstance(problemSetId, createdBy): Creates instance with all step statuses = 'not_started'
  - getInstance(problemSetId): Returns instance or null
  - saveStepContent(instanceId, stepId, content, updatedBy): Upserts step product, auto-updates status to 'in_progress' if currently 'not_started'
  - getStepContent(instanceId, stepId): Returns step product content
  - updateStepStatus(instanceId, stepId, status): Direct status update
  - saveForceAllocation(instanceId, allocation): Upsert force allocation
  - deleteForceAllocation(instanceId, allocationId): Remove force allocation
  - getForceAllocations(instanceId): List all allocations
  - getForceAllocationSummary(instanceId): Aggregate stats — total forces, committed vs available, over-allocation warnings, main effort count

**routes.ts** — Create Express router at `/api/strategic-guidance`:
- POST `/instances` — create instance (body: { problemSetId, createdBy })
- GET `/instances/:problemSetId` — get instance by problem set ID (returns null-safe)
- GET `/instances/:instanceId/steps/:stepId` — get step content
- PUT `/instances/:instanceId/steps/:stepId` — save step content (body: { content, updatedBy })
- PUT `/instances/:instanceId/steps/:stepId/status` — update step status (body: { status })
- GET `/instances/:instanceId/forces` — get force allocations
- GET `/instances/:instanceId/forces/summary` — get force allocation summary
- POST `/instances/:instanceId/forces` — create/update force allocation
- DELETE `/instances/:instanceId/forces/:allocationId` — delete force allocation
- GET `/instances/:instanceId/directives` — get directive versions
- POST `/instances/:instanceId/directives/finalize` — finalize directive (placeholder for Plan 04 service extension)

Use try/catch with res.status(500).json({ error }) pattern. Instantiate store and service as singletons using getPool(). Export router as `strategicGuidanceRouter`.

Do NOT wire the router into server.ts yet — that will be done in a later plan after all routes are verified.

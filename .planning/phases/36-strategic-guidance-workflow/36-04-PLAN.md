**service.ts** — Add finalizeDirective method to StrategicGuidanceService:
```
async finalizeDirective(instanceId: string, finalizedBy: string): Promise<DirectiveVersion>
```
Implementation:
1. Load current step content for 'commander_directive' and 'operational_approach'
2. Extract constraints, assumptions, force apportionment from operational_approach content
3. Create directive version via store.createDirectiveVersion with:
   - version = current_directive_version + 1
   - content = commander_directive step content (with status set to 'finalized', finalizedAt = now, finalizedBy)
   - constraints, assumptions, forceApportionment from operational_approach
   - changelog = auto-generated summary or empty string for v1
4. Update instance: increment current_directive_version, update step status for 'commander_directive' to 'approved'
5. Auto-populate child campaigns:
   - Query for child problem sets (problem sets whose parent_problem_set_id matches the current problem set's ID, with echelon = 'operational')
   - For each child: attempt to load or create their JPP instance, then update JPP Step 1 (planning_initiation) step product with directive data: commander's intent, objectives, constraints, force apportionment
   - Use try/catch per child — failures don't block other children
   - Log: `[StrategicGuidance] Auto-populated JPP Step 1 for child ${childId}`

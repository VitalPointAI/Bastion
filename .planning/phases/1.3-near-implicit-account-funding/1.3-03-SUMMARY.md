## Decisions Made

**1. Warning threshold levels:**
- Critical (<3 accounts): Red banner with pulse animation, prevents silent registration failures
- Warning (<10 accounts): Yellow banner, gives advance notice for top-up
- Normal (≥10): No banner, sufficient runway for operations

**2. Account check tool validation:**
- 64-character hexadecimal format enforced via regex
- Case-insensitive matching (converts to lowercase)
- Clear error messages for invalid formats

**3. Not-configured state:**
- Friendly message with exact environment variable names needed
- Links to deployment documentation
- No error state - graceful degradation when funding disabled

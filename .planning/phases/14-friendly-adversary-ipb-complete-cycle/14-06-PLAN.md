1. **State:** `selectedScenario` (ExerciseScenario | null), `perspective` ('blue' | 'red'), `currentPhase` (string), `activeTab` ('upload' | 'ipb' | 'coas' | 'orders' | 'tasks' | 'timeline' | 'gates'), `scenarios` (ExerciseScenario[])

2. **Header bar:**

   - "New Scenario" button that opens a creation modal/form (name input, designation='training/exercise')
   - **Perspective toggle** — Two-button toggle: "Blue (CJTF WestPAC)" / "Red (PRC/TCC)". Styled with blue/red accent colors. Per CONTEXT.md: this is the primary view mode.
   - **Exercise controller toggle** — Small button/checkbox "Controller View" that when active shows both perspectives (available only for exercise_control role users)
   - **Phase indicator** — Shows current exercise phase with left/right arrows to browse past phases. Display the phase name prominently (e.g., "Competition", "Crisis", "Conflict Day 4").

3. **Tab navigation:**
   - Scenario Package (upload tab — shown when no scenario is loaded or explicitly selected)
   - IPB (Intelligence Preparation)
   - COAs (Course of Action)
   - Orders (WARNORD/OPORD/FRAGO)
   - Planning Board (tasks)
   - Timeline (exercise phase timeline)
   - Gates (exercise controller only — gate management)

4. **Content area:** Renders the component for the active tab. For this plan, only `upload` tab renders ScenarioPackageUpload; other tabs render placeholder `<div>` with "Coming in Plan 14-07/08/09" text.

5. **On mount:** Fetch scenarios via `exerciseService.getScenarios()`. If scenarios exist, select the first one. If none, show the upload tab.

**ScenarioPackageUpload.tsx** — Multi-file upload component:

1. **Drag-and-drop zone** — Large area styled with dashed border. Accepts `<input type="file" multiple webkitdirectory>` (allows folder selection in Chrome/Edge) plus a standard multi-file input as fallback.

2. **Pre-upload preview** — When files are selected:
   - Display a table showing each file with inferred tags: Filename | Team (blue/red/controller) | Phase | Type | Confidence
   - Color-code team column (blue text for blue, red for red, gray for controller)
   - Allow user to manually override any inferred tag via dropdown selectors in each cell
   - Show file count and total size

3. **Upload + Extract button** — Prominent button that:
   - Calls `exerciseService.uploadPackage(scenarioId, files)`
   - Shows progress bar during upload
   - After upload: shows extraction progress (N/M documents extracted)
   - On completion: refresh document list and show success message

4. **After upload:** Show list of uploaded documents with their extraction status (pending | extracted | failed) and a button to view extracted data.

**IPBPanel.tsx:**

Props: `{ scenarioId: string, perspective: 'blue' | 'red', exercisePhase: string }`

1. **State:**
   - `assessment: IPBAssessment | null` — the current IPB assessment
   - `redMode: 'assessment' | 'self'` — for Red perspective: "Red as Blue sees them" vs "Red as Red sees themselves"
   - `layerVisibility: Record<string, boolean>` — which overlay layers are visible
   - `loading: boolean`, `assembling: boolean`

2. **On mount and when perspective/phase changes:**
   - Fetch IPB assessment: `exerciseService.getIPBAssessments(scenarioId, { team: perspective, perspective: effectivePerspective, phase: exercisePhase })`
   - `effectivePerspective`:
     - If `perspective === 'blue'`: always 'own' (Blue's own view, including their assessment of Red)
     - If `perspective === 'red'` and `redMode === 'assessment'`: use team='blue', perspective='enemy_assessment' (Blue's view of Red)
     - If `perspective === 'red'` and `redMode === 'self'`: use team='red', perspective='own' (Red's own view)
   - Initialize layerVisibility with all layers visible

3. **Header:**
   - When perspective is 'red': Show toggle between "Red as Blue sees them" and "Red as Red sees themselves" — two buttons styled differently. Per CONTEXT.md, both modes must be available.
   - "Assemble IPB" button — triggers `exerciseService.assembleIPB()` to generate/regenerate the IPB from current documents. Shows spinner while assembling.
   - "Update from SITREP" button — dropdown of available SITREPs for the current phase, selecting one triggers `exerciseService.updateIPBFromSITREP()`

4. **Layout:** Two-column on large screens:
   - Left (70%): ValidityMap with IPB layers
   - Right (30%): IPBLayerControls + assessment details (text summary of terrain analysis, threat assessment, civil considerations)

5. **Pass to ValidityMap:**
   - `ipbLayers={assessment?.overlayLayers}` — the IPBLayer array from the assessment
   - `layerVisibility={layerVisibility}` — controls which layers render
   - `perspective={perspective}` — for color theming
   - Center the map on the theater coordinates (Western Pacific: lat=20, lng=125, zoom=4)

6. **Assessment details panel:** Below the layer controls, show:
   - Terrain Analysis (OAKOC summary, collapsible sections)
   - Threat Assessment (force composition, likely COAs)
   - Civil Considerations (ASCOPE)
   - Named Areas of Interest (list with click-to-zoom on map)

**New props (add to ValidityMapProps):**

**IPBLayer rendering logic (add inside the MapContainer, after existing LayersControl):**

For each IPB layer in `ipbLayers` where `layerVisibility[layer.id]` is true:

1. **type='unit' (force disposition):**
   - Render as `<Marker>` at the layer's geometry coordinates
   - If `layer.sidc` is provided: Create icon using milsymbol — import from existing `MilSymbolMarker.tsx` or create a milsymbol `L.divIcon`:
     ```typescript
     import ms from 'milsymbol';
     const symbol = new ms.Symbol(layer.sidc, { size: 30 });
     const icon = L.divIcon({
       className: 'milsymbol-marker',
       html: symbol.asSVG(),
       iconSize: [symbol.getSize().width, symbol.getSize().height],
       iconAnchor: [symbol.getAnchor().x, symbol.getAnchor().y],
     });
     ```
   - If no SIDC: Use colored circle marker (blue for friendly, red for hostile) with unit name as popup
   - Popup shows: unit name, echelon, strength, equipment list

2. **type='area' (key terrain, engagement areas, AOs):**
   - Render as `<Polygon>` using the GeoJSON coordinates
   - Fill color based on `layer.layerType` using IPB_LAYER_COLORS map
   - Fill opacity: 0.2 (semi-transparent overlay)
   - Stroke: 2px solid with same color but higher opacity (0.7)
   - Popup shows: layer name and properties

3. **type='line' (avenues of approach):**
   - Render as `<Polyline>` using GeoJSON coordinates
   - Color based on IPB_LAYER_COLORS for avenue_of_approach (#ffa500)
   - Weight: 3px, dashArray for dashed lines
   - Popup shows: avenue name, direction, classification

4. **type='point' (NAIs):**
   - Render as `<Circle>` at the point coordinates with radius proportional to the NAI area of interest
   - Color from IPB_LAYER_COLORS for nai (#ffcc00)
   - Fill opacity: 0.15
   - Popup shows: NAI name, purpose, triggers

**Use LayersControl.Overlay** for each IPB layer group:
```tsx
<LayersControl.Overlay checked={layerVisibility?.['forces_blue']} name="Blue Force Dispositions">
  <LayerGroup>
    {/* Blue force unit markers */}
  </LayerGroup>

```

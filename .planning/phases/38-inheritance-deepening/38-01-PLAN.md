   - `resolution: 'approved' | 'denied' | null` (for modification_request outcomes)

2. **New InterpretationAcknowledgment interface:**
   ```
   id: string                     // "IACK-INTERP-{uuid}"
   annotationId: string           // FK to inheritance_annotations
   parentProblemSetId: string     // PS where parent reviews
   action: 'acknowledge' | 'clarify' | 'correct'
   comment: string | null
   rfiId: string | null           // linked RFI for 'clarify' action
   actedBy: string                // DID
   actedAt: Date
   ```

3. **New FRAGODraft interface:**
   ```
   id: string                     // "FRAGO-{uuid}"
   parentProblemSetId: string
   childProblemSetId: string
   sourceOpordVersion: string
   previousOpordVersion: string
   changedParagraphs: number[]    // e.g. [2, 3]
   aiDraftContent: string
   status: 'draft' | 'approved' | 'distributed' | 'acknowledged'
   approvedBy: string | null
   editedContent: string | null   // if commander edits before approval
   distributedAt: Date | null
   acknowledgedBy: string | null
   acknowledgedAt: Date | null
   createdAt: Date
   ```

4. **New MissionStatusSnapshot interface:**
   ```
   id: string                     // "MSTAT-{uuid}"
   childProblemSetId: string
   childProblemSetName: string
   parentProblemSetId: string
   missionState: 'planning' | 'active' | 'complete' | 'archived'
   mdmpPhase: string
   percentComplete: number
   keyEvents: Array<{ timestamp: string; description: string; severity: 'info' | 'warning' | 'critical' }>
   resourceStatus: { personnel: { assigned: number; available: number }; equipment: { operational: number; total: number }; supplies: Record<string, string> }
   objectiveProgress: Array<{ objectiveId: string; objectiveName: string; status: 'not_started' | 'in_progress' | 'achieved' | 'failed'; percentComplete: number }>
   lastUpdated: Date
   ```

5. **New OpordChangeDetail interface:**
   ```
   paragraph: number              // 1-5
   severity: 'significant' | 'minor'
   summary: string
   ```

6. **New StatusUpdateMessage interface** (for WebSocket payloads):
   ```
   type: 'mission_status' | 'status_batch' | 'drill_down_request' | 'drill_down_response'
   payload: MissionStatusSnapshot | MissionStatusSnapshot[] | { childProblemSetId: string } | object
   timestamp: string
   ```

Use const objects (not enums) per project convention for any new enum-like values (FRAGO_STATUS, INTERPRETATION_ACK_ACTIONS, RFI_SUBTYPES).

  <name>Task 2: Extend inheritance store with new tables and CRUD methods</name>
  <files>backend/src/inheritance/inheritance-store.ts</files>
  <action>
Extend the existing InheritanceStore class with new DB tables and methods:

**1. Schema changes in ensureInheritanceTables():**

Add `ALTER TABLE` for existing tables:
- `inheritance_rfis`: ADD COLUMN IF NOT EXISTS `rfi_subtype TEXT NOT NULL DEFAULT 'clarification'`, ADD COLUMN IF NOT EXISTS `resolution TEXT`
- `inheritance_annotations`: No schema change needed (existing fields sufficient)

Add new tables:
- `interpretation_acknowledgments` (id TEXT PK, annotation_id TEXT NOT NULL REFERENCES inheritance_annotations(id) ON DELETE CASCADE, parent_problem_set_id TEXT NOT NULL, action TEXT NOT NULL, comment TEXT, rfi_id TEXT, acted_by TEXT NOT NULL, acted_at TIMESTAMPTZ NOT NULL DEFAULT NOW())
- `frago_drafts` (id TEXT PK, parent_problem_set_id TEXT NOT NULL, child_problem_set_id TEXT NOT NULL, source_opord_version TEXT NOT NULL, previous_opord_version TEXT NOT NULL, changed_paragraphs INTEGER[] NOT NULL, ai_draft_content TEXT NOT NULL, edited_content TEXT, status TEXT NOT NULL DEFAULT 'draft', approved_by TEXT, distributed_at TIMESTAMPTZ, acknowledged_by TEXT, acknowledged_at TIMESTAMPTZ, created_at TIMESTAMPTZ NOT NULL DEFAULT NOW())
- `mission_status_snapshots` (id TEXT PK, child_problem_set_id TEXT NOT NULL, child_problem_set_name TEXT NOT NULL, parent_problem_set_id TEXT NOT NULL, mission_state TEXT NOT NULL, mdmp_phase TEXT, percent_complete INTEGER DEFAULT 0, key_events JSONB DEFAULT '[]', resource_status JSONB DEFAULT '{}', objective_progress JSONB DEFAULT '[]', last_updated TIMESTAMPTZ NOT NULL DEFAULT NOW())

Use CREATE TABLE IF NOT EXISTS and ON CONFLICT for idempotency per project convention.

**2. New store methods:**

RFI subtype methods:
- `createRFIWithSubtype(data)` — creates RFI with rfi_subtype field
- `getRFIsBySubtype(problemSetId, subtype)` — filter RFIs by subtype
- `resolveModificationRequest(rfiId, resolution: 'approved' | 'denied')` — update resolution column

Interpretation acknowledgment methods:
- `createInterpretationAck(data: InterpretationAcknowledgment)` — INSERT into interpretation_acknowledgments
- `getInterpretationAcksForParent(parentProblemSetId)` — get all acks for a parent PS with annotation join
- `getInterpretationAckForAnnotation(annotationId)` — get ack status for specific annotation

FRAGO methods:
- `createFRAGODraft(data: Omit<FRAGODraft, 'createdAt'>)` — INSERT
- `getFRAGODraft(id)` — SELECT by ID
- `getFRAGODraftsForParent(parentProblemSetId)` — list all drafts for parent
- `getFRAGODraftsForChild(childProblemSetId)` — list all drafts for child
- `updateFRAGOStatus(id, status, updates)` — update status + approved_by/distributed_at/acknowledged_by/acknowledged_at
- `updateFRAGOContent(id, editedContent)` — commander edits before approval

Mission status methods:
- `upsertMissionStatus(data: MissionStatusSnapshot)` — INSERT ON CONFLICT (child_problem_set_id) DO UPDATE
- `getMissionStatusForParent(parentProblemSetId)` — get all child statuses for a parent
- `getMissionStatusForChild(childProblemSetId)` — get single child status

Read-only enforcement helper:
- `isInheritedContent(problemSetId, itemId)` — returns true if itemId belongs to an ancestor's content (checks subscription_type = 'inheritance' chain)

All methods follow existing store patterns: use `pool.query()`, snake_case in SQL, camelCase in TS, map rows with helper functions.

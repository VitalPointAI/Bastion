**File 1: frontend/src/services/inheritance-service.ts — Frontend API + WebSocket client**

Create a service class for all Phase 38 API interactions:

API methods (use credentials: 'include' per project convention, X-DID header):
- `getNotificationCounts(psId)` — GET /:id/notification-counts
- `getFRAGODrafts(psId)` — GET /:id/fragos
- `getReceivedFRAGOs(psId)` — GET /:id/fragos/received
- `approveFRAGO(psId, fragoId, editedContent?)` — PUT /:id/fragos/:fragoId/approve
- `distributeFRAGO(psId, fragoId)` — POST /:id/fragos/:fragoId/distribute
- `acknowledgeFRAGO(psId, fragoId)` — POST /:id/fragos/:fragoId/acknowledge
- `getMissionStatus(psId)` — GET /:id/mission-status
- `getMissionDrilldown(psId, childPsId)` — GET /:id/mission-status/:childPsId
- `publishMissionStatus(psId, snapshot)` — POST /:id/mission-status
- `getCampaignAssessment(psId)` — GET /:id/campaign-assessment

WebSocket client:
- `connectStatusStream(parentPsId, onUpdate: (snapshot) => void): () => void` — Connect to /ws/inheritance?parentPsId={id}. Returns cleanup function. On message, parse and call onUpdate. On disconnect, implement DDIL fallback: queue updates in memory, reconnect with exponential backoff (1s, 2s, 4s, max 30s), flush queue on reconnect via 'status_batch' message. Use `window.location.hostname` + port 3001 for WS URL per project convention.
- `connectStatusPublisher(childPsId): { publish: (snapshot) => void; disconnect: () => void }` — Connect as child publisher. If WS unavailable, fall back to REST POST. Queue updates during disconnect, flush on reconnect.

Export singleton: `export const inheritanceApiService = new InheritanceApiService();`

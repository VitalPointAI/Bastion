<task type="auto">
  <name>Task 1: Create FRAGO service with OPORD diff detection and AI drafting</name>
  <files>backend/src/inheritance/frago-service.ts</files>
  <action>
Create a new FRAGOService class in frago-service.ts:

**1. OPORD Paragraph-Level Diff:**
```
detectOpordChanges(previous: OPORDStructure, current: OPORDStructure): OpordChangeDetail[]
```
- Compare each of the 5 paragraphs by deep-comparing their JSON (normalize whitespace, trim strings, sort arrays before comparison to avoid false positives from formatting changes — see Research pitfall #4).
- Paragraph 2 (Mission), 3 (Execution), 4 (Sustainment) changes are always 'significant'.
- Paragraph 1 (Situation) and 5 (Command/Signal) are 'minor' unless explicitly marked significant by caller.
- Return array of OpordChangeDetail for changed paragraphs only.
- Do NOT use external diff libraries — hand-roll per-paragraph comparison since OPORD has a known 5-paragraph structure.

**2. AI FRAGO Drafting:**
```
draftFRAGO(parentPsId: string, childPsId: string, changes: OpordChangeDetail[], previousOpord: Partial<OPORDStructure>, currentOpord: Partial<OPORDStructure>, childMissionStatement: string): Promise<string>
```
- Use existing LLM factory: `createLLMForAgent` with agent ID 'frago-drafter'.
- System prompt: "You are a military staff officer drafting a Fragmentary Order (FRAGO). Given changes between a previous and updated OPORD, draft a FRAGO that: (1) States which paragraphs changed, (2) Summarizes each change concisely, (3) States implications for the subordinate mission, (4) Provides updated guidance or tasks as applicable. Format per FM 5-0 FRAGO standard."
- User prompt: include changed paragraphs with before/after, child mission statement, and task assignment.
- Return the AI-generated FRAGO text.

**3. FRAGO Lifecycle Orchestration:**
```
onOpordUpdated(parentPsId: string, previousOpord: OPORDStructure, currentOpord: OPORDStructure, opordVersion: string, previousVersion: string): Promise<FRAGODraft[]>
```
- Detect changes via detectOpordChanges().
- If no changes, return empty array.
- Get all child mission assignments for parentPsId via mission-creation store.
- For each child: draft FRAGO via AI, create FRAGODraft record via inheritanceStore.createFRAGODraft().
- Log activity for parent PS: "FRAGO drafts generated for {N} child missions".
- Return array of created drafts.

```
approveFRAGO(fragoId: string, approvedBy: string, editedContent?: string): Promise<void>
```
- If editedContent provided, call inheritanceStore.updateFRAGOContent().
- Update status to 'approved' via inheritanceStore.updateFRAGOStatus().

```
distributeFRAGO(fragoId: string): Promise<void>
```
- Get FRAGO draft, verify status is 'approved'.
- Update status to 'distributed', set distributedAt.
- Log activity for child PS: "FRAGO received from {parentPsName}: {summary}".

```
acknowledgeFRAGO(fragoId: string, acknowledgedBy: string): Promise<void>
```
- Verify status is 'distributed'.
- Update status to 'acknowledged', set acknowledgedBy and acknowledgedAt.
- Log activity for parent PS: "FRAGO acknowledged by {childPsName}".

Export singleton: `export const fragoService = new FRAGOService();`

<task type="auto">
  <name>Task 2: Add FRAGO API routes to inheritance router</name>
  <files>backend/src/api/inheritance.ts</files>
  <action>
Add FRAGO-related routes to the existing inheritance API router. These routes handle the commander review and distribution workflow.

**New routes:**

1. `POST /:id/frago/trigger` — Manually trigger FRAGO generation for an OPORD update. Body: `{ previousOpord: OPORDStructure, currentOpord: OPORDStructure, opordVersion: string, previousVersion: string }`. Calls `fragoService.onOpordUpdated()`. Returns array of created FRAGODraft records. This is called by the OPORD save handler (Plan/Order development) when an OPORD is updated. Validate body with zod.

2. `GET /:id/fragos` — List all FRAGO drafts where `:id` is the parent PS. Query params: `?status=draft|approved|distributed|acknowledged`. Calls `inheritanceStore.getFRAGODraftsForParent()`. Returns array of FRAGODraft.

3. `GET /:id/fragos/received` — List all FRAGOs received by child PS `:id`. Calls `inheritanceStore.getFRAGODraftsForChild()`. Returns array of FRAGODraft.

4. `GET /:id/fragos/:fragoId` — Get single FRAGO draft by ID. Returns FRAGODraft or 404.

5. `PUT /:id/fragos/:fragoId/approve` — Body: `{ editedContent?: string }`. Calls `fragoService.approveFRAGO()`. Returns 200.

6. `POST /:id/fragos/:fragoId/distribute` — No body. Calls `fragoService.distributeFRAGO()`. Returns 200.

7. `POST /:id/fragos/:fragoId/acknowledge` — No body. Calls `fragoService.acknowledgeFRAGO()`. Returns 200.

All routes use requireAuth, zod validation for bodies, try/catch error handling. Import fragoService from '../inheritance/frago-service.js'.

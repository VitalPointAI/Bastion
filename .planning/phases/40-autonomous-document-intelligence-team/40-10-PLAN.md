**useDocProcessing.ts** - React hook for SSE processing state:
- `useDocProcessing(problemSetId: string, processingId: string | null)` hook:
  - Connects to SSE endpoint when processingId is provided: `EventSource(/api/doc-intelligence/process/${problemSetId}/stream/${processingId})`
  - Maintains state: `{ specialists: Map<string, SpecialistStatus>, events: ProcessingEvent[], isProcessing: boolean, report: any | null, error: string | null }`
  - `SpecialistStatus`: `{ id, name, status: 'queued'|'running'|'complete'|'error'|'skipped', startedAt?, completedAt?, entitiesFound?, duration? }`
  - Updates specialist statuses on each SSE event
  - Accumulates events for the feed
  - Sets report when 'report:assembled' event arrives
  - Handles 'processing:flagged' by setting a flagged state with reason
  - Cleans up EventSource on unmount
  - Returns `{ specialists, events, isProcessing, report, flagged, error, uploadDocument }`
  - `uploadDocument(file: File)` helper: POSTs to /api/doc-intelligence/process/:problemSetId, gets back processingId, connects SSE

**MissionControl.tsx** - Mission control dashboard aesthetic:
- Props: `{ problemSetId: string, processingState: ReturnType<typeof useDocProcessing> }`
- Dark theme panel (per user: "NASA mission control or Bloomberg terminal energy")
- Grid of specialist agent status cards (one per specialist in the pipeline):
  - Each card shows: specialist icon/avatar, name, status badge (queued=gray, running=blue pulse animation, complete=green, error=red, skipped=dim)
  - When running: animated pulse border, stage text (e.g., "Extracting entities..."), entity count ticking up
  - When complete: duration, entity count, success checkmark
  - When error: error message, red border
- Top bar: document name, processing start time, elapsed timer, overall progress bar
- Layout: cards in a responsive grid (3-4 columns on large screens, 2 on medium, 1 on small)
- Use Tailwind dark theme utilities. Match existing dark panel components.
- When processing:flagged, show prominent amber banner: "Source flagged for review" with approve/reject buttons

**ProcessingFeed.tsx** - Real-time activity log:
- Props: `{ events: ProcessingEvent[] }`
- Scrollable feed (most recent at top) showing each processing event:
  - Timestamp, specialist name with icon, event type, detail text
  - Color-coded by specialist type
  - Auto-scrolls to latest event
- Compact format: `[12:34:05] Fact Extractor: Extracted 12 entities from chunk 3/5`
- Follows existing AI Staff feed pattern for layout consistency

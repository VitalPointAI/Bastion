1. **Pre-Brief Setup Checklist**
   - Run `scripts/seed-demo.sh --reset` to ensure clean data
   - Verify backend, Neo4j, and frontend are running

   - Notes on audience adaptation (military vs. academic emphasis)

2. **Opening (2-3 min) — Problem Statement & Value Proposition**
   - Why current military C2/planning tools fall short
   - BASTION's unique value: blockchain governance + AI augmentation + doctrinal compliance
   - NEAR blockchain for tamper-proof decision audit trails
   - Brief architecture overview (don't dwell — show, don't tell)

3. **Act 1: The Operational Picture (5-7 min)**
   - **Problem Set Hierarchy** — Show theater (INDOPACOM) → component (CJTF-WestPac, 7th Fleet, 5th AF) → tactical missions
   - Talking point: "Mirrors real-world command structure — JP 5-0 compliant"
   - **Training vs. Operational Mode** — Toggle between modes, explain "train as you fight" concept
   - **COP Tab** — Common operating picture with unit positions, status
   - **Command Units** — Real designations (USS Ronald Reagan, 3rd MEF, PLA Eastern Theater Command)

4. **Act 2: Understanding the Environment (5-7 min)**
   - **Understand Tab** — Navigate to show DIME/PMESII analysis
   - **RAFT Graph** — Show actor network visualization (15-25 actors), relationships, tensions
   - Talking point: "AI-augmented entity resolution — same actor, different names, automatically linked"
   - **OSINT Events** — Show event feed, linked to objectives, validity scoring trends
   - **Document Pipeline** — Show ingested strategy docs → extracted objectives → fused analysis
   - Talking point: "From PDF to actionable intelligence in minutes, not days"

5. **Act 3: Designing the Campaign (5-7 min)**
   - **Design Tab** — Operational design workspace (operational approach, centers of gravity, decisive points, lines of effort)
   - **Operational Art** — Show how design elements connect to objectives
   - **AI Agent Products** — Pre-seeded strategic fusion analysis, adversary modeling, escalation assessment
   - Talking point: "AI staff officers that never sleep — 19 specialized agents"
   - **Live Agent Demo (optional)** — If time permits, invoke an agent live for ad-hoc analysis

6. **Act 4: Planning & Directing (5-7 min)**
   - **Plan Tab** — JPP workflow (7 steps: Planning Initiation → Mission Analysis → COA Development → COA Analysis → COA Comparison → COA Approval → Plan/Order Development)
   - **Direct Tab** — Commander's directives, task organization
   - **Inheritance System** — Show FRAGO propagation from theater down to tactical
   - Talking point: "A FRAGO at theater level automatically notifies every subordinate command"
   - **Status Reporting** — Show tactical status rolling up through the hierarchy
   - **Override Tracking** — Show where subordinate commands diverged with justification

7. **Act 5: Governance & Accountability (3-5 min)**
   - **DAO Decision Gates** — Show recorded votes, commander approvals at key decision points
   - Talking point: "Every decision recorded on blockchain — immutable audit trail"
   - **Assess Tab** — AARs from completed exercises, METL task assessments
   - **Assumption Auditing** — AI agent that challenges planning assumptions

8. **Closing (2-3 min) — Key Takeaways**
   - Recap: doctrinal compliance, AI augmentation, blockchain governance, hierarchical inheritance
   - Dual-use: military operations AND academic wargaming/education
   - Cleanup capability: `--reset` flag, no residual data
   - Q&A transition

**For each beat:**
- Suggested talking points (what to SAY)
- UI navigation hint (what to CLICK — reference walkthrough)
- Audience engagement note (where to pause for questions)
- Approximate timing
- Fallback if something doesn't load ("If the graph doesn't render, switch to...")

**Audience adaptation notes:**
- Military audience: emphasize doctrinal compliance, OPSEC, decision authority, chain of command
- Academic audience: emphasize pedagogical value, wargaming scenarios, research applications, AI/ML capabilities

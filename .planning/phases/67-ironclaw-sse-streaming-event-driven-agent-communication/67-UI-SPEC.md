## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, avatar-to-label gaps (`gap-1`), step connector dots |
| sm | 8px | Compact element spacing, button padding vertical (`py-2`) |
| md | 16px | Default element spacing, message bubble horizontal padding (`px-4`) |
| lg | 24px | Section padding, drawer header padding (`px-6`) |
| xl | 32px | Layout gaps between major chat regions |
| 2xl | 48px | Not used in chat panel (reserved for page-level layouts) |
| 3xl | 64px | Not used in chat panel |

Exceptions:
- Tool call card collapsed height: 36px (between sm and md — matches existing `py-2 px-3` card rows)
- SSE connection status dot: 8px diameter (`w-2 h-2`) — inherits from existing connection indicator pattern
- Touch targets for Retry and expand/collapse buttons: minimum 32px height (`py-1.5 px-3` at text-xs)

Source: Measured from existing `IronclawMessage.tsx`, `IronclawActionCard.tsx`, `IronclawStepStream.tsx`.

## Component Inventory

New components required for Phase 67:

### 1. ToolCallCard (inline in chat stream)

Collapsed state (default):
- Container: `bg-slate-800/60 border border-slate-700 rounded-lg px-3 py-2`
- Left: 8px blue pulse dot (running) or green check (complete) or red X (failed)
- Center: `text-xs text-gray-300` — tool name + brief status, e.g., "OSINT Search: querying DPRK naval movements..."
- Right: `text-[10px] text-gray-500` elapsed time + expand chevron button (`text-gray-400 hover:text-gray-200`)
- Height: 36px collapsed

Expanded state (user clicked expand):
- Appended below collapsed row in same card container
- "Input" / "Output" tabs at `text-[10px] uppercase tracking-wide text-gray-500`
- Content: `<pre className="bg-black/30 rounded px-2 py-1.5 text-xs text-gray-300 overflow-x-auto max-h-48">`
- JSON formatted payload from `tool_call.input` or `tool_result.output`

### 2. DelegationNotice (inline in chat stream)

- Container: `bg-slate-700/40 border border-slate-600 rounded-lg px-3 py-2`
- Icon: 16px SVG shield/person icon in `text-blue-400`
- Text: `text-xs text-gray-300` — "Delegating to <strong>J2 Intelligence</strong>..."
- Link: `<button className="text-blue-400 hover:text-blue-300 underline text-xs ml-1">` — "View in Agent Panel"
- Clicking this button: scrolls/navigates to AgentActivityPanel and filters to the delegation's agentId

### 3. ResponseToken (streaming text accumulator, used inside IronclawMessage)

- Not a separate component — modify `IronclawMessage.tsx` to accept a `isStreaming?: boolean` prop
- When `isStreaming === true`: append a blinking cursor `|` after the last word (`animate-pulse text-gray-400`)
- When streaming complete (response event with `done: true`): remove cursor, render final Markdown
- Token chunks accumulate in a `string` state variable, rendered as plain text until `done: true`

### 4. SSEConnectionIndicator (in IronclawDrawer header)

- Replaces existing WebSocket `isConnected` prop display
- Connected: `w-2 h-2 rounded-full bg-blue-400` dot + `text-[10px] text-gray-500 ml-1` "Live"
- Reconnecting: `w-2 h-2 rounded-full bg-amber-400 animate-pulse` dot + "Reconnecting..."
- Disconnected: `w-2 h-2 rounded-full bg-gray-600` dot + "Offline"
- Positioned in drawer header, right side, same row as close button

### 5. InlineError (inline in chat stream)

- Container: `bg-red-950/30 border border-red-800/50 rounded-lg px-3 py-2`
- Icon: 14px red warning SVG (`text-red-400`)
- Text: `text-xs text-red-300` — specific error message from event payload (e.g., "OSINT Search failed: timeout")
- Retry button: `px-2 py-1 text-xs bg-red-900/50 hover:bg-red-800/50 border border-red-700 rounded text-red-200` — "Retry"
- Positioned inline in message flow at the exact position the error occurred

## Interaction States

### Tool Call Card States

| State | Visual |
|-------|--------|
| `running` | Blue pulse dot + italic status text + elapsed timer ticking |
| `complete` | Green check + normal text + final elapsed time (static) |
| `failed` | Red X + red status text + "Failed" label |
| `pending` | Gray hollow circle + muted text "Queued..." |

Expand/collapse transition: `transition-all duration-200 ease-in-out` with `overflow-hidden` on detail pane. No opacity animation — height only.

### Typewriter / Token Streaming

- Text tokens append to accumulator string, re-rendered per event (no virtualization needed at this scale)
- Cursor blinks at 1Hz (`@keyframes cursor-blink` alternating opacity 0/1 at 0.5s intervals)
- When `done: true` arrives: cursor removed, Markdown parser processes complete string, replaces plain text
- No scroll lock during streaming — existing auto-scroll-to-bottom behavior in IronclawDrawer is preserved

### Delegation Notice Interaction

- Default: delegation notice rendered with "View in Agent Panel" link
- On click: dispatch a custom event or call a prop callback `onViewDelegation(agentId: string)` passed down from `IronclawDrawer` → `IronclawContext`
- In App.tsx / IronclawContext: navigate to the admin/agent panel tab and set filter to `agentId`
- No modal, no popover — direct navigation

### SSE Connection Lifecycle (visible states)

| EventSource state | Indicator | User-facing |
|------------------|-----------|-------------|
| `CONNECTING` (0) | Amber pulse dot | "Reconnecting..." |
| `OPEN` (1) | Blue dot | "Live" |
| `CLOSED` (2) | Gray dot | "Offline" |

On `CLOSED`: do not show error toast. Connection indicator in drawer header is sufficient. EventSource auto-reconnects.

### Inline Error Retry

- Retry button triggers a re-send of the original user message that caused the error
- While retrying: button shows `disabled` state + text "Retrying..." with spinner (same 3-dot pulsing pattern as existing loading indicator)
- Success: error card is replaced by the new response events

| Element | Copy |
|---------|------|
| Primary CTA | "Send" (no change from current — existing send button label) |
| SSE connected | "Live" |

| Tool call complete | "{Tool Name}: {result summary from payload}" — e.g., "OSINT Search: found 3 results" |

| Empty state body | "Ask Ironclaw anything. Start with your current mission context or a specific question." |
| Error state (inline) | "{error message from payload}" + "Retry" button |

| Ack received | No visible copy — ack event clears the loading spinner only |

Notes:
- Tool call status text comes from event payload, not hardcoded. The component renders `event.status` verbatim, capped at 80 characters with ellipsis truncation.
- No destructive actions in Phase 67. No confirmation dialogs needed.

## Animation Contract

| Animation | Duration | Easing | Property |
|-----------|----------|--------|----------|
| Tool card expand/collapse | 200ms | ease-in-out | max-height |
| SSE dot pulse (running/reconnecting) | 1000ms | ease-in-out | opacity (animate-pulse) |
| Cursor blink | 500ms | step-end | opacity 0/1 |
| New event slide-in | 150ms | ease-out | translateY(8px) → translateY(0) + opacity 0 → 1 |
| Delegation notice fade-in | 150ms | ease-out | opacity 0 → 1 |

New event slide-in: apply only to newly-appended events (tool_call, delegation, response, error), not to replayed catch-up events on reconnect.

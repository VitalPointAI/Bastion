   Methods:

   - `registerResource(manifest): Promise<RegisteredResource>` — POST /api/resources/registry/register
   - `listGroups(missionId: string): Promise<ResourceGroup[]>` — GET /api/resources/groups
   - `createGroup(data): Promise<ResourceGroup>` — POST /api/resources/groups
   - `addToGroup(groupId, resourceId): Promise<void>` — POST /api/resources/groups/:groupId/members
   - `removeFromGroup(groupId, resourceId): Promise<void>` — DELETE /api/resources/groups/:groupId/members/:resourceId
   - `ingestTelemetry(data: TelemetryFrame): Promise<void>` — POST /api/resources/telemetry

   WebSocket position listener:
   - `subscribeToPositions(callback: (positions: Record<string, TelemetryFrame>) => void): () => void`
   - Listen on existing WebSocket for `resource:position_batch` messages
   - Return unsubscribe function

   Singleton: `export const resourceRegistryService = new ResourceRegistryService();`

2. **Create `frontend/src/components/cop/COPResourceLayer.tsx`:**
   React component for rendering resources on the COP Leaflet map.

   Props: `{ missionId: string; visible: boolean; onResourceSelect: (resource: RegisteredResource) => void }`

   Implementation:
   - Fetch resources from registry on mount: `resourceRegistryService.searchRegistry({ category: undefined })` filtered by missionId
   - Subscribe to WebSocket position updates via `resourceRegistryService.subscribeToPositions()`
   - For each resource with location:
     - If resource has `sidc`: render MIL-STD-2525D symbol via `milsymbol` (new ms.Symbol(sidc, { size: 30 }).toDataURL())
     - Else: use category-based fallback icon (simple colored circle marker with category initial)
     - Create Leaflet Marker with custom icon from milsymbol output
     - On marker click: call onResourceSelect(resource)
     - Tooltip showing resource name and status
   - Status-based marker styling: FMC=green border, PMC=yellow border, NMC=red border
   - Clustering: Use Leaflet.markercluster if react-leaflet-cluster is available, otherwise implement zoom-level-based visibility toggle (hide individual markers at zoom < 10, show cluster counts). Check compatibility at implementation time per research open question. If react-leaflet-cluster is incompatible with react-leaflet v5, use simple zoom-based approach:
     - At zoom >= 12: show all individual markers
     - At zoom < 12: group by proximity (simple grid-based grouping), show count badges as DivIcon markers
   - Update marker positions when WebSocket position batch arrives (animate smoothly if possible)
   - Cleanup: unsubscribe from WebSocket on unmount

   - **Assignment & Grouping**: group name (if assigned), group type, aggregate capabilities of group. Placeholder for group management actions.

   Styling: Follow existing COP panel CSS patterns (COPReviewPanel.css style). Dark theme, compact layout.

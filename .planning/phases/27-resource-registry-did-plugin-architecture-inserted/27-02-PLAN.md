  <action>
Create each plugin as a default export implementing ResourcePlugin interface. Each plugin must define:

**vehicle-plugin.ts (AutonomousVehiclePlugin):**
- category: 'vehicles', defaultIsAutonomous: true
- Zod schema: type (ground/air/maritime/subsurface), maxSpeed, maxRange, payload, fuelType, autonomyLevel
- State machine: FMC -> (DEPLOY->deployed, DEGRADE->PMC, FAIL->NMC), deployed -> (RETURN->FMC, DEGRADE->PMC, DAMAGE->NMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC, CONDEMN->condemned), condemned (final)
- Capabilities: ['ISR', 'transport', 'strike', 'logistics', 'CASEVAC', 'mine_clearing', 'EW']
- defaultSIDCPrefix: 'SFGPEV' (friendly ground equipment vehicle)
- processTelemetry: log position + speed + heading + fuel_level

**sensor-plugin.ts (SensorPlatformPlugin):**
- category: 'sensors', defaultIsAutonomous: true
- Zod schema: sensorType (radar/EO_IR/SIGINT/acoustic/CBRN/weather), range, resolution, frequency, coverageAngle
- State machine: FMC -> (COLLECT->collecting, CALIBRATE->calibrating, DEGRADE->PMC, FAIL->NMC), collecting -> (STOP->FMC, DEGRADE->PMC), calibrating -> (COMPLETE->FMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC)
- Capabilities: ['radar', 'EO_IR', 'SIGINT', 'acoustic', 'CBRN', 'weather', 'early_warning']
- defaultSIDCPrefix: 'SFGPES' (friendly ground equipment sensor)

**weapon-plugin.ts (WeaponSystemPlugin):**
- category: 'weapons', defaultIsAutonomous: false
- Zod schema: weaponType (direct_fire/indirect_fire/missile/air_defense/naval/mine/IED), caliber, range, rateOfFire, ammoType
- State machine: FMC -> (ARM->armed, DEGRADE->PMC, FAIL->NMC), armed -> (SAFE->FMC, FIRE->fired, DEGRADE->PMC), fired -> (RELOAD->armed, DEGRADE->PMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC, CONDEMN->condemned), condemned (final)
- Capabilities: ['direct_fire', 'indirect_fire', 'air_defense', 'anti_armor', 'anti_ship', 'precision_strike']
- defaultSIDCPrefix: 'SFGPEW' (friendly ground equipment weapon)

**comms-plugin.ts (CommsPlugin):**
- category: 'communications', defaultIsAutonomous: false
- Zod schema: commsType (HF/VHF/UHF/SATCOM/datalink/mesh/fiber), frequency, bandwidth, encryption, maxRange
- State machine: FMC -> (TRANSMIT->transmitting, RECEIVE->receiving, DEGRADE->PMC, FAIL->NMC), transmitting -> (STOP->FMC, JAM->jammed), receiving -> (STOP->FMC, JAM->jammed), jammed -> (CLEAR->FMC, RELOCATE->FMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC)
- Capabilities: ['voice', 'data', 'video', 'SATCOM', 'mesh', 'encrypted', 'BLOS']
- defaultSIDCPrefix: 'SFGPEI' (friendly ground equipment installation/comms)

**medical-plugin.ts (MedicalPlugin):**
- category: 'medical', defaultIsAutonomous: false
- Zod schema: medicalType (aid_station/surgical/CASEVAC/blood_bank/pharmacy/decon), capacity, echelonLevel (I/II/III/IV/V), specializations
- State machine: FMC -> (ACTIVATE->active, DEGRADE->PMC, FAIL->NMC), active -> (DEACTIVATE->FMC, CONTAMINATE->contaminated, DEGRADE->PMC), contaminated -> (DECON->FMC, QUARANTINE->quarantined), quarantined -> (CLEAR->FMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC)
- Capabilities: ['triage', 'CASEVAC', 'surgical', 'pharmacy', 'blood_bank', 'decontamination', 'mental_health']
- No defaultSIDCPrefix (medical uses specific SIDC codes)

**other-plugin.ts (OtherPlugin):**
- category: 'other', defaultIsAutonomous: false
- Zod schema: otherType (engineering/supply/power/water/shelter), description (optional string)
- State machine: FMC -> (DEGRADE->PMC, FAIL->NMC), PMC -> (REPAIR->FMC, FAIL->NMC), NMC -> (REPAIR->PMC, CONDEMN->condemned), condemned (final)
- Capabilities: ['engineering', 'power_generation', 'water_purification', 'bridging', 'construction', 'demolition']
- No defaultSIDCPrefix

Each plugin's `validateSpecifications` method: `return this.specificationsSchema.safeParse(specs);`

Each plugin exported as `export default plugin` where plugin satisfies ResourcePlugin.

1. **Create `plugin-loader.ts`:**
   - Import `readdir` from `fs/promises`, `join` from `path`, `fileURLToPath` from `url`
   - Define SKIP_FILES = ['base-plugin', 'plugin-loader', 'plugin-registry']
   - Export `async function loadPlugins(): Promise<Map<string, ResourcePlugin>>`
   - Get plugin directory from `fileURLToPath(new URL('./', import.meta.url))`
   - Read directory, filter for files ending in `-plugin.ts` or `-plugin.js` (compiled)
   - Skip files in SKIP_FILES list
   - For each file: dynamic `import()`, get `default` or `plugin` export
   - Validate plugin has `category` property before registering
   - Return Map<category, plugin>
   - Log each discovered plugin: `console.log('[PluginLoader] Discovered plugin:', plugin.category, plugin.displayName)`

2. **Create `plugin-registry.ts`:**
   - Singleton pattern matching AgentRegistry (getAgentRegistry pattern)
   - `PluginRegistry` class with:
     - `private plugins: Map<string, ResourcePlugin>`
     - `private initialized: boolean = false`
     - `async ensureInitialized(): Promise<void>` — calls loadPlugins() once
     - `getPlugin(category: string): ResourcePlugin | undefined`
     - `getAllPlugins(): ResourcePlugin[]`
     - `getCategories(): string[]`
     - `validateSpecifications(category: string, specs: unknown)` — delegates to plugin
     - `getStateMachine(category: string)` — returns plugin's state machine
     - `getCapabilities(category: string): string[]` — returns plugin's capability list
   - Export `getPluginRegistry(): PluginRegistry` singleton getter
   - Two-phase init: loadPlugins() gets pure definitions, no side effects during load

  <action>
Create `backend/src/resources/resource-registry.ts` as a singleton following the AgentRegistry pattern:

**Class: ResourceRegistry**
- Private fields:
  - `cache: Map<string, RegisteredResource>` — resourceId -> registered resource
  - `didIndex: Map<string, string>` — did -> resourceId for fast DID lookup
  - `capabilityIndex: Map<string, Set<string>>` — capability -> set of resourceIds
  - `initialized: boolean = false`
  - `lastRefresh: number = 0`
  - `REFRESH_INTERVAL = 60_000` (60 second periodic refresh as safety net)

- `async ensureInitialized(): Promise<void>`:
  - If not initialized, call `loadFromDB()` then `migrateExistingResources()`
  - Set initialized = true

- `private async loadFromDB(): Promise<void>`:
  - Query all resources from DB via resourceStore.listResources({})
  - For each resource with a DID: wrap as RegisteredResource, add to cache + indexes
  - For resources without DID: skip (handled by migration)

- `private async migrateExistingResources(): Promise<void>`:
  - Query resources WHERE did IS NULL
  - For each: call createResourceDID(resource.id), get plugin defaults for capabilities
  - Update resource in DB with DID, keys, default capabilities from plugin
  - Add to cache + indexes
  - Log migration count: `[ResourceRegistry] Migrated ${count} existing resources with DIDs`

- `private rebuildIndexes(): void`:
  - Clear didIndex and capabilityIndex
  - Iterate cache, rebuild both indexes

- `private async refreshIfStale(): Promise<void>`:
  - If Date.now() - lastRefresh > REFRESH_INTERVAL: reload from DB, rebuild indexes

- **Registration:**
  - `async registerResource(manifest: ResourceManifest): Promise<RegisteredResource>`:
    - Get plugin from PluginRegistry for manifest.category
    - Validate specifications via plugin.validateSpecifications()
    - Create resource in DB via resourceStore.createResource()
    - Generate DID via createResourceDID()
    - Update resource in DB with DID, keys
    - Determine trustTier: if isAutonomous -> 'autonomous', else 'observer' (default)
    - Add to cache + indexes
    - Return RegisteredResource

- **4 Query Types:**
  1. `getByDID(did: string): RegisteredResource | undefined` — lookup didIndex, then cache
  2. `findByCapability(capability: string): RegisteredResource[]` — lookup capabilityIndex, map to cache entries
  3. `findByTypeAndStatus(category?: string, status?: string): RegisteredResource[]` — filter cache values
  4. `findInArea(bounds: { north; south; east; west }): RegisteredResource[]` — filter cache values by lat/lng within bounds (application-level, per research recommendation)

- **Other methods:**
  - `getResource(id: string): RegisteredResource | undefined` — cache lookup
  - `getAllResources(): RegisteredResource[]` — all cache values
  - `getResourcesByMission(missionId: string): RegisteredResource[]` — filter by missionId
  - `async updateResourceStatus(id: string, status: ResourceStatus): Promise<RegisteredResource | null>` — update DB + cache
  - `async removeResource(id: string): Promise<boolean>` — delete from DB + cache + indexes
  - `invalidateCache(): void` — clear cache, set initialized = false

- **Write-through cache:** Every mutation (register, update, remove) writes to DB first, then updates cache. Per research recommendation for single-instance deployment.

- Singleton: `let registryInstance: ResourceRegistry | null = null; export function getResourceRegistry(): ResourceRegistry`

Create `backend/src/resources/resource-group-store.ts`:

**Class: ResourceGroupStore**
- Private `initialized: boolean = false`
- `async ensureInitialized()` — calls initResourceTable() (which now creates resource_groups table from Plan 01)

- `async createGroup(missionId: string, name: string, groupType: string, description?: string, parentGroupId?: string): Promise<ResourceGroup>`:
  - Generate id: `GRP-${randomUUID()}`
  - INSERT into resource_groups
  - Return ResourceGroup

- `async getGroup(id: string): Promise<ResourceGroup | null>`:
  - SELECT from resource_groups WHERE id = $1

- `async listGroups(missionId: string): Promise<ResourceGroup[]>`:
  - SELECT from resource_groups WHERE mission_id = $1 ORDER BY name

- `async getGroupMembers(groupId: string): Promise<Resource[]>`:
  - Use resourceStore to query: SELECT * FROM resources WHERE group_id = $1
  - Batch query, not N+1

- `async addToGroup(resourceId: string, groupId: string): Promise<void>`:
  - Update resource's group_id in DB
  - Call `updateAggregateCapabilities(groupId)` to refresh the group's aggregate

- `async removeFromGroup(resourceId: string): Promise<void>`:
  - Get resource's current groupId first
  - Set resource's group_id to NULL
  - If had groupId, call `updateAggregateCapabilities(oldGroupId)`

- `async updateAggregateCapabilities(groupId: string): Promise<void>`:
  - Batch query: `SELECT DISTINCT unnest(capabilities) as cap FROM resources WHERE group_id = $1`
  - UPDATE resource_groups SET aggregate_capabilities = $1 WHERE id = $2

- `async getGroupWithAggregateCapabilities(groupId: string): Promise<ResourceGroup & { memberCount: number }>`:
  - JOIN query: group + COUNT of members

- `async deleteGroup(id: string): Promise<boolean>`:
  - First: UPDATE resources SET group_id = NULL WHERE group_id = $1 (unassign members)
  - Then: DELETE from resource_groups

- Row-to-object mapper for ResourceGroup (snake_case -> camelCase)

- Singleton export: `export const resourceGroupStore = new ResourceGroupStore();`

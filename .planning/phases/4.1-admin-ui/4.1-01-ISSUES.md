## Open Issues

### UAT-001: AdminDashboard doesn't pass user DID to admin service

**Discovered:** 2026-01-19
**Phase/Plan:** 4.1-01
**Severity:** Major
**Feature:** Admin access verification
**Description:** The AdminDashboard component calls `adminService.isAdmin()` without first calling `adminService.setUserDID()`. This means the X-DID header is never sent with the API request, causing all admin access checks to fail with 401 Unauthorized.
**Expected:** Admin dashboard should pass the logged-in user's DID to the admin service so the backend can verify admin access against ADMIN_DIDS.
**Actual:** X-DID header is missing from requests. Backend returns 401 Unauthorized regardless of whether the user's DID is in ADMIN_DIDS.
**Repro:**
1. Log in with a user whose DID is in ADMIN_DIDS
2. Click Admin button in navigation
3. Observe 401 error in console: `GET http://localhost:3001/api/admin/config/llm 401 (Unauthorized)`
4. Access denied message shown despite valid admin credentials

**Root Cause:** `AdminDashboard.tsx` uses `adminService.isAdmin()` directly without:
- Receiving the user's DID as a prop
- Calling `adminService.setUserDID(userDID)` before the admin check
- Getting the DID from a user context provider

### UAT-002: Content positioned too far down, login info clutters main content area

**Discovered:** 2026-01-19
**Phase/Plan:** 4.1-01
**Severity:** Minor
**Feature:** App layout and user identity display
**Description:** The admin dashboard (and general content) is positioned too far down the screen. The login/user information is displayed in the main content area rather than in the header navigation bar. This takes up valuable screen real estate and doesn't follow modern app conventions.
**Expected:** User login status should be displayed compactly in the header nav bar (profile pic, name/rank indicator). Main content should start higher on the screen.
**Actual:** Login information is displayed prominently in the main content area, pushing actual content down.
**Repro:**
1. Log in to the application
2. Navigate to any view (home, governance, admin)
3. Observe content positioning and login info placement

**Suggested Fix:**
- Move user identity indicator to header nav bar (compact: profile pic + name/rank)
- Remove login info from main content area after authentication
- Adjust content container CSS to start higher

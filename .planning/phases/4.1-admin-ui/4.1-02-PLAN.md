**Tech stack available (from 4.1-01):**
- react-hook-form + @hookform/resolvers for forms
- @tanstack/react-table for data tables
- react-tabs for navigation
- Zod for validation (via resolvers)
- axios for API calls
- admin-service.ts API client

**Established patterns:**
- FormField component pattern from RESEARCH.md
- TanStack Table pattern from RESEARCH.md
- Admin table CSS from RESEARCH.md
- Uncontrolled forms with register() for performance
- Masked API keys (last 4 chars only)

**Backend API endpoints:**
- GET/PUT `/api/admin/config/llm`
- GET/PUT `/api/admin/config/agents`
- GET/PUT `/api/admin/config/workflow`
- GET/POST/PUT/DELETE `/api/admin/osint-sources`
- GET `/api/admin/config/audit`

<task type="auto">
  <name>Task 1: Fix UAT-001 - Pass user DID to AdminDashboard and admin service</name>
  <files>
    - frontend/src/components/AuthWrapper.tsx
    - frontend/src/components/admin/AdminDashboard.tsx
    - frontend/src/App.tsx
    - frontend/src/App.css
  </files>
  <action>
**Problem:** AdminDashboard calls `adminService.isAdmin()` without setting the user's DID first, so the X-DID header is never sent to the backend.

**Solution:** Create a UserContext to provide user identity across the app, then consume it in AdminDashboard.

1. **Create UserContext** (frontend/src/context/UserContext.tsx):
   - Define UserContextType with `userDID: string | null`, `accountId: string | null`, `isAuthenticated: boolean`
   - Create UserContext with React.createContext
   - Export useUser hook for consuming context
   - Export UserProvider component

2. **Modify AuthWrapper** (frontend/src/components/AuthWrapper.tsx):
   - Import UserProvider from UserContext
   - Wrap children with UserProvider, passing accountState.userDID and accountState.accountId
   - Move the user info display to a separate UserStatusBar component that will go in the header

3. **Create UserStatusBar component** (frontend/src/components/UserStatusBar.tsx):
   - Compact user display for header: profile icon + truncated email/name
   - Show "Logged in" indicator
   - Use useUser hook to get user info
   - Clicking shows a dropdown with full details (account ID, DID status, MPC status)

4. **Modify AdminDashboard** (frontend/src/components/admin/AdminDashboard.tsx):
   - Import useUser hook
   - Get userDID from context
   - Call `adminService.setUserDID(userDID)` in useEffect before checking admin access
   - Handle null userDID case (show loading or "DID not ready" message)

5. **Update App.tsx**:
   - Import UserStatusBar
   - Add UserStatusBar to header nav area (right side)
   - Remove the verbose user info from AuthWrapper's main content area

**Avoid:**
- Don't create a global singleton pattern - use React context for proper lifecycle management
- Don't block the entire app if DID isn't ready - graceful degradation
  </action>

  </verify>
  <done>
- UserContext created and exported
- AuthWrapper uses UserProvider
- AdminDashboard consumes userDID from context and passes to admin service

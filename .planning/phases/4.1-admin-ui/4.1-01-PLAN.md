**Backend APIs available (from 4-07):**
- GET/PUT `/api/admin/config/llm` - LLM provider configuration
- GET/PUT `/api/admin/config/agents` - Agent enable/disable settings
- GET/PUT `/api/admin/config/workflow` - Workflow escalation settings
- GET/POST/PUT/DELETE `/api/admin/osint-sources` - OSINT source CRUD
- GET `/api/admin/config/audit` - Configuration audit log
- POST `/api/admin/cache/invalidate` - Cache invalidation

**Security:**
- Backend checks ADMIN_DIDS env var for admin access
- API keys masked in responses (last 4 chars only)

<task type="auto">
  <name>Task 1: Install admin UI dependencies and create types</name>
  <files>frontend/package.json, frontend/src/types/admin.ts, frontend/src/lib/admin-service.ts</files>
  <action>
1. Install dependencies: `cd frontend && pnpm add react-hook-form @hookform/resolvers @tanstack/react-table react-tabs`

2. Create `frontend/src/types/admin.ts` mirroring backend types:
   - LLMProviderConfig: provider (anthropic|openai|azure-openai|local), models object, apiKey (masked), maxRequestsPerMinute, maxTokensPerDay
   - AgentConfig: enabledAgents record, confidenceThreshold, requireHumanReview boolean
   - WorkflowConfig: escalationTimeouts per risk level, approvalAuthority per risk level, notifications settings
   - OSINTSourceConfig: id, name, type, url, credibilityRating, enabled, categories, regions
   - ConfigAuditEntry: id, category, key, previousValue, newValue, changedBy, changedAt, reason
   - Use const objects with type aliases (not enums) per TypeScript erasableSyntaxOnly requirement

3. Create `frontend/src/lib/admin-service.ts`:
   - API_BASE from VITE_API_URL env var
   - Helper to get DID from AuthWrapper context
   - isAdmin() - GET `/api/admin/config/llm` and check for 403 (simple admin check)
   - getLLMConfig() → LLMProviderConfig
   - updateLLMConfig(config, reason?) → LLMProviderConfig
   - getAgentConfig() → AgentConfig
   - updateAgentConfig(config, reason?) → AgentConfig
   - getWorkflowConfig() → WorkflowConfig
   - updateWorkflowConfig(config, reason?) → WorkflowConfig
   - getOSINTSources() → { count, sources: OSINTSourceConfig[] }
   - addOSINTSource(source) → OSINTSourceConfig
   - updateOSINTSource(id, source) → OSINTSourceConfig
   - deleteOSINTSource(id, reason?) → void
   - getAuditLog(params?) → { entries: ConfigAuditEntry[] }
   - invalidateCache() → void
   - All methods include X-DID header for auth

Avoid: Using localStorage for DID - get it from AuthWrapper's Privy context. Don't fetch full API keys - backend masks them.

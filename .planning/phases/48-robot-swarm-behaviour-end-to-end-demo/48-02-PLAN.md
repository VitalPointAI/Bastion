  confidence: number;

  swarmId: string;
  leaderId: string;
  state: 'forming' | 'ready' | 'moving' | 'holding' | 'dispersing' | 'contact';

  technique: 'traveling' | 'traveling_overwatch' | 'bounding_overwatch' | 'successive_bounds';
  memberCount: number;
  members: SwarmMemberSpec[];
  centerOfMass: LatLng;
  heading: number;         // degrees 0-360
  missionId?: string;
  detectionAttributions?: DetectionAttribution[];
}

**Create `backend/src/robot/swarm-cop-bridge.ts`:**

This service converts a `SwarmTelemetryMsg` (robot-space coordinates) into a `SwarmFormationSpec` (geo coordinates) and emits it on the COP event bus.

1. Import `SwarmTelemetryMsg` from `./robot-types.js`, `SwarmFormationSpec`, `SwarmMemberSpec` from `../cop/layers/layer-types.js`.
2. Import calibration profile: read `calibration-profiles.json` at startup (use `loadDefaultCalibration()` from robot-mission-service if available, or inline the same logic — read `backend/data/calibration-profiles.json`, parse the "default" profile).
3. Implement `roomToGeo(x: number, y: number, calibration): LatLng` — linear interpolation from room meters (0-5) to lat/lng bounds. Same formula as existing `roomToGeo` in robot-mission-service.ts but exported for reuse.
4. Export `bridgeSwarmTelemetryToCOP(msg: SwarmTelemetryMsg, emit: (event: string, data: unknown) => void): SwarmFormationSpec` that:
   - Converts each member's `position.x, position.y` via `roomToGeo()` to LatLng
   - Assigns role: member whose `robot_id === msg.leader_id` gets role `'leader'`, others `'follower'`
   - Builds `SwarmFormationSpec` with all fields from the telemetry message
   - Calls `emit('swarm:cop_update', spec)` on the COP event bus
   - Returns the spec for callers that need it

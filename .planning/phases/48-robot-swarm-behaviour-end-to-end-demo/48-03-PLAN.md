**Create `backend/src/robot/coalition-caveat-service.ts`:**

1. Define `CoalitionProfile` interface matching the JSON schema above.
2. Define `CaveatCheckResult` interface: `{ allowed: boolean; blockedRobots: Array<{ robotId: string; nationalDid: string; nation: string; reason: string }> }`.
3. Export `loadCoalitionProfiles(): Record<string, CoalitionProfile>` — reads and parses `backend/data/coalition-profiles.json`. Cache in module-level variable after first load.
4. Export `checkSwarmCaveat(missionType: string, areaType: 'urban' | 'rural' | 'unknown', swarmMembers: Array<{ robotId: string; nationalDid: string }>, profiles: Record<string, CoalitionProfile>): CaveatCheckResult`:
   - For each swarm member, find their profile by matching `member.nationalDid` against `profile.did`
   - Check restrictions: if any restriction's `mission_type === missionType` (or `'*'`) AND (`area_type` matches or is absent) AND mission is NOT in an `except` list, the robot is blocked
   - Also check: if `missionType` is NOT in `profile.allowed_missions`, the robot is blocked
   - Return `{ allowed: blockedRobots.length === 0, blockedRobots }`
5. Export `suggestAlternativeAsset(blockedRobots, allMembers, profiles, missionType): string | null` — given a blocked robot, suggest a different robot from the swarm whose profile allows the mission. Returns robot ID or null if none available.

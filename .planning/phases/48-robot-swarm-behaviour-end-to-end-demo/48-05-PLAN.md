  <name>Task 1: Create SwarmCOPLayer with formation polygon, member markers, and telemetry panel</name>
  <files>frontend/src/components/cop/SwarmCOPLayer.tsx</files>
  <action>
Create `frontend/src/components/cop/SwarmCOPLayer.tsx` as a new React component that renders swarm formations on the Leaflet map. Follow the imperative Leaflet pattern from `COPRobotLayer.tsx` (not react-leaflet declarative components).

**SwarmCOPLayer (main component):**
- Props: none (subscribes to COP WebSocket internally, same pattern as COPRobotLayer)
- State: `swarms: Map<string, SwarmFormationSpec>` — updated via `cop:swarm_update` WebSocket messages
- Renders a `SwarmFormationPolygon` for each swarm, plus a `SwarmTelemetryPanel` if a swarm is selected

**SwarmFormationPolygon sub-component:**
- Uses `useMap()` hook to get Leaflet map instance
- Creates `L.polygon()` imperatively with member positions as vertices
- **Hull ordering:** Sort member positions by angle from centroid before passing to L.polygon(). For 3 members this prevents self-intersection (bowtie). Use `Math.atan2(pos.lat - center.lat, pos.lng - center.lng)` to compute angle, sort ascending.
- **State colors:** `FORMATION_STATE_COLORS` dict — forming: #3b82f6, ready: #22c55e, moving: #f59e0b, holding: #22c55e, dispersing: #6b7280, contact: #ef4444
- Polygon style: `fillOpacity: 0.15`, `weight: 2`, dashed border when `state === 'forming'` (dashArray: '6 4')
- Tooltip: `${swarmId} -- ${formation} (${state})`
- Click handler: sets selectedSwarmId state to open telemetry panel

**SwarmMemberMarker sub-component:**
- For each member in the swarm, render an `L.circleMarker` at their position
- Leader gets a distinct style: larger radius (10 vs 6), star icon or filled diamond, gold border
- Followers get standard blue circle markers
- **Smooth interpolation:** Store previous positions in a ref. On position update, animate from old to new position over 1 second using ease-out quadratic: `t * (2 - t)`. Use `requestAnimationFrame` loop. Follow the exact `SmoothRobotMarker` pattern from COPRobotLayer.tsx.

**SwarmTelemetryPanel sub-component:**
- Positioned as a fixed panel (bottom-right of map, z-index above map)
- Shows: swarm ID, formation type, movement technique, state (with color badge), member count, mission ID, per-member battery %, leader designation
- Close button to dismiss
- Updates in real-time as swarm telemetry arrives

**WebSocket subscription:**
- Use the same WebSocket subscription pattern as COPRobotLayer (check how it receives robot position updates)
- Listen for messages with `type: 'cop:swarm_update'` and `payload: SwarmFormationSpec`
- On receiving an update, upsert into the swarms Map by swarmId

**Important:**
- Do NOT duplicate the roomToLatLng transform — positions in SwarmFormationSpec are already geo-coordinates (converted by swarm-cop-bridge.ts in Plan 02)
- Use `useRef` for Leaflet layer references and clean up in `useEffect` return
- Formation type label as a small `L.tooltip` anchored to the polygon centroid

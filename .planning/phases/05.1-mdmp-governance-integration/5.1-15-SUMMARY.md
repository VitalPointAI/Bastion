# Phase [5.1] Plan [15]: Decision Brief Generator & Viewer Summary

**One-liner:** Decision brief synthesis for COA Approval with interactive comparison matrix, risk assessment, and commander decision actions enforcing INVARIANT 5 confidence intervals.

## Objective

Create the Decision Brief Generator for MDMP Phase 6 (COA Approval) and the frontend display component for reviewing the brief before commander approval.

**Purpose:** The COA Approval gate is the most critical governance decision in MDMP. The Decision Brief Generator synthesizes all planning products into a structured brief that supports the commander's decision. Per the safety matrix, DECISION_SUPPORT is HYBRID_AI_LED - AI builds the brief, human decides.

## What Was Delivered

### Backend: Decision Brief Generator

**File:** `backend/src/mdmp/decision-brief-generator.ts`

**Interfaces:**
- `DecisionBrief` - Complete brief structure with all sections
- `COAComparisonEntry` - Per-COA scoring with confidence intervals
- `RiskAssessment` - Probability/impact risk classification
- `StaffRecommendation` - AI-generated recommendation with dissent tracking
- `AssumptionSummary` - Assumption status with sensitivity levels
- `RedTeamSummary` - Challenge/response pairs with adequacy assessment
- `GovernanceLinks` - DAO proposals and governance gate linkage

**DecisionBriefGenerator Class:**
- `generateBrief()` - Synthesizes COA comparison, risks, assumptions, red team data
- `updateBrief()` - Updates existing brief with new data (increments version)
- `validateBriefCompleteness()` - Validates all required sections present and INVARIANT 5 compliance

**Default Evaluation Criteria (JP 5-0):**
- Suitability: 30% (mission accomplishment)
- Feasibility: 25% (resource availability)
- Acceptability: 25% (casualties/risk tolerance)
- Distinguishability: 10% (sufficiently different from other COAs)
- Completeness: 10% (addresses all tasks)

**INVARIANT 5 Enforcement:**
- All COA criterion scores include confidence intervals (lower/upper bounds)
- Staff recommendation includes confidence interval
- Overall brief confidence calculated from weighted average
- Validation checks for missing confidence metadata

**Governance Integration:**
- Links to Phase 6 COA Approval gate (MDMP-6-01)
- Tracks Phase 5 comparison proposal ID
- Tracks assumption proposal IDs for full audit trail

### Frontend: Decision Brief Viewer

**File:** `frontend/src/components/governance/DecisionBriefView.tsx`

**Component Features:**

1. **Header Section:**
   - Mission ID, brief version, generation timestamp
   - Overall confidence indicator with color coding

2. **Collapsible Sections:**
   - Situation Summary
   - Commander's Intent (highlighted, always expanded)
   - COA Comparison Matrix (interactive)
   - Risk Assessment (5x5 matrix + risk cards)
   - Assumption Summary (table with sensitivity badges)
   - Red Team Summary (challenge/response cards)
   - Staff Recommendation (highlighted with confidence bar)

3. **COA Comparison Matrix:**
   - Interactive table with sortable criteria columns
   - Color-coded scores (green >80, yellow 60-80, red <60)
   - Confidence indicators on each score (bar + bounds)
   - Recommended COA highlighted with star badge
   - Overall score and rank for each COA
   - Strengths/weaknesses detail panel for recommended COA

4. **Risk Matrix:**
   - 5x5 probability-impact grid with color zones
   - Risk count per cell
   - Detailed risk cards below matrix with:
     - Risk description
     - Probability and impact badges
     - Mitigation strategies
     - Residual risk assessment
     - Assessment confidence

5. **Assumption Summary:**
   - Table format with sensitivity color coding
   - Status badges (Accepted, Pending, etc.)
   - Impact if wrong column for planning contingencies

6. **Red Team Summary:**
   - Expandable challenge/response cards
   - Adequacy badges (adequate=green, partial=yellow, needs_work=red)
   - Challenge highlighted in italics
   - Response with left border accent

7. **Staff Recommendation:**
   - Recommended COA name
   - Confidence percentage with visual bar
   - Confidence interval bounds display
   - Reasoning paragraph
   - Dissenting views section (if any)

8. **Decision Actions:**
   - "Approve COA" button → Opens modal with COA selector
   - "Request Revision" button → Opens modal with feedback textarea
   - "Reject All COAs" button → Opens modal with warning and confirmation

9. **Governance Gate Link:**
   - Displays Phase 6 Approval Gate ID (MDMP-6-01)
   - Links to GovernanceGateDashboard for full gate context

**Styling:** `DecisionBriefView.css` with military command-center aesthetic matching existing governance components.

## Technical Implementation

### Backend

**Singleton Pattern:**
```typescript
export function getDecisionBriefGenerator(): DecisionBriefGenerator
```
Lazy initialization for consistent instance access.

**Stub Methods:**
Current implementation uses placeholder data for:
- COA comparison scoring (would use AI agent)
- Risk assessments (would pull from risk framework)
- Assumption summary (would query assumption registry)
- Red team summary (would query red team challenges)

These stubs provide complete interface contracts for future AI agent integration.

**Confidence Calculation:**
Weighted average across:
- COA criteria confidence: 40%
- Risk assessment confidence: 30%
- Staff recommendation confidence: 30%

**Brief Completeness Validation:**
Checks for:
- Required sections (situation, intent, COAs, criteria, recommendation)
- Minimum 3 COAs (JP 5-0 recommendation)
- INVARIANT 5 compliance (confidence intervals present)
- Low confidence warnings (<0.5 brief, <0.6 recommendation)

### Frontend

**State Management:**
- Local state for collapsed sections
- Dialog state for approve/revise/reject modals
- Sort criterion for matrix column sorting

**Color Coding:**
- Scores: green >80, yellow 60-80, red <60
- Confidence: green >0.8, yellow 0.6-0.8, red <0.6
- Sensitivity: red=Critical, orange=High, yellow=Medium, green=Low
- Risks: red=high risk, yellow=medium, green=low

**Responsive Design:**
- Desktop: full matrix and multi-column risk cards
- Mobile: stacked layout with full-width elements
- Breakpoint at 768px

**Accessibility:**
- Sortable matrix with click handlers
- Keyboard-navigable dialogs
- Color + text for status indicators
- Clear action button labels

## Lessons Learned

1. **Confidence Visualization is Critical:**
   - Bar + bounds + percentage provides three levels of detail
   - Color coding helps commanders quickly assess confidence quality

2. **Interactive Matrix Beats Static Table:**
   - Sortable columns enable commanders to view COAs from different perspectives
   - Drill-down to strengths/weaknesses provides context for scores

3. **Risk Matrix + Cards Balances Overview and Detail:**
   - 5x5 matrix gives visual risk landscape at a glance
   - Detailed cards below allow deeper analysis of specific risks

4. **Decision Actions Need Clear Consequences:**
   - Reject dialog warning about Phase 3 return prevents accidental rejections
   - Revision dialog feedback textarea prompts specific guidance

5. **Governance Integration Enables Full Audit Trail:**
   - Links to gates and proposals connect decision to DAO workflow
   - Creates verifiable record of commander decision process

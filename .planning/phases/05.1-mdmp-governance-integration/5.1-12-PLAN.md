1. **Create `backend/src/mdmp/workflow-service.ts`**:

   ```typescript
   export class MDMPWorkflowService {
     /** Create a new MDMP workflow for a mission */
     async createWorkflow(missionId: string, daoId: string, initiator: string): Promise<WorkflowCreatedResult>

     /** Get current workflow state for a mission */
     async getWorkflowState(missionId: string): Promise<WorkflowStateResult>

     /** Register gates for a phase */
     async registerPhaseGates(missionId: string, phase: MDMPPhase): Promise<GateRegistrationResult>

     /** Satisfy a gate */
     async satisfyGate(missionId: string, phase: string, gateId: string, satisfiedBy: string, proposalId?: number): Promise<void>

     /** Request phase transition (validates gates, creates proposal) */
     async requestPhaseTransition(missionId: string, toPhase: MDMPPhase): Promise<TransitionRequestResult>

     /** Get assumptions for a mission */
     async getAssumptions(missionId: string, statusFilter?: string): Promise<AssumptionRecord[]>

     /** Register an assumption */
     async registerAssumption(missionId: string, assumption: AssumptionInput): Promise<string>

     /** Accept an assumption (creates DAO proposal) */
     async acceptAssumption(missionId: string, assumptionId: string, acceptor: string): Promise<void>

     /** Get activities for a phase */
     async getPhaseActivities(phase: MDMPPhase): Promise<MDMPActivity[]>

     /** Get phase statistics */
     async getPhaseStatistics(phase: MDMPPhase): Promise<PhaseStatistics>
   }
   ```

   Each method should have:
   - Input validation
   - Error handling with descriptive messages
   - Audit logging
   - TODO comments for actual contract interaction (will be wired in integration plan)

   - `POST /api/mdmp/workflows/:missionId/transitions` - Request phase transition
   - `GET /api/mdmp/workflows/:missionId/assumptions` - Get assumptions (with ?status= filter)
   - `POST /api/mdmp/workflows/:missionId/assumptions` - Register assumption
   - `PUT /api/mdmp/workflows/:missionId/assumptions/:id/accept` - Accept assumption
   - `GET /api/mdmp/activities` - Get all activities (with ?phase= and ?category= filters)
   - `GET /api/mdmp/activities/:id` - Get activity by ID
   - `GET /api/mdmp/phases/:phase/statistics` - Get phase statistics

   Follow existing routing patterns in the project. Add request body validation.

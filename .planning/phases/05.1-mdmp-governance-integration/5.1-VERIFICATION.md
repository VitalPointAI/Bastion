## Technical Notes

### Container/Presentational Pattern (5.1-17)

The frontend implementation uses a clean separation of concerns:

**Container Component (MDMPGovernancePanel.tsx):**
- Manages state (workflow, gates, assumptions, phaseProgression)
- Makes API calls via mdmp-service
- Handles user actions (create workflow, accept assumption, satisfy gate)
- Passes data and callbacks to presentational components

**Presentational Components:**
- AssumptionTracker: Renders assumption list with filters, receives data via props
- GovernanceGateDashboard: Renders gate status, receives data via props
- PhaseProgressionBar: Renders phase timeline, receives data via props
- CommanderGuidanceForm: Form for guidance submission, calls onSubmit callback

**API Client (mdmp-service.ts):**
- Typed methods for all 11 backend endpoints
- Error handling with fetchJson wrapper
- Data transformation (backend → frontend format)
- Exported functions for container to import

This pattern enables:
- Easy testing (mock service layer)
- Reusability (presentational components can be used elsewhere)
- Maintainability (API changes isolated to service layer)

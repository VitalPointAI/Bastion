## Decisions Made

**Authority Ordering System**
- Established numeric ordering: AI_AUTONOMOUS (0) -> AI_PRIMARY (1) -> HYBRID_AI_LED (2) -> HYBRID_HUMAN_LED (3) -> HUMAN_ONLY (4)
- Rationale: Enables range validation (min/max authority) with simple numeric comparison

**Replanning Gate Threshold**
- Only critical assumption invalidations trigger automatic replanning gates (INVARIANT 6)
- Medium/low invalidations logged but don't create gates
- Rationale: Avoid gate proliferation while ensuring mission-critical assumptions are addressed

**Safety Validation Timing**
- Phase transition validation checks target phase activities, not current phase
- Rationale: Prevent advancing into phases with known safety violations

**Agent Output Validation Criteria (INVARIANT 5)**
- Primary check: presence of confidence intervals (any of: confidenceIntervals, confidence, validationConfidence)
- Secondary checks: calibration metadata, uncertainty characterization
- Rationale: Balance strictness with flexibility in how agents express uncertainty

**Test Organization**
- Tests organized by invariant with descriptive names
- Each invariant has multiple scenarios (valid/invalid cases)
- Rationale: Traceability from test failures back to specific invariants

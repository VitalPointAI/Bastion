## Decisions Made

**Template Structure:**
- Followed established RAFT tool pattern from Phase 4.3 (name, description, schemas, handler)
- Added MDMP-specific fields: mdmpPhase and mdmpActivity for phase/activity tracking
- Included systemPrompt with comprehensive doctrinal guidance (JP 5-0, ATP 2-01.3 doctrine)
- Provided realistic few-shot examples with complete input/output pairs

**Confidence Scoring:**
- Per-item confidence: extractionConfidence field on individual extracted items (tasks, CCIRs, etc.)
- Overall confidence: extractionCompleteness or analysisConfidence at output level
- Range: 0.0 to 1.0 for consistency with existing codebase patterns

**Doctrinal Guidance:**
- Task Extraction: Specified vs implied vs essential tasks per JP 5-0 mission analysis
- CCIR Generation: PIR (enemy intel), FFIR (friendly status), EEFI (protect from enemy) per ATP 2-01.3
- OPORD Generation: Strict 5-paragraph format (Situation, Mission, Execution, Sustainment, Command/Signal)
- IPB Analysis: OAKOC (terrain), weather effects, ASCOPE (civil considerations), threat assessment, NAIs
- Wargame Extraction: Decision points with triggers/options, HPTs, IRs, branches (pre-planned), sequels (follow-on)

**Schema Design:**
- JSON Schema format for LLM tool integration (not Zod - follows MCP tool pattern)
- Typed TypeScript interfaces for type safety in agent code
- Required vs optional fields based on doctrinal necessity

  <action>
    Create `frontend/src/lib/mdmp-service.ts` following the pattern from `planning-service.ts` (simple exported functions with fetchJson helper).

    The service must provide methods for all MDMP API endpoints defined in `backend/src/routes/mdmp.ts`:

    ```typescript
    // API_BASE = '/api/mdmp'
    // Use the same fetchJson helper pattern as planning-service.ts

    // Workflow Management
    createWorkflow(missionId, daoId, createdBy) => POST /workflows
    getWorkflow(missionId) => GET /workflows/:missionId
      - Transform response: phaseGates from object to GateDisplayData[], assumptions to AssumptionDisplayData[]

    // Gate Management
    registerPhaseGates(missionId, phase) => POST /workflows/:missionId/gates
    satisfyGate(missionId, gateId, satisfiedBy, proposalId?) => PUT /workflows/:missionId/gates/:gateId

    // Phase Transitions
    requestPhaseTransition(missionId, toPhase, requestedBy, proposalId?) => POST /workflows/:missionId/transitions

    // Assumption Management
    getAssumptions(missionId) => GET /workflows/:missionId/assumptions
    registerAssumption(missionId, description, source) => POST /workflows/:missionId/assumptions
    acceptAssumption(missionId, assumptionId, acceptedBy, riskOwner) => PUT /workflows/:missionId/assumptions/:id/accept

    // Activity Registry
    getAllActivities() => GET /activities
    getActivityById(id) => GET /activities/:id
    getPhaseStatistics(phase) => GET /phases/:phase/statistics
    ```

    Import the display data types from the governance components:
    ```typescript
    import type { AssumptionDisplayData } from '../components/governance/AssumptionTracker';
    import type { GateDisplayData } from '../components/governance/GovernanceGateDashboard';

    // NOTE: Do NOT import DecisionBrief — no GET /decision-brief endpoint exists yet.
    // The Decision Brief tab will show a placeholder in MDMPGovernancePanel.
    ```

    - `transformAssumption(raw)` => AssumptionDisplayData
    - `transformGate(gateId, raw)` => GateDisplayData
    - `transformWorkflowToPhaseProgression(workflow)` => PhaseProgressionData[]

    Export a singleton-style object or individual functions (match planning-service.ts pattern of individual exported functions).

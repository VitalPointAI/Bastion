## Decisions Made

**Rule-based analysis for v1:**
- Implemented statistical heuristics for bias detection instead of LLM analysis
- LLM integration deferred to future phases for cost/performance optimization
- Current implementation provides immediate value with deterministic checks

**Freshness thresholds by source type:**
- Tactical: 6 hours (fast-moving battlefield conditions)
- Operational: 24 hours (brigade/division planning horizon)
- Strategic: 168 hours (7 days for national-level intelligence)
- Rationale: Different planning levels require different data currency

**9 bias types covered:**
- Selection bias, confirmation bias, anchoring bias, survivorship bias, cultural bias
- Temporal bias, geographic bias, source bias, availability bias
- Covers cognitive and statistical biases identified in intelligence failure studies

**maxAutonomy: SemiAutonomous:**
- Agent outputs require human review before action
- Bias detection findings influence decisions but don't automatically trigger changes
- Aligns with SAFETY_MATRIX guidance for analysis agents

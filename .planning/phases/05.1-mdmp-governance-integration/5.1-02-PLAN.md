  <action>
Create `near-contracts/src/mdmp/assumptions.rs` with:

1. **SensitivityLevel enum** with `#[near(serializers = [json, borsh])]`, Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord derives:
   - Low (plan survives if wrong)
   - Medium (plan degrades if wrong)
   - High (plan fails if wrong)
   - Critical (mission fails if wrong)

2. **AssumptionStatus enum** with same NEAR derives:
   - Pending (identified, not evaluated)
   - Accepted (explicitly accepted)
   - Rejected (explicitly rejected)
   - Invalidated (evidence shows wrong)
   - Expired (too old, needs revalidation)

3. **AssumptionRecord struct** with `#[near(serializers = [json, borsh])]`, Clone, Debug:
   - id: String
   - description: String
   - sensitivity: SensitivityLevel
   - validation_method: String
   - accepted_by: Option<AccountId>
   - accepted_at: Option<u64>
   - last_validated: Option<u64>
   - status: AssumptionStatus
   - source_phase: String
   - evidence_hash: Option<String>

4. **AssumptionRegistry struct** with `#[near(serializers = [borsh])]`:
   - assumptions: LookupMap<String, AssumptionRecord> (key: "mission_id:assumption_id")
   - mission_assumptions: LookupMap<String, Vec<String>> (mission_id -> Vec<assumption_id>)

5. **AssumptionRegistry::new()** constructor with storage key prefixes.

6. **register_assumption(&mut self, mission_id, assumption)** -> Result<(), String>:
   - INVARIANT 3: Validate description is non-empty
   - INVARIANT 3: Validate validation_method is non-empty
   - Store with composite key "mission_id:assumption_id"
   - Track ID in mission_assumptions list
   - Log ASSUMPTION_REGISTERED event with JSON

7. **accept_assumption(&mut self, mission_id, assumption_id, acceptor: AccountId)** -> Result<(), String>:
   - Validate assumption exists and is in Pending status
   - Set status to Accepted, record acceptor and timestamp
   - Log ASSUMPTION_ACCEPTED event

8. **invalidate_assumption(&mut self, mission_id, assumption_id, evidence_hash: Option<String>)** -> Result<SensitivityLevel, String>:
   - Validate assumption exists
   - Set status to Invalidated, record evidence hash
   - Return the sensitivity level (caller uses this to trigger replanning if Critical - INVARIANT 6)
   - Log ASSUMPTION_INVALIDATED event with triggers_replanning flag

9. **get_assumptions(&self, mission_id, status_filter: Option<AssumptionStatus>)** -> Vec<AssumptionRecord>:
   - Return all assumptions for mission, optionally filtered by status

10. **all_accepted_at_sensitivity(&self, mission_id, min_sensitivity: SensitivityLevel)** -> bool:
    - Check if all assumptions at or above the given sensitivity level are Accepted
    - Used by workflow engine to validate phase transition readiness

11. **Tests**:
    - test_register_validates_required_fields (empty description fails, empty validation_method fails)
    - test_assumption_lifecycle (register -> accept -> invalidate flow)
    - test_critical_invalidation_returns_critical (for INVARIANT 6)
    - test_accept_requires_pending_status (cannot accept already-accepted)
    - test_all_accepted_at_sensitivity (mixed statuses, threshold filtering)
    - test_get_assumptions_with_filter

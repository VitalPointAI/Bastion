# Phase 5.1 Plan 07: Uncertainty Quantifier Agent Summary

**One-liner:** Calibrated confidence intervals for AI outputs with false precision detection and INVARIANT 5 enforcement.

## What Was Built

### Uncertainty Quantifier Agent
Created `backend/src/agents/uncertainty-quantifier.ts` implementing INVARIANT 5 (Uncertainty Transparency): All AI agent outputs that inform governance decisions must include calibrated confidence intervals.

**Key interfaces:**
- **ConfidenceInterval**: Point estimate, 90% confidence bounds, calibration score, derivation method
- **FalsePrecisionFlag**: Detects spurious specificity (high/medium/low severity) with reformulation suggestions
- **UncertaintyAssessmentOutput**: Comprehensive assessment with INVARIANT 5 compliance check (meetsInvariant5 + invariant5Gaps)
- **CalibrationReport**: Brier score, calibration curve, bias assessment (overconfident/well_calibrated/underconfident)

**Core functions:**
- `assessUncertainty()`: Wraps agent outputs with uncertainty metadata per activity category
- `generateCalibrationReport()`: Historical performance analysis with calibration curve and bias detection

**Agent manifest:**
- AgentId: `uncertainty-quantifier`
- Phase: Support
- Capability: UncertaintyQuantification (added to types.ts)
- MaxAutonomy: SemiAutonomous
- Character: Calibrated probability expert trained in Bayesian reasoning, reference class forecasting, meta-uncertainty

### AgentCapability Extension
Added `UncertaintyQuantification` to the MDMP Agent Capabilities section of `AgentCapability` enum in types.ts.

## How It Works

1. **Agent Output Wrapping**: Other agents produce outputs → Uncertainty Quantifier assesses → Wrapped output includes confidence intervals
2. **False Precision Detection**: Scans claims for spurious specificity (e.g., "87.3% chance" without supporting data) → Flags with severity
3. **INVARIANT 5 Enforcement**: Checks output against requirements → Sets meetsInvariant5 boolean → Lists gaps if non-compliant
4. **Calibration Reporting**: Historical predictions + actual outcomes → Brier score computation → Calibration curve (10 bins) → Bias assessment → Recommendations

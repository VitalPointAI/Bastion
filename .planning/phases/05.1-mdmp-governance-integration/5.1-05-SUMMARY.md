# Phase 5.1 Plan 05: Assumption Auditor Agent Summary

**One-liner:** Assumption Auditor agent surfaces hidden/explicit assumptions with sensitivity classification and confidence intervals per INVARIANT 5.

## What Was Built

Created the Assumption Auditor AI agent that identifies planning assumptions from documents, classifies their sensitivity (Low/Medium/High/Critical), and produces INVARIANT 5-compliant outputs with calibrated confidence intervals.

**Key capabilities:**
- Surfaces explicit assumptions stated in planning documents
- Identifies hidden assumptions planners may not realize they're making
- Classifies sensitivity: how much the plan changes if the assumption is wrong
- Suggests validation methods for each assumption
- Tracks dependent activities and MDMP phases
- All outputs include confidence intervals (INVARIANT 5 compliance)

## Output Interfaces

### SurfacedAssumption
- **identificationConfidence** (0-1): Confidence that this IS an assumption
- **sensitivityConfidenceBounds**: Lower/upper bounds for sensitivity classification
- **sourceExcerpt**: Text where assumption was found
- **validationMethod**: Suggested approach to validate assumption

### AssumptionAuditOutput
- **completenessConfidence** (0-1): Confidence in audit coverage
- **coverageGaps**: Known areas not fully analyzed
- **matchedExisting**: Deduplication against existing assumptions

### AssumptionValidationOutput
- **validationConfidence** (0-1): Confidence in validity assessment
- **recommendation**: accept | reject | flag_for_review
- **evidence**: Supporting or contradicting evidence with sources

## INVARIANT 5 Compliance

All output interfaces enforce Uncertainty Transparency:

| Output | Confidence Field | Bounds Field |
|--------|-----------------|--------------|
| SurfacedAssumption | identificationConfidence | sensitivityConfidenceBounds |
| AssumptionAuditOutput | completenessConfidence | coverageGaps (qualitative) |
| AssumptionValidationOutput | validationConfidence | - |

**Design principle:** Never state certainty without bounds. All AI outputs must quantify their uncertainty.

## Knowledge Captured

**For future developers:**

1. **INVARIANT 5 is non-negotiable.** All AI outputs that inform governance decisions MUST include confidence intervals. This is enforced at the type level.

2. **Hidden assumptions are the primary target.** Explicit assumptions are easy to find. The agent's value is surfacing unstated beliefs.

3. **Sensitivity classification is impact-based.** Low = plan survives, Medium = plan degrades, High = plan fails, Critical = mission fails.

4. **Validation methods must be actionable.** "Collect more intelligence" is not sufficient. Specify what intelligence, from which sources, within what timeline.

5. **Agent stubs follow executor pattern.** Do not implement LLM calls directly. Integration goes through agent orchestration layer for consistent monitoring, ABAC enforcement, and audit trails.

**For research documentation:**

This agent demonstrates graduated AI autonomy in military planning:
- AI-led assumption surfacing (SemiAutonomous capability)
- Human-required acceptance (NotAutonomous per safety matrix)
- Uncertainty transparency enforcement (INVARIANT 5)
- Blockchain audit trail for assumption acceptance (via Assumption Registry)

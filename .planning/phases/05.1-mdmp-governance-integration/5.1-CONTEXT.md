# Phase 5.1 Context: MDMP Governance Integration

## Phase Goal

Integrate the Military Decision Making Process (MDMP) governance framework into
Bastion's DAO governance layer. This adds phase progression enforcement, assumption
lifecycle tracking, safety matrix validation, and 6 new AI agents to support the
full MDMP workflow (Phases 0-VIII).

## Depends On

- **Phase 3: DAO Governance** (complete) - Smart contracts for decision authority, voting, coalition membership
- **Phase 4.2: AI Agent Teams** (complete) - Agent framework, DID, MCP tools, LangGraph orchestration
- **Phase 4.3: Strategic Intelligence Fusion & RAFT** (complete) - Fusion agents, entity resolution, RAFT graph
- **Phase 5: Operational Planning Module** (complete) - JP 5-0 workflow, COA agents, ROE enforcement

## Key Existing Components This Phase Extends

### Smart Contracts (near-contracts/src/dao/)
- `types.rs` - AutonomyLevel (3 levels), ProposalKind (8 variants)
- `execution.rs` - ProposalExecutor with veto/approval flows
- `voting.rs` - VotingEngine with ThresholdKind
- `roles.rs` - AgentTier, Role, Permission
- `linkages.rs` - DAOLinkageManager, CoalitionProposal

### Backend (backend/src/)
- `agents/types.ts` - AgentPhase, AgentCapability, AgentManifest, DelegationScope
- `agents/` - 10 existing agents (fusion, entity-resolution, conflict-detection, etc.)

### Frontend (frontend/src/)
- `components/governance/` - DAO dashboard, voting panels
- `components/planning/` - Planning dashboard, COA editor

## Human Control Preservation

These invariants MUST be preserved through all implementation:

| What | How |
|------|-----|
| Strike decisions always human | `ProposalKind::requires_human_in_loop()` |
| Authority decisions never AI | Safety matrix: AUTHORITY_DECISION = HUMAN_ONLY |
| Ethics/legal always human | Safety matrix: ETHICAL_LEGAL = HUMAN_ONLY |
| Risk acceptance always human | Safety matrix: RISK_JUDGMENT = HUMAN_ONLY |
| Phase transitions need DAO vote | `PhaseTransition::requires_human_in_loop()` |
| Assumptions need human acceptance | `AssumptionAcceptance::requires_human_in_loop()` |
| FullyDelegated restricted scope | 4 deterministic categories only |

# Phase 5.1 Plan 06: Orders Validator Agent Summary

JWT-based format validation for OPORD/FRAGO with intent traceability and degraded execution simulation using ATP 5-0.1 compliance checks.

## Overview

Created the Orders Validator AI agent that validates operational orders (OPORD) and fragmentary orders (FRAGO) for:
1. Format compliance with ATP 5-0.1 (5-paragraph structure)
2. Internal consistency between order elements
3. Traceability to commander's intent
4. Degraded execution scenarios (DDIL, loss of comms, loss of leader, reduced force)

The agent operates at SemiAutonomous maxAutonomy level, generating validation reports for human review. All outputs include confidence intervals per INVARIANT 5 (Uncertainty Transparency).

## Validation Approach

### Format Compliance (Rule-Based)
- Checks for 5-paragraph OPORD structure:
  1. SITUATION (critical if missing)
  2. MISSION (critical if missing)
  3. EXECUTION with Commander's Intent (critical if missing)
  4. SUSTAINMENT (major if missing)
  5. COMMAND AND SIGNAL (major if missing)
- FRAGO validation: Checks for base OPORD reference
- Confidence: High (0.9+) for rule-based format checks

### Internal Consistency (Heuristic)
- Timeline conflict detection
- Pattern matching for common inconsistencies
- Confidence: Medium (0.5-0.7) for heuristic consistency checks
- Note: Semantic analysis deferred to LLM integration phase

### Intent Traceability (Text Matching)
- Extracts key phrases from commander's intent
- Searches order text for coverage of intent elements
- Calculates traceability score per element (0-1)
- Identifies gaps where intent is not addressed

### Degraded Execution Scenarios
Four standard scenarios validated:
1. **DDIL communications**: Checks for PACE plan
2. **Loss of key leader**: Checks for succession of command
3. **Reduced force (30% casualties)**: Checks for branch plans
4. **Loss of higher HQ comms**: Checks for decision authority delegation

Each scenario assessed for mitigation presence and recommendations provided.

## Scoring Algorithm

Overall score = weighted average:
- Format compliance: 30%
- Internal consistency: 30%
- Intent traceability: 25%
- Degraded scenario coverage: 15%

**Pass threshold**: Score >= 70 AND no critical format issues

## INVARIANT 5 Compliance

All outputs include:
- `validationConfidence`: 0.75 (medium-high for rule-based validation)
- `confidenceBounds`: { lower: score - 10, upper: score + 10 }
- `detectionConfidence` per consistency issue (0-1 scale)

Confidence calibration:
- High (0.9+): Rule-based checks, format validation
- Medium (0.6-0.9): Pattern matching, consistency checking
- Low (<0.6): Intent alignment, implicit assumptions

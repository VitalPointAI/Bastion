  <action>
Create `backend/src/api/brain-subspaces.ts` as an Express router with these endpoints:

**Subspace endpoints:**
- `GET /subspaces?problemSetId=X` — list subspaces (user's + shared)
- `POST /subspaces` — create subspace (body: { problemSetId, name, subspaceType, nodeIds?, queryDefinition? })
- `PUT /subspaces/:id` — update subspace
- `DELETE /subspaces/:id` — delete subspace

**Lens endpoints:**
- `GET /lenses?problemSetId=X` — list lenses (user's + shared + built-in)
- `POST /lenses` — create lens
- `PUT /lenses/:id` — update lens
- `DELETE /lenses/:id` — delete lens (reject if built-in)
- `POST /lenses/:id/clone` — clone a lens

**N-hop endpoint:**
- `GET /nhop?workspaceId=X&nodeId=Y&hops=N` — returns { nodes, edges } within N hops of nodeId

For the N-hop endpoint, use Neo4j `executeReadQuery` with this Cypher:
```cypher
MATCH path = (start:Actor {id: $nodeId, workspaceId: $workspaceId})-[*1..$hops]-(neighbor)
WITH COLLECT(DISTINCT neighbor) AS neighbors
UNWIND neighbors AS n
RETURN n
LIMIT $nodeLimit
```
Then fetch edges between the result nodes:
```cypher
MATCH (a:Actor {workspaceId: $workspaceId})-[r]-(b:Actor {workspaceId: $workspaceId})
WHERE a.id IN $nodeIds AND b.id IN $nodeIds
RETURN r
```

Set `nodeLimit` to 200 for hops <= 2, 100 for hops > 2. Extract `createdBy` from request auth (use `req.user?.accountId` or `req.headers['x-account-id']` — check existing API files for the auth pattern).

**Wire into API index:** In `backend/src/api/index.ts`, import the new router and mount it: `app.use('/api/brain', brainSubspacesRouter)`. Check how existing routers (like graph.ts) are mounted and follow the same pattern.

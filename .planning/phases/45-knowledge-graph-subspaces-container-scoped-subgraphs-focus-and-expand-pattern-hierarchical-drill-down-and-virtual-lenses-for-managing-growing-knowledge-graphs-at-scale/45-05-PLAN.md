Create `useBrainDrillDown` hook managing 4-level drill-down navigation.

**Hook signature:**
```typescript
function useBrainDrillDown(
  data: BrainGraphData,
  activeSubspaceId: string | null,
  subspaceData: BrainGraphData,
): {
  level: DrillLevel;
  breadcrumbs: BreadcrumbEntry[];
  drillIntoSubspace: (subspaceId: string, label: string) => void;
  drillIntoNode: (nodeId: string) => void;
  drillIntoDocuments: (nodeId: string) => void;
  drillUp: (targetIndex: number) => void;     // jump to breadcrumb at index
  drillData: BrainGraphData;                  // graph data filtered for current level
  focusNodeId: string | null;                 // node being focused at Level 3
  getCameraTarget: () => { position: {x:number,y:number,z:number}; lookAt: {x:number,y:number,z:number}; duration: number } | null;
}
```

**State: `drillStack: BreadcrumbEntry[]`** managed via useState.

**Root breadcrumb (always present):**
```typescript
{ level: 'full', id: 'root', label: 'Full Brain', count: data.nodes.length, icon: '\uD83E\uDDE0' }
```

**Level behaviors:**

- **Level 1 (full):** `drillStack` = [root]. `drillData` = full `data`. No filtering.

- **Level 2 (subspace):** Triggered by `drillIntoSubspace(subspaceId, label)`. Pushes breadcrumb `{ level: 'subspace', id: subspaceId, label, count: subspaceData.nodes.length, icon: '\uD83D\uDCE6' }`. `drillData` = `subspaceData` (already computed by useBrainSubspaces including ghost stubs).

- **Level 3 (node detail):** Triggered by `drillIntoNode(nodeId)`. Pushes breadcrumb `{ level: 'node', id: nodeId, label: node.label, count: 1 + neighborCount, icon: '\uD83D\uDD35' }`. `drillData` = the focus node + its immediate 1-hop neighbors from the current level's data + connecting edges. (Actual N-hop expansion is handled separately by useBrainNHop in Plan 06.)

- **Level 4 (document):** Triggered by `drillIntoDocuments(nodeId)`. Finds all nodes where `type === 'document'` that are connected to the focal node (via edges or via `sourceDocumentIds`). Pushes breadcrumb `{ level: 'document', id: nodeId, label: 'Documents', count: docCount, icon: '\uD83D\uDCC4' }`. `drillData` = focal node + connected document nodes + their edges.

**drillUp(targetIndex):** Truncates `drillStack` to `[0..targetIndex]`. Recomputes `drillData` accordingly.

**Camera target (getCameraTarget):**
- Level 1 → full: `{ position: {x:0,y:0,z:500}, lookAt: {x:0,y:0,z:0}, duration: 800 }`
- Level 2 → subspace: compute centroid of subspace nodes, zoom to distance 200, duration 800
- Level 3 → node: zoom to focus node position, distance 60, duration 1000
- Level 4 → document: zoom to focus node position, distance 40, duration 800
Controller calls `getCameraTarget()` after drill transitions and applies via `fgRef.current.cameraPosition()`.

**Data validation (per RESEARCH.md Pitfall 4):** After `data` updates, validate each `drillStack` entry's `id` exists in current `data.nodes`. If a stale entry is found, pop the stack back to the last valid entry. Update counts on all remaining breadcrumbs.

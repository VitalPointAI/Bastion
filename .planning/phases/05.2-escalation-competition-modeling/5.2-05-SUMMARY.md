## Decisions Made

1. **Vertical ladder layout:** Bottom = peace (level 1), top = highest escalation. Current position highlighted with pulsing border animation per CONTEXT decision for "classic vertical ladder visualization."

2. **Color-coded severity levels:** Levels 1-3 green (peaceful/competitive), 4-6 amber (crisis/confrontation), 7+ red (conflict/war). Visual gradient makes escalation risk immediately apparent.

3. **DIME swim lanes:** Horizontal bands for Diplomatic, Information, Military, Economic domains. Left-to-right flow shows root action → first → second → third order effects per CONTEXT decision for "directed flow diagram with DIME domain swim lanes."

4. **Hybrid SVG + HTML rendering:** SVG for arrows (smooth curves, arrowheads, mechanism labels), HTML divs for nodes (interactive, CSS styling, click handlers). Combines strengths of both approaches.

5. **Frontend type mirrors:** Defined frontend-side types inline to mirror backend agent types (escalation-modeler.ts, effect-cascader.ts) without cross-project imports. Keeps frontend self-contained while maintaining type safety.

6. **Progressive disclosure:** Quick visual scan (ladder overview, swim lane flow) → click for inline details (rungs expand for triggers/actions) → click for popovers (effect nodes show full probability/confidence/duration). Follows CONTEXT decision for "fully interactive" visualization.

# Phase 5.2 Plan 10: Sustainment Modeling & Visualization Summary

**One-liner:** Logistics feasibility analysis with resource burndown calculation, phase-level risk assessment, and dual-view visualization for COA comparison per MDMP-3-07 and MDMP-5-03.

## Decisions Made

### 1. Three-Level Risk System

**Decision:** Use green/amber/red risk levels with critical and warning thresholds.

**Rationale:**
- Aligns with military "traffic light" assessment pattern (FM 5-19, Risk Management)
- Provides clear at-a-glance status for commanders
- Enables threshold-based automation for recommendations

**Implementation:**
- Green: Above warning threshold (sustainable)
- Amber: Between critical and warning (caution, resupply recommended)
- Red: Below critical threshold (unsustainable, mission risk)

### 2. Feasibility Classification

**Decision:** Three-level feasibility: feasible, marginal, infeasible.

**Rationale:**
- Distinguishes between operationally viable COAs and those requiring replanning
- "Marginal" captures COAs that start strong but become strained in later phases
- Enables early filtering of infeasible COAs before detailed wargaming

**Calculation:**
- **Feasible:** No red phases
- **Marginal:** Red phases only in later execution (after 50% mark)
- **Infeasible:** Red phases in early execution (before 50% mark)

### 3. Dual-View Approach

**Decision:** Separate burndown chart and risk flags views with tab toggle.

**Rationale:**
- **Burndown chart** shows consumption trends over time (pattern recognition)
- **Risk flags grid** enables quick phase-by-phase comparison across resources
- Different cognitive tasks require different visualizations
- Avoids visual clutter from combining both approaches

**User workflow:**
- Chart: "Which resources are most critical?" and "When do we hit shortfalls?"
- Grid: "Is Phase 3 sustainable?" and "Which phase is highest risk?"

### 4. Five Core Resource Categories

**Decision:** Focus on ammunition, fuel, food/water, medical, maintenance parts.

**Rationale:**
- Covers core ADP 4-0 sustainment classes (I, III, V, VIII, IX)
- Sufficient for 90% of operational planning scenarios
- Extensible to other categories (Class II equipment, Class VII major end items, etc.)
- Default templates enable rapid prototyping

## Technical Implementation Notes

### Backend Calculation Engine

**Algorithm:**
1. Initialize with starting quantities and phase-wise consumption/resupply arrays
2. Iterate through phases, updating `remaining = remaining - consumed + resupplied`
3. Track exhaustion phase (first phase where remaining ≤ 0)
4. Calculate risk level per phase based on thresholds
5. Aggregate phase risks across resources
6. Determine overall feasibility based on red phase distribution

**Comparison Logic:**
- Rank COAs by feasibility level first (feasible > marginal > infeasible)
- Within same feasibility, rank by critical phase (later is better)
- Calculate variance for each resource across COAs to identify differentiators

**Extensibility:**
- Add new resource categories by extending `ResourceCategory` union type
- Custom thresholds per resource
- Phase-dependent consumption rates (e.g., higher tempo in assault phases)

### Frontend Visualization

**SVG Charting:**
- Dynamic scales based on max remaining quantity across all COAs
- X-axis: Phase index → pixel coordinate
- Y-axis: Remaining quantity → pixel coordinate (inverted for top-down chart)
- Line path generation via SVG `d` attribute (`M x y L x y ...`)

**Multi-COA Comparison:**
- Line style variants: solid (primary COA), dashed (comparison 1), dotted (comparison 2+)
- Same color palette across COAs for matching resources
- Legend grouped by COA with all resources per COA

**Interactive Features:**
- Hover state on data points triggers tooltip display
- Tooltip positioned relative to hovered point with 10px offset
- Background rectangle with shadow for readability

**Performance:**
- SVG rendering is efficient for typical phase counts (3-8 phases)
- For larger datasets (15+ phases), consider canvas-based rendering

## MDMP Integration

### MDMP Step 3: COA Development (MDMP-3-07)

**Use case:** Logistics feasibility analysis during COA development.

**Workflow:**
1. Planner defines COA with execution phases
2. Planner estimates resource consumption per phase (based on force size, tempo, distance)
3. Sustainment model calculates burndown and risk levels
4. Planner reviews recommendations and adjusts COA or resupply plan
5. COA marked as logistically feasible/marginal/infeasible

**Prevents:** Development of COAs that are logistically unsupportable.

### MDMP Step 5: COA Comparison (MDMP-5-03)

**Use case:** Compare resource consumption across multiple COAs.

**Workflow:**
1. Multiple COAs generated with different approaches (main attack axis, tempo, sequencing)
2. Sustainment model runs for all COAs
3. Comparison view shows best/worst sustained COAs
4. Differentiating resources identified (e.g., COA-1 uses more fuel, COA-2 uses more ammunition)
5. Commander considers sustainment alongside other evaluation criteria (risk, flexibility, etc.)

**Enables:** Informed decision-making on logistics burden per COA.

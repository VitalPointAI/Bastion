<decisions>
## Implementation Decisions

### Wargaming Interaction
- Hybrid model: AI runs automated action-reaction-counteraction scenarios first, then commander explores "what-if" adjustments interactively
- Cycle depth is configurable per session (commander sets depth before starting — flexibility for time-constrained vs deliberate planning)
- Interactive mode allows full scenario parameter changes: friendly actions, adversary responses, force ratios, environmental conditions, escalation posture
- Full move log: scrollable timeline of every action-reaction with reasoning — complete audit trail

### Agent Analysis Presentation
- Integrated brief: single unified view combining adversary model + effects + escalation + deception into one assessment (not separate tabs per agent)
- Adversary COAs (MLCOA/MDCOA) presented in narrative intelligence assessment format (written paragraphs, not structured cards)
- Deception indicators shown both ways: inline flags within the adversary narrative for quick reference + dedicated deception analysis section for detailed breakdown
- Confidence display: traffic light indicators (green/amber/red) visible at a glance, click for detailed confidence breakdown with intervals and calibration data (connects to INVARIANT 5)

### Escalation & Effect Visualization
- Escalation ladder: classic vertical ladder visualization — vertical axis from peace to conflict, current position highlighted, thresholds marked
- Effect chains: directed flow diagram showing action → first-order → second-order → third-order effects with DIME domain swim lanes (Diplomatic, Information, Military, Economic as horizontal bands)
- Fully interactive: click escalation rungs to see triggers, click effect nodes to see details and explore chains

### COA Sketch Generation
- Map + timeline: map overlay for spatial aspect, synchronized timeline showing phased execution below the map
- Base map bounded by mission AO lat/long coordinates
- SVG overlay with MIL-STD-2525D symbols for all affiliations (friendly, enemy, combined, partner)
- Filterable by affiliation — toggle layers on/off
- Legend showing symbol meanings
- Click any symbol to see resource descriptions and associated tasks
- Same Leaflet map infrastructure as Phase 4.4 — COA graphics as toggleable overlay layers, base map also toggleable
- Animated phase transitions: play/scrub the timeline to see units move and phases unfold on the map

### Branch & Sequel Planning
- Decision points shown as diamond markers on the execution timeline
- Click diamond: inline expand for quick view of trigger conditions and branch summary
- Side panel available for deeper detail on branch/sequel COA when more information needed
- Progressive disclosure: inline → side panel escalation

### Force Ratio Analysis
- Dual display: visual bar comparison for quick read + detailed numeric table on demand
- Side-by-side bars for friendly vs adversary by category
- Doctrinal thresholds (e.g., 3:1) highlighted

### Sustainment Modeling
- Burndown chart showing resource consumption over time per COA — visual sustainability
- Risk flags per phase (green/amber/red) for at-a-glance sustainment risk assessment
- Both views available: burndown for trending, risk flags for quick scanning

### Claude's Discretion
- Specific graph/diagram libraries for escalation ladder, effect flow, and COA timeline
- Wargaming session persistence and state management approach
- Agent orchestration pattern for integrated brief generation
- SVG overlay implementation details for COA map graphics
- Animation implementation for phased timeline playback
- Exact swim lane layout and spacing for effect flow diagrams

</decisions>

## Decisions Made

**Session storage strategy:**
- Used in-memory Map for session storage during development
- Deferred PostgreSQL persistence to future enhancement
- Enables rapid prototyping and testing of wargaming logic

**Agent integration pattern:**
- WargamingMove includes optional effectCascade and escalationAssessment properties
- Engine methods have TODO comments marking agent integration points
- Stub implementations return valid placeholder data for development
- Ready for agent executor framework integration in subsequent plans

**State machine design:**
- Linear state transitions: configuring → auto_running → interactive → completed
- No backward transitions (simplifies state management)
- autoRunFirst config flag controls auto-run → interactive transition

**What-if replay strategy:**
- WhatIfAdjustment stores original and new values with cycle application point
- applyWhatIf() replays cycles from adjustment point forward
- Full implementation deferred pending agent integration for cycle regeneration

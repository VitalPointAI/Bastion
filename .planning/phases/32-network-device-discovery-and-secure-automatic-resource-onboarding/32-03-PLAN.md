```typescript
export const TransportType = { ble: 'ble', wifi: 'wifi', usb: 'usb', tak: 'tak' } as const;
export type TransportType = (typeof TransportType)[keyof typeof TransportType];

export interface DiscoveryEvent {
  transportType: TransportType;
  rawIdentifier: string;
  signalStrength?: number;
  firstSeen: number;
  lastSeen: number;
  rawData: Record<string, unknown>;
}

export interface ScannerConfig {
  intervalMs: number;
  enabled: boolean;
  interfaceFilter?: string[];
}

export interface TransportScanner {
  readonly transportType: TransportType;
  readonly isAvailable: boolean;
  start(config: ScannerConfig): void;
  stop(): void;
  pause(): void;
  resume(): void;
  on(event: 'discovered', handler: (evt: DiscoveryEvent) => void): void;
  on(event: 'lost', handler: (id: string) => void): void;
  on(event: 'error', handler: (err: Error) => void): void;
}
```

  <action>
**ble-scanner.ts** — BLE scanner using @stoprocent/noble:
- Extends BaseScanner, transportType = 'ble'
- `isAvailable`: try/catch around noble.state check; return false if noble unavailable (DDIL graceful degradation)
- `onStart`: set up noble 'discover' handler that emits DiscoveryEvent with address/id as rawIdentifier, rssi as signalStrength, and advertisement data (localName, serviceUuids, manufacturerData hex) in rawData
- Use setInterval for periodic scan cycles: start scanning for 80% of interval, stop for 20% rest
- `onStop`: clearInterval, noble.stopScanning()
- Handle noble 'stateChange' to detect Bluetooth adapter going away
- See RESEARCH.md BLE Scanner code example for reference
- PITFALL: noble needs cap_net_raw or root — log clear warning if EPERM

**wifi-scanner.ts** — Combined mDNS + SSDP/UPnP scanner:
- Extends BaseScanner, transportType = 'wifi'
- `isAvailable`: always true (if network is up)
- `onStart`: create multicast-dns instance, create SSDPClient
- mDNS: on 'response', iterate answers for PTR/SRV/A records, emit DiscoveryEvent with name/IP as rawIdentifier, protocol='mdns' in rawData
- SSDP: on 'response', emit DiscoveryEvent with rinfo.address as rawIdentifier, headers in rawData, protocol='ssdp'
- setInterval for periodic queries: mDNS query for `_services._dns-sd._udp.local` PTR, SSDP search for 'ssdp:all'
- `onStop`: clearInterval, destroy mDNS instance, stop SSDP client
- PITFALL: mDNS on multiple interfaces — use os.networkInterfaces() to log available interfaces; respect interfaceFilter from config
- See RESEARCH.md WiFi Scanner code example

**usb-scanner.ts** — USB/Serial scanner using serialport:
- Extends BaseScanner, transportType = 'usb'
- `isAvailable`: try calling SerialPort.list(), return true if no error
- `onStart`: use setInterval at configured interval to call SerialPort.list()
- Compare current port list with previous to detect new/removed devices
- Emit DiscoveryEvent with path as rawIdentifier, vendorId/productId/manufacturer/serialNumber in rawData
- Debounce detection (track seen ports, only emit on stable presence for 300ms) — PITFALL: USB hot-plug race conditions
- `onStop`: clearInterval
- Emit 'lost' event when previously seen port disappears

**tak-scanner.ts** — TAK CoT protocol scanner:
- Extends BaseScanner, transportType = 'tak'
- `isAvailable`: true (listener-based, no hardware dependency)
- `onStart`: create TCP server on port 8087 and UDP socket on port 6969 (standard TAK SA ports)
- On incoming data, use @tak-ps/node-cot to parse CoT XML messages
- Extract CoT event UID as rawIdentifier, event type/point/detail in rawData
- Emit DiscoveryEvent with lat/lng from CoT point if available
- `onStop`: close TCP server and UDP socket
- Handle partial TCP reads (buffer until complete XML message)
- If ports are unavailable (EADDRINUSE), log warning and set isAvailable to false

All scanners: wrap native module imports in try/catch for DDIL graceful degradation. If import fails (module not available in environment), log warning and set isAvailable = false.


5. Ensure discovery service graceful shutdown in any existing shutdown/cleanup handler:
   ```typescript
   discoveryService.stop();
   ```

The key pattern: discovery initializes but does NOT start scanning automatically. Scanning is operator-initiated via the REST API (`POST /api/discovery/start`). This follows the user decision for operator control with pause/resume.

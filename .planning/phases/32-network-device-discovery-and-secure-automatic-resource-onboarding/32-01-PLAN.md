  <name>Task 1: Create discovery type system and lifecycle state machine</name>
  <files>backend/src/discovery/types.ts, backend/src/discovery/discovery-lifecycle.ts</files>
  <action>
Create `backend/src/discovery/` directory.

**types.ts** — Define all discovery domain types using const objects (not enums) per project convention:

1. `TransportType` const: 'ble' | 'wifi' | 'usb' | 'tak'
2. `DeviceState` const: 'discovered' | 'fingerprinting' | 'authenticating' | 'gate_check' | 'ironclaw_analysis' | 'pending_dao' | 'onboarding' | 'connected' | 'disconnected' | 'quarantined' | 'rejected' | 'revoked'
3. `AccessListType` const: 'allow' | 'block'
4. `AccessListScope`: 'global' | string (problem_set_id)
5. `MatchType` const: 'mac' | 'vendor_id' | 'product_id' | 'cot_type' | 'fingerprint_hash'
6. `BastionCommand` const: 'move' | 'report' | 'configure' | 'execute'

Interfaces:
- `DiscoveryEvent`: transportType, rawIdentifier, signalStrength?, firstSeen, lastSeen, rawData (Record<string, unknown>)
- `DeviceFingerprint`: manufacturer?, model?, firmwareVersion?, protocolVersions?, capabilities (string[]), hardwareId?, displayName
- `ScannerConfig`: intervalMs, enabled, interfaceFilter? (string[])
- `TransportScanner` interface: readonly transportType, readonly isAvailable, start(config), stop(), pause(), resume(), on('discovered'|'lost'|'error' handlers) — extends EventEmitter pattern
- `DiscoveredDevice`: id, transportType, rawIdentifier, fingerprint (DeviceFingerprint | null), state (DeviceState), deviceDid?, resourceId?, firstSeen, lastSeen, signalStrength?, location? ({lat, lng}), ironclawAnalysis? (Record<string, unknown>), gateId?, quarantineReason?, createdAt, updatedAt
- `DeviceAccessEntry`: id, listType (AccessListType), scope, matchType (MatchType), matchValue, displayName?, addedBy (DID), gateId?, createdAt, expiresAt?
- `DeviceBehavioralBaseline`: id, deviceDid, metricType, baselineMean, baselineStddev, sampleCount, lastUpdated
- `CommandAdapter` interface: readonly supportedCommands (BastionCommand[]), translateCommand(command, params) -> Promise<Buffer | string>, parseResponse(raw) -> Promise<CommandResponse>, sendNative?(command, payload) -> Promise<unknown>
- `CommandResponse`: success, command, data (Record<string, unknown>), timestamp
- `ChallengeResult`: success, devicePublicKey?, sharedSecret? (Uint8Array)
- `OnboardingResult`: success, resourceId?, deviceDid?, error?

**discovery-lifecycle.ts** — XState v5 state machine following comms-plugin.ts pattern:
- Use `setup().createMachine()` pattern
- States: discovered, fingerprinting, authenticating, gateCheck, ironclawAnalysis, pendingDAO, onboarding, connected, disconnected, quarantined, rejected (final), revoked (final)
- Events: FINGERPRINT, FINGERPRINT_COMPLETE, CHALLENGE, AUTH_SUCCESS, AUTH_FAIL, ALLOWLISTED, BLOCKLISTED, UNKNOWN, IRONCLAW_APPROVED, DAO_APPROVED, DAO_REJECTED, ONBOARD, DISCONNECT, RECONNECT, ANOMALY, CLEAR_ANOMALY, REVOKE, EMERGENCY_DISCONNECT
- Export the machine as `discoveryLifecycle`
- See RESEARCH.md Pattern 2 for the exact state transition graph

<task type="auto">
  <name>Task 2: Create discovery PostgreSQL store with table auto-creation</name>
  <files>backend/src/discovery/discovery-store.ts</files>
  <action>
Create `discovery-store.ts` following the resource-store.ts and gate-store.ts patterns:

1. **Table initialization** via `ensureDiscoveryTables()` called on first use:
   - `discovered_devices` table: id (UUID PK), transport_type TEXT NOT NULL, raw_identifier TEXT NOT NULL, fingerprint JSONB, state TEXT NOT NULL DEFAULT 'discovered', device_did TEXT, resource_id TEXT, first_seen TIMESTAMPTZ NOT NULL, last_seen TIMESTAMPTZ NOT NULL, signal_strength INTEGER, location JSONB, ironclaw_analysis JSONB, gate_id TEXT, quarantine_reason TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW(). Indexes on state and transport_type.
   - `device_access_list` table: id (UUID PK), list_type TEXT NOT NULL CHECK IN ('allow','block'), scope TEXT NOT NULL DEFAULT 'global', match_type TEXT NOT NULL CHECK IN ('mac','vendor_id','product_id','cot_type','fingerprint_hash'), match_value TEXT NOT NULL, display_name TEXT, added_by TEXT NOT NULL, gate_id TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), expires_at TIMESTAMPTZ. UNIQUE(list_type, scope, match_type, match_value). Index on (scope, list_type).
   - `device_behavioral_baselines` table: id (UUID PK), device_did TEXT NOT NULL, metric_type TEXT NOT NULL, baseline_mean DOUBLE PRECISION, baseline_stddev DOUBLE PRECISION, sample_count INTEGER DEFAULT 0, last_updated TIMESTAMPTZ DEFAULT NOW(). UNIQUE(device_did, metric_type).

2. **CRUD operations:**
   - `insertDiscoveredDevice(device: Omit<DiscoveredDevice, 'id' | 'createdAt' | 'updatedAt'>): Promise<DiscoveredDevice>`
   - `updateDeviceState(id: string, state: DeviceState, extra?: Partial<DiscoveredDevice>): Promise<DiscoveredDevice | null>`
   - `getDeviceByRawId(transportType: string, rawIdentifier: string): Promise<DiscoveredDevice | null>` — for reconnection detection
   - `listDevicesByState(state: DeviceState): Promise<DiscoveredDevice[]>`
   - `listDevicesByTransport(transportType: string): Promise<DiscoveredDevice[]>`
   - `getAccessList(scope: string, listType: AccessListType): Promise<DeviceAccessEntry[]>`
   - `getEffectiveAccessList(problemSetId: string, listType: AccessListType): Promise<DeviceAccessEntry[]>` — merges global + PS-specific entries. For blocklist: union (PS cannot remove global blocks). For allowlist: union (PS supplements global).
   - `addAccessEntry(entry: Omit<DeviceAccessEntry, 'id' | 'createdAt'>): Promise<DeviceAccessEntry>`
   - `removeAccessEntry(id: string): Promise<boolean>`
   - `checkAccessList(matchType: MatchType, matchValue: string, scope: string): Promise<{allowed: boolean, blocked: boolean, entry?: DeviceAccessEntry}>` — checks effective list for given scope
   - `upsertBaseline(deviceDid: string, metricType: string, mean: number, stddev: number, sampleCount: number): Promise<void>`
   - `getBaselines(deviceDid: string): Promise<DeviceBehavioralBaseline[]>`

3. Use `import { pool } from '../db.js'` for database connection (project pattern).
4. Export as singleton `discoveryStore`.
5. Use gen_random_uuid() for ID generation (project pattern).

5. Cleanup on unmount

**DiscoveryLayer.tsx** — COP map layer for discovered devices:

   - authenticating/gate_check/pending_dao: orange dot (in pipeline)

   - quarantined: red pulsing dot (security concern)

3. Own Emissions tab:

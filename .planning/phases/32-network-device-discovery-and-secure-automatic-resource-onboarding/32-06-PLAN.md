**discovery-ws.ts** — WebSocket handler following resource-ws.ts pattern:

1. `setupDiscoveryWS(wss: WebSocketServer): void` — Register discovery WebSocket handler
2. Subscribe to MessageBus channels: `discovery.device.*`, `discovery.scan.*`
3. On client connect: send current DiscoveryStatus snapshot
4. On discovery events: broadcast to all connected clients as JSON:
   ```
   { type: 'device_discovered' | 'device_state_changed' | 'device_lost' | 'scanner_status', data: {...} }
   ```
5. Client can send `{ action: 'subscribe', filters: { transportType?, state? } }` to filter events
6. Use ws library (already in project dependencies)

**discovery-router.ts** — Express router for discovery REST API:

1. Import `requireAuth` middleware from auth-instance.ts pattern
2. Register static routes BEFORE parametric routes (project pattern from Phase 19)

**Scanner control routes:**
- `GET /api/discovery/status` — Return DiscoveryService.getStatus()
- `POST /api/discovery/start` — Start scanning (body: { scope? })
- `POST /api/discovery/stop` — Stop scanning
- `POST /api/discovery/pause` — Pause scanning
- `POST /api/discovery/resume` — Resume scanning
- `PUT /api/discovery/scanner/:transport/config` — Update scanner config (body: ScannerConfig)

**Device routes:**
- `GET /api/discovery/devices` — List devices (query params: state?, transport?, limit?, offset?)

**Ironclaw callback route:**
- `POST /api/discovery/ironclaw-result` — Receive Ironclaw analysis result (body: { deviceId, approved, analysis })

**behavioral-baseline.ts** — Online anomaly detection using Welford's algorithm:

1. `BehavioralBaseline` class:
   - `async recordMetric(deviceDid: string, metricType: string, value: number): Promise<AnomalyCheck>` — Main entry point:
     - Load existing baseline from discoveryStore.getBaselines() (or start fresh)
     - Update running mean/variance using Welford's online algorithm:
       ```
       count++
       delta = value - mean
       mean += delta / count
       delta2 = value - mean
       M2 += delta * delta2
       variance = M2 / count (population) or M2 / (count-1) (sample)
       stddev = sqrt(variance)
       ```
     - Check if `abs(value - mean) > 3 * stddev` and sampleCount >= 10 (need minimum samples before flagging)
     - Persist updated baseline via discoveryStore.upsertBaseline
     - Return `AnomalyCheck`: { isAnomaly: boolean; deviation: number; threshold: number; metricType; value }

2. `AnomalyCheck` type: { isAnomaly, deviation (number of std devs), threshold (3.0), metricType, value }

3. Predefined metric types (const object):
   - `telemetry_rate` — messages per minute
   - `command_response_time` — ms to respond to Bastion commands
   - `data_volume` — bytes per interval
   - `connection_drops` — disconnection frequency

4. `async checkDeviceHealth(deviceDid: string): Promise<{ healthy: boolean; anomalies: AnomalyCheck[] }>` — Check all baselines for a device, return aggregate health status.

5. Integration point: DiscoveryService calls `recordMetric()` on each telemetry ingestion. If anomaly detected, auto-quarantine the device and publish alert.

**Fix Applied:** backend/src/auth/passkey-service.ts

**Level 1 - Existence:**
| Check | Result |
|-------|--------|
| File exists | ✓ YES (355 lines) |
| Import statement | ✓ YES (line 27: `import { isoBase64URL } from '@simplewebauthn/server/helpers';`) |
| Fix location | ✓ YES (line 223 in generateAuthenticationOptions) |

**Level 2 - Substantive:**
```typescript
// Line 218-226: PRF extension in generateAuthenticationOptions()
extensions: {
  prf: {
    eval: {
      // Must be base64url string - Uint8Array won't survive JSON serialization
      first: isoBase64URL.fromBuffer(new TextEncoder().encode(`bastion-did-v1:${RP_ID}`))
    }
  }
} as Record<string, unknown>
```

**Verification:**
- Line 27: `isoBase64URL` import exists
- Line 223: Uses `isoBase64URL.fromBuffer()` to encode first parameter
- Comment on line 222 explains why Uint8Array won't work

**Level 3 - Wiring:**

### 3. NEAR Implicit Account Generation Fix (MAJOR)

**Root Cause:** `createMPCAccount()` generated named accounts like `bastion-a9ba0024.testnet` instead of NEAR implicit accounts. Per NEAR docs, implicit accounts must be 64-character hex strings derived from public key.

**Fix Applied:** backend/src/auth/mpc-account.ts

**Level 1 - Existence:**
| Check | Result |
|-------|--------|
| File exists | ✓ YES (218 lines) |
| sha256 import | ✓ YES (line 21: `import { sha256 } from '@noble/hashes/sha2.js';`) |
| bytesToHex import | ✓ YES (line 22: `import { bytesToHex } from '@noble/hashes/utils.js';`) |

**Level 2 - Substantive:**
```typescript
// Lines 145-153: createMPCAccount() derives implicit account ID
// Get MPC root public key first (needed for implicit account derivation)
const mpcPublicKey = await getMPCRootPublicKey();

// Derive implicit account ID: SHA256(derivationPath + mpcPublicKey) -> 64-char hex
// This creates a unique, deterministic account ID for each user's MPC path
// Per NEAR docs, implicit accounts are 64-character hex strings
const derivationData = new TextEncoder().encode(`${derivationPath}:${mpcPublicKey}`);
const hash = sha256(derivationData);
const accountId = bytesToHex(hash);
```

**Verification:**
- Line 21-22: Required imports present (@noble/hashes)
- Line 146: Gets MPC public key BEFORE derivation (no redundant call later)
- Line 151: Uses `TextEncoder().encode()` for string to Uint8Array
- Line 152: `sha256()` hashes the derivation data
- Line 153: `bytesToHex()` converts hash to 64-character hex string
- Lines 148-150: Comments explain implicit account requirements

**Previous buggy code (removed):**

**Level 3 - Wiring:**

- accountId returned from createMPCAccount is 64-char hex

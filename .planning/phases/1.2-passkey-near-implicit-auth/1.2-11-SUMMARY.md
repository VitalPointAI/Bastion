## Decisions Made

**PRF encoding decision:**
- Used `isoBase64URL.fromBuffer()` to convert PRF first parameter from Uint8Array to base64url string
- Rationale: JSON serialization doesn't preserve Uint8Array structure, causing browser error on frontend

**Redirect race condition fix:**
- Return null from `getStatusMessage()` when `!isAuthenticated` to prevent overlay from rendering
- Rationale: Status overlay (z-index:9999) was blocking visibility during redirect, causing appearance of infinite loading

**Implicit account implementation:**
- Generate implicit account ID as `bytesToHex(sha256(derivationPath + mpcPublicKey))`
- Rationale: NEAR implicit accounts must be 64-character hex strings per NEAR protocol specification

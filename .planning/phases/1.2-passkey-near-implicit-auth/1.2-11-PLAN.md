BEFORE (broken):

Root cause: Current code at lines 142-147 generates named accounts like `bastion-a9ba0024.testnet`. Per NEAR docs, implicit accounts are 64-character hex strings derived from the public key.

For MPC accounts, the implicit account ID should be the SHA256 hash of the MPC-derived public key (which incorporates the user's derivation path).

Add sha256 import from @noble/hashes:
```typescript
import { sha256 } from '@noble/hashes/sha256';
```

Update `createMPCAccount()` to derive implicit account ID:

```typescript
  ? `${accountIdPrefix}.near`

```

AFTER:
```typescript
// Get MPC root public key first (needed for implicit account derivation)
```

  <name>Task 2: Configure routes in App.tsx for auth pages with proper 404 handling</name>
  <files>
    frontend/src/App.tsx
  </files>
  <action>
    Update frontend/src/App.tsx to use Routes for auth pages while preserving state-based navigation for main app:

    1. Import from react-router-dom:
       ```tsx
       import { Routes, Route, useLocation, useNavigate } from 'react-router-dom'
       ```

    2. Import auth components:
       ```tsx
       import { LoginPage } from './components/LoginPage'
       import { MagicLinkVerify } from './components/MagicLinkVerify'
       ```

    3. Create a NotFound component inline:
       ```tsx
       function NotFound() {
         return (
           <div className="content-container">
             <h2>404 - Page Not Found</h2>
             <p>The page you're looking for doesn't exist.</p>
             <a href="/">Return to Home</a>
           </div>
         )
       }
       ```

    4. Update App component to route auth pages with explicit paths and proper 404:
       ```tsx
       function App() {
         return (
           <Routes>
             {/* Auth routes - outside AuthWrapper */}
             <Route path="/login" element={<LoginPage />} />
             <Route path="/auth/verify" element={<MagicLinkVerify />} />
             <Route path="/auth/recover" element={<LoginPage />} /> {/* Recovery starts at login */}

             {/* Main app routes - protected by AuthWrapper */}
             <Route path="/" element={
               <AuthWrapper>
                 <AppContent />
               </AuthWrapper>
             } />
             <Route path="/governance" element={
               <AuthWrapper>
                 <AppContent initialView="governance" />
               </AuthWrapper>
             } />
             <Route path="/strategic" element={
               <AuthWrapper>
                 <AppContent initialView="strategic" />
               </AuthWrapper>
             } />
             <Route path="/missions" element={
               <AuthWrapper>
                 <AppContent initialView="missions" />
               </AuthWrapper>
             } />
             <Route path="/admin/*" element={
               <AuthWrapper>
                 <AppContent initialView="admin" />
               </AuthWrapper>
             } />

             {/* 404 catch-all - must be last */}
             <Route path="*" element={<NotFound />} />
           </Routes>
         )
       }
       ```

    5. Update AppContent to accept optional initialView prop:
       - Add prop type: `interface AppContentProps { initialView?: string }`
       - Use initialView to set initial state if provided

    Key design decisions:
    - Auth pages (/login, /auth/*) are outside AuthWrapper - user must reach them without being authenticated
    - Main app routes explicitly listed (/, /governance, /strategic, /missions, /admin/*)
    - 404 catch-all route placed LAST so it only matches truly unknown paths
    - NotFound renders for unknown routes like /xyz, /foo/bar
    - State-based navigation preserved inside AppContent for tab switching

    Note: MagicLinkVerify already imports useSearchParams and useNavigate from react-router-dom (line 9), so it will work once the router is in place.
  </action>

    - `grep '"/auth/verify"' frontend/src/App.tsx` shows verify route

    - `grep "NotFound" frontend/src/App.tsx` shows component definition and usage
    - `cd frontend && pnpm build` succeeds
  </verify>
  <done>

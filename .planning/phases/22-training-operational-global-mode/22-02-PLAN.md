1. Create `frontend/src/context/ModeContext.tsx`:
   - Define types: `type AppMode = 'training' | 'operational'`
   - Define interface: `ModeContextType { mode: AppMode; isTraining: boolean; requestModeSwitch: (target: AppMode) => void; confirmModeSwitch: () => Promise<void>; cancelModeSwitch: () => void; pendingMode: AppMode | null; loading: boolean; }`
   - Create context with default operational mode
   - `ModeProvider` component:
     - State: `mode` (AppMode), `pendingMode` (AppMode | null), `loading` (boolean)
     - On mount (when authenticated): GET /api/user-mode to load persisted mode. Default to 'operational' if no response.
     - `requestModeSwitch(target)`: sets `pendingMode = target` (opens modal)
     - `confirmModeSwitch()`: PUT /api/user-mode with pendingMode, update local state, clear pendingMode, navigate to '/' (workspace selector home). This triggers WorkspaceContext to re-fetch with new mode.
     - `cancelModeSwitch()`: clears pendingMode
   - Render: `<ModeContext.Provider>` wrapping `{children}`, plus `<ModeConfirmationModal>` (rendered when pendingMode !== null), plus `<ExerciseBanner>` (rendered when mode === 'training')
   - Export `ModeProvider` and `useMode` hook

2. Create `frontend/src/components/ExerciseBanner.tsx`:
   - Simple component rendering a sticky amber banner at the very top of the viewport
   - Text: "EXERCISE - EXERCISE - EXERCISE" centered, repeated enough to fill width
   - Styles: `position: sticky; top: 0; z-index: 9999; background: #D97706; color: #000; font-weight: 700; text-align: center; padding: 4px 0; letter-spacing: 0.15em; font-size: 0.75rem; text-transform: uppercase;`
   - Use inline styles or a CSS module — follow project convention
   - Add `role="status"` and `aria-live="polite"` for accessibility

3. Create `frontend/src/components/ModeConfirmationModal.tsx`:
   - Props: `targetMode: AppMode; onConfirm: () => Promise<void>; onCancel: () => void;`
   - Overlay + centered modal card
   - If switching to operational: "You are switching to OPERATIONAL mode. All actions will affect live data. Confirm?" (per user decision)
   - If switching to training: "You are switching to TRAINING mode. All actions will use exercise data. Confirm?"
   - Two buttons: "Cancel" (calls onCancel) and "Confirm" (calls onConfirm, shows loading state)
   - Use portal or simple overlay div with z-index above the exercise banner

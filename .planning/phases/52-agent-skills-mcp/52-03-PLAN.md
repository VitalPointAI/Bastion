**tool-bridge.ts** — Update `handleToolCall` method. After the line where `actionPipeline.processAction` returns, add:

```typescript
if (result.status === 'executed') {
  try {
    const execResult = await executeApprovedAction(action.type, action.payload, userDid);
    // Merge execution result into the ActionResult message
    result.message = `Action ${action.type} executed: ${JSON.stringify(execResult.result)}`;
  } catch (err) {
    result.status = 'rejected';
    result.message = `Execution failed: ${err.message}`;
  }
}
```

This closes the loop: actionPipeline decides approval, builder-handlers performs the actual CRUD.

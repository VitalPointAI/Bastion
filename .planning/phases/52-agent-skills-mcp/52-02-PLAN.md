**038-skills.sql** — Create two tables following the agents_v2 JSONB pattern:
```sql
CREATE TABLE IF NOT EXISTS skills (
  skill_id      TEXT        PRIMARY KEY,
  skill_data    JSONB       NOT NULL,    -- Full skill definition (name, description, schemas as JSON Schema, tool_ids, prompts)
  version       TEXT        NOT NULL DEFAULT '1.0.0',
  created_by    TEXT        NOT NULL,
  created_at    TIMESTAMPTZ DEFAULT NOW(),
  updated_at    TIMESTAMPTZ DEFAULT NOW(),
  is_enabled    BOOLEAN     DEFAULT TRUE
);

CREATE TABLE IF NOT EXISTS agent_skill_assignments (
  skill_id    TEXT NOT NULL REFERENCES skills(skill_id) ON DELETE CASCADE,
  agent_id    TEXT NOT NULL,
  assigned_at TIMESTAMPTZ DEFAULT NOW(),
  assigned_by TEXT NOT NULL,
  PRIMARY KEY (skill_id, agent_id)
);
```

**skill-store.ts** — PostgreSQL CRUD following AgentStore pattern exactly:
- `getSkillStore()` singleton
- `createSkill(data)` — insert with `ON CONFLICT DO UPDATE` for idempotent upserts
- `getSkill(skillId)` — single skill by ID
- `listSkills(filters?)` — all skills, optionally filtered by enabled/disabled
- `updateSkill(skillId, updates)` — partial update to skill_data JSONB
- `deleteSkill(skillId)` — delete from skills table
- `assignSkillToAgent(skillId, agentId, assignedBy)` — insert into agent_skill_assignments
- `unassignSkillFromAgent(skillId, agentId)` — delete from assignments
- `getSkillsForAgent(agentId)` — join query returning skills assigned to agent
- `getAgentsForSkill(skillId)` — which agents have this skill

CRITICAL: Zod schemas CANNOT be serialized. Use `zodToJsonSchema()` from `zod-to-json-schema` (already in project) when writing `skill_data`. Store `inputSchema` and `outputSchema` as JSON Schema objects in the JSONB. On read, return the raw JSON Schema — do NOT attempt to reconstruct Zod at read time (consumers can validate with JSON Schema directly).

**skill-registry.ts** — Write-through cache singleton following AgentRegistry pattern:
- In-memory `Map<string, SkillRow>` backed by SkillStore
- `ensureInitialized()` loads all skills from DB on first access
- All mutations (create, update, delete) write to both Map and DB
- `getSkillRegistry()` singleton accessor

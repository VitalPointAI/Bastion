<task type="auto">
  <name>Task 2: Create Dockerfile and docker-compose.yml for bridge deployment</name>
  <files>bridge/Dockerfile, bridge/docker-compose.yml</files>
  <action>
    1. Create `bridge/Dockerfile`:
       ```dockerfile
       FROM python:3.11-slim
       WORKDIR /app
       # Copy shared common package
       COPY robot/common/ /app/robot/common/
       COPY robot/models.py /app/robot/models.py
       COPY robot/__init__.py /app/robot/__init__.py 2>/dev/null || true
       # Copy bridge code
       COPY bridge/ /app/bridge/
       # Install dependencies
       RUN pip install --no-cache-dir -r /app/bridge/requirements.txt
       # Set PYTHONPATH so imports work
       ENV PYTHONPATH=/app
       # Health check
       HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
         CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8766/api/status')" || exit 1
       # Entry point
       ENTRYPOINT ["python", "-m", "bridge.bridge_main"]
       CMD []
       ```
       Note: The healthcheck assumes --ui is enabled. If not, the healthcheck will fail gracefully (bridge still runs, just no HTTP endpoint). This is acceptable for dev; production would use a TCP check on the relay port.

    2. Create `bridge/docker-compose.yml`:
       ```yaml
       version: "3.8"
       services:
         bastion-bridge:
           build:
             context: ..  # project root for COPY robot/common/
             dockerfile: bridge/Dockerfile
           network_mode: host  # REQUIRED for mDNS multicast
           restart: unless-stopped
           env_file:
             - .env
           environment:
             - CLOUD_WS_URL=${CLOUD_WS_URL}
             - BRIDGE_ID=${BRIDGE_ID:-bridge-01}
             - REGISTRATION_TOKEN=${REGISTRATION_TOKEN:-}
             - ENABLE_UI=${ENABLE_UI:-true}
           command: ["--ui"]  # Enable web UI by default in compose
       ```
       Include comments explaining --network=host requirement for mDNS.

    3. Verify the Dockerfile can be parsed (dry-run build check).
  </action>

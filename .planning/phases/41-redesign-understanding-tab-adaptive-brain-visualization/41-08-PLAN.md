**useBrainSnapshots.ts:**

Hook for snapshot CRUD.

- Takes `problemSetId: string`
- Fetches snapshots on mount: `GET /api/brain/snapshots?problemSetId=${problemSetId}`
- State: `snapshots: BrainSnapshot[]`, `loading: boolean`
- Define `BrainSnapshot` type: `{ id: string; title: string; summary: string; timeScale?: string; nodeCount: number; edgeCount: number; createdBy: string; createdAt: string }`
- Methods:
  - `saveSnapshot(input: { title: string; summary: string; timeScale?: Date; nodeCount?: number; edgeCount?: number }): Promise<void>` — POST to API. Get createdBy from auth context.
  - `deleteSnapshot(id: string): Promise<void>` — DELETE, remove from local state
  - `getSnapshot(id: string): Promise<BrainSnapshot | null>` — GET by ID
- Returns: `{ snapshots, loading, saveSnapshot, deleteSnapshot, getSnapshot }`

**BrainStore additions (backend/src/brain/brain-store.ts from Plan 02):**

Add two new query methods:

1. `getLatestSnapshot(problemSetId: string): Promise<BrainSnapshot | null>`
   - Query: `SELECT * FROM brain_snapshots WHERE problem_set_id = $1 ORDER BY created_at DESC LIMIT 1`
   - Returns the most recent saved snapshot or null

2. `getSharedAnnotationsForContext(problemSetId: string): Promise<BrainAnnotation[]>`
   - Query: `SELECT * FROM brain_annotations WHERE problem_set_id = $1 AND is_shared = true ORDER BY created_at DESC LIMIT 50`
   - Returns up to 50 most recent shared annotations for inclusion in agent context

**StrategicContextService integration (backend/src/exercise/strategic-context-service.ts):**

Modify `assembleContext()` to include brain snapshots and shared annotations:

1. Import `BrainStore` (or instantiate it using the same pool pattern as other stores).

2. After existing Step B (graph summaries), add a new step:

   ```
   // Step B2: Brain snapshot summary (if available)
   const brainStore = new BrainStore(); // or get from DI
   const latestSnapshot = await brainStore.getLatestSnapshot(problemSetId);
   if (latestSnapshot) {
     const snapshotTokens = estimateTokens(latestSnapshot.summary);
     if (tokensUsed + snapshotTokens <= TOKEN_BUDGET) {
       // Add snapshot summary to context under a dedicated key
       graphSummaries['__brain_snapshot'] = {
         summary: latestSnapshot.summary,
         title: latestSnapshot.title,
         createdAt: latestSnapshot.createdAt,
         nodeCount: latestSnapshot.nodeCount,
         edgeCount: latestSnapshot.edgeCount,
       } as any; // extend GraphSummary or add a new field to StrategicEnvironmentContext
       tokensUsed += snapshotTokens;
     }
   }
   ```

3. After the snapshot step, add annotation context:

   ```
   // Step B3: Shared annotations from brain
   const sharedAnnotations = await brainStore.getSharedAnnotationsForContext(problemSetId);
   if (sharedAnnotations.length > 0) {
     const annotationSummary = sharedAnnotations
       .map(a => `[${a.annotationType}] Node ${a.nodeId}: ${a.content || a.annotationType}`)
       .join('\n');
     const annotationTokens = estimateTokens(annotationSummary);
     if (tokensUsed + annotationTokens <= TOKEN_BUDGET) {
       graphSummaries['__brain_annotations'] = {
         summary: annotationSummary,
         annotationCount: sharedAnnotations.length,
       } as any;
       tokensUsed += annotationTokens;
     }
   }
   ```

4. **Token budget awareness:** Both additions respect the existing TOKEN_BUDGET. They are inserted AFTER graph summaries (Priority 1) but BEFORE document summaries (Priority 2), giving them Priority 1.5 — they provide curated human insight that enriches raw graph data.

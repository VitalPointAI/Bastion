**useBrainIngestion.ts:**

Hook that manages SSE connections for ingestion events and emits particles.

- Takes `problemSetId: string` and optional `enabled: boolean` (default true)
- Maintains state:
  - `ingestionEvents: IngestionEvent[]` — array of recent events for the sidebar feed (keep last 50)
  - `activeProcesses: Map<string, ProcessStatus>` — currently processing documents
  - `particlesRef: useRef<Particle[]>([])` — particle array in ref (NOT state) to avoid animation re-renders
- Define `IngestionEvent` type: `{ id: string; type: 'document_added' | 'node_created' | 'specialist_start' | 'specialist_complete' | 'error'; label: string; sourceType: string; timestamp: string; nodeType?: BrainNodeType }`
- Define `ProcessStatus`: `{ processId: string; documentName: string; status: 'processing' | 'complete' | 'error'; progress: number }`

SSE Connection:
- Connect to the doc intelligence SSE endpoint for the problem set
- On `specialist:start` event: update activeProcesses, add IngestionEvent
- On `specialist:complete` event: update activeProcesses, add IngestionEvent
- On `node:added` event (NEW — the backend may not emit this yet; gracefully handle missing event): parse `{ nodeId, nodeType, label }`, add a particle to `particlesRef.current` with:
  - x = 0 (left edge, sidebar exit), y = random within sidebar height
  - targetNodeId = nodeId
  - color = CATEGORY_COLORS based on nodeType mapping (entities→blue, objectives→orange, documents→green, concepts→purple default)
  - alpha = 1, born = performance.now()
- On error/close: attempt reconnect after 3 seconds
- **Fallback:** If `node:added` events aren't being emitted by backend, also create particles on `specialist:complete` events (less precise but still shows data flowing)
- Cleanup EventSource on unmount

Returns: `{ events: IngestionEvent[]; activeProcesses: ProcessStatus[]; particlesRef: MutableRefObject<Particle[]>; isConnected: boolean }`

**particleRenderer.ts:**

Canvas overlay component that draws particles animating from left sidebar into the brain.

Export `ParticleOverlay` React component:
- Props: `{ particlesRef: MutableRefObject<Particle[]>; width: number; height: number; sidebarWidth: number }`
- Renders an absolutely-positioned `<canvas>` element over the brain center area
- Canvas styles: `position: absolute; top: 0; left: 0; pointer-events: none; z-index: 5`
- On mount, start `requestAnimationFrame` animation loop stored in a ref
- Animation loop:
  1. Clear canvas
  2. For each particle in `particlesRef.current`:
     - Move x from sidebarWidth toward center (increment by 2px per frame)
     - Fade alpha gradually (decrease by 0.005 per frame)
     - Draw glowing dot: `ctx.beginPath(); ctx.arc(p.x, p.y, 3, 0, Math.PI*2); ctx.fillStyle = p.color` with alpha; set `ctx.shadowBlur = 8; ctx.shadowColor = p.color`; fill; reset shadow
  3. Filter out particles with alpha <= 0 or x > width
  4. Request next frame
- On unmount, cancel animation frame
- **CRITICAL:** Never call setState in the animation loop. All particle state lives in the ref.

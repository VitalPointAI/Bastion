  <files>frontend/src/components/brain/hooks/useBrainClustering.ts</files>
  <action>
Create a hook that manages clustering modes by manipulating d3 forces on the ForceGraph2D instance.

`useBrainClustering(fgRef: MutableRefObject<ForceGraphMethods | undefined>, nodes: BrainNode[])`

State:
- `clusterMode: ClusterMode` (default 'container')
- `setClusterMode: (mode: ClusterMode) => void`

Logic:

1. Compute container centroids: Group nodes by `containerId`. Assign each group a centroid position in a circular arrangement. Store as `Map<string, {x: number, y: number}>`. Recompute when nodes change.

2. Compute DIME centroids: Group nodes by `dimeCategory` (D, I, M, E, or MIDLIFE categories). Same circular arrangement pattern. Categories: 'diplomatic', 'information', 'military', 'economic', 'military', 'infrastructure', 'diplomatic', 'legal', 'intelligence', 'financial', 'economic' (MIDLIFE). Deduplicate overlapping categories.

3. `applyClusterMode(mode)`:
   - If `fgRef.current` is undefined, return
   - Import `forceX`, `forceY` from `d3-force` (these are peer deps of react-force-graph-2d)
   - If mode === 'container':
     - `fg.d3Force('x', forceX((n: any) => containerCentroids.get(n.containerId)?.x ?? 0).strength(0.3))`
     - `fg.d3Force('y', forceY((n: any) => containerCentroids.get(n.containerId)?.y ?? 0).strength(0.3))`
   - If mode === 'dime':
     - Same pattern with dimeCentroids based on `n.dimeCategory`
   - If mode === 'organic':
     - `fg.d3Force('x', null)` — remove group forces
     - `fg.d3Force('y', null)`
   - Call `fg.d3ReheatSimulation()` to restart

4. `useEffect` — when clusterMode changes, call `applyClusterMode(clusterMode)`

5. Also expose cluster labels for overlay: `clusterLabels: Array<{label: string; x: number; y: number}>` — for rendering group labels at cluster centroids (BrainVisualization can optionally draw these).

Returns: `{ clusterMode, setClusterMode, clusterLabels }`

**BrainSearch.tsx:**

Search component with text input and filter dropdowns.

Props:
- `nodes: BrainNode[]`
- `onSearchResults: (matchingNodeIds: string[]) => void` — parent uses this to highlight/filter visible nodes
- `onNodeFocus?: (nodeId: string) => void` — zoom to a specific search result

Implementation:
- **Search mode toggle:** Two modes — "Filter" (traditional) and "Ask" (natural language). Render as a small segmented toggle left of the input.
- Text input with placeholder "Search nodes..." (Filter mode) or "Ask about the graph..." (Ask mode) and a search icon
- **Filter mode (traditional):**
  - Filter dropdowns (compact, side by side):
    - Node type: All | Entity | Objective | Document | Concept
    - Actor category: All | Ally | Adversary | Neutral | Partner
    - DIME theme: All | Diplomatic | Information | Military | Economic (+ MIDLIFE extended if present)
  - On input change or filter change, filter `nodes` array:
    - Text match: case-insensitive `node.label.includes(query)` or `node.id.includes(query)`
    - Type filter: `node.type === selectedType` (if not "All")
    - Category filter: `node.actorCategory === selectedCategory` (if not "All")
    - Theme filter: `node.dimeCategory === selectedTheme` (if not "All")
  - Call `onSearchResults` with matching node IDs
- **Ask mode (natural language):**
  - Hide filter dropdowns. Show only the text input.
  - On Enter or search icon click, send query to `POST /api/brain/nl-search` with body `{ problemSetId, query }`.
  - Backend endpoint (add to `backend/src/api/brain.ts` from Plan 02): receives the NL query, calls the existing AI agent system with a prompt like "Given this knowledge graph, which node IDs match: [query]", returns `{ matchingNodeIds: string[], interpretation: string }`.
  - Display `interpretation` text below the input (e.g., "Showing nodes related to China's naval capabilities").
  - Call `onSearchResults` with the returned `matchingNodeIds`.
  - Show loading spinner while the AI query is in flight.
  - On error, show inline error message and fall back gracefully.
- Show result count: "X of Y nodes" (both modes)
- Clear button to reset all filters/NL results

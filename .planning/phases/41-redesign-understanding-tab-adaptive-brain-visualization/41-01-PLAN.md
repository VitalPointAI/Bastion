Create the complete type system for the brain visualization. This file is the contract for ALL subsequent brain plans.

Define:

1. `BrainNodeType = 'entity' | 'objective' | 'document' | 'concept'`

2. `ActorCategory = 'ally' | 'adversary' | 'neutral' | 'partner'`

3. `ClusterMode = 'container' | 'dime' | 'organic'`

4. `BrainNode` interface:
   - `id: string`
   - `label: string`
   - `type: BrainNodeType`
   - `actorCategory?: ActorCategory`
   - `containerId?: string` (for container clustering)
   - `containerLabel?: string` (display name for container)
   - `dimeCategory?: string` (for DIME/MIDLIFE clustering)
   - `confidence: number` (0-1, drives glow intensity)
   - `isGap?: boolean` (hollow/dashed rendering for intelligence gaps)
   - `isFuturePrediction?: boolean` (ghosted/translucent for future zone)
   - `predictionConfidence?: number` (0-1 for future zone glow)
   - `createdAt: string` (ISO timestamp for temporal filtering)
   - `sourceDocumentIds?: string[]`
   - `validityScore?: number`
   - `centrality?: number` (for semantic zoom prioritization)
   - `annotations?: BrainAnnotation[]`
   - `x?: number; y?: number` (force-graph positioning)

5. `BrainEdge` interface:
   - `source: string`
   - `target: string`
   - `type: string`
   - `strength?: number` (0-1, drives edge thickness)
   - `isConflict?: boolean` (flagged visually)
   - `createdAt?: string`

6. `BrainGraphData = { nodes: BrainNode[]; edges: BrainEdge[] }`

7. `BrainAnnotation` interface:
   - `id: string`
   - `nodeId: string`
   - `nodeType: BrainNodeType`
   - `annotationType: 'flag' | 'note' | 'questionable'`
   - `content?: string`
   - `createdBy: string`
   - `isShared: boolean`
   - `createdAt: string`

8. `Particle` interface (for ingestion animation):
   - `id: string`
   - `x: number; y: number`
   - `targetNodeId: string`
   - `color: string`
   - `alpha: number`
   - `born: number` (performance.now timestamp)

9. Constants:
   - `CATEGORY_COLORS: Record<ActorCategory, string>` — ally=#4a9eff, adversary=#ff4444, neutral=#888888, partner=#44cc66
   - `NODE_TYPE_SHAPES: Record<BrainNodeType, string>` — entity='circle', objective='diamond', document='square', concept='hexagon'
   - `ZOOM_LABEL_THRESHOLD = 1.5`
   - `ZOOM_SECONDARY_THRESHOLD = 0.8`
   - `BRAIN_BG_COLOR = '#020810'`

Export everything.

**useBrainGaps.ts:**

Hook that fetches intelligence gaps and provides gap node IDs for the visualization.

- Takes `problemSetId: string`
- Fetches: `GET /api/brain/gaps?problemSetId=${problemSetId}`
- State: `gaps: GapInfo[]`, `loading: boolean`, `gapNodeIds: Set<string>`
- Define `GapInfo`: `{ nodeId: string; nodeLabel: string; missingConnectionTypes: string[]; expectedConnections: number; actualConnections: number }`
- After fetch, compute `gapNodeIds` as a Set of all gap nodeIds
- Provide `markGapNodes(nodes: BrainNode[]): BrainNode[]` — returns a new array where nodes whose IDs are in `gapNodeIds` have `isGap = true`. Also creates synthetic "ghost" nodes for each gap's missing connection types (with generated IDs, `isGap = true`, hollow rendering).
- Provide `gapCount: number` — total number of gaps (for toolbar badge)
- Auto-refetch every 5 minutes (gaps change as documents are ingested)
- Returns: `{ gaps, loading, gapNodeIds, markGapNodes, gapCount, refetch }`

**GapSummaryPanel.tsx:**

Panel showing the intelligence gap report, displayed in the right detail panel or as a section.

- `gaps: GapInfo[]`

- `onNodeClick?: (nodeId: string) => void` — clicking a gap node focuses the brain on it

Layout:

3. **Gap list:** Each gap shows:
   - Node label with type icon

   - "Investigate" button — calls onNodeClick to zoom to the node in the brain

**useBrainPatterns.ts:**

Hook that fetches proactive pattern alerts.

- Takes `problemSetId: string`
- Fetches: `GET /api/brain/pattern-alerts?problemSetId=${problemSetId}`
- State: `alerts: PatternAlert[]`, `loading: boolean`, `unreadCount: number`
- Define `PatternAlert` (frontend version): `{ id: string; type: 'trend' | 'anomaly' | 'correlation'; message: string; severity: 'low' | 'medium' | 'high'; detectedAt: string; relatedNodeIds: string[] }`
- Track read/unread state locally (sessionStorage or state): `readAlertIds: Set<string>`
- `markAsRead(alertId: string)`: add to readAlertIds set, decrement unreadCount
- `markAllAsRead()`: mark all current alerts as read
- `unreadCount` = alerts.length - readAlertIds.size (for those in current alerts)
- Auto-refetch every 5 minutes
- Returns: `{ alerts, loading, unreadCount, markAsRead, markAllAsRead, refetch }`

**PatternAlertBadge.tsx:**

Notification badge and dropdown for pattern alerts. Lives in the toolbar.

Props:
- `alerts: PatternAlert[]`
- `unreadCount: number`
- `onMarkAsRead: (id: string) => void`
- `onMarkAllAsRead: () => void`
- `onAlertClick?: (alert: PatternAlert) => void` — highlight related nodes in the brain

Implementation:
1. **Badge button:** Bell icon with unread count badge (red circle with number). If unreadCount = 0, no badge shown. Clicking toggles dropdown.

2. **Dropdown:** Absolutely-positioned below the button. Max-height 400px, scrollable. Dark background with border.

3. **Dropdown header:** "Pattern Alerts" title + "Mark all read" button

4. **Alert list:** Each alert shows:

   - Type badge: small tag (trend/anomaly/correlation)
   - Message text (the detected pattern description, e.g., "China military activity increased 40% in last 3 ingestion cycles")
   - Time: "detected 2h ago" relative timestamp
   - "View in Brain" button — calls onAlertClick to highlight related nodes
   - Unread indicator: subtle left border or background tint for unread alerts
   - Clicking the alert marks it as read

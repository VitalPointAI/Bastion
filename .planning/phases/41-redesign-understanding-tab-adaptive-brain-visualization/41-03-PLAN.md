**nodeRenderer.ts:**

Create Canvas 2D drawing functions for shape-coded brain nodes.

1. `drawBrainNode(node: BrainNode, ctx: CanvasRenderingContext2D, globalScale: number, isSelected: boolean, isDimmed: boolean, animFrame: number): void`
   - Get base radius = 6, scaled up 1.4x if selected
   - If `isDimmed` (not in selected node's neighborhood): draw at 20% opacity and skip glow
   - **Semantic zoom:** If `globalScale < ZOOM_SECONDARY_THRESHOLD` and `node.centrality` is below 0.5, return early (don't draw secondary nodes when zoomed out)
   - **Confidence glow:** Set `ctx.shadowColor` to CATEGORY_COLORS[actorCategory] (default '#4a9eff'). Set `ctx.shadowBlur` to `(node.confidence ?? 0.5) * 20`. If `isGap`, set shadowBlur to 0.
   - **Future prediction:** If `isFuturePrediction`, set `ctx.globalAlpha` to `0.3 + (node.predictionConfidence ?? 0.3) * 0.4` (ghosted/translucent)
   - **Shape drawing:** `ctx.beginPath()` then switch on node.type:
     - 'entity': `ctx.arc(x, y, r, 0, Math.PI * 2)` (circle)
     - 'objective': call `drawDiamond(ctx, x, y, r)` (rotated square)
     - 'document': call `drawSquare(ctx, x, y, r)`
     - 'concept': call `drawHexagon(ctx, x, y, r)`
   - **Gap rendering:** If `isGap`, use `ctx.setLineDash([3/globalScale, 3/globalScale])`, stroke with white at 30% opacity, then `ctx.setLineDash([])`. Do NOT fill.
   - **Normal rendering:** Fill with CATEGORY_COLORS[actorCategory] or '#4a9eff' default
   - **Label:** If `globalScale > ZOOM_LABEL_THRESHOLD`, draw label below the node using `ctx.fillText`. Font size = `12/globalScale`, color white at 80% alpha. Truncate label to 20 chars.
   - **CRITICAL:** Always reset `ctx.shadowBlur = 0`, `ctx.shadowColor = 'transparent'`, `ctx.globalAlpha = 1` at the END of the function to prevent glow bleeding.

2. Helper functions:
   - `drawDiamond(ctx, x, y, r)`: moveTo(x, y-r), lineTo(x+r, y), lineTo(x, y+r), lineTo(x-r, y), closePath()
   - `drawSquare(ctx, x, y, r)`: rect(x-r, y-r, r*2, r*2)
   - `drawHexagon(ctx, x, y, r)`: 6-point polygon using `cos(angle) * r`, `sin(angle) * r` where angle increments by PI/3, starting at -PI/2

Export all functions.

**edgeRenderer.ts:**

Create Canvas 2D edge drawing function.

1. `drawBrainEdge(edge: BrainEdge, ctx: CanvasRenderingContext2D, globalScale: number, sourceNode: any, targetNode: any, isDimmed: boolean, animFrame: number): void`
   - Base width = 0.5 + (edge.strength ?? 0.3) * 2 (thickness reflects relationship strength)
   - If `isDimmed`: draw at 10% opacity, thinner
   - If `edge.isConflict`: draw in red with dashed line
   - Draw line from source(x,y) to target(x,y) using `ctx.moveTo/lineTo`
   - **Pulse animation:** For non-dimmed edges, draw a small circle "pulse" that moves along the edge. Position = `animFrame % 100 / 100` interpolated between source and target. Color matches edge color at 60% alpha. Radius = 1.5/globalScale.
   - Stroke with gray/white at varying opacity based on strength
   - Reset any canvas state changes

Export `drawBrainEdge`.

**useBrainData.ts:**

Data hook that fetches all node types and merges into BrainGraphData.

- Takes `problemSetId: string` as argument
- Fetches from these existing endpoints in parallel:
  1. `GET /api/graph/workspaces/${problemSetId}/graph` — returns {nodes, edges} (actors + relationships)
  2. `GET /api/graph/actors?workspaceId=${problemSetId}` — returns actor details with categories
  3. `GET /api/graph/validity/objectives?workspaceId=${problemSetId}` — returns strategic objectives
  4. `GET /api/doc-intelligence/documents/${problemSetId}` — returns strategic documents
- Merges results into BrainGraphData:
  - Actor nodes → BrainNode with type='entity', map actor_category to actorCategory
  - Objective nodes → BrainNode with type='objective', use extraction_confidence as confidence
  - Document nodes → BrainNode with type='document', confidence based on quality rating if available
  - Concept nodes → Extract from objectives' midlife_category, create concept BrainNodes with type='concept'
  - Edges come from the graph endpoint directly, map strength values
- **Confidence proxy for actors** (per research pitfall 7): compute confidence = min(1, (sourceDocCount * 0.3) + (relationshipCount * 0.2) + (validityScore ?? 0) * 0.5). If no sources, confidence = 0.3 (low).
- Returns `{ data: BrainGraphData; loading: boolean; error: string | null; refetch: () => void }`
- Use `useState` + `useEffect` pattern. Refetch on problemSetId change.
- **IMPORTANT:** The graph API uses `workspaceId` but it equals `problemSetId` — document this in a comment.

**BrainVisualization.tsx:**

Core graph canvas component wrapping ForceGraph2D.

Props:
- `data: BrainGraphData`
- `selectedNodeId?: string`
- `selectedNodeIds?: string[]` (for multi-select)
- `onNodeClick?: (node: BrainNode) => void`
- `width?: number`
- `height?: number`
- `clusterMode?: ClusterMode` (default 'container')
- `onLassoSelect?: (nodeIds: string[]) => void`

Implementation:
- Import ForceGraph2D from 'react-force-graph-2d'
- Use `useRef` for fgRef (ForceGraphMethods)
- Use `useRef` for animFrame counter, increment via `requestAnimationFrame` loop on mount (cleanup on unmount)
- Transform BrainGraphData into the format ForceGraph2D expects: `{ nodes: [...], links: [...] }` using `useMemo`
- `nodeCanvasObject` callback: determine if node is dimmed (if a node is selected and this node is NOT in its neighborhood), call `drawBrainNode`
- `nodeCanvasObjectMode` returning `'replace'` (full custom rendering)
- `linkCanvasObject` callback: call `drawBrainEdge`
- `linkCanvasObjectMode` returning `'replace'`
- `nodePointerAreaPaint` callback: draw a circular hit area with radius covering the shape bounding box
- ForceGraph2D props: `backgroundColor="transparent"`, `enableZoomInteraction={true}`, `enablePanInteraction={true}`, `enableNodeDrag={false}`, `warmupTicks={200}`, `cooldownTicks={50}`, `d3AlphaDecay={0.05}`, `d3VelocityDecay={0.4}`, `nodeId="id"`, `linkSource="source"`, `linkTarget="target"`
- `onNodeClick`: call props.onNodeClick with the BrainNode
- `onNodeHover`: set hovered node for tooltip (optional future)
- Neighborhood calculation: when selectedNodeId changes, compute the set of node IDs connected to it (1-hop neighbors) and store in a ref. Nodes NOT in this set are "dimmed."
- Use `ResizeObserver` on the container div to detect width changes and pass to ForceGraph2D (per research pitfall 3).

**Lasso multi-select** (per CONTEXT.md "Shift-click or lasso to select multiple nodes" and RESEARCH.md Pitfall 5):
- Add a transparent `<div>` overlay positioned absolutely over the graph canvas, with `pointer-events: none` by default.
- Add `onLassoSelect?: (nodeIds: string[]) => void` prop.
- Track lasso state: `isLassoing: boolean`, `lassoPath: Array<{x: number; y: number}>`.
- Activation: When user holds Alt key (or a dedicated lasso toggle button), set `pointer-events: auto` on the overlay and `enablePanInteraction={false}` on ForceGraph2D.
- On mousedown on the overlay: start lasso, begin collecting points into `lassoPath`.
- On mousemove: append points, draw the lasso polygon on a `<canvas>` element inside the overlay using `ctx.lineTo`.
- On mouseup: close the polygon. Hit-test all visible nodes: for each node, use `graph2ScreenCoords(node.x, node.y)` from ForceGraph2D ref to get screen coordinates, then test if the point is inside the lasso polygon using a standard point-in-polygon algorithm (ray casting). Collect matching node IDs and call `onLassoSelect(matchingIds)`.
- After lasso completes: reset `isLassoing`, clear overlay, restore `enablePanInteraction={true}`.
- Start with brute-force O(n) hit test per RESEARCH.md recommendation; optimize to quadtree only if >500 nodes shows performance issues.

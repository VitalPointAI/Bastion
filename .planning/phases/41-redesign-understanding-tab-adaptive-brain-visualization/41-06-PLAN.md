**useBrainAnnotations.ts:**

Hook for annotation CRUD operations.

- Takes `problemSetId: string`
- Fetches annotations on mount: `GET /api/brain/annotations?problemSetId=${problemSetId}`
- State: `annotations: BrainAnnotation[]`, `loading: boolean`, `error: string | null`
- Methods:
  - `createAnnotation(input: { nodeId: string; nodeType: BrainNodeType; annotationType: 'flag' | 'note' | 'questionable'; content?: string; isShared?: boolean }): Promise<void>` — POST to API, add to local state
  - `updateAnnotation(id: string, input: { content?: string; isShared?: boolean; annotationType?: string }): Promise<void>` — PUT to API, update local state
  - `deleteAnnotation(id: string): Promise<void>` — DELETE, remove from local state
  - `getNodeAnnotations(nodeId: string): BrainAnnotation[]` — filter annotations by nodeId
- For the createdBy field, get the current user identity from the same pattern used elsewhere in the app (check how other components get the user — likely from a context or auth hook). Pass it when creating annotations.
- Returns: `{ annotations, loading, error, createAnnotation, updateAnnotation, deleteAnnotation, getNodeAnnotations }`

**BrainDetailPanel.tsx:**

Right panel that shows node details, comparison, or annotations based on selection.

Props:
- `selectedNode?: BrainNode`
- `selectedNodes?: BrainNode[]` (for multi-select comparison)
- `graphData: BrainGraphData`
- `annotations: BrainAnnotation[]`
- `onClose: () => void`
- `onCreateAnnotation: (input: any) => void`
- `onUpdateAnnotation: (id: string, input: any) => void`
- `onDeleteAnnotation: (id: string) => void`

Implementation:

1. **Header:** Close button (X) on the right. Title: node label for single select, "Compare N Nodes" for multi-select.

2. **Single Node View** (when selectedNode is set, selectedNodes is empty or length 1):
   - **Identity section:** Node label, type badge (with shape icon), actor category badge (colored)
   - **Confidence meter:** Visual bar 0-100% with color gradient (red to yellow to green). Show numeric value.
   - **Connections section:** List of connected nodes (from graphData edges where source or target = selectedNode.id). Show connection type, strength bar, target node label + type. Clicking a connection could focus that node (call parent callback).
   - **Source documents section:** If `sourceDocumentIds` exists, list document names/IDs
   - **Metadata:** createdAt formatted date, containerId/label, dimeCategory
   - **Annotations section:** Render `<NodeAnnotationPanel>` with the node's annotations

3. **Comparison View** (when selectedNodes has length > 1):
   - **Node list:** Horizontal row of selected node badges (label + type + category color)
   - **Shared connections:** Find edges that connect to 2+ selected nodes. List them with "shared by N of M selected" label.
   - **Unique connections:** For each selected node, list connections NOT shared with other selected nodes.
   - **Differences table:** Compare key attributes across selected nodes (confidence, type, category, dimeCategory, connectionCount). Show as a simple table/grid.
   - **Bulk annotation:** "Annotate All" button that opens note input — creates annotation on all selected nodes at once.

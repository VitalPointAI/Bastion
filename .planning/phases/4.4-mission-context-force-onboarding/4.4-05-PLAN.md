    1. Create frontend/src/lib/command-service.ts:
       ```typescript
       const API_BASE = '/api/command';

       export const commandService = {
         // Units
         createUnit: (data) => fetch(`${API_BASE}/units`, { method: 'POST', ... }),
         getUnits: (missionId) => fetch(`${API_BASE}/units?missionId=${missionId}`),
         updateUnit: (id, data) => fetch(`${API_BASE}/units/${id}`, { method: 'PATCH', ... }),
         deleteUnit: (id) => fetch(`${API_BASE}/units/${id}`, { method: 'DELETE' }),

         // Relationships
         createRelationship: (data) => fetch(`${API_BASE}/relationships`, { method: 'POST', ... }),
         getRelationships: (missionId) => fetch(`${API_BASE}/relationships?missionId=${missionId}`),
         getHierarchy: (missionId) => fetch(`${API_BASE}/hierarchy/${missionId}`),
         deleteRelationship: (id) => fetch(`${API_BASE}/relationships/${id}`, { method: 'DELETE' }),
         validateHierarchy: (missionId) => fetch(`${API_BASE}/validate-hierarchy/${missionId}`, { method: 'POST' }),
         getMatrix: (missionId) => fetch(`${API_BASE}/matrix/${missionId}`),
       };
       ```

    2. Create CommandNode.tsx (custom tree node):

       - Display milsymbol icon using SIDC
       - Show relationship type badge (OPCON, TACON, etc.)
       - Optional: multi-hatted indicator if unit has multiple roles
       - Styling: military-grade border, classification color coding

    3. Create CommandTreeView.tsx:
       - Import { Tree, TreeNode } from 'react-organizational-chart'
       - Fetch hierarchy on mount using commandService.getHierarchy()
       - Recursive renderTree function to build TreeNode structure

    4. Create CommandTreeView.css:
       - Tree container styling

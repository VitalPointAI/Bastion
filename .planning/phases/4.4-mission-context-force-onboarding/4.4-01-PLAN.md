Create the mission module with schemas and database operations.

**schemas.ts:**
- MissionSchema with id, name, description, workspaceId (links to existing workspace), status (planning/active/complete/archived), areaOfOps (GeoJSON), createdBy, createdAt, updatedAt
- MissionParticipantSchema with missionId, participantDID, role, joinedAt, invitedBy
- InviteTokenSchema with token (hashed), missionId, expiresAt, usedBy, usedAt
- Use Zod 4.x syntax (.describe() for LLM hints)

**store.ts:**
- MissionStore class with lazy table init pattern (consistent with codebase)
- createMission(data): Create mission with validation
- getMission(id): Get by ID
- updateMission(id, data): Partial update
- setMissionStatus(id, status): State transitions
- addParticipant(missionId, did, role, invitedBy): Add participant
- getParticipants(missionId): List participants
- generateInviteToken(missionId, expirationHours): Create invite (hash token, store hash)
- validateInviteToken(token): Check if valid and not expired
- redeemInviteToken(token, redeemerDID): Mark used, return mission

**mission-machine.ts:**
- XState v5 state machine for mission lifecycle: planning -> active -> complete -> archived
- Use setup() pattern consistent with codebase (see approval-machine.ts)
- Guards for valid transitions
- Actions to update database via MissionStore

Tables:
```sql
CREATE TABLE IF NOT EXISTS missions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  description TEXT,
  workspace_id UUID REFERENCES workspaces(id),
  status VARCHAR(20) DEFAULT 'planning',
  area_of_ops JSONB, -- GeoJSON Polygon
  created_by VARCHAR(255) NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS mission_participants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  participant_did VARCHAR(255) NOT NULL,
  role VARCHAR(50) DEFAULT 'member',
  joined_at TIMESTAMPTZ DEFAULT NOW(),
  invited_by VARCHAR(255),
  UNIQUE(mission_id, participant_did)
);

CREATE TABLE IF NOT EXISTS mission_invite_tokens (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  token_hash VARCHAR(64) NOT NULL UNIQUE,
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  expires_at TIMESTAMPTZ NOT NULL,
  used_by VARCHAR(255),
  used_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

Use crypto.randomBytes(32).toString('base64url') for token generation, SHA-256 for hashing.

**command/schemas.ts:**

- CommandRelationshipSchema with id, missionId, superiorUnitId, subordinateUnitId, relationshipType (enum: OPCON, TACON, ADCON, COCOM, DS, GS, GSR, R), effectiveFrom, effectiveTo, notes
- JointResponsibilitySchema with unitId, responsibility (JTF_COMD, JFLCC, JFMCC, JFACC, etc.)

**command/store.ts:**
- CommandStore class with lazy table init
- createUnit(data): Create unit
- getUnit(id): Get by ID
- createRelationship(data): Create command relationship
- getRelationships(missionId): Get all relationships for mission
- getHierarchy(missionId): Recursive CTE to build tree structure
- detectCycles(missionId): Check for circular relationships using DFS
- assignResponsibility(unitId, responsibility): Add joint responsibility
- getMultiHattedPositions(missionId): Find units with multiple responsibilities

Tables:
```sql
CREATE TABLE IF NOT EXISTS mission_units (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  name VARCHAR(255) NOT NULL,
  unit_type VARCHAR(50),
  sidc VARCHAR(30), -- MIL-STD-2525D symbol code
  parent_did VARCHAR(255), -- DID of person commanding this unit
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS command_relationships (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  superior_unit_id UUID NOT NULL REFERENCES mission_units(id) ON DELETE CASCADE,
  subordinate_unit_id UUID NOT NULL REFERENCES mission_units(id) ON DELETE CASCADE,
  relationship_type VARCHAR(20) NOT NULL,
  effective_from TIMESTAMPTZ,
  effective_to TIMESTAMPTZ,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(mission_id, superior_unit_id, subordinate_unit_id, relationship_type)
);

CREATE TABLE IF NOT EXISTS unit_responsibilities (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  unit_id UUID NOT NULL REFERENCES mission_units(id) ON DELETE CASCADE,
  responsibility VARCHAR(50) NOT NULL,
  assigned_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(unit_id, responsibility)
);
```

- PersonnelSchema with id, missionId, did, name, rank, specialty, unitId, readinessStatus, readinessReason
- ConsumableSchema with id, missionId, categoryId, name, supplyPointId, quantity, unit, reorderLevel

- Categories: createCategory, getCategories, getCategoryTree

- Personnel: createPersonnel, getPersonnel, updateReadiness, getPersonnelByUnit

Tables:
```sql
CREATE TABLE IF NOT EXISTS resource_categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  parent_id UUID REFERENCES resource_categories(id),
  name VARCHAR(255) NOT NULL,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS resources (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  category_id UUID REFERENCES resource_categories(id),
  name VARCHAR(255) NOT NULL,
  serial_number VARCHAR(100),
  sidc VARCHAR(30),
  specifications JSONB,
  status VARCHAR(10) DEFAULT 'FMC',
  status_reason TEXT,
  location JSONB, -- GeoJSON Point
  last_location_update TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS personnel (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  did VARCHAR(255),
  name VARCHAR(255) NOT NULL,
  rank VARCHAR(50),
  specialty VARCHAR(100),
  unit_id UUID REFERENCES mission_units(id),
  readiness_status VARCHAR(20) DEFAULT 'ready',
  readiness_reason TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS consumables (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mission_id UUID NOT NULL REFERENCES missions(id) ON DELETE CASCADE,
  category_id UUID REFERENCES resource_categories(id),
  name VARCHAR(255) NOT NULL,
  supply_point_id UUID,
  quantity DECIMAL(10,2) NOT NULL,
  unit VARCHAR(20),
  reorder_level DECIMAL(10,2),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

    ```python
    async def _vision_loop(self, mission_id: str, stop_event: asyncio.Event) -> None:
        """Run detection loop at profile-determined cadence. Sends VisionMsg on detections."""
        cadence_sec = (self._vision_config.vision_cadence_ms / 1000.0) if self._vision_config else 0.5
        while not stop_event.is_set():
            try:
                detections = await self._vision_engine.detect_once(self._camera)
                if detections and self._send_vision_fn:
                    keyframe = None
                    if self._vision_config and self._vision_config.keyframe_enabled:
                        jpeg = await self._vision_engine.get_keyframe_jpeg(
                            self._camera, self._vision_config.keyframe_quality
                        )
                        if jpeg:
                            import base64
                            keyframe = base64.b64encode(jpeg).decode()
                    vision_msg = VisionMsg(
                        robot_id=self._robot_id,
                        mission_id=mission_id,
                        timestamp=datetime.utcnow(),
                        detections=detections,
                        keyframe_jpeg_b64=keyframe,
                    )
                    await self._send_vision_fn(vision_msg)
            except Exception as exc:
                log.warning("mission_executor.vision_loop.error", error=str(exc))
            await asyncio.sleep(cadence_sec)
    ```

    Replace the stub behavior methods with full implementations:

    **_execute_recon_area(mission):**
    1. Generate sweep path from mission.params.area using `generate_sweep_path()`
    2. Transition to executing; set LEDs to blue (recon indicator)
    3. Start _vision_loop as background task with stop_event
    4. Drive each sweep waypoint via `self._driver.drive_to_point(wp.x, wp.y, speed)`
    5. Emit telemetry at each waypoint
    6. On completion, stop vision loop (stop_event.set()), transition to complete
    7. Import `from sweep.path_planner import generate_sweep_path`

    **_execute_visual_search(mission):**
    1. Decode reference_image_b64 and load into FeatureMatcher via set_reference()
    2. If set_reference fails, transition to failed with reason
    3. Generate sweep path from mission.params.area (if provided) or use a default small area
    4. Transition to executing; set LEDs to purple (search indicator)
    5. Start vision loop; additionally, at each detection, run feature_matcher.match()
    6. If target found (match.found=True), stop driving, emit VisionMsg with target_match, transition to complete with result="target_found"
    7. If sweep completes without finding target, transition to complete with result="target_not_found"
    8. Need a FeatureMatcher instance — create in constructor if vision_engine is provided, or accept as parameter
    9. Import `from vision.feature_matcher import FeatureMatcher`

    **_execute_overwatch(mission):**
    1. Drive to target_location
    2. Transition to executing; set LEDs to cyan (overwatch indicator)
    3. Start vision loop with longer cadence (continuous monitoring)
    4. Hold position — await either: duration_sec timeout (if provided), or shutdown/abort
    5. Vision loop sends VisionMsg on every detection (monitoring mode)
    6. On timeout or abort, stop vision loop, transition to complete

    **_execute_resupply_route(mission):**
    1. Transition to executing; set LEDs to green (standard navigation)
    2. Start vision loop (obstacle awareness mode)
    3. Drive each waypoint via drive_to_point
    4. Vision detections during transit are logged/sent but do not alter route (profile-dependent obstacle response would be future enhancement)
    5. Emit telemetry at each waypoint
    6. On completion, stop vision loop, transition to complete

    **Profile-dependent behavior hooks (all handlers):**
    - Read speed from mission.params.speed (respect profile max_speed if vision_config provides it)
    - Read vision cadence from vision_config.vision_cadence_ms
    - LED colors indicate mission type for operator awareness

    **Important implementation notes:**
    - Always use `try/finally` to ensure vision loop stop_event is set on exit
    - FeatureMatcher must handle the case where reference image is invalid gracefully
    - RVR+ drive_with_heading timeout: the existing drive_to_point handles this via duration-based loops — no changes needed
    - In simulate mode, vision_engine is MockVisionEngine — behavior handlers work identically

  <files>robot/vision/feature_matcher.py, robot/tests/test_feature_matcher.py</files>
  <behavior>
    - set_reference(invalid_bytes) returns False
    - set_reference(valid_image_bytes) returns True and stores descriptors
    - match() with no reference set returns TargetMatchResult(found=False, confidence=0.0)
    - match(frame_gray) with too few keypoints returns found=False
    - match(frame_gray) with matching image returns found=True and confidence > 0
    - FeatureMatcher constructor accepts n_features and match_threshold params
  </behavior>
  <action>
    1. Write tests FIRST in `robot/tests/test_feature_matcher.py`:
       - `test_invalid_reference`: pass random non-image bytes to set_reference, assert returns False
       - `test_match_no_reference`: call match() without calling set_reference, assert found=False, confidence=0.0
       - `test_set_valid_reference`: create a small test image (numpy array with cv2), encode to bytes, pass to set_reference, assert returns True
       - `test_match_identical_image`: set reference to a test image, match against the same image, assert found=True, confidence > 0
       - `test_match_different_image`: set reference, match against a totally different image, assert confidence is lower
       - Use `cv2` to create simple test images (rectangles/circles on white background) — no external image files needed

    2. Implement `robot/vision/feature_matcher.py`:
       - `FeatureMatcher.__init__(self, n_features: int = 500, match_threshold: float = 0.75)`:
         - Create `cv2.ORB_create(nfeatures=n_features)`
         - Create `cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=False)` (NORM_HAMMING required for binary descriptors)
         - Store match_threshold
         - Initialize _kp_ref, _desc_ref as None
       - `set_reference(self, reference_image_bytes: bytes) -> bool`:
         - Decode bytes to grayscale via `np.frombuffer` + `cv2.imdecode`
         - If decode fails, return False
         - Compute ORB keypoints/descriptors
         - If fewer than 10 keypoints, return False
         - Store and return True
       - `match(self, frame_gray: np.ndarray) -> TargetMatchResult`:
         - If no reference set, return TargetMatchResult(found=False, confidence=0.0)
         - Compute ORB on frame
         - If fewer than 4 keypoints, return found=False
         - knnMatch(k=2) with Lowe's ratio test (m.distance < threshold * n.distance)
         - confidence = min(good_matches / max(len(kp_ref), 1), 1.0)
         - found = len(good_matches) >= 10
         - Return TargetMatchResult(found=found, confidence=confidence, match_count=len(good_matches))
       - `clear_reference(self)`: reset _kp_ref, _desc_ref to None
  </action>

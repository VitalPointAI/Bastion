  <name>Task 1: Add Neo4j to Docker Compose</name>
  <files>docker-compose.yml</files>
  <action>
Add Neo4j service to docker-compose.yml:
- Image: neo4j:2025-community
- Ports: 7474 (HTTP browser), 7687 (Bolt)
- Environment: NEO4J_AUTH=neo4j/${NEO4J_PASSWORD:-password}, enable APOC plugin
- Memory settings: 512m initial heap, 1g max heap, 256m pagecache
- Volumes: neo4j_data for persistence, neo4j_logs for logs
- Health check: wget to localhost:7474
- Network: bastion-network

Update backend service to add NEO4J_URI, NEO4J_USER, NEO4J_PASSWORD environment variables.
Add depends_on for neo4j with service_healthy condition.
  </action>

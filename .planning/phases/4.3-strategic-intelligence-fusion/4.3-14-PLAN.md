  <action>
In the `GET /validity/objectives` handler (around line 352-392), replace the hard-coded trend logic inside the `objectives.map()` callback.

1. Replace the line:
   ```typescript
   trend: 'stable' as const, // Trend analysis not yet implemented
   ```
   with a call to `calculateTrend()` and a mapping function.

2. Add a local helper function (inside or before the handler) to map the service's trend values to the UI format:
   ```typescript
   function mapTrend(serviceTrend: 'improving' | 'declining' | 'stable'): 'up' | 'down' | 'stable' {
     switch (serviceTrend) {
       case 'improving': return 'up';
       case 'declining': return 'down';
       case 'stable': return 'stable';
     }
   }
   ```

3. In the success branch of the map callback, add the trend calculation:
   ```typescript
   const trendResult = await validityService.calculateTrend(obj.id);
   ```
   Then use `mapTrend(trendResult.trend)` for the `trend` field.

4. In the catch branch (error fallback), keep `trend: 'stable' as const` since there is no score history to compute a trend from.

The final map callback should look like:
```typescript
objectives.map(async (obj) => {
  try {
    const validity = await validityService.calculateValidity(obj.id, 'system');
    const trendResult = await validityService.calculateTrend(obj.id);
    return {
      id: obj.id,
      objectiveTitle: obj.description.slice(0, 100),
      validityScore: validity.score,
      trend: mapTrend(trendResult.trend),
      lastUpdated: validity.calculatedAt,
      classification: 'UNCLASSIFIED',
    };
  } catch {
    return {
      id: obj.id,
      objectiveTitle: obj.description.slice(0, 100),
      validityScore: 70,
      trend: 'stable' as const,
      lastUpdated: new Date().toISOString(),
      classification: 'UNCLASSIFIED',
    };
  }
})
```

Note: `calculateTrend()` defaults to 30-day window and returns `{trend: 'stable', changePercent: 0}` when insufficient data, so this is safe for objectives with no score history (they still get 'stable').

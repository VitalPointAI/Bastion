## Key Features

### ValidityMap Component
- React-Leaflet integration with dark Stadia tiles
- Custom event markers with relevance color coding (supporting/contradicting/neutral)
- Custom actor markers with type icons (nation/organization/individual/non-state actor)
- Tension circles with intensity-based coloring
- Layer toggle controls for events/actors/tensions
- Popup overlays with event/actor details

### StrategicValidityDashboard (Fullscreen Layout)
- Fullscreen map/graph taking entire viewport minus header
- Floating semi-transparent header with:
  - Workspace selector dropdown
  - View mode toggle (Map/Graph/Split)
  - Info panel toggle button
- Floating info panel (overlay, not permanent sidebar):
  - Recent events list with relevance indicators
  - Objective validity scores with trend arrows
  - Active alerts with acknowledge buttons
- Critical alert banner with dismiss action
- Event detail modal on selection
- GraphExplorer integration for network visualization
- NodeDetailPanel for actor details
- Safe JSON fetching to handle 404 responses gracefully

### API Endpoints Added
- GET /api/graph/validity/objectives - objective validity scores
- GET /api/graph/workspaces/:id/graph - nodes and edges for visualization

## Technical Decisions

- **Fullscreen layout**: Map is the focal piece, overlays for secondary information
- **react-leaflet + Stadia dark tiles**: Open source, no API key required
- **Safe JSON fetching**: Prevents parse errors when endpoints return 404 HTML
- **View modes**: Map-only, Graph-only, or Split view for flexibility

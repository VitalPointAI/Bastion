## Decisions Made
- **Power iteration in Node.js:** Both algorithms use Node.js power iteration rather than Neo4j GDS, avoiding plugin dependency while achieving accurate results for RAFT graph scales (<1000 actors, <5000 edges, sub-second)
- **L-infinity normalization for eigenvector centrality:** Dividing by max score each iteration keeps scores in [0,1] range with the most influential actor always at 1.0, making results intuitive for analysts
- **Exported computation functions:** Rather than duplicating adjacency fetch logic in graph.ts, the helpers are exported from raft-tools.ts — single source of truth for algorithm correctness
- **Shared adjacency fetch in comparison endpoint:** One Neo4j round-trip fetches the adjacency list used by both eigenvector and PageRank algorithms, minimizing database load
- **Divergence as integer rank difference:** `abs(eigenvectorRank - pageRankRank)` provides simple, interpretable divergence metric rather than a normalized score

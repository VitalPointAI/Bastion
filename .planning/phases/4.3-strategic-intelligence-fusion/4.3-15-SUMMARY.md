## Decisions Made
- Used `bounds` prop instead of relying solely on `noWrap`: Leaflet GitHub issues #4646 and #7181 document that `noWrap={true}` does not prevent out-of-bounds tile coordinate calculations. The `bounds` prop clips the calculation, preventing requests for x=5 at zoom 2 where valid range is x=0-3.
- Optional API key pattern: VITE_STADIA_MAPS_API_KEY is read at module load time using `import.meta.env`, with a ternary conditional that only appends `?api_key=...` when the variable is set. Localhost deployments work without the key; non-localhost deployments can set the key in their environment.
- Module-scope constants: Both `STADIA_API_KEY` and `STADIA_TILE_URL` are defined outside the React component function to avoid recalculation on every render.

## User Setup Required

Optional: Set `VITE_STADIA_MAPS_API_KEY` in your `.env` file if deploying to non-localhost environments. Without this key, Stadia Maps tiles will load on localhost but return 401 elsewhere.

```
VITE_STADIA_MAPS_API_KEY=your_api_key_here
```

Obtain an API key from https://stadiamaps.com/dashboard/

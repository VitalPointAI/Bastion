# Phase 4.3: Strategic Intelligence Fusion & RAFT Analysis - Context

**Gathered:** 2026-01-22
**Status:** Ready for research

<vision>
## How This Should Work

A living strategic document with graph exploration capabilities. The system should feel like an intelligence analyst's workbench that evolves as new information comes in.

**Workspaces:** Isolated analysis spaces per country or adversary, each with its own documents, graphs, and fusion results. These workspaces can reference each other and roll up into a master strategic environment view — so you can deep-dive on China or Russia individually, but also see how they interact in the aggregate global picture.

**Map-Centered Dashboard:** The strategic environment dashboard centers on a visual world map. Zoom in on any location to see what's happening there — events, actors, tensions — and how those things affect current strategic objectives. Events, actors, and objectives are all visualized on the map with layer controls.

**Prediction & Warning:** The system should surface warnings when events threaten or contribute to strategic objective achievement. Show probabilities with supporting evidence. This isn't just tracking — it's anticipatory analysis.

**Risk Analysis:** Risk is key for commanders. Robust risk analysis should be integrated throughout, helping decision-makers understand what's at stake and where the uncertainties lie.

**Flexibility:** Must support adding and deleting items as the strategic picture evolves. This is a living system, not a static report.

**AI Agents:** Single-responsibility agents built following agentic-ai-guide.pdf best practices. Each agent has discrete expectations and appropriate tools. Agents are registered in the existing agent platform with DIDs.

</vision>

All four are critical. This phase doesn't succeed if any of these are weak.

## Specific Ideas

- **Visualization style:** Network analysis style like Palantir or i2 Analyst Notebook — nodes and edges with filtering capabilities
- **Map integration:** Geographic visualization with layered overlays for events, actors, and objectives
- **Workspace isolation:** Country/adversary workspaces that link to each other and aggregate to global view
- **Probability display:** Show prediction probabilities with supporting evidence for transparency
- **Risk prominence:** Risk analysis should be front-and-center for commander decision support

</specifics>

The map-centered approach suggests the geographic dimension is primary for navigation and understanding. Graph exploration supplements this by showing relationship networks that may not be geographically obvious.

Agent design must follow the agentic-ai-guide.pdf patterns already established in the project — single-responsibility, single-tool agents with proper DID registration.

## Key Features

### GraphExplorer Component
- Force-directed graph using react-force-graph-2d with D3 simulation
- Interactive filtering by actor type (nation, organization, individual, non-state actor)
- Interactive filtering by relationship type (alliance, cooperation, conflict, competition, dependency)
- Search functionality to filter nodes by name
- Custom canvas rendering for nodes with color coding by type
- Custom edge rendering with strength-based line width
- Dashed lines for negative relationships
- Legend showing node colors and edge types
- Grid overlay for tactical command-center aesthetic
- Zoom and pan controls with automatic zoom-to-fit on mount
- Responsive design with mobile breakpoints at 768px
- Node hover tooltips with type badge

### NodeDetailPanel Component
- Tabbed interface (Overview, Relationships, Tensions)
- Actor details display (type, aliases, sources, attributes)
- Relationship list with direction indicators and strength bars
- Navigation to related actors via clickable links
- Tension list with intensity and domain badges
- Fetches full actor profile from /api/graph/actors/{id} endpoint

## Technical Decisions

- **react-force-graph-2d**: Chosen for force-directed layout with good performance and D3 integration
- **Canvas rendering**: Custom nodeCanvasObject and linkCanvasObject for full control over appearance
- **Color scheme**: Consistent with command-center grade styling from Phase 3
- **Filtering**: Client-side filtering for responsive interaction without API calls

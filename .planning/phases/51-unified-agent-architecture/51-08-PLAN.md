# Plan 08: Agent & Ironclaw Activity Audit Trail

## Objective

Wire 100% audit visibility into every agent and Ironclaw operation. Create a persistent activity log (PostgreSQL) with a filterable admin panel showing real-time agent/team activity across the entire system.

## Context

Two existing activity systems are limited:
- `COPAgentActivity` — COP-only, in-memory ring buffer (100 entries, lost on restart)
- `AuditLogPanel` — config changes only, not agent execution

This plan creates a **comprehensive, persistent audit trail** for ALL agent activity.

**1. SQL migration** (`036-agent-activity-log.sql`):
```sql
CREATE TABLE IF NOT EXISTS agent_activity_log (
  id SERIAL PRIMARY KEY,
  activity_id UUID NOT NULL DEFAULT gen_random_uuid(),
  agent_id TEXT NOT NULL,
  agent_name TEXT,
  team_id TEXT,
  team_name TEXT,
  problem_set_id TEXT,
  action_type TEXT NOT NULL,  -- 'llm_invocation', 'tool_call', 'delegation', 'message_received', 'message_sent', 'action_card', 'checkpoint', 'error', 'team_dispatch', 'specialist_handoff'
  action_detail TEXT,         -- human-readable description
  input_summary TEXT,         -- truncated input (first 500 chars)
  output_summary TEXT,        -- truncated output (first 500 chars)
  duration_ms INTEGER,
  status TEXT NOT NULL DEFAULT 'success',  -- 'success', 'error', 'pending', 'cancelled'
  metadata JSONB DEFAULT '{}',  -- tokens used, model, tool name, error details, etc.
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_activity_agent ON agent_activity_log(agent_id, created_at DESC);
CREATE INDEX idx_activity_team ON agent_activity_log(team_id, created_at DESC);
CREATE INDEX idx_activity_problem_set ON agent_activity_log(problem_set_id, created_at DESC);
CREATE INDEX idx_activity_type ON agent_activity_log(action_type, created_at DESC);
CREATE INDEX idx_activity_created ON agent_activity_log(created_at DESC);
```

**2. ActivityStore** (`activity-store.ts`):
- `ensureInitialized()` — run migration
- `insert(entry: Omit<ActivityEntry, 'id' | 'activityId' | 'createdAt'>): Promise<ActivityEntry>`
- `query(filter: ActivityFilter): Promise<{ entries: ActivityEntry[], total: number }>` — supports agentId, teamId, actionType, problemSetId, startDate, endDate, status, limit, offset
- `getStats(filter?: Partial<ActivityFilter>): Promise<ActivityStats>` — total count, success rate, avg duration, by-agent breakdown, by-team breakdown
- `cleanup(olderThan: Date): Promise<number>` — prune old entries
- Singleton: `getActivityStore()`

**3. AgentActivityLogger** (`activity-logger.ts`):
Convenience wrapper over ActivityStore. Singleton `getActivityLogger()`.

Methods:
- `logAgentExecution(agentId, agentName, input, output, durationMs, status, metadata?)` — action_type: 'llm_invocation'
- `logToolCall(agentId, agentName, toolName, input, output, durationMs, status)` — action_type: 'tool_call'
- `logIronclawMessage(direction: 'inbound' | 'outbound', agentId, content, problemSetId, metadata?)` — action_type: 'message_received' or 'message_sent'
- `logActionCard(agentId, actionType, riskLevel, decision, problemSetId)` — action_type: 'action_card'
- `logDelegation(agentId, targetAgentId, taskDescription, problemSetId)` — action_type: 'delegation'
- `logSupervisorDispatch(supervisorId, targetAgentId, teamId, reason)` — action_type: 'team_dispatch'
- `logSpecialistHandoff(fromAgentId, toAgentId, teamId, stage)` — action_type: 'specialist_handoff'
- `logCheckpoint(agentId, checkpointType, threadId)` — action_type: 'checkpoint'
- `logError(agentId, error, context)` — action_type: 'error'

All methods are fire-and-forget (don't await DB insert in hot path — use setImmediate or buffer).

```typescript
  const filter: ActivityFilter = {
    agentId: req.query.agentId as string,
    teamId: req.query.teamId as string,
    actionType: req.query.type as string,
    problemSetId: req.query.problemSetId as string,
    limit: parseInt(req.query.limit as string) || 50,
    offset: parseInt(req.query.offset as string) || 0,
  };
  const result = await getActivityStore().query(filter);
  res.json(result);
});

// GET /api/admin/agents/activity/stats
router.get('/agents/activity/stats', requireAuth, async (req, res) => {
  const stats = await getActivityStore().getStats({ agentId: req.query.agentId, teamId: req.query.teamId });
  res.json(stats);
});
```

```typescript
async getAgentActivity(filter: ActivityFilter): Promise<{ entries: ActivityEntry[], total: number }> {
  const params = new URLSearchParams();
  if (filter.agentId) params.set('agentId', filter.agentId);
  if (filter.teamId) params.set('teamId', filter.teamId);
  if (filter.type) params.set('type', filter.type);
  if (filter.problemSetId) params.set('problemSetId', filter.problemSetId);
  params.set('limit', String(filter.limit || 50));
  params.set('offset', String(filter.offset || 0));
  const res = await fetch(`/api/admin/agents/activity?${params}`);
  return res.json();
}

async getAgentActivityStats(filter?: { agentId?: string; teamId?: string }): Promise<ActivityStats> {
  const params = new URLSearchParams();
  if (filter?.agentId) params.set('agentId', filter.agentId);
  if (filter?.teamId) params.set('teamId', filter.teamId);
  const res = await fetch(`/api/admin/agents/activity/stats?${params}`);
  return res.json();
}
```

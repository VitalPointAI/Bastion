**Modal/dialog width audit:**
Search the entire `frontend/src/` directory for inline `width:` style props on modal/dialog/overlay components that use fixed pixel values without the `min()` guard. The correct pattern (already used in PendingDecisionModal.tsx) is:
```tsx
style={{ width: 'min(560px, 95vw)' }}
```

Known fixed-width overlay candidates to fix:
1. `COPGateNotifications.tsx` line 161: `maxWidth: '480px'` — change to `maxWidth: 'min(480px, 95vw)'`
2. `COPGateNotifications.tsx` line 331: `maxWidth: '340px'` — change to `maxWidth: 'min(340px, 95vw)'`
3. `COPResourceDetail.tsx` line 111: `width: '360px'` — change to `width: 'min(360px, 95vw)'`
4. `MissionSequencePanel.tsx` line 239: `width: collapsed ? 'auto' : '360px'` — change to `width: collapsed ? 'auto' : 'min(360px, 95vw)'`

Also run this grep to find any additional candidates missed above:
```bash
grep -rn "width.*['\"].*px['\"]" frontend/src/components/ --include="*.tsx" | grep -iv "min(" | grep -iv "calc(" | grep -iv "max-width" | grep -iv "height" | grep -iv "border" | grep -iv "gap"
```
Fix each additional occurrence by wrapping in `min(Xpx, 95vw)`. Skip small decorative elements (icons, bullets, progress bars under 50px). The `PendingDecisionModal.tsx` already uses the correct pattern — verify and skip.

**TabLayout.css — fluid tab content padding:**
Update the `.tab-content` rule (line 115-124) to use `clamp()` for responsive padding:
```css
.tab-content {
  flex: 1;
  min-width: 0;
  min-height: 0;
  display: flex;
  flex-direction: column;
  overflow-y: auto;
  overflow-x: hidden;
  padding: clamp(0.75rem, 2vw, 1.5rem);  /* was fixed 1.5rem */
}
```
This scales padding smoothly from 0.75rem (at ~375px) to 1.5rem (at ~1200px+).

**index.css — add global responsive utility:**
At the end of `index.css` (after the light mode @layer block, outside any @layer), add:
```css
/* Global responsive utilities — outside @layer so they apply unconditionally */

/* Hide scrollbar on horizontal scroll containers (used by tab bar) */
.overflow-x-auto::-webkit-scrollbar {
  display: none;
}

/* Ensure all fixed/absolute overlays respect viewport bounds */
[style*="position: fixed"],
[style*="position:fixed"] {
  max-width: 100vw;
}
```

Do NOT add any new npm dependencies. Do NOT convert existing CSS files to Tailwind. Do NOT modify any component logic — only CSS values and class additions.

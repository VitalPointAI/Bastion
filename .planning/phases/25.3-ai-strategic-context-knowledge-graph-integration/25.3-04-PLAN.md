  <action>
1. Create `backend/src/exercise/strategic-context-service.ts`:

2. **StrategicEnvironmentContext interface:**
   ```typescript
   export interface StrategicEnvironmentContext {
     graphSummaries: Record<string, GraphSummary>;  // keyed by container name
     documentSummaries: Array<{ title: string; docType: string; extractedData?: unknown; textContent?: string }>;
     tokensUsed: number;
     tokenBudget: number;
   }
   ```

3. **StrategicContextService class:**
   - Constructor takes `subscriptionStore: ProblemSetSubscriptionStore`, `containerStore: ContainerStore`, `graphSummaryService: GraphSummaryService`
   - Token estimation helper: `private estimateTokens(text: string): number { return Math.ceil(text.length / 4); }` -- per user decision, no tiktoken

4. **`async assembleContext(problemSetId: string, scenarioPhase?: string): Promise<StrategicEnvironmentContext>`:**
   - `const TOKEN_BUDGET = 8000;`
   - `let tokensUsed = 0;`

   a. Get containers for this problem set:
      - Try `containerStore.getEnvironmentByProblemSet(problemSetId)` (may return null if no environment)
      - If environment exists, get `containerStore.getContainersGroupedByCategory(env.id)`
      - Flatten to container list

   b. **Priority 1 -- Graph summaries** (highest priority per user decision):
      - For each container, call `graphSummaryService.getGraphSummary(container.id, scenarioPhase)`
      - Estimate tokens for each summary: `estimateTokens(JSON.stringify(summary))`
      - Add to `graphSummaries` dict keyed by container name, tracking tokensUsed
      - Stop adding when budget would be exceeded
      - If scenarioPhase provided, sort containers so those with temporally relevant graph content come first (larger token share)

   c. **Priority 2 -- Cached document summaries:**
      - Call `subscriptionStore.getCachedDocs(problemSetId)`
      - For each cached doc's payload, add `extractedData` first (priority per user decision)
      - Then add truncated `textContent` if budget permits
      - Track tokensUsed, stop when budget exhausted

   d. Return `{ graphSummaries, documentSummaries, tokensUsed, tokenBudget: TOKEN_BUDGET }`

5. Wrap the entire method in try/catch. On any error, log warning and return empty context `{ graphSummaries: {}, documentSummaries: [], tokensUsed: 0, tokenBudget: 8000 }` -- never crash the AI pipeline.

6. Export the class (NOT a singleton -- it's instantiated in getAIWorkspace with its dependencies injected).

2. Add `materializeCache(subscriberProblemSetId: string): Promise<void>` method to `ProblemSetSubscriptionStore`:
   - Call `this.listBySubscriber(subscriberProblemSetId)` and filter to `approvalStatus === 'approved'`
   - For each approved subscription, query `strategic_documents WHERE workspace_id = $publisherProblemSetId AND doc_type = ANY($dataTypes)` ordered by `updated_at DESC`
   - Compute `source_version` hash: `createHash('sha256').update(docs.map(d => d.updated_at.toISOString()).join('|')).digest('hex').slice(0, 16)` using Node.js built-in `crypto`
   - Check existing cache: query `problem_set_data_cache WHERE consumer_problem_set_id = $subscriber AND source_problem_set_id = $publisher LIMIT 1` and compare `source_version`. If match, skip (no re-materialization needed)
   - If version differs, delete existing cache entries for this subscriber-publisher pair, then INSERT new entries -- one per document
   - Each cache entry payload: `{ title, docType, extractedData, textContent: (text_content || '').slice(0, 2000) }` -- prioritize extracted_data (structured) over raw text per user decision
   - Set `source_version` on each entry, `cached_at = NOW()`, `stale_at = NULL`

3. Add `refreshCacheForPublisher(publisherProblemSetId: string): Promise<void>` method:
   - Query all approved subscriptions where `publisher_problem_set_id = $publisherProblemSetId`
   - For each subscriber, call `this.materializeCache(subscriberProblemSetId)`
   - This is the method pg-boss worker will call

4. Add `getCachedDocs(subscriberProblemSetId: string): Promise<Array<{ dataType: string; payload: unknown; sourceVersion: string; staleAt: Date | null }>>` method:
   - Simple SELECT from `problem_set_data_cache WHERE consumer_problem_set_id = $1 ORDER BY cached_at DESC`
   - Map snake_case rows to camelCase return type

Use `import { createHash } from 'crypto'` at the top of the file (Node.js built-in, no new dependency).

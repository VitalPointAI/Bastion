  <action>
1. Create `backend/src/exercise/graph-summary-service.ts` with:

2. **TTLCache class** (generic, in-memory):
   - `private cache = new Map<string, { data: T; expiresAt: number }>()`
   - Constructor takes `ttlMs: number`
   - `get(key): T | undefined` -- returns data if not expired, deletes and returns undefined if expired
   - `set(key, data): void` -- stores with expiresAt = Date.now() + ttlMs
   - `invalidate(key): void` -- deletes entry

3. **GraphSummary interface:**
   ```typescript
   interface GraphSummary {
     topActors: Array<{ name: string; type: string; centrality: number; temporalRelevance?: string }>;
     keyRelationships: Array<{ source: string; target: string; type: string; strength: number }>;
     activeTensions: Array<{ description: string; intensity: string; domain: string; actors: string[] }>;
     communityClusters: Array<{ actors: string[]; cohesion: number }>;
     summary: string; // Compact text summary for agent consumption
   }
   ```

4. **GraphSummaryService class:**
   - `private summaryCache = new TTLCache<GraphSummary>(5 * 60 * 1000)` (5-min TTL)
   - `async getGraphSummary(containerId: string, scenarioPhase?: string): Promise<GraphSummary | null>`:
     a. Check TTL cache with key `${containerId}:${scenarioPhase || 'none'}` -- return cached if present
     b. Call `fetchAdjacencyListByContainer(containerId)` from raft-tools
     c. If adjacency list is empty (no entities), return null
     d. Run `computeEigenvectorCentrality(adj)` to get actor centrality rankings
     e. Take top 10 actors by centrality
     f. Call `fetchTensionsByContainer(containerId)` for active tensions
     g. Extract key relationships from adjacency list (top connections by weight)
     h. Detect community clusters using simple connected-component analysis on the adjacency list (group actors that are connected, compute cohesion as internal edges / possible edges)
     i. **Temporal boosting:** If `scenarioPhase` provided, boost actors/relationships that have temporal relevance:
        - Check if actor names or relationship descriptions contain keywords from the scenario phase name
        - Actors matching current phase context get `temporalRelevance: 'active in current phase'`
        - Re-sort top actors to prioritize temporally relevant ones
     j. Build `summary` text string: a compact paragraph summarizing the top actors, key dynamics, and active tensions -- formatted for LLM consumption (not UI display)
     k. Cache the result and return

   - `invalidateContainer(containerId: string): void` -- invalidates all cached entries for this container (iterate cache keys starting with containerId)

5. **Export singleton:** `export const graphSummaryService = new GraphSummaryService()`

Import from raft-tools: `fetchAdjacencyListByContainer`, `fetchTensionsByContainer`, `computeEigenvectorCentrality`. Wrap all Neo4j calls in try/catch -- if Neo4j is unavailable, return null (graceful degradation per Pitfall 2 in RESEARCH.md).

## Accomplishments
- GraphSummaryService generates compact text summaries combining centrality-ranked actors, key relationships, active tensions, and community clusters
- Temporal boosting re-prioritizes actors and relationships relevant to the current scenario phase
- 5-minute TTL cache with prefix-based invalidation prevents repeated Neo4j queries
- REST API provides both summary retrieval and cache invalidation endpoints
- Graceful degradation returns null when Neo4j is unavailable

## Decisions Made
- Used connected-component BFS for community detection -- simpler than Louvain and appropriate for container-scoped sub-graphs which tend to be smaller
- Inferred relationship type from weight magnitude since adjacency list only carries numeric weight (cooperative >= 0.5, adversarial <= -0.5, neutral between)
- Cache key format `containerId:scenarioPhase` allows per-phase caching while prefix-based invalidation clears all cached phases for a container

## Decisions Made
- Used direct SQL query on problem_set_environments table instead of containerStore.getEnvironmentByProblemSet() to avoid auto-creating environments as a side effect of context assembly (read-only operation)

- StrategicContextService is NOT a singleton -- instantiated in getAIWorkspace with explicit dependency injection, consistent with testability patterns

<objective>
Add containerIds tagging to all graph entity types and stores, update GraphBuilder to pass containerIds through, create container-scoped graph query functions, and auto-trigger RAFT extraction when documents are assigned to containers.

Purpose: Container-scoped knowledge graphs enable graph summaries per strategic container, which feed into AI agent context. Without containerIds tagging and scoped queries, graph summaries cannot be isolated to a container's sub-graph. Auto-triggering extraction ensures the knowledge graph stays current as documents are organized into containers.
Output: Updated RAFT types/stores with containerIds, updated GraphBuilder, new fetchAdjacencyListByContainer() in raft-tools, auto-trigger hook in container document assignment.
</objective>

**`frontend/src/components/exercise/ChannelEvent.tsx`:**

Renders a single AI channel event with type-specific visual treatment. Each event type has a distinct icon, color, and layout.

Props: `{ event: AIChannelEvent; onReviewAction?: (runId: string) => void }`

Event type rendering map:
- `task_started` — blue info icon, "Started: [task name from payload.taskName]", agent name sub-label
- `task_progress` — grey progress icon, "[agent name]: [progress description from payload.description]"
- `draft_ready` — green check icon, "Draft ready for review", product type from payload.productType
- `review_required` — amber/orange alert icon, **prominent card with CTA**: "Review Required — [product type]" + "Review Now" button that calls `onReviewAction(event.runId!)`; if `payload.escalated === true` add "(Escalated — max iterations reached)"
- `revision_requested` — yellow revision icon, "Revision requested", notes from payload.notes (truncated)
- `approved` — green checkmark, "Approved and published", product type
- `rejected` — red X, "Rejected", reason from payload.reason
- `waiting_on_role` — blue hourglass, "Waiting on [payload.waitingFor]: [payload.whatNeeded]"
- `ai_to_ai_request` — purple double-arrow, "→ [payload.targetRole]: [payload.requestType]"
- `ai_to_ai_response` — purple reply, "← [payload.sourceRole]: responded"
- `error` — red error icon, "Error: [payload.message]"
- `paused` — grey pause icon, "Execution paused"
- `resumed` — grey play icon, "Execution resumed"

```tsx
import type { AIChannelEvent } from '../../types/exercise';

export function ChannelEvent({ event, onReviewAction }: ChannelEventProps) {
  const timestamp = new Date(event.createdAt).toLocaleTimeString();

      </div>
      <div className="ce-body">
        {renderEventBody(event, onReviewAction)}
      </div>
    </div>
  );
}
```

**`frontend/src/components/exercise/ChannelFeed.tsx`:**

Subscribes to SSE stream, renders scrollable event list, auto-scrolls to bottom on new events.

Props: `{ scenarioId: string; roleKey: string; activeRunId?: string; onReviewRequired: (runId: string) => void }`

State:
- `events: AIChannelEvent[]` — accumulated SSE events + initial backfill from SSE stream
- `isConnected: boolean`
- `error: string | null`

SSE subscription:
```tsx
useEffect(() => {
  const API_BASE = import.meta.env.VITE_API_URL ?? '';
  const url = `${API_BASE}/api/exercise/scenarios/${scenarioId}/roles/${roleKey}/channel`;
  const source = new EventSource(url);

  source.onmessage = (e) => {
    const event: AIChannelEvent = JSON.parse(e.data);
    setEvents(prev => {
      // Deduplicate by id in case of reconnect/backfill overlap
      if (prev.some(p => p.id === event.id)) return prev;
      return [...prev, event];
    });
  };

  source.onopen = () => setIsConnected(true);
  source.onerror = () => { setIsConnected(false); source.close(); };

  return () => source.close();
}, [scenarioId, roleKey]);
```

Auto-scroll: use a `useRef` on the bottom sentinel div with `scrollIntoView({ behavior: 'smooth' })` in a `useEffect` that fires when events.length changes.

Layout:
```tsx
<div className="channel-feed">
  <div className="cf-header">
    <span className="cf-title">Activity</span>
    <span className={`cf-status ${isConnected ? 'cf-connected' : 'cf-disconnected'}`}>
      {isConnected ? '●' : '○'}
    </span>
  </div>
  <div className="cf-event-list" ref={listRef}>
    {events.length === 0 && (
      <div className="cf-empty">Waiting for agent activity...</div>
    )}
    {events.map(event => (
      <ChannelEvent
        key={event.id}
        event={event}
        onReviewAction={onReviewRequired}
      />
    ))}
    <div ref={bottomRef} />
  </div>
</div>
```

  <name>Task 1: Create validation type system</name>
  <files>backend/src/validation/validation-types.ts</files>
  <action>
Create `backend/src/validation/validation-types.ts` with all domain types for the validation framework. Use const objects (not enums) per project erasableSyntaxOnly convention.

Define these const objects and corresponding types:
- `ValidationCategory` = { determinism, reliability, authority }
- `ValidationStatus` = { passing, warning, critical, disabled, unknown }
- `CircuitState` = { closed, warning, open }
- `ScoringMethod` = { structured_diff, semantic_similarity, both }
- `AttackType` = { privilege_escalation, scope_creep, unauthorized_action }
- `ExpectedBehavior` = { refuse, escalate, scope_limit }
- `TriggerType` = { scheduled, manual }
- `CircuitEventType` = { disabled, reinstated, override, warning, fallback_activated }
- `ThresholdScope` = { global, category, agent, team }

Define these interfaces:
- `TestScenario` — id, name, category (ValidationCategory), input (messages array + optional context record), expected (structuredOutput?, freeTextReference?, requiredCitations?, requiredTerminology?, forbiddenActions?, maxAutonomyLevel?), scoringMethod, weight (0-1)
- `AdversarialScenario` — id, name, attackType, input (messages array), expectedBehavior
- `TestFixture` — agentId, agentRole, version, lastReviewedAt (ISO string), scenarios (TestScenario[]), adversarialScenarios (AdversarialScenario[]), runCount (configurable repeats for determinism), metadata (Record)
- `AssertionResult` — name, passed (boolean), expected (string), actual (string), details? (string)
- `EvaluationResult` — functionalScore (0-1), llmJudgeScore (0-1), combinedScore (0-1), disagreement (boolean), functionalDetails (AssertionResult[]), llmJudgeRationale (string)
- `TestRunRow` — id (uuid), triggered_by (string), started_at (ISO), completed_at? (ISO), total_agents (number), total_scenarios (number), status ('running'|'completed'|'failed')
- `TestResultRow` — id, run_id, agent_id, scenario_id, category, functional_score?, llm_judge_score?, combined_score?, disagreement (boolean), input_snapshot (Record), output_snapshot (Record), expected_snapshot (Record), details? (Record), created_at
- `ValidationAgentScoreRow` — id, run_id, agent_id, category, avg_score, min_score, max_score, scenario_count, status (ValidationStatus), created_at
- `CircuitBreakerEventRow` — id, agent_id, category, event_type (CircuitEventType), previous_state, new_state, triggered_by, justification?, run_id?, details? (Record), created_at
- `ThresholdConfigRow` — id, scope_type (ThresholdScope), scope_id? (string), category, warning_threshold, critical_threshold, grace_period_runs, immediate_disable (boolean), updated_by, updated_at
- `EvaluatorDriftRow` — id, run_id, calibration_scenario_id, expected_score, actual_score, drift_magnitude, created_at

Also export utility type `ValidationDashboardSummary` — agentId, agentName, agentRole, overallStatus (ValidationStatus), categories (Record of ValidationCategory to { avgScore, status, trend (number[]) }), lastRunAt? (ISO), scenarioCount

<task type="auto">
  <name>Task 2: Create validation store and threshold config</name>
  <files>backend/src/validation/validation-store.ts, backend/src/validation/threshold-config.ts</files>
  <action>
Create `backend/src/validation/validation-store.ts` — a class `ValidationStore` following existing store patterns (ai-staff-store.ts as reference).

Constructor calls `ensureTable()` which creates all 6 tables if not exist using the SQL schema from RESEARCH.md (validation_runs, validation_results, validation_agent_scores, validation_circuit_events, validation_thresholds, validation_evaluator_drift). Include all indexes from RESEARCH.md.

Methods (all async, use getPool()):
- `ensureTable()` — CREATE TABLE IF NOT EXISTS for all 6 tables + indexes
- `createRun(triggeredBy: string): Promise<TestRunRow>` — INSERT into validation_runs
- `completeRun(runId: string, status: 'completed'|'failed', totalAgents: number, totalScenarios: number): Promise<void>` — UPDATE completed_at, status, totals
- `insertResult(result: Omit<TestResultRow, 'id'|'created_at'>): Promise<TestResultRow>` — INSERT into validation_results
- `insertAgentScore(score: Omit<ValidationAgentScoreRow, 'id'|'created_at'>): Promise<void>` — INSERT into validation_agent_scores
- `getAgentScoreHistory(agentId: string, category: string, limit?: number): Promise<ValidationAgentScoreRow[]>` — SELECT ordered by created_at DESC
- `getLatestAgentScores(agentId: string): Promise<ValidationAgentScoreRow[]>` — latest score per category
- `getAllLatestScores(): Promise<ValidationAgentScoreRow[]>` — latest scores for all agents (for dashboard grid)
- `getRunResults(runId: string): Promise<TestResultRow[]>` — all results for a run
- `getRecentRuns(limit?: number): Promise<TestRunRow[]>` — recent runs ordered by started_at DESC
- `insertCircuitEvent(event: Omit<CircuitBreakerEventRow, 'id'|'created_at'>): Promise<void>` — INSERT
- `getCircuitEvents(agentId: string, limit?: number): Promise<CircuitBreakerEventRow[]>` — ordered by created_at DESC
- `getThresholds(scopeType?: string, scopeId?: string): Promise<ThresholdConfigRow[]>` — SELECT with optional filters
- `upsertThreshold(threshold: Omit<ThresholdConfigRow, 'id'|'updated_at'>): Promise<void>` — INSERT ON CONFLICT UPDATE
- `insertEvaluatorDrift(drift: Omit<EvaluatorDriftRow, 'id'|'created_at'>): Promise<void>` — INSERT
- `getDashboardSummaries(): Promise<ValidationDashboardSummary[]>` — aggregation query joining agent_scores with agent registry info, returns last 20 data points as trend array per category

Export a singleton: `export const validationStore = new ValidationStore();`

Create `backend/src/validation/threshold-config.ts`:
- `getThresholdForAgent(agentId: string, category: ValidationCategory): Promise<{ warningThreshold: number; criticalThreshold: number; gracePeriodRuns: number; immediateDisable: boolean }>` — implements scope hierarchy: agent-specific > team > category > global. Falls back to hardcoded defaults (warning: 0.7, critical: 0.5, grace: 3, immediateDisable: true for authority / false for others).
- `seedDefaultThresholds(): Promise<void>` — inserts global defaults if none exist (idempotent, ON CONFLICT DO NOTHING)

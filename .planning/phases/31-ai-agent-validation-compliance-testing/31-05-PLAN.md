First, install recharts: run `cd frontend && pnpm add recharts` (per RESEARCH.md, only new dependency needed).

Create `frontend/src/lib/validation-service.ts`:
- Class `ValidationService` following existing frontend service patterns (e.g., admin-service.ts).
- Private `fetch(path, options?)` method that adds credentials: 'include' and X-DID header from stored DID (follow existing service class patterns).
- Methods mapping to each API endpoint:
  - `getDashboard()` -> GET /api/validation/dashboard
  - `getRecentRuns(limit?)` -> GET /api/validation/runs
  - `getRunDetails(runId)` -> GET /api/validation/runs/:runId
  - `triggerRun()` -> POST /api/validation/runs
  - `getAgentScores(agentId, category?, limit?)` -> GET /api/validation/agents/:id/scores
  - `getCircuitEvents(agentId, limit?)` -> GET /api/validation/agents/:id/circuit-events
  - `getThresholds(scopeType?, scopeId?)` -> GET /api/validation/thresholds
  - `updateThreshold(data)` -> PUT /api/validation/thresholds
  - `reinstateAgent(agentId, justification?)` -> POST /api/validation/agents/:id/reinstate
  - `exportCSV(agentId?, from?, to?)` -> GET /api/validation/export/csv (returns blob)
  - `exportPDF(agentId?, from?, to?)` -> GET /api/validation/export/pdf (returns blob)
- Export singleton: `export const validationService = new ValidationService();`

Create `frontend/src/components/admin/ValidationDashboard.tsx`:
- Main dashboard component. State: selectedAgent (null or agentId), summaries (from getDashboard()), recentRuns, loading.
- useEffect fetches dashboard data on mount. Poll every 30 seconds.
- **Main view (no agent selected):**
  - Header: "Agent Validation & Compliance" with "Run Validation" button (triggers manual run, shows spinner while running)
  - Summary stats bar: total agents, passing (green count), warning (yellow count), critical (red count), disabled (gray count)
  - Agent grid: CSS grid (3 cols on xl, 2 on lg, 1 on md). Each cell is a `<ValidationAgentCard>`.
  - Below grid: `<ValidationRunLog>` showing recent runs
- **Drill-down view (agent selected):**
  - Back button to return to grid
  - `<ValidationDrillDown>` for the selected agent
  - `<CircuitBreakerPanel>` for the selected agent
- Tailwind classes for layout. Use dark card backgrounds consistent with existing admin panel styles.

Create `frontend/src/components/admin/ValidationAgentCard.tsx`:
- Props: ValidationDashboardSummary + onClick handler
- Card layout with:
  - Top row: AgentHealthDot (overall status color), agent name, agent role badge
  - Middle: three sparklines (one per category: determinism, reliability, authority) using Recharts `<LineChart>` with `<Line>` component inside `<ResponsiveContainer width={80} height={24}>`. Per-category trend data from summary. Color-code: blue=determinism, green=reliability, purple=authority.
  - Bottom row: last run timestamp, scenario count
- Hover effect: slight scale + shadow. Click opens drill-down.

Create `frontend/src/components/admin/ValidationDrillDown.tsx`:
- Props: agentId
- Fetches agent scores via validationService.getAgentScores(agentId)
- Fetches thresholds via validationService.getThresholds('agent', agentId) with fallback to category-level
- Time range selector: 7d / 30d / 90d
- Three Recharts `<LineChart>` panels (one per category), each inside `<ResponsiveContainer width="100%" height={300}>`:
  - X axis: date
  - Y axis: 0-1 score range
  - `<Line>` for avg_score
  - `<ReferenceLine>` for warning threshold (yellow, dashed)
  - `<ReferenceLine>` for critical threshold (red, dashed)
  - `<CartesianGrid>`, `<Tooltip>` with score details
- Below charts: expandable test run detail log (last 20 runs for this agent) showing input/output/scores per scenario

- Import zod (already installed). Define `FixtureSchema` as a zod schema matching TestFixture interface. Validate at load time.
- `loadAllFixtures(): Promise<TestFixture[]>` — reads `backend/src/validation/fixtures/` directory, parses each .json file, validates with FixtureSchema, returns array. Logs warnings for invalid files (doesn't throw — skips invalid).
- `loadFixture(roleKey: string): Promise<TestFixture | null>` — loads single fixture by filename `{roleKey}.json`.

- Export FixtureSchema for external use.

Create `backend/src/validation/fixture-generator.ts`:
- Import the agent library definitions from `backend/src/exercise/agent-library.ts` to read StaffAgentDef entries.
- Export `generateFixture(agentDef: StaffAgentDef): TestFixture` — generates a baseline fixture from an agent definition:
  1. Creates 3 golden prompt scenarios using the agent's focus, systemPromptHint, and roleKey:
     - Scenario 1 (determinism): "Standard {role} task" — a typical request within the agent's focus area. Uses scoringMethod appropriate to role (semantic_similarity for free-text, structured_diff for structured output, both for mixed).
     - Scenario 2 (reliability): "Doctrinal response for {role}" — requests output that should cite relevant doctrine. Sets requiredCitations based on role (JP 3-0 for J3, JP 2-0 for J2, etc — include a mapping of roleKey to primary doctrine pub).

  2. Creates 2 adversarial scenarios:
     - privilege_escalation: attempts to get agent to make decisions above its authority
     - scope_creep: attempts to get agent to work outside its assigned focus
  3. Sets runCount: 5 for high-stakes roles (commander, sja, fires, j2, j3), 3 for others.
  4. Sets version "1.0.0-generated", lastReviewedAt to current date, metadata with "generated: true".

- Export `generateAllMissingFixtures(): Promise<{ generated: string[]; skipped: string[] }>` — reads fixtures directory, compares against all roleKeys from agent-library.ts, generates and writes .json files for any missing roles. Returns which were generated and which already existed.

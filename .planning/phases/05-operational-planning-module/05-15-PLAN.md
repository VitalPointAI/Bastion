<objective>
Fix Vite proxy configuration to work in Docker containers

Purpose: The Planning Dashboard fails to load in Docker because the Vite proxy uses `localhost:3001` which doesn't work inside containers. Containers use their own network namespace where `localhost` refers to the container itself, not the host machine. The backend service is accessible via the container name `backend` on the Docker network.

Output: Environment-aware Vite proxy that uses `http://backend:3001` in Docker and falls back to `http://localhost:3001` for local development.
</objective>

  <name>Task 1: Update Vite config to use environment variable for proxy target</name>
  <files>frontend/vite.config.ts</files>
  <action>
Update the Vite proxy configuration to read the backend URL from `process.env.VITE_BACKEND_URL` with a fallback to `http://localhost:3001` for local development.

Current proxy config (lines 14-18):
```typescript
proxy: {
  '/api': {
    target: 'http://localhost:3001',
    changeOrigin: true,
  },
},
```

Update to:
```typescript
proxy: {
  '/api': {
    target: process.env.VITE_BACKEND_URL || 'http://localhost:3001',
    changeOrigin: true,
  },
},
```

Note: Vite config runs in Node.js context during dev server startup, so `process.env` is available. This is NOT a browser-side env var (which would need `import.meta.env`), this is a build-time/server-time configuration.
  </action>

<task type="auto">
  <name>Task 2: Update docker-compose.yml with correct backend URL for Docker networking</name>
  <files>docker-compose.yml</files>
  <action>
Update the frontend service environment to use the Docker network URL instead of localhost.

Current environment (line 103):
```yaml
environment:
  - VITE_BACKEND_URL=http://localhost:3001
```

Update to:
```yaml
environment:
  - VITE_BACKEND_URL=http://backend:3001
```

Explanation: In Docker Compose, services can reach each other using the service name as hostname. The frontend container needs to reach the backend container, so it must use `backend:3001` (the service name defined in docker-compose.yml), not `localhost:3001`.
  </action>

```typescript
import type { ConceptEntry } from './concept-types.js';
```

1. **`getLearnedContextBlock(userDid: string, problemSetId: string | null, messageContent: string, timeoutMs: number = 400): Promise<string>`:**
   - Wrap entire function in a race against timeout (same pattern as assembleMemoryBlock):
     ```typescript
     const timeoutPromise = new Promise<string>((resolve) =>
       setTimeout(() => resolve(''), timeoutMs),
     );
     return Promise.race([timeoutPromise, this._doRetrieval(userDid, problemSetId, messageContent)]);
     ```
   - `_doRetrieval` does the actual work:
     a. Generate embedding for messageContent via `generateConceptEmbedding(messageContent)`
     b. If embedding is null (OPENAI_API_KEY missing), return ''
     c. Call `conceptStore.semanticSearch(embedding, userDid, problemSetId, 5)`
     d. Filter results to similarity > 0.3 (discard irrelevant matches)
     e. For each concept, format as a bullet:
        ```
        - {concept_key} (confidence: {confidence}, v{version}): {value.text}
        ```
     f. If concept has version > 1, add evolution note:
        ```
        [Evolution: v1 → v{version}]
        ```
     g. Assemble into block:
        ```
        [LEARNED CONTEXT]
        {bullets}
        [/LEARNED CONTEXT]
        ```
     h. Hard-cap at 500 tokens (~2000 characters). Truncate with '...' if exceeded.
     i. Return '' if no concepts match (don't inject empty block)
   - Wrap in try/catch returning '' on any error (never block message flow)

2. **Export singleton:**
   ```typescript
   class ConceptRetrievalService { ... }
   export const conceptRetrievalService = new ConceptRetrievalService();
   ```

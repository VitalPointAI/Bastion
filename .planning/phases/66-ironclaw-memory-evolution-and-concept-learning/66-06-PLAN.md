2. **`runConsolidation(): Promise<void>`:**
   - Get all concept keys with 2+ active versions from different threads:
     ```typescript
     const candidates = await conceptStore.getConsolidationCandidates(null); // null = all problem sets
     ```
   - For each candidate:
     a. Fetch full version chain: `conceptStore.getVersionChain(candidate.userDid, candidate.conceptKey, problemSetId)`
     b. Get only active versions (filter by status === 'active')
     c. If 2+ active versions exist from different source_thread_ids:
        - Build LLM merge prompt using `@anthropic-ai/sdk` Haiku:
          ```
          You are synthesizing multiple versions of the same concept from different conversations.

          Concept key: {conceptKey}
          Versions:
          {versions.map(v => `v${v.version} (thread ${v.sourceThreadId}): ${JSON.stringify(v.currentValue)}`).join('\n')}

          Instructions:
          1. If versions AGREE: Synthesize into a single comprehensive understanding. Set confidence to the highest version's confidence + 0.05 (capped at 1.0).
          2. If versions CONTRADICT: Set status to "contradicted" in your response. Include both perspectives. Set confidence to 0.5.

          Return JSON:
          { "value": "synthesized understanding", "confidence": 0.0-1.0, "contradicted": true|false }
          ```
        - Parse LLM response
        - If contradicted: log warning, set concept status to indicate contradiction (store a 'contradicted' field in the value JSONB: `{ text: "...", contradicted: true, perspectives: [...] }`)
        - Upsert new consolidated version:
          ```typescript
          await conceptStore.upsertConcept({
            problemSetId,
            userDid: candidate.userDid,
            conceptKey: candidate.conceptKey,
            conceptType: latestVersion.conceptType,
            value: { text: mergedValue, contradicted: isContradicted },
            confidence: mergedConfidence,
            sourceThreadId: 'consolidation',
            embedding: await generateConceptEmbedding(mergedValue),
          });
          ```
   - Log summary: `[ironclaw] consolidation: processed N candidates, M consolidated, K contradictions`

3. **`startConsolidationJob(): void`:**
   ```typescript
   export function startConsolidationJob(): void {
     console.log('[ironclaw] starting concept consolidation job (6h interval)');
     // Run once on startup after 5-minute delay (let system stabilize)
     setTimeout(() => {
       runConsolidation().catch(err => console.error('[ironclaw] consolidation error:', err));
     }, 5 * 60 * 1000);
     // Then every 6 hours
     setInterval(() => {
       runConsolidation().catch(err => console.error('[ironclaw] consolidation error:', err));
     }, CONSOLIDATION_INTERVAL_MS);
   }
   ```

4. **Export:**

**Per D-03:** Fire extraction on ALL THREE triggers: idle timeout (5 minutes), thread switch, drawer close.

1. **Add extraction trigger function:**
   ```typescript
   const triggerExtraction = useCallback((threadId: string) => {
     if (!threadId || !problemSetId) return;
     // Fire-and-forget
     fetch(`/api/ironclaw/${problemSetId}/extract`, {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({ threadId }),
     }).catch(() => {}); // Silent failure
   }, [problemSetId]);
   ```

2. **Idle timeout (5 minutes no messages):**
   Add an idle timer ref:
   ```typescript
   const idleTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
   ```

   After every message sent (in the sendMessage handler), reset the timer:
   ```typescript
   // Reset idle extraction timer
   if (idleTimerRef.current) clearTimeout(idleTimerRef.current);
   if (currentThreadId) {
     idleTimerRef.current = setTimeout(() => {
       triggerExtraction(currentThreadId);
     }, 5 * 60 * 1000); // 5 minutes
   }
   ```

   Clean up timer on unmount in the useEffect cleanup.

3. **Thread switch trigger:**
   In the `selectThread` function (or wherever thread switching occurs), before switching to the new thread, trigger extraction on the PREVIOUS thread:
   ```typescript
   // Extract from previous thread before switching
   if (currentThreadId && currentThreadId !== threadId) {
     triggerExtraction(currentThreadId);
   }
   ```
   Clear the idle timer when switching threads.

4. **Drawer close / session end trigger:**

   ```typescript
   // Extract from current thread on drawer close

   }
   ```

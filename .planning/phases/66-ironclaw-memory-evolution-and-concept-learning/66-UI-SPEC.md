## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (`px-1.5 py-0.5`) |
| sm | 8px | Compact element spacing, button padding (`px-3 py-1`) |
| md | 16px | Default element spacing, panel horizontal padding (`px-4`) |
| lg | 24px | Section padding, empty state vertical padding (`py-6`) |
| xl | 32px | Layout gaps between major panel regions |
| 2xl | 48px | Major section breaks (not used in drawer panels) |
| 3xl | 64px | Page-level spacing (not applicable inside drawer) |

Exceptions:
- Drawer panels use `py-2.5` (10px) for card vertical padding — this is the established `IronclawMemoryPanel` and `IronclawActivityFeed` card rhythm; maintain for visual consistency with existing panels.
- Card inner gap uses `gap-3` (12px) — established pattern in `IronclawMemoryPanel`; maintain for new concept cards.
- Thumbs rating buttons must have a minimum touch target of 44px via padding (`p-2.5` + icon size `w-5 h-5`).

Source: codebase inspection of `IronclawMemoryPanel.tsx` and `IronclawActivityFeed.tsx`

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 12px (text-xs) | 400 (regular) | 1.4 (leading-snug) |
| Label / Meta | 10px (text-[10px]) | 400 (regular) | 1.5 |
| Badge / Micro | 9px (text-[9px]) | 700 (bold, uppercase + tracking-wider) | 1 |
| Section heading | 14px (text-sm) | 600 (semibold) | 1.25 |

Notes:
- 12px body at weight 400, line-height 1.4 is the established pattern for all Ironclaw panel content (`text-xs text-slate-300 leading-snug` in `IronclawActivityFeed`).
- Section headings at 14px weight 600 for concept titles and panel headers (matching `text-sm font-medium text-slate-200` in `IronclawMemoryPanel`).
- Badge text at 9px all-caps uppercase with `tracking-wider font-bold` — established severity and source badge pattern; apply to concept type badges.
- No display size used inside the drawer panels; headings cap at 14px.

Source: codebase inspection of `IronclawMemoryPanel.tsx`, `IronclawActivityFeed.tsx`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (slate-900) | Panel background (`bg-slate-900/50`), message areas |
| Secondary (30%) | `#1e293b` (slate-800) | Cards (`bg-slate-800/60`), header strips (`bg-slate-800/40`) |
| Accent (10%) | `#f59e0b` (amber-400) | Decision links, contradiction alert indicators |
| Destructive | `#ef4444` (red-400) | Retract concept action, delete memory, delete all |

Accent reserved for:
- Decision link text (`text-amber-400`) — concept contradiction "Resolve" CTA
- Contradiction status badge background (`bg-amber-900/60 border-amber-700/60 text-amber-300`) — matching existing URGENT severity style
- Version evolution chevron/arrow connectors in history viewer

Destructive color reserved for:
- "Retract Concept" button hover state (`hover:text-red-400`)
- Delete confirmation inline banner (`bg-red-900/20 border border-red-700/40`)
- Retracted status badge (`bg-red-900/40 text-red-400`)

Semantic palette extensions (new for Phase 66):

## Component Inventory

### New Components (Phase 66)

#### IronclawConceptsPanel (Plan 66-06)

A new tab panel inside the existing `IronclawDrawer` tab strip, parallel to the existing "Memory" and "Activity" tabs.

**Tab label:** "Knowledge" (not "Concepts" — more commander-accessible language)

**Layout:** Vertical flex column inside the drawer's scrollable panel area.

**Subregions:**

1. **Filter bar** — horizontal row of concept type filter pills (all, actor, situation, assessment, preference, lesson, intent, relationship, directive). Active pill: `bg-slate-700 text-slate-200`. Inactive pill: `text-slate-500 hover:text-slate-400`. Pill height: 24px, `text-[10px] uppercase tracking-wider font-semibold`.

2. **Concept card list** — scrollable, uses same `gap-3 px-4 py-3` rhythm as `IronclawMemoryPanel`. Each concept card:
   - Background: `bg-slate-800/60 border border-slate-700/60 rounded-lg px-3 py-2.5`
   - Header row: concept_key (14px semibold, `text-slate-200`) + concept type badge (9px, color per semantic palette above) + version indicator (`v{N}`, `text-[9px] text-slate-500 font-mono`) + confidence percentage (`text-[10px] text-slate-500`) + relative time
   - Value preview: first 120 characters of value text, `text-xs text-slate-300 leading-snug`, truncated with `...`
   - Expand/collapse chevron icon (16px inline SVG) — same pattern as `IronclawMemoryPanel`
   - When expanded: full value text + version history button ("View history", `text-[10px] text-amber-400`) + retract button (`text-slate-600 hover:text-red-400`)
   - Contradiction badge: amber CONTRADICTED badge visible if `status === 'contradicted'`, with "Resolve" link text in amber-400
   - Consolidated version indicator: emerald "Consolidated" badge when `source_thread_id === 'consolidation'`

3. **Version history drawer** (inline expand, not a modal) — appears below the concept card when "View history" is clicked:
   - Timeline list, oldest to newest, each entry: version number + thread reference + date + value excerpt
   - Current version highlighted with left border accent `border-l-2 border-amber-400`
   - Superseded versions: `text-slate-500 line-through` value, `text-[9px] SUPERSEDED` badge in slate
   - Retracted versions: `text-red-400 text-[9px] RETRACTED` badge

4. **Empty state** (no concepts):
   - Icon: brain/lightbulb SVG (24px, `text-slate-700`)
   - Heading: "No concepts learned yet"
   - Body: "As you work with Ironclaw, it will extract key knowledge from your conversations and store it here."

#### IronclawDirectivesPanel (Plan 66-09)

A sub-panel accessible from the existing "Config" tab in the Ironclaw drawer (via `AgentConfigPanel`), or as a dedicated section within `AgentConfigPanel`.

**Section label:** "Commander Priorities" inside a settings accordion/section.

**Layout:** Vertical list of directive entries + "Add Priority" input row at the bottom.

**Directive entry row:**
- Text description: `text-xs text-slate-300 leading-snug flex-1`
- Remove button: `text-slate-600 hover:text-red-400` trash icon (14px inline SVG)
- Drag handle (optional, Phase 66 discretion): `text-slate-600` gripper dots icon, only if reordering is implemented

**"Add Priority" input:**
- Text input: `bg-slate-800/60 border border-slate-700/60 rounded px-3 py-1.5 text-xs text-slate-200 placeholder:text-slate-500 focus:border-slate-500 outline-none w-full`
- Submit button: "Add" — `px-3 py-1 text-[10px] font-semibold rounded bg-slate-700 hover:bg-slate-600 text-slate-200 transition-colors`
- Placeholder: "e.g. Prioritize Baltic naval movements over economic data"

**Empty state:** "No priorities set. Add a priority to guide Ironclaw's focus." — `text-xs text-slate-500 italic`

#### Activity Feed — Outcome Rating Extension (Plan 66-07)

Extends existing `IronclawActivityFeed` `ActivityCard` component. Add a rating row below the `summary` text:

**Rating row layout:** `flex items-center gap-2 mt-1.5`

- Thumbs-up button: SVG thumb-up icon (16px), `text-slate-600 hover:text-emerald-400 transition-colors p-1 rounded` — when rated positive: `text-emerald-400 bg-emerald-900/20`
- Thumbs-down button: SVG thumb-down icon (16px), `text-slate-600 hover:text-red-400 transition-colors p-1 rounded` — when rated negative: `text-red-400 bg-red-900/20`
- Notes input (appears inline on first rating click): `text-[10px] text-slate-400 placeholder:text-slate-600 bg-transparent border-b border-slate-700 outline-none flex-1` — placeholder "Optional note..."
- Only show rating row for activities older than 30 seconds (prevents rating in-flight actions)

## Interaction Contracts

### Concept Card Expand/Collapse

- Chevron rotates 180deg on expand: `transition-transform duration-200`
- Expansion is immediate (no async) — value is already in component state
- Only one version history viewer open at a time per panel (accordion behavior)
- Keyboard: `Enter` / `Space` on chevron button toggles expansion

### Version History Inline Expand

- Appears as an indented list below the card, not a modal
- Animate height: use `max-h-0 overflow-hidden` → `max-h-96` with `transition-all duration-200`
- Each history entry is read-only except the "Retract" action on the current version

### Concept Retract Flow

1. User clicks trash/retract icon on current version
2. Inline confirmation banner appears (same `bg-red-900/20 border border-red-700/40 rounded-lg px-3 py-2.5` pattern as IronclawMemoryPanel delete-all)
3. User confirms "Retract" or cancels
4. On confirm: optimistic removal of card from list, API call, revert on error
5. No page reload — list re-renders in place

### Activity Outcome Rating

1. Thumbs up/down buttons visible on each activity card
2. On click: button immediately fills to rated state (optimistic)
3. Notes input appears inline below thumbs (focus auto-captured)
4. Notes submit on blur or Enter key
5. On API error: revert thumb state, show inline error `text-[10px] text-red-400`

### Commander Priority Directives

1. User types in "Add Priority" input, presses Enter or clicks "Add"
2. New directive appears at top of list immediately (optimistic)
3. On API error: remove optimistic entry, show inline error
4. Delete: click trash icon → optimistic remove → 3-second undo window (snackbar pattern)
5. No drag-to-reorder in Phase 66 (deferred)

### Filter Pills (Concepts Panel)

- Filter is client-side only (no new API calls on filter change)
- Active filter: `bg-slate-700 text-slate-200 border border-slate-600`
- "All" pill selected by default
- Multiple simultaneous filters: not supported in Phase 66 (single-select)

## Accessibility Notes

- All icon-only buttons must carry `aria-label` attributes (established pattern in `IronclawMemoryPanel`)
- Thumbs up/down: `aria-label="Mark as helpful"` / `aria-label="Mark as not helpful"` + `aria-pressed` toggled on rate
- Concept type filter pills: `role="group"` on container, `aria-pressed` on each pill
- Retract confirmation: focus trap to confirmation inline banner while open
- Version history inline: `aria-expanded` on toggle button
- Contradiction badge: `role="status"` with descriptive text for screen readers

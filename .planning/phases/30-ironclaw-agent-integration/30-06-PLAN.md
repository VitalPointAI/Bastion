**ironclaw-service.ts:**

Class `IronclawApi` with methods (follows existing service class pattern like ai-staff-service.ts -- use credentials: 'include' for cookie auth, X-DID header for DID identification):

- `async sendMessage(problemSetId: string, content: string, mentionedAgent?: string): Promise<void>` -- POST to `/api/ironclaw/${problemSetId}/message` with JSON body { content, mentionedAgent }. Response is 202 (streaming via WebSocket). Include credentials: 'include'.

- `async getHistory(problemSetId: string, limit?: number): Promise<IronclawChatMessage[]>` -- GET to `/api/ironclaw/${problemSetId}/history?limit=${limit}`. Parse response JSON. Transform snake_case to camelCase. Include credentials: 'include'.

- `async confirmAction(problemSetId: string, actionId: string, decision: TrustDecision): Promise<ActionResult>` -- POST to `/api/ironclaw/${problemSetId}/confirm` with JSON body { actionId, decision }. Returns parsed ActionResult.

- `async getTrustPreferences(problemSetId: string): Promise<TrustPreference[]>` -- GET to `/api/ironclaw/trust-preferences?problemSetId=${problemSetId}`.

- `async revokeTrust(preferenceId: string): Promise<void>` -- DELETE to `/api/ironclaw/trust-preferences/${preferenceId}`.

- `async checkHealth(): Promise<boolean>` -- GET to `/api/ironclaw/health`. Returns response.healthy.

Helper: `snakeToCamelMessage(row: Record<string, unknown>): IronclawChatMessage` -- transforms snake_case DB row to camelCase frontend type.

Export singleton: `export const ironclawApi = new IronclawApi();`

**useIronclaw.ts:**

Hook `useIronclaw(problemSetId: string | null)` returns:
```typescript
{
  messages: IronclawChatMessage[];
  isOpen: boolean;
  isLoading: boolean;
  isConnected: boolean;
  hasUnread: boolean;
  openDrawer: () => void;
  closeDrawer: () => void;
  toggleDrawer: () => void;
  sendMessage: (content: string, mentionedAgent?: string) => Promise<void>;
  handleActionDecision: (actionId: string, decision: TrustDecision) => Promise<void>;
}
```

Implementation:
- State: messages (IronclawChatMessage[]), isOpen (boolean), isLoading (boolean), isConnected (boolean), hasUnread (boolean, set true when new message arrives while drawer closed).
- On mount (when problemSetId is non-null): fetch history via ironclawApi.getHistory. Connect to WebSocket channel `ironclaw.${problemSetId}` using existing WebSocket connection pattern (window.location.hostname + port 3001 -- same as NotificationPanel).
- WebSocket message handler: parse incoming IronclawChatMessage, append to messages state. If drawer closed, set hasUnread true. If message contains stepProgress, update the existing message's stepProgress (find by action_id).
- sendMessage: set isLoading true, call ironclawApi.sendMessage, set isLoading false on WebSocket response. Optimistically add user message to messages state.
- handleActionDecision: call ironclawApi.confirmAction, update the relevant message's actionCard to show it's been decided (set disabled).
- openDrawer: set isOpen true, set hasUnread false.
- Cleanup: close WebSocket on unmount or problemSetId change.

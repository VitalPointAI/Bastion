Import { Octokit } from '@octokit/rest'.

Class `GitHubService`:
- Private octokit: Octokit instance created with auth from process.env.GITHUB_TOKEN.
- Private owner/repo: extracted from process.env.GITHUB_REPO (format "owner/repo", default "vitalpointai/bastion").

**Methods:**

`async createPR(params: { title: string; description: string; branchName: string; files: Array<{ path: string; content: string }>; baseBranch?: string }): Promise<{ prNumber: number; prUrl: string; summary: string }>`:
1. Get base branch SHA (default 'master') via octokit.rest.git.getRef.
2. Create new branch via octokit.rest.git.createRef with name `ironclaw/${params.branchName}`.
3. For each file: get current file blob (if exists) via octokit.rest.repos.getContent, create blob via octokit.rest.git.createBlob, build tree entries.
4. Create tree via octokit.rest.git.createTree with base_tree from base branch.
5. Create commit via octokit.rest.git.createCommit.
6. Update branch ref to point to new commit.
7. Create PR via octokit.rest.pulls.create with title, body (description), head (branch), base.
8. Return PR number, URL, and summary string: "PR #{number}: {title} ({fileCount} files changed) - {prUrl}".

Error handling: if branch creation succeeds but PR fails, clean up the branch via octokit.rest.git.deleteRef. Log all operations.

`async getPRStatus(prNumber: number): Promise<{ state: string; mergeable: boolean | null; ciStatus: string; checks: Array<{ name: string; status: string; conclusion: string | null }> }>`:
1. Get PR via octokit.rest.pulls.get.
2. Get check runs via octokit.rest.checks.listForRef with the PR head SHA.
3. Aggregate: overall CI status is 'success' if all checks pass, 'failure' if any fail, 'pending' if any pending.
4. Return state, mergeable, ciStatus, and individual checks.

`async getDeploymentStatus(sha: string): Promise<{ status: string; environment: string; url?: string } | null>`:
1. List deployments via octokit.rest.repos.listDeployments with sha.
2. If any, get latest deployment status via octokit.rest.repos.listDeploymentStatuses.
3. Return latest status or null.

`async handleEmergencyMerge(prNumber: number): Promise<{ merged: boolean; sha: string; deploymentStarted: boolean }>`:
1. Merge PR via octokit.rest.pulls.merge with merge_method 'squash'.
2. Poll CI status for merged SHA (max 5 minutes, check every 30 seconds).
3. If CI fails within monitoring window, create revert PR automatically:
   - Create branch `ironclaw/revert-${prNumber}`.
   - Use octokit.rest.repos.merge to attempt a revert.
   - Create PR titled "Revert: Emergency PR #{prNumber} - CI failed".
4. Return merge result.

`isConfigured(): boolean` -- Returns true if GITHUB_TOKEN is set. Allows graceful degradation when GitHub isn't configured.

Export singleton: `export const githubService = new GitHubService();`

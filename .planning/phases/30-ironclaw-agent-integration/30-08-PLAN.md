Create `backend/src/ironclaw/self-update-service.ts`.

Class `SelfUpdateService`:

Private state:
- currentVersion: string | null (read from Ironclaw health endpoint or env var IRONCLAW_VERSION)
- pollIntervalMs: 6 * 60 * 60 * 1000 (6 hours)
- pollTimer: NodeJS.Timeout | null
- isUpdating: boolean

**Methods:**

`async start(): Promise<void>`:
1. Fetch current version from Ironclaw health endpoint (ironclawClient.healthCheck could be extended, or do a direct GET to /version).
2. Store as currentVersion.
3. Start polling timer with setInterval at pollIntervalMs.
4. Log "Self-update service started, current version: {version}, polling every 6 hours".

`async stop(): Promise<void>`:
1. Clear poll timer if set.
2. Log "Self-update service stopped".

`async checkForUpdate(): Promise<{ available: boolean; latestVersion?: string; releaseNotes?: string }>`:
1. Fetch latest release from GitHub API: `https://api.github.com/repos/nearai/ironclaw/releases/latest`. Use native fetch (no Octokit needed for public API).
2. Parse response: tag_name as version, body as release notes.
3. Compare with currentVersion (simple string comparison -- semver-aware would be better but avoid adding a dependency).
4. If tag_name !== currentVersion: return { available: true, latestVersion: tag_name, releaseNotes: body truncated to 500 chars }.
5. Otherwise return { available: false }.
6. Catch errors gracefully (network issues, rate limiting) -- log warning and return { available: false }.

`async performUpdate(notifyProblemSetId?: string): Promise<{ success: boolean; oldVersion: string; newVersion: string; error?: string }>`:
1. Set isUpdating = true.
2. Notify system admin by adding a system message to Ironclaw chat (if notifyProblemSetId provided): "Ironclaw update detected: {oldVersion} -> {newVersion}. Beginning update..."
3. Drain active sessions: call ironclawClient with a drain request (if supported), or simply wait 30 seconds for in-flight requests to complete. Log "Draining active sessions...".
4. Execute Docker container restart via shell command: `docker compose -f docker-compose.prod.yml pull ironclaw && docker compose -f docker-compose.prod.yml up -d ironclaw`. Use child_process.exec wrapped in a promise. Set timeout of 120 seconds.
5. Wait for health check to pass (poll ironclawClient.healthCheck every 5 seconds, max 60 seconds).
6. If health check passes: update currentVersion, notify admin with changelog summary: "Ironclaw updated to {newVersion}. Changes: {releaseNotes}".
7. If health check fails within 60 seconds: attempt rollback by running `docker compose -f docker-compose.prod.yml up -d ironclaw` with the previous image tag. Notify admin: "Update to {newVersion} failed. Rolled back to {oldVersion}."
8. Set isUpdating = false.

`private async notifyAdmin(content: string): Promise<void>`:
- Find system admin's most recent Ironclaw session from ironclaw_sessions table.
- Add message as 'ironclaw' sender with content to that session's problem_set_id.
- Also publish to WebSocket channel so admin sees it in real-time.

`getStatus(): { currentVersion: string | null; isUpdating: boolean; lastChecked: Date | null }`:
Return current state for health endpoint.

Export singleton: `export const selfUpdateService = new SelfUpdateService();`

Create `backend/src/ironclaw/audit-anchor-service.ts`.

Import { createHash } from 'crypto' (Node built-in). Import ironclawStore.

Class `AuditAnchorService`:

Private state:
- batchSize: 100 (anchor every 100 actions)
- batchIntervalMs: 60 * 60 * 1000 (1 hour)
- intervalTimer: NodeJS.Timeout | null

**Methods:**

`async start(): Promise<void>`:
1. Start interval timer at batchIntervalMs.
2. Log "Audit anchor service started, batch every {batchSize} actions or {batchIntervalMs/60000} minutes".

`async stop(): Promise<void>`:
1. Clear interval timer.

`async checkAndAnchor(): Promise<{ anchored: boolean; actionCount?: number; merkleRoot?: string }>`:
1. Get latest anchor from ironclawStore.getLatestAnchor().
2. Determine since: if anchor exists, use anchor.batch_end. Otherwise use epoch (all actions).
3. Get unanchored actions from ironclawStore.getUnanchoredActions(since).
4. If count < batchSize AND not triggered by interval timer: return { anchored: false } (wait for more actions).
5. If count === 0: return { anchored: false }.
6. Compute Merkle root:
   - Hash each action: SHA-256 of JSON.stringify({ id, action_type, action_payload, user_did, decision, created_at }).
   - Build binary Merkle tree from leaf hashes: pair and hash recursively. If odd number, duplicate last hash.
   - Result is the root hash (hex string).
7. Create anchor record via ironclawStore.createAnchor({ batch_start: first action's created_at, batch_end: last action's created_at, action_count: count, merkle_root: root hash, tx_hash: null, anchored_at: null }).
8. Submit to NEAR blockchain: use existing NEAR connection pattern from the project. Call a simple contract method to store the Merkle root. For now, log a TODO comment: "// TODO: Submit Merkle root to NEAR contract -- requires contract method for audit anchoring. For now, log the anchor." Log the anchor details.
9. If blockchain submission succeeds (when implemented), update anchor with tx_hash and anchored_at.
10. Return { anchored: true, actionCount: count, merkleRoot: root hash }.

`computeMerkleRoot(hashes: string[]): string`:
- If empty, return hash of empty string.
- If single, return it.
- Recursively pair hashes and combine: SHA-256(hash1 + hash2).
- If odd count, duplicate last hash.
- Return root.

`hashAction(action: ActionLogEntry): string`:
- Return SHA-256 hex of canonical JSON (sorted keys): JSON.stringify({ id, action_type, action_payload, user_did, decision, created_at }, Object.keys({ id: '', action_type: '', action_payload: '', user_did: '', decision: '', created_at: '' }).sort()).

`async anchorEmergencyAction(action: ActionLogEntry): Promise<void>`:
- Per discretion recommendation: emergency actions anchored immediately (not batched).
- Compute single-action Merkle root (just the hash of the action).
- Create anchor with action_count: 1.
- Submit immediately to blockchain (same TODO as above).

Export singleton: `export const auditAnchorService = new AuditAnchorService();`

Update `backend/src/ironclaw/index.ts` barrel to re-export selfUpdateService and auditAnchorService.

  <name>Task 1: Ironclaw type system and action risk classification</name>
  <files>backend/src/ironclaw/ironclaw-types.ts, backend/src/ironclaw/index.ts</files>
  <action>
Create `backend/src/ironclaw/ironclaw-types.ts` with all type definitions for the Ironclaw integration. Use const objects (not enums) per project erasableSyntaxOnly convention.

Define these types:

1. **Chat message types** - `IronclawChatMessage` with fields: id (string), problem_set_id (string), content (string), sender ('user' | 'ironclaw' | 'specialist'), specialist_id (string | null), specialist_display_name (string | null), delegated_by (string | null -- always 'ironclaw' for specialist messages), action_card (ActionCardData | null), step_progress (StepProgressData | null), created_at (string).

2. **Action system types** - `IronclawAction` with fields: id (string), type (string -- action type key like 'ps.read', 'code.create_pr'), description (string), payload (Record<string, unknown>), problem_set_id (string), requested_by (string -- user DID). `ActionCardData` with fields: action_id (string), action_type (string), description (string), risk_level (ActionRiskLevel), options ('yes' | 'no' | 'always')[]. `StepProgressData` with fields: action_id (string), steps (StepInfo[]), current_step (number), started_at (string). `StepInfo` with fields: label (string), status ('pending' | 'running' | 'complete' | 'failed'), started_at (string | null), completed_at (string | null).

3. **Risk classification** - const `ActionRiskLevel` = { low: 'low', medium: 'medium', high: 'high' } as const, type from const. const `ACTION_RISK` mapping action type strings to risk levels: 'ps.read' -> low, 'ps.list_children' -> low, 'ps.update_field' -> medium, 'ps.create_child' -> medium, 'ps.configure_agents' -> medium, 'resource.create' -> medium, 'resource.update' -> medium, 'resource.delete' -> high, 'code.create_pr' -> high, 'code.emergency_deploy' -> high, 'system.update_config' -> high, 'gate.create' -> medium.

4. **Trust preference types** - `TrustPreference` with fields: id (string), user_did (string), problem_set_id (string), action_type (string), granted_at (string). `TrustDecision` = 'yes' | 'no' | 'always'.

5. **Action log types** - `ActionLogEntry` with fields: id (string), problem_set_id (string), user_did (string), action_type (string), action_payload (Record<string, unknown>), risk_level (ActionRiskLevel), decision ('approved' | 'denied' | 'auto_approved' | 'gate_pending'), gate_id (string | null), result (Record<string, unknown> | null), error (string | null), emergency (boolean), justification (string | null), created_at (string).

6. **Audit anchor types** - `AuditAnchor` with fields: id (string), batch_start (string), batch_end (string), action_count (number), merkle_root (string), tx_hash (string | null), anchored_at (string | null), created_at (string).

7. **Session types** - `IronclawSession` with fields: id (string), problem_set_id (string), user_did (string), ironclaw_session_id (string | null -- Ironclaw's internal session ID), created_at (string), last_active_at (string).

8. **Rate limit config** - const `RATE_LIMITS` with per-risk-level limits: low: 60/minute, medium: 10/minute, high: 3/minute, code_pr: 5/hour.

Create `backend/src/ironclaw/index.ts` as barrel that re-exports everything from ironclaw-types.ts. Will add more re-exports in subsequent plans.

<task type="auto">
  <name>Task 2: Ironclaw PostgreSQL store and Docker sidecar config</name>
  <files>backend/src/ironclaw/ironclaw-store.ts, docker-compose.prod.yml, docker-compose.yml</files>
  <action>
Create `backend/src/ironclaw/ironclaw-store.ts` following the exact pattern from `ai-staff-store.ts` (singleton class, getPool() import, ensureTable(), row mappers).

**Tables to create in ensureTable():**

1. `ironclaw_sessions` - id UUID PK, problem_set_id TEXT NOT NULL, user_did TEXT NOT NULL, ironclaw_session_id TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), last_active_at TIMESTAMPTZ DEFAULT NOW(). Index on (problem_set_id, user_did). UNIQUE on (problem_set_id, user_did).

2. `ironclaw_chat` - id UUID PK, problem_set_id TEXT NOT NULL, content TEXT NOT NULL, sender TEXT NOT NULL DEFAULT 'user' (values: 'user', 'ironclaw', 'specialist'), specialist_id TEXT, specialist_display_name TEXT, delegated_by TEXT, action_card JSONB, step_progress JSONB, created_at TIMESTAMPTZ DEFAULT NOW(). Index on problem_set_id. Index on (problem_set_id, created_at).

3. `ironclaw_trust_preferences` - id UUID PK, user_did TEXT NOT NULL, problem_set_id TEXT NOT NULL, action_type TEXT NOT NULL, granted_at TIMESTAMPTZ DEFAULT NOW(). UNIQUE on (user_did, problem_set_id, action_type).

4. `ironclaw_action_log` - id UUID PK, problem_set_id TEXT NOT NULL, user_did TEXT NOT NULL, action_type TEXT NOT NULL, action_payload JSONB NOT NULL, risk_level TEXT NOT NULL DEFAULT 'medium', decision TEXT NOT NULL, gate_id UUID, result JSONB, error TEXT, emergency BOOLEAN NOT NULL DEFAULT FALSE, justification TEXT, created_at TIMESTAMPTZ DEFAULT NOW(). Index on problem_set_id. Index on user_did. Index on created_at for anchoring queries.

5. `ironclaw_audit_anchors` - id UUID PK, batch_start TIMESTAMPTZ NOT NULL, batch_end TIMESTAMPTZ NOT NULL, action_count INTEGER NOT NULL, merkle_root TEXT NOT NULL, tx_hash TEXT, anchored_at TIMESTAMPTZ, created_at TIMESTAMPTZ DEFAULT NOW().

**CRUD methods:**

Session: getOrCreateSession(problemSetId, userDid) -> IronclawSession (upsert, updates last_active_at), getSession(problemSetId, userDid) -> IronclawSession | null.

Chat: addMessage(msg: Omit<IronclawChatMessage, 'id' | 'created_at'>) -> IronclawChatMessage, getHistory(problemSetId, limit=100) -> IronclawChatMessage[] (ordered ASC by created_at).

Trust: grantTrust(userDid, problemSetId, actionType) -> TrustPreference (ON CONFLICT DO NOTHING), revokeTrust(userDid, problemSetId, actionType) -> void, getTrustPreference(userDid, problemSetId, actionType) -> TrustPreference | null, getAllTrustPreferences(userDid, problemSetId) -> TrustPreference[].

Action log: logAction(entry: Omit<ActionLogEntry, 'id' | 'created_at'>) -> ActionLogEntry, getUnanchoredActions(since: string) -> ActionLogEntry[] (WHERE created_at > since ORDER BY created_at ASC).

Audit anchors: createAnchor(anchor: Omit<AuditAnchor, 'id' | 'created_at'>) -> AuditAnchor, getLatestAnchor() -> AuditAnchor | null (ORDER BY batch_end DESC LIMIT 1).

Export singleton: `export const ironclawStore = new IronclawStore();`

Update barrel `index.ts` to re-export from ironclaw-store.ts.

- volumes: ironclaw-data:/home/ironclaw/.ironclaw
- networks: internal only (no ports exposed to host)
- depends_on: postgres

Add IRONCLAW_URL=http://ironclaw:3000 and GITHUB_TOKEN=${GITHUB_TOKEN} to backend service environment.
Add depends_on ironclaw to backend service.
Add ironclaw-data to volumes section.

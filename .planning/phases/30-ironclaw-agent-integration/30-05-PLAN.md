**frontend/src/types/ironclaw.ts:**

Frontend type definitions (camelCase, mirroring backend snake_case). Duplicated per project convention (no shared package, backend authoritative):

```typescript
export type IronclawSender = 'user' | 'ironclaw' | 'specialist';
export type ActionRiskLevel = 'low' | 'medium' | 'high';
export type TrustDecision = 'yes' | 'no' | 'always';
export type StepStatus = 'pending' | 'running' | 'complete' | 'failed';

export interface IronclawChatMessage {
  id: string;
  problemSetId: string;
  content: string;
  sender: IronclawSender;
  specialistId?: string;
  specialistDisplayName?: string;
  delegatedBy?: string;
  actionCard?: ActionCardData;
  stepProgress?: StepProgressData;
  createdAt: string;
}

export interface ActionCardData {
  actionId: string;
  actionType: string;
  description: string;
  riskLevel: ActionRiskLevel;
  options: TrustDecision[];
}

export interface StepProgressData {
  actionId: string;
  steps: StepInfo[];
  currentStep: number;
  startedAt: string;
}

export interface StepInfo {
  label: string;
  status: StepStatus;
  startedAt?: string;
  completedAt?: string;
}

export interface SuggestionData {
  id: string;
  content: string;
  agentId: string;
  agentDisplayName: string;
  actionType?: string;
}

export interface TrustPreference {
  id: string;
  actionType: string;
  problemSetId: string;
  grantedAt: string;
}
```

**IronclawMessage.tsx:**
Props: { message: IronclawChatMessage }. Renders a chat bubble:
- User messages: right-aligned, blue/indigo background, "You" label.
- Ironclaw messages: left-aligned, dark background, "Ironclaw" label with a small shield/robot icon.
- Specialist messages: left-aligned, slightly different background (slate), shows specialist_display_name as label with an agent icon, small "via Ironclaw" subtitle text.
- If message has actionCard, render IronclawActionCard inline below the message text.
- If message has stepProgress, render IronclawStepStream inline below the message text.
- Timestamp shown as relative time (e.g., "2m ago").
- Use Tailwind classes. No separate CSS file needed for this component.

**IronclawActionCard.tsx:**
Props: { card: ActionCardData, onDecision: (actionId: string, decision: TrustDecision) => void, disabled?: boolean }.
- Yellow/amber border card with action description text.
- Risk level badge: green for low, yellow for medium, red for high.
- Three buttons: "Approve" (green), "Deny" (red), "Always Allow" (blue outline). If risk is 'high', omit "Always Allow" button (high-risk actions never auto-approve per locked decision).
- Buttons call onDecision with appropriate decision value.
- disabled prop grays out buttons (for already-decided actions).

**IronclawSuggestion.tsx:**
Props: { suggestion: SuggestionData, onAccept: (id: string) => void, onDismiss: (id: string) => void }.
- Blue-tinted card with suggestion content.
- Agent attribution line: "Suggested by {agentDisplayName}".
- Two buttons: "Accept" (green) and "Dismiss" (gray).
- Appears inline in chat as a special message type.

**IronclawStepStream.tsx:**

- Time elapsed shown at bottom: "Started {relative_time}".
- Uses Tailwind. Compact design to fit in chat bubble.

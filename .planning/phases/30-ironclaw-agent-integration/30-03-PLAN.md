Create `backend/src/ironclaw/action-pipeline.ts`.

Import gateService from '../gates/index.js' and ironclawStore from './ironclaw-store.js' and actionRegistry from './action-registry.js'.

Interface `ActionResult`:
- status: 'executed' | 'confirm_required' | 'gate_created' | 'denied' | 'rate_limited'
- result?: Record<string, unknown> (for executed actions)
- action_card?: ActionCardData (for confirm_required)
- gate_id?: string (for gate_created)
- error?: string
- retry_after?: number (for rate_limited, in seconds)

Class `ActionPipeline`:

`async processAction(action: IronclawAction, userDid: string): Promise<ActionResult>`:
1. Rate limit check via actionRegistry.checkRateLimit. If not allowed, log action with decision 'denied' and return { status: 'rate_limited', retry_after }.
2. Get risk level via actionRegistry.getRiskLevel(action.type).
3. Check trust preference via ironclawStore.getTrustPreference(userDid, action.problem_set_id, action.type).
4. Decision logic:
   - If trust exists AND risk is NOT 'high': log action with decision 'auto_approved', return { status: 'executed' }. (Caller must actually execute the action -- pipeline just decides.)
   - If risk is 'high': ALWAYS create Decision Gate regardless of trust. Use gateService.createGate with gate_type extended to 'agent_action' (cast as needed), target_item_id = action.id, target_item_type = 'ironclaw_action', target_item_title = action.description, enforcement = 'hard_block'. Log action with decision 'gate_pending' and gate_id. Return { status: 'gate_created', gate_id }.
   - Otherwise (no trust, low/medium risk): return { status: 'confirm_required', action_card: { action_id: action.id, action_type: action.type, description: action.description, risk_level, options: ['yes', 'no', 'always'] } }.

`async handleConfirmation(actionId: string, userDid: string, problemSetId: string, decision: TrustDecision): Promise<ActionResult>`:
1. If decision === 'no': log action with decision 'denied', return { status: 'denied' }.
2. If decision === 'always': grant trust via ironclawStore.grantTrust, then fall through to execute.
3. If decision === 'yes' or 'always': log action with decision 'approved', return { status: 'executed' }.

`async handleEmergencyAction(action: IronclawAction, userDid: string, justification: string): Promise<ActionResult>`:
1. Verify user has system_admin role (check via action.payload or separate role check -- leave as a TODO comment noting that role verification should be done by the caller/router).
2. Log action with decision 'auto_approved', emergency: true, justification.
3. Return { status: 'executed' }.

Export singleton: `export const actionPipeline = new ActionPipeline();`

Update `index.ts` barrel to re-export actionRegistry and actionPipeline.

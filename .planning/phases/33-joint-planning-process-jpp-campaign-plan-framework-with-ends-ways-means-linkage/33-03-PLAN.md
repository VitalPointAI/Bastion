6. `get_loes_from_design` -- Fetch LOEs from Operational Design (Design tab) for a problem set -- these are the input to COA Development

Each tool: MCPToolInput with name, description, Zod inputSchema. Handler functions call jppStore methods. Import jppStore lazily (it may not exist at tool registration time -- use dynamic import or assume store is available at call time).

For `get_loes_from_design`, call designService or query operational_design table for the problem set's LOE data. This bridges Design tab output to JPP input.

1. `create_ewm_linkage` -- Create a linkage (endObjectiveId, wayId, wayType, meanId, meanType, allocationPct)

3. `get_ewm_linkages` -- Get all linkages for a JPP instance
4. `find_ewm_gaps` -- Run gap analysis and return EWMGap[]
5. `update_ewm_allocation` -- Update allocation percentage on a linkage
6. `get_ewm_summary` -- Aggregate view: count of ends, ways, means, linkages, gaps

Export both toolDefinitions arrays and toolHandlers objects.

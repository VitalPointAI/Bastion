<task type="auto">
  <name>Task 2: JPP store and E-W-M store with gap analysis</name>
  <files>backend/src/jpp/jpp-store.ts, backend/src/jpp/ewm-store.ts</files>
  <action>
Create two PostgreSQL stores following the singleton + ensureTable() pattern from planStore/coaStore.

**jpp-store.ts (JPPStore):**
- `ensureTable()`: CREATE TABLE IF NOT EXISTS jpp_instances (id TEXT PK, problem_set_id TEXT NOT NULL, parent_jpp_id TEXT, echelon TEXT NOT NULL DEFAULT 'operational', current_step TEXT NOT NULL DEFAULT 'planning_initiation', step_statuses JSONB NOT NULL DEFAULT '{}', status TEXT NOT NULL DEFAULT 'active', created_by TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW()); CREATE INDEX on problem_set_id. Also create jpp_step_products table (id TEXT PK, jpp_instance_id TEXT NOT NULL, step TEXT NOT NULL, role_id TEXT, content JSONB DEFAULT '{}', ai_drafted_by TEXT, reviewed_by TEXT, status TEXT DEFAULT 'draft', created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ); CREATE INDEX on (jpp_instance_id, step).
- `createInstance(data)`: INSERT with ON CONFLICT DO NOTHING. Initialize step_statuses with all 7 steps as 'not_started'.
- `getInstance(id)`: SELECT by id
- `getInstanceByProblemSet(problemSetId)`: SELECT by problem_set_id (returns first active, auto-creates if none exists following project pattern)
- `updateStepStatus(instanceId, step, status)`: UPDATE step_statuses JSONB field, set updated_at
- `getStepProducts(instanceId, step)`: SELECT from jpp_step_products WHERE jpp_instance_id AND step
- `saveStepProduct(product)`: UPSERT (ON CONFLICT (id) DO UPDATE)
- `getChildInstances(parentJppId)`: For parent->child JPP inheritance
- Export singleton: `export const jppStore = new JPPStore();`

**ewm-store.ts (EWMStore):**
- `ensureTable()`: CREATE TABLE IF NOT EXISTS ewm_linkages (id TEXT PK, jpp_instance_id TEXT NOT NULL, end_objective_id TEXT NOT NULL, way_id TEXT NOT NULL, way_type TEXT NOT NULL, mean_id TEXT, mean_type TEXT, allocation_pct REAL DEFAULT 0, created_at TIMESTAMPTZ DEFAULT NOW()); Indexes on jpp_instance_id, end_objective_id, way_id.
- `createLinkage(data)`: INSERT
- `deleteLinkage(id)`: DELETE
- `getLinkagesByInstance(jppInstanceId)`: SELECT all for a JPP instance
- `getEnds(jppInstanceId)`: Distinct end_objective_id values with linked way count
- `getWays(jppInstanceId)`: Distinct way_id values with linked end and mean counts
- `getMeans(jppInstanceId)`: Distinct mean_id values with linked way count and total allocation
- `findGaps(jppInstanceId)`: Query that identifies: (a) objectives with zero linked ways, (b) ways with zero linked ends, (c) means with zero linked ways, (d) means where total allocation_pct > 100. Return as EWMGap[].
- `updateAllocation(linkageId, allocationPct)`: UPDATE allocation_pct
- Export singleton: `export const ewmStore = new EWMStore();`

Both stores import pool from '../../db/pool.js' (or whatever the project's DB pool path is -- check planStore for the exact import).

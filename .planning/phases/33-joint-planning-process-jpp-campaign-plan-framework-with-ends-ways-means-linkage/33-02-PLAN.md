<task type="auto">
  <name>Task 2: Argus webhook endpoint with HMAC verification and entity auto-linking</name>
  <files>backend/src/api/osint-webhook.ts</files>
  <action>
Create backend/src/api/osint-webhook.ts as an Express router.

**Endpoint: POST /api/osint/webhook/argus**
1. Read ARGUS_WEBHOOK_SECRET from process.env (default empty string -- if empty, skip signature check for dev)
2. If secret is set, verify HMAC-SHA256: compute crypto.createHmac('sha256', secret).update(JSON.stringify(req.body)).digest('hex'), compare against X-Argus-Signature header. Return 401 if mismatch.
3. Transform Argus payload to OSINTEventInput format:
   - title: req.body.title
   - description: req.body.summary || req.body.description
   - sourceType: 'news'
   - sourceUrl: req.body.url
   - sourceName: 'Argus'
   - publishedAt: req.body.publishedAt || new Date().toISOString()
   - actors: req.body.entities || []
   - tags: req.body.tags || []
   - rawContent: req.body.content || ''
4. Store via osintEventStore.create(event)
5. For each actor name in req.body.entities (if any), call entityToolHandlers.search_entities({ query: actorName, fuzzy: true }). If match confidence >= 0.9, auto-link via osintToolHandlers.link_event_to_objective (if objectives reference that entity). If confidence < 0.9, store as pending review (add to event metadata).
6. Return 200 { eventId, status: 'received' }

**Endpoint: GET /api/osint/feeds/:problemSetId**
- Return feed configs for the problem set via osintFeedStore.getFeedsByProblemSet

**Endpoint: POST /api/osint/feeds**
- Create feed config via osintFeedStore.createFeed(req.body)

Export router as osintWebhookRouter. Register in the main API router file (check where other routers are registered -- likely backend/src/api/index.ts or similar).

**CrossWorkspaceLayerToggle.tsx:**

A panel rendered adjacent to the Overview tab's validity map (above or as sidebar). Shows approved subscriptions as toggle switches.

1. Props: `{ workspaceId: string }`
2. State: `enabledLayers: Set<string>` (workspace IDs whose data is visible), `subscriptions` (loaded from service)
3. On mount, fetch subscriptions via `workspaceService.getSubscriptions(workspaceId, userDID)`. Filter to `approvalStatus === 'approved'` from `asSubscriber`.
4. Render each approved subscription as a row:
   - Workspace name (from subscription data or display publisherWorkspaceId)
   - Data types badge pills (decide, monitor, etc.)
   - Toggle switch: `<input type="checkbox" checked={enabledLayers.has(sub.publisherWorkspaceId)} onChange={...} />`
   - Style: `flex items-center justify-between py-2 border-b border-gray-700`
5. Empty state: "No cross-workspace subscriptions. Request access from workspace commanders."
6. Compact design: max-height with overflow-auto, dark theme
7. Export `enabledLayers` state via a callback prop `onLayersChange?: (enabledIds: string[]) => void` so parent can pass to validity map.

**TabNotificationDropdown.tsx:**

Inline dropdown that opens from a tab badge click.

1. Props: `{ tab: string; updates: CrossWorkspaceUpdate[]; onClose: () => void; onAction: (update: CrossWorkspaceUpdate) => void }`
2. Filter `updates` to those matching `tab`
3. Render as absolute-positioned dropdown below the tab button:
   - `absolute top-full left-0 w-80 bg-gray-800 border border-gray-700 rounded-lg shadow-xl z-50`
4. Each update item:
   - Source workspace name (bold)
   - Update type badge: directive (red), data_change (blue), escalation (yellow)
   - Summary text (truncated)
   - Timestamp (relative: "2 min ago")
   - Click → calls `onAction(update)` (parent navigates to relevant content)
5. "Mark all as read" button at bottom → calls `clearTabNotifications(tab)` + `onClose()`
6. Click outside (or backdrop) → `onClose()`
7. Empty state: "No updates for this tab"

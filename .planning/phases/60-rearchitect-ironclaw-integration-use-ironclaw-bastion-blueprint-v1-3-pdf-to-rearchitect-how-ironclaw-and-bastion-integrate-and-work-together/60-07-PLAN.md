  <name>Task 1: Create ironclaw-admin routes and enhance self-update service</name>
  <files>backend/src/api/routes/ironclaw-admin.ts, backend/src/ironclaw/self-update-service.ts</files>
  <action>
**ironclaw-admin.ts (new route file):**
- Export `ironclawAdminRouter` (Express Router).
- `POST /api/admin/ironclaw-update` — Admin-only endpoint. Triggers Ironclaw container update by calling `selfUpdateService.triggerUpdate()`. Requires admin auth check (use existing admin middleware pattern). Returns 200 with `{ status: 'update-initiated', version: newVersion }`.
- `POST /api/admin/ironclaw-webhook/github-release` — GitHub webhook endpoint for release events. Validates `X-Hub-Signature-256` header using a configured webhook secret (`GITHUB_WEBHOOK_SECRET` env var). On valid `release.published` event, stores the release info and notifies admin (in-app notification) that an update is available. Does NOT auto-update — per blueprint, updates are admin-confirmed only. Returns 200.
- `GET /api/admin/ironclaw-status` — Returns Ironclaw health status, current version, last update check, available update (if any). Calls `selfUpdateService.getStatus()`.
- Mount in main app with admin auth prefix.

**self-update-service.ts modifications:**
- The existing service polls for GitHub releases. Enhance it to:
  - Add `handleReleaseWebhook(payload: GitHubReleasePayload): void` — stores new release info, sets `updateAvailable` flag.
  - Add `triggerUpdate(): Promise<{ success: boolean; version: string }>` — executes `docker pull` + `docker-compose up -d ironclaw` sequence. This is the admin-confirmed update path. Log the operation to audit trail.
  - Add `getStatus(): IronclawStatus` — returns `{ healthy: boolean; version: string; lastCheck: Date; updateAvailable: boolean; availableVersion: string | null; }`.
  - Keep the existing polling as a fallback (if webhook is not configured, polling still works).
  - Store the webhook secret safely: read from `process.env.GITHUB_WEBHOOK_SECRET`, NOT in docker-compose env (add to .env.example only).
  </action>

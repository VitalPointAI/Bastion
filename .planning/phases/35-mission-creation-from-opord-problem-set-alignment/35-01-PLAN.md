Table auto-creation in `ensureTable()` method (called in constructor via `getPool().query()`):
```sql
CREATE TABLE IF NOT EXISTS mission_assignments (
  id TEXT PRIMARY KEY,
  source_opord_ps_id TEXT NOT NULL REFERENCES problem_sets(id),
  target_problem_set_id TEXT NOT NULL REFERENCES problem_sets(id) UNIQUE,
  task_ids TEXT[] NOT NULL,
  task_statement TEXT NOT NULL,
  purpose TEXT NOT NULL,
  commanders_intent JSONB,
  task_organization JSONB,
  constraints JSONB,
  ccirs JSONB,
  roe_references TEXT[],
  area_of_operations JSONB,
  timeline JSONB,
  warno_drafted BOOLEAN DEFAULT FALSE,
  created_by TEXT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_mission_assignment_source ON mission_assignments(source_opord_ps_id);
CREATE INDEX IF NOT EXISTS idx_mission_assignment_target ON mission_assignments(target_problem_set_id);
```

Also run: `ALTER TABLE problem_sets ADD COLUMN IF NOT EXISTS metadata JSONB DEFAULT '{}';`

Methods:
- `createMissionAssignment(input)` -- INSERT, returns MissionAssignment. Generate id with `MA-${randomUUID()}`.
- `getAssignmentsBySource(sourceOpordPsId)` -- SELECT WHERE source_opord_ps_id = $1
- `getAssignmentByTarget(targetProblemSetId)` -- SELECT WHERE target_problem_set_id = $1
- `markWarnoAsDrafted(id)` -- UPDATE warno_drafted = true WHERE id = $1
- `setMissionMetadata(problemSetId, metadata: MissionMetadata)` -- UPDATE problem_sets SET metadata = $2 WHERE id = $1
- `getMissionMetadata(problemSetId)` -- SELECT metadata FROM problem_sets WHERE id = $1

Map snake_case DB rows to camelCase MissionAssignment in a private `mapRow()` method.

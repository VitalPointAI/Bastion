**MissionGroupEditor.tsx:**

Props:
```typescript
interface MissionGroupEditorProps {
  tasks: OPORDSubordinateTask[];
  groups: MissionGroup[];
  onTasksChange: (tasks: OPORDSubordinateTask[]) => void;
  onGroupsChange: (groups: MissionGroup[]) => void;
  onCreateMission: (group: MissionGroup) => void;  // Opens confirm modal
  problemSetId: string;
}
```

Layout: Two-column layout.
- LEFT: "Ungrouped Tasks" -- list of tasks where `missionGroupId === null`. Each task card shows unitName, task excerpt, purpose excerpt.
- RIGHT: "Mission Groups" -- list of MissionGroup panels. Each panel has editable name field, list of assigned tasks, assigned unit display, status badge (draft/created).

Drag interaction:
- Use HTML5 drag and drop (no external library needed):
  - Task cards have `draggable={true}`, `onDragStart` sets `dataTransfer` with task ID
  - Mission group panels have `onDragOver` (preventDefault) and `onDrop` (reads task ID, updates missionGroupId, adds to group.taskIds)
  - "Ungrouped" column also accepts drops (removes from group, clears missionGroupId)
- Support ongoing editing: tasks can be moved between groups or back to ungrouped
- When task is dragged to a group: update task's `missionGroupId`, add task ID to group's `taskIds`
- When task is dragged back to ungrouped: clear `missionGroupId`, remove from group's `taskIds`

Group actions:
- "New Group" button creates empty MissionGroup with auto-name "Mission {N+1}"
- Each group has "Delete Group" button (returns tasks to ungrouped) -- only for draft groups
- Each group has "Create Mission" button -- calls `onCreateMission(group)` -- disabled if group has 0 tasks or status is 'created'
- Created groups show link to child PS instead of create button

Visual: Use existing Tailwind patterns from the codebase. Group panels with border, task cards with drag handle icon. Drop target highlight on dragover. Status badge: draft=yellow, created=green.

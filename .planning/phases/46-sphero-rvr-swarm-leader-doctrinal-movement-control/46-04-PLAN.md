# Phase 46 Plan 04: Backend Swarm Types, Coordination Service & REST API

## Goal
Add swarm type definitions, telemetry handling, DAO-driven membership management, and COP integration to the backend TypeScript layer. Expose swarm state via REST endpoints.

## Tasks

### Task 1: Backend Swarm Types
**File:** `backend/src/robot/robot-types.ts`

1. Extend `MissionJSONSchema` command enum with: `swarm_patrol`, `swarm_recon`, `swarm_advance`
2. Add WS message types: `swarm_telemetry`, `swarm_add_resource`, `swarm_remove_resource`
3. Add const objects: `SwarmFormationType`, `SwarmState`, `ResourceType`
4. Add interfaces:
   - `SwarmMemberHeartbeat`: robot_id, role, position, heading, battery_pct, slot_index
   - `SwarmTelemetryMsg`: swarm_id, leader_id, state, formation, member_count, members, center_of_mass
   - `SwarmAddResourceMsg`: robot_id, resource_type, did, capabilities, dao_proposal_id
   - `SwarmRemoveResourceMsg`: robot_id, reason, dao_proposal_id
5. Add `SwarmTelemetryMsg` to `RobotWsMessage` union type

### Task 2: Swarm Telemetry Handler
**File:** `backend/src/robot/robot-mission-service.ts`

1. Add `swarmStates` map (keyed by swarm_id)
2. Add `swarm_telemetry` case to message router
3. Implement `handleSwarmTelemetry()`:
   - Store latest swarm state
   - Forward **each swarm member's position** to COP resource layer via `ResourceTelemetryService`
   - Publish to message bus (`swarm:telemetry` channel) for UI consumers
4. Add query methods: `getSwarmState(swarmId)`, `getActiveSwarms()`

### Task 3: DAO-Driven Membership API
**File:** `backend/src/robot/robot-mission-service.ts`

1. `sendSwarmAddResource(leaderId, robotId, resourceType, did, capabilities, daoProposalId)` — forward `swarm:add_resource` to leader's WebSocket
2. `sendSwarmRemoveResource(leaderId, robotId, reason, daoProposalId)` — forward `swarm:remove_resource` to leader's WebSocket

### Task 4: Pre-Flight Swarm Capability
**File:** `backend/src/robot/robot-mission-service.ts`

Add `swarm_leader` capability requirement to `commandCapabilityMap` for all 3 swarm commands.

### Task 5: Intent Translator Update
**File:** `backend/src/robot/robot-mission-service.ts`

Add swarm commands, formation types, and movement techniques to the intent translator system prompt.

### Task 6: REST API Endpoints
**File:** `backend/src/api/robot-routes.ts`

1. `GET /swarms` — list all active swarms
2. `GET /swarms/:swarmId` — get specific swarm state
3. `POST /swarms/:leaderId/add-resource` — DAO directive to add resource
4. `POST /swarms/:leaderId/remove-resource` — DAO directive to remove resource

### Task 7: Barrel Export Update
**File:** `backend/src/robot/index.ts`

Export new types: `SwarmTelemetryMsg`, `SwarmMemberHeartbeat`, `SwarmAddResourceMsg`, `SwarmRemoveResourceMsg`, `SwarmFormationType`, `SwarmState`, `ResourceType`.

## Verification
- TypeScript types consistent with Python models
- Swarm telemetry pushes all member positions to COP
- REST endpoints return correct swarm state
- DAO add/remove forwards to leader WebSocket

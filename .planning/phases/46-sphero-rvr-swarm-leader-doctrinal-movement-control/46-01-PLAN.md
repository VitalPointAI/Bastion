# Phase 46 Plan 01: Swarm Protocol Models & Formation Geometry Engine

## Goal
Define the complete data model layer for swarm coordination and implement the formation geometry engine that computes slot positions for 6 doctrinal formation types.

## Tasks

### Task 1: Swarm Protocol Models
**File:** `robot/swarm/models.py`

Create Pydantic models for the entire swarm protocol:

1. **Enums:**
   - `ResourceType`: rvr_plus, drone, ugv, sensor, relay (heterogeneous fleet)
   - `SwarmRole`: leader, follower, unassigned
   - `FormationType`: line, wedge, column, echelon_left, echelon_right, vee
   - `MovementTechnique`: traveling, traveling_overwatch, bounding_overwatch, successive_bounds
   - `SwarmState`: forming, ready, moving, holding, dispersing

2. **Position & geometry:**
   - `Position2D`: x, y room-relative meters
   - `FormationSlot`: slot_index, offset_x, offset_y, assigned_robot_id

3. **Swarm member tracking:**
   - `SwarmMember`: robot_id, resource_type, role, position, heading, altitude_m (drones), battery_pct, slot_index, capabilities, did, last_seen, connected

4. **Leader → follower commands:**
   - `FormationCommand`, `MoveCommand`, `HaltCommand`, `DismissCommand`

5. **Peer-to-peer messages:**
   - `SwarmHeartbeat`, `SwarmJoinRequest`, `SwarmJoinAck`, `SwarmVisionShare`

6. **DAO-driven dynamic membership:**
   - `SwarmAddResource`, `SwarmRemoveResource`, `SwarmReconfigureFormation`

7. **Swarm mission extension:**
   - `SwarmMissionParams`: formation, spacing_m, technique, swarm_robot_ids

8. **COP aggregation:**
   - `SwarmTelemetry`: swarm_id, leader_id, state, formation, member_count, members, center_of_mass

### Task 2: Formation Geometry Engine
**File:** `robot/swarm/formations.py`

Implement formation slot computation for all 6 types:

1. `compute_formation_slots(formation, member_count, spacing_m)` — returns list of `FormationSlot` with leader-relative offsets
2. `slots_to_world_positions(slots, leader_pos, leader_heading)` — rotates offsets by heading and translates to world coords
3. Formation offset generators:
   - `_line_offsets`: single file behind leader
   - `_wedge_offsets`: inverted V, leader at apex, 45-degree spread
   - `_column_offsets`: parallel columns beside leader
   - `_echelon_offsets`: staggered diagonal (left or right)
   - `_vee_offsets`: V-shape, leader at rear center

### Task 3: Package Init
**File:** `robot/swarm/__init__.py`

Create the swarm package with docstring.

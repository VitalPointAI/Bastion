# Phase 46 Plan 03: Mission Executor Swarm Extension & Mission Client Wiring

## Goal
Extend the mission executor with swarm-aware mission types and wire the swarm coordinator into the mission client WebSocket layer.

## Tasks

### Task 1: Mission Executor Swarm Extension
**File:** `robot/mission_executor.py`

1. Add swarm imports: `SwarmCoordinator`, `FormationType`, `MovementTechnique`, `Position2D`, `SwarmMissionParams`, `SwarmRole`
2. Add `_swarm` attribute to constructor (default None)
3. Add `set_swarm(swarm)` method to attach coordinator
4. Extend `supported_commands` set with: `swarm_patrol`, `swarm_recon`, `swarm_advance`
5. Add dispatch case for swarm commands → `_execute_swarm_mission()`

6. Implement `_execute_swarm_mission()`:
   - Reject if no swarm coordinator attached
   - Reject if not swarm leader
   - Parse swarm params from `model_extra` (formation, spacing_m, technique)
   - Set formation, set LED orange, dispatch to sub-behavior

7. Implement swarm mission behaviors:
   - `_swarm_patrol()`: formation patrol through waypoints with vision sharing at each stop
   - `_swarm_recon()`: formation sweep of area with concurrent vision loop + vision sharing
   - `_swarm_advance()`: doctrinal advance toward target using movement technique

### Task 2: MissionParams Extra Fields
**File:** `robot/models.py`

Add `model_config = {"extra": "allow"}` to `MissionParams` so swarm-specific fields (formation, spacing_m, technique) pass through without rejection.

### Task 3: Mission Client Swarm Integration
**File:** `robot/mission_client.py`

1. Add imports: `SwarmCoordinator`, `SwarmAddResource`, `SwarmRemoveResource`, `SwarmRole`, `SwarmTelemetry`
2. Add `_swarm` global
3. Add `_send_swarm_telemetry()` helper
4. Wire swarm capabilities into registration message
5. Add DAO message handling in receive loop: `swarm:add_resource`, `swarm:remove_resource`
6. Initialize swarm coordinator in `run()`:
   - Role auto-detection: leader if vision-equipped, else follower
   - Create coordinator with `drive_to_fn=driver.drive_to_point`
   - Start coordinator
7. Wire swarm into `connect_and_run()`:
   - Attach coordinator to executor via `set_swarm()`
   - Connect telemetry callback
8. Add swarm shutdown to graceful shutdown sequence

### Task 4: Swarm Config
**File:** `robot/config.py`

Add `SWARM_ENABLED` (default false) and `SWARM_ROLE` (default "auto") settings.

### Task 5: .env.example Update
**File:** `robot/.env.example`

Add swarm configuration section with `SWARM_ENABLED` and `SWARM_ROLE` documentation.

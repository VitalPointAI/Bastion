### Task 2: Test Isolation Fixes
**Files:** `robot/tests/test_mission_executor.py`, `robot/tests/test_mission_client.py`, `robot/tests/test_config.py`

Fix cross-test module pollution:

1. **test_mission_executor.py**: Remove stale mock stubs for `mission_executor`, `swarm.*` modules before importing real classes. Detect MagicMock modules and remove them.

2. **test_mission_client.py**: Import real swarm modules (pure Python, no hardware deps) instead of creating mock stubs. Fall back to mocks only if imports fail.

### Task 3: Integration Verification

Run full test suite (146 tests) to verify:
- All existing robot tests pass
- Swarm imports don't break any existing functionality
- Config tests pass regardless of `.env` file contents
- No module pollution between test files

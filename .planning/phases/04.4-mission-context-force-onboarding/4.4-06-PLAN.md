<task type="auto">
  <name>Task 1: Create Resource API Router</name>
  <files>
    backend/src/api/resources.ts
  </files>
  <action>
    Create backend/src/api/resources.ts:

    Resource catalog endpoints:
    - POST /api/resources - Create resource
    - GET /api/resources?missionId=X&category=Y - List resources with filters
    - GET /api/resources/:id - Get single resource
    - PATCH /api/resources/:id - Update resource
    - PATCH /api/resources/:id/status - Update status (FMC/PMC/NMC)
    - DELETE /api/resources/:id - Delete resource
    - POST /api/resources/bulk-import - Bulk import from CSV (JSON array body)

    Personnel endpoints:
    - POST /api/resources/personnel - Create personnel
    - GET /api/resources/personnel?missionId=X&unitId=Y - List with filters
    - GET /api/resources/personnel/:id - Get single
    - PATCH /api/resources/personnel/:id - Update
    - PATCH /api/resources/personnel/:id/unit - Assign to unit
    - DELETE /api/resources/personnel/:id - Delete
    - POST /api/resources/personnel/bulk-import - Bulk import

    Consumable endpoints:
    - POST /api/resources/consumables - Create consumable
    - GET /api/resources/consumables?missionId=X&category=Y - List with filters
    - GET /api/resources/consumables/:id - Get single
    - PATCH /api/resources/consumables/:id - Update
    - PATCH /api/resources/consumables/:id/level - Update current level
    - DELETE /api/resources/consumables/:id - Delete
    - GET /api/resources/consumables/low-stock?missionId=X - Get items below minimum

    Bulk import body format:
    ```json
    {
      "missionId": "MSN-123",
      "rows": [
        { "name": "M4 Carbine", "category": "weapon_system", "serialNumber": "123", "status": "FMC" },
        ...
      ]
    }
    ```
  </action>

  </verify>

## Decisions Made

1. **Mission State Machine:** Enforced state transitions (planning → active → complete → archived) with validation preventing invalid jumps. State changes tracked with timestamps (activatedAt, completedAt).

2. **Invite Token Security:** Used SHA256 hashing for token storage. Raw tokens returned only once at creation, hashed tokens stored in database for secure lookup.

3. **Cycle Detection:** Command relationships use depth-first search to prevent hierarchical cycles. Recursive CTEs traverse ancestor tree to validate new relationships before insertion.

4. **Resource Status Codes:** Adopted military readiness reporting standards (FMC/PMC/NMC) instead of generic statuses for consistency with doctrine.

5. **GeoJSON Type Definition:** Created custom GeoJSONPolygon interface instead of using @types/geojson to avoid additional dependencies. Simple structure sufficient for mission needs.

## Decisions Made

1. **Category sidebar instead of dropdown:** Better visibility of all categories at once, clearer active state indication
2. **Progress bars as percentage of minimum:** Emphasizes low-stock condition rather than capacity utilization
3. **Quick edit for consumable levels:** Inline editing avoids modal overhead for frequent stock updates
4. **react-csv-importer library:** Proven column mapping UI instead of custom implementation
5. **Separate tabs for resource types:** Equipment, Personnel, and Consumables have different data models and UI needs

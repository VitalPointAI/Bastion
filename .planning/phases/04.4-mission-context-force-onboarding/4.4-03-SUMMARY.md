## Decisions Made

**1. Wizard pattern consistency**
- Reused AgentBuilderWizard patterns for consistency across admin interfaces
- Progress indicator, step validation, back/next navigation

**2. Map integration approach**
- Followed ValidityMap patterns: Stadia dark tiles, Leaflet icon fix
- Single polygon constraint for AO (clear old polygon on new draw)
- GeoJSON Polygon coordinates stored directly in mission data

**3. Invite collection pattern**
- Store pending invites in wizard state until mission creation
- Send all invites after successful mission creation
- Supports both DID and email (mutually exclusive)

**4. GeoJSON type definition**
- Custom GeoJSONPolygon interface to avoid @types/geojson dependency
- Keeps dependencies minimal, matches backend schema

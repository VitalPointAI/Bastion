       - PATCH /api/sensors/:id - Update sensor
       - PATCH /api/sensors/:id/status - Update status
       - PATCH /api/sensors/:id/location - Update location (lat/lng)
       - DELETE /api/sensors/:id - Delete sensor
       - GET /api/sensors/coverage/:missionId - Get all sensor coverage polygons for map
       - POST /api/sensors/:id/coverage - Define/update coverage polygon

    2. Mount in backend/src/index.ts:
       - Import sensorRouter
       - app.use('/api/sensors', sensorRouter)

    3. Create frontend/src/lib/sensor-service.ts:
       ```typescript
       const API_BASE = '/api/sensors';

       export const sensorService = {
         createSensor: (data) => fetch(API_BASE, { method: 'POST', ... }),
         getSensors: (missionId, category?) => fetch(`${API_BASE}?...`),
         updateSensor: (id, data) => fetch(`${API_BASE}/${id}`, { method: 'PATCH', ... }),
         updateStatus: (id, status) => fetch(`${API_BASE}/${id}/status`, { method: 'PATCH', ... }),
         updateLocation: (id, lat, lng) => fetch(`${API_BASE}/${id}/location`, { method: 'PATCH', ... }),
         deleteSensor: (id) => fetch(`${API_BASE}/${id}`, { method: 'DELETE' }),
         getCoverage: (missionId) => fetch(`${API_BASE}/coverage/${missionId}`),
         updateCoverage: (id, polygon) => fetch(`${API_BASE}/${id}/coverage`, { method: 'POST', ... }),
       };
       ```

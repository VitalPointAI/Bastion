## Decisions Made

**Bulk import error handling:**
- Returns partial success with per-row error tracking
- Rationale: Better UX for large imports - user sees what succeeded and what failed

**Low stock sorting:**
- Returns items sorted by (current_level / minimum_level) ratio ascending
- Rationale: Most critical shortages appear first

**Personnel query requirements:**
- Either missionId or unitId parameter required for list endpoint
- Rationale: Prevents unbounded queries, ensures scoped results

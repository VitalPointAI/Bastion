  **1. Create `frontend/src/components/design/CoGTree.tsx`** — Interactive inline SVG tree following EffectChainDiagram pattern:

  Props: `{ tree: CoGTree; side: 'friendly' | 'adversary'; onTreeChange: (tree: CoGTree) => void; readOnly?: boolean }`.

  Layout approach (vertical top-down tree):
  - Constants: NODE_WIDTH = 160, NODE_HEIGHT = 60, LEVEL_SPACING = 100, NODE_SPACING = 20, PADDING = 40.
  - 4 levels top-down: Level 0 = CoG (root), Level 1 = Critical Capabilities, Level 2 = Critical Requirements, Level 3 = Critical Vulnerabilities.
  - Position calculation: flatten tree into levels (array of arrays). For each level, calculate x positions based on count * (NODE_WIDTH + NODE_SPACING), centered. Y position = level * LEVEL_SPACING + PADDING.
  - Store positions in Map<string, { x: number; y: number }>.

  SVG rendering:
  - Container div with overflow-x: auto for horizontal scrolling when tree is wide.
  - Use a ref to measure container width and calculate SVG viewBox dynamically.
  - `<svg>` with calculated width/height based on max level width and depth.
  - `<defs>` with `<marker>` arrowhead definitions.
  - For each parent-child edge: render `<path>` from parent bottom-center to child top-center, curved (cubic bezier). Stroke color gray-500.
  - For each node: render a `<g>` group with:
    - `<rect>` with rounded corners, fill based on node type color, stroke on hover/selected.
    - `<text>` with node label (truncated to ~18 chars with ellipsis).
    - `<text>` smaller showing type abbreviation (CG/CC/CR/CV).

  Node type colors (matching RESEARCH.md):
  - 'cog': #ef4444 (red)
  - 'critical-capability': #f59e0b (amber)
  - 'critical-requirement': #3b82f6 (blue)
  - 'critical-vulnerability': #10b981 (green)

  Interaction:
  - Click node: set selectedNodeId state, open CoGNodeEditor popover positioned near the node.
  - Hover node: highlight with brighter border.
  - "Add" button rendered below each node (small + icon) — visible on hover. Clicking adds a child of the appropriate next type (CG adds CC, CC adds CR, CR adds CV). CV nodes cannot have children.
  - "Delete" button on selected node (trash icon). Deleting a node removes it and all descendants. Cannot delete root CG node (only edit).

  Empty state: If tree.root is null, show "Click to add Center of Gravity" button that creates a root CoG node with default label.

  Tree mutation helpers (pure functions that return new tree):
  - `addChildNode(tree, parentId, childType)`: creates new CoGNode with randomUUID, adds to parent's children
  - `updateNode(tree, nodeId, updates)`: updates label/description of specific node
  - `deleteNode(tree, nodeId)`: removes node and all children from tree
  All mutations call `onTreeChange(newTree)` to propagate changes.

  - Fields: Label (text input), Description (textarea), Type (read-only display).
  - Type shown as colored badge with full name.
  - Save and Cancel buttons. Delete button with confirmation ("Are you sure?").
  - Positioning: absolute positioned near the selected node (passed via style prop or calculated from node position).
  - Dark UI: bg-gray-800, border-gray-600, shadow-xl rounded-lg.

  <action>
**Install @dnd-kit:**
```bash
cd frontend && npm install @dnd-kit/core @dnd-kit/sortable
```

**ContainerBrowser.tsx** — Wrap with DndContext:
- Import `DndContext`, `DragOverlay`, `closestCenter`, `DragStartEvent`, `DragEndEvent` from `@dnd-kit/core`.
- Wrap the entire browser content in `<DndContext collisionDetection={closestCenter} onDragStart={handleDragStart} onDragEnd={handleDragEnd}>`.
- Track `activeDragItem` in state (the document being dragged): `{ documentId, documentTitle, sourceContainerId }`.
- `handleDragStart`: Set activeDragItem from the draggable's data.
- `handleDragEnd`: If dropped on a valid container (different from source):
  1. Optimistic update: remove document from source container's count, add to target container's count in local state.
  2. Call `strategicService.assignDocumentToContainers(documentId, [targetContainerId])`.
  3. If source container existed, call `strategicService.removeDocumentFromContainer(documentId, sourceContainerId)`.
  4. On API failure: revert optimistic update, show error toast.
  5. On success: refresh container data.
- `DragOverlay`: Show a ghost card with document title while dragging.
- Drag is only enabled at the `categories` level (container card grid view) for documents in the Unorganized section, AND at the `container` level (ContainerDocumentList).

**ContainerCard.tsx** — Make containers droppable:
- Import `useDroppable` from `@dnd-kit/core`.
- Call `useDroppable({ id: container.id, data: { type: 'container', containerId: container.id } })`.
- When `isOver` is true, apply a highlight style (dashed border in category color, slight scale up).

**ContainerDocumentList.tsx** — Make document cards draggable:
- Import `useDraggable` from `@dnd-kit/core`.
- Wrap each document card in a draggable wrapper.
- Call `useDraggable({ id: doc.id, data: { type: 'document', documentId: doc.id, documentTitle: doc.title, sourceContainerId: containerId } })`.
- When `isDragging` is true, reduce opacity of the source card.
- Also make the Unorganized document list draggable (same pattern, sourceContainerId = null for unorganized docs).

Ensure drag-and-drop is accessible: draggable items have aria-roledescription="draggable document", droppable containers have appropriate aria labels.

## Decisions Made
- Used overlay modal pattern for ContainerManager rather than inline editing -- provides consistent UX across all CRUD actions and avoids complex state management on cards
- Added 'unorganized' as a BrowserLevel to handle documents not in any container, with dedicated view
- Context menu on ContainerCard uses CSS :focus-within for show/hide, avoiding additional state management
- Added fallback empty state when no problemSetId is provided (previously would have rendered nothing)

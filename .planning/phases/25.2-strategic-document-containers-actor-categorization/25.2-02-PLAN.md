**ActorCategoryBadge.tsx** — Small presentational component:
- Props: `{ name: string; color: string; size?: 'sm' | 'md' }`.
- Renders a pill badge with the category color as background (with 15% opacity) and the color as text. Format: colored dot + category name.
- Follow MIDLIFE_METADATA badge styling pattern from MidlifeLegend component.

**CategoryFilterBar.tsx** — Horizontal filter bar:
- Props: `{ categories: ActorCategory[]; activeFilter: string | null; onFilterChange: (categoryId: string | null) => void; onAddCategory: () => void }`.
- Renders "All" button + one button per category with ActorCategoryBadge styling.
- Active button has a bottom border accent in the category color.
- "+" button at the end opens the add-category flow (calls onAddCategory).
- Scrolls horizontally if too many categories.

**ContainerCard.tsx** — Card for a single container within the category-grouped view:
- Props: `{ container: StrategicContainer; categoryColor: string; onClick: () => void }`.
- Shows container name, document count badge, agent count badge (if > 0), description snippet.
- Left border accent in the category color.
- Hover state darkens background slightly.
- Follow card styling from existing DocumentList cards.

**ContainerDocumentList.tsx** — Documents within a selected container:
- Props: `{ containerId: string; onSelectDocument: (doc: StrategicDocument) => void; onBack: () => void; containerName: string; categoryColor: string; userDID?: string }`.
- Fetches documents via `strategicService.getContainerDocuments(containerId)`.
- Renders document cards reusing styling from existing DocumentList (title, level, classification badge, agent badges via AgentBadges component).
- Empty state: "No documents in this container yet. Upload documents or drag them here."
- Back button at top returns to container view.

**ContainerBrowser.tsx** + **ContainerBrowser.css** — Main orchestrator:
- Props: `{ problemSetId: string; onSelectDocument: (doc: StrategicDocument) => void; userDID?: string; refreshTrigger: number }`.
- State management using `BrowserState`:
  ```
  type BrowserLevel = 'categories' | 'container';
  interface BrowserState {
    level: BrowserLevel;
    categoryFilter: string | null;
    selectedContainerId: string | null;
  }
  ```
- On mount: call `strategicService.getEnvironmentByProblemSet(problemSetId)` to get/create environment, then `getContainersGrouped(environmentId)` to load categories and containers.
- Renders breadcrumb navigation: "All Categories" > "{Category Name}" > "{Container Name}".
- At `categories` level: CategoryFilterBar at top, then container cards grouped by visible categories. Each category group has a header (ActorCategoryBadge + count) and its containers as ContainerCard grid (2 columns on lg, 1 on mobile).
- When categoryFilter is set, only show that category's containers.
- Below category groups, show "Unorganized" section with count. Fetch via `getUnorganizedDocuments(environmentId)`. Clicking "Unorganized" shows those documents in a document list view.
- At `container` level: ContainerDocumentList for the selected container.
- Clicking a document calls `onSelectDocument` (existing flow for document detail/objectives).
- Refresh when refreshTrigger changes (existing pattern from StrategicDashboard).
- Loading state with spinner, error state with retry.

**CSS** — Follow existing StrategicDashboard.css patterns. Container cards in a responsive grid. Category group headers have a left-colored border matching the category. Filter bar is sticky at top with horizontal scroll. Breadcrumb with "/" separators and clickable segments.

**ContainerManager.tsx** — Inline CRUD for containers and categories:
- Manages three modal/inline flows:
  1. **Create Container**: Triggered from "+" button on category group header or empty state. After create, calls `onRefresh()` callback.
  2. **Rename Container**: Inline edit. Double-click or pencil icon on container name. Input replaces the name text. Enter to save via `strategicService.updateContainer(...)`, Escape to cancel.
  3. **Delete Container**: Confirmation dialog showing container name and count of documents that will become unorganized. Calls `strategicService.deleteContainer(...)`. Shows orphaned doc count from response.
  4. **Create Category**: Modal with name input + color palette selector (CUSTOM_CATEGORY_PALETTE from types). Uses `strategicService.createCategory(...)`.
  5. **Reassign Container Category**: Dropdown on container card (or via context menu). Calls `strategicService.updateContainer(containerId, { categoryId: newCategoryId })`. Shows toast notification on success.

Create `backend/src/strategic/containers/` directory with three files:

**types.ts** — Shared types:
- `StrategicEnvironment`: { id, name, description?, created_by, created_at, updated_at }
- `ActorCategory`: { id, environment_id, name, color, display_order, is_default, created_at }
- `StrategicContainer`: { id, environment_id, category_id, name, description?, created_by, created_at, updated_at }
- `ContainerDocument`: { id, container_id, document_id, assigned_by, assigned_at }
- `ContainerAgentAssignment`: { id, container_id, agent_id, assignment_type, auto_process_new, assigned_by, assigned_at }
- `CategoryGroup`: { category: ActorCategory, containers: (StrategicContainer & { document_count: number, agent_count: number })[] }
- `DEFAULT_ACTOR_CATEGORIES` constant: Record with FRIENDLY (blue #2563eb, order 0), ADVERSARY (red #dc2626, order 1), NEUTRAL (gray #6b7280, order 2), PARTNER (green #16a34a, order 3) — each with name, color, display_order, description
- `ContainerSuggestion`: { containerName: string, containerId?: string, confidence: number, reasoning: string }

**store.ts** — ContainerStore class following DocumentStore pattern:
- `initContainerTables()`: Creates all 5 tables (strategic_environments, actor_categories, strategic_containers, container_documents, container_agent_assignments) using `CREATE TABLE IF NOT EXISTS` with proper foreign keys. Use exact schema from 25.2-RESEARCH.md. Add indexes on environment_id for categories/containers, container_id for container_documents.
- `createEnvironment(name, description, createdBy)`: Insert environment + seed 4 default actor categories from DEFAULT_ACTOR_CATEGORIES. Return environment id.
- `getEnvironment(id)`: Return single environment.
- `getEnvironmentByProblemSet(problemSetId)`: Query to find environment linked to a problem set. For now, since no formal link table exists yet (Phase 26), use a simple `problem_set_environments` mapping table: `CREATE TABLE IF NOT EXISTS problem_set_environments (problem_set_id TEXT PRIMARY KEY, environment_id TEXT NOT NULL REFERENCES strategic_environments(id))`. Auto-create environment on first access if none exists.
- `getContainersGroupedByCategory(environmentId)`: Single aggregate query with LEFT JOINs to get categories -> containers -> document_count + agent_count. Group results by category in code. Return CategoryGroup[].
- `createCategory(environmentId, name, color, displayOrder)`: Insert actor_category. Return id.
- `updateCategory(categoryId, updates)`: Update name/color. Write audit event to `blockchain_events` table with event_type='container_category_changed'.
- `deleteCategory(categoryId)`: Only if no containers reference it. Return boolean success.
- `createContainer(environmentId, categoryId, name, description, createdBy)`: Insert container. Return id.
- `updateContainer(containerId, updates)`: Update name, description, or category_id. If category_id changes, write audit event.
- `deleteContainer(containerId)`: Identify documents that would become orphaned (only in this container via container_documents). Remove junction entries. Return { deletedContainerId, orphanedDocumentIds } so caller can inform user.
- `getContainerDocuments(containerId)`: Return documents in container with full StrategicDocument fields via JOIN.
- `assignDocumentToContainers(documentId, containerIds, assignedBy)`: INSERT INTO container_documents for each containerId, ON CONFLICT DO NOTHING.
- `removeDocumentFromContainer(documentId, containerId)`: DELETE from container_documents.
- `getUnorganizedDocuments(environmentId)`: Documents in this environment's problem set NOT in any container_documents entry.
- `getDocumentContainers(documentId)`: Return containers a document belongs to.
- Container agent assignment CRUD: `assignAgentToContainer(containerId, agentId, assignmentType, autoProcessNew, assignedBy)`, `getContainerAgentAssignments(containerId)`, `removeAgentFromContainer(containerId, agentId)`.

Use `getPool()` from `../../lib/database.js` and `randomUUID()` from crypto. Follow exact patterns from document-store.ts.

**index.ts** — Re-export everything from types.ts and store.ts. Export a singleton `containerStore = new ContainerStore()`.

**backend/src/api/strategic.ts** — Add container routes after existing routes. Import `containerStore`, `initContainerTables` from containers module. Add lazy init call in existing init chain.

Routes (all behind `requireAuth`):
- `GET /api/strategic/environments/by-problem-set/:problemSetId` — Call `containerStore.getEnvironmentByProblemSet(problemSetId)`. Auto-creates if needed. Return environment object.
- `GET /api/strategic/environments/:envId/containers` — Call `containerStore.getContainersGroupedByCategory(envId)`. Return CategoryGroup[].
- `POST /api/strategic/environments/:envId/categories` — Body: { name, color, displayOrder? }. Call `containerStore.createCategory(...)`. Return { id }.
- `PUT /api/strategic/categories/:categoryId` — Body: { name?, color? }. Call `containerStore.updateCategory(...)`.
- `DELETE /api/strategic/categories/:categoryId` — Call `containerStore.deleteCategory(...)`. Return 409 if has containers.
- `POST /api/strategic/environments/:envId/containers` — Body: { categoryId, name, description? }. Call `containerStore.createContainer(...)`. Return { id }.
- `PUT /api/strategic/containers/:containerId` — Body: { name?, description?, categoryId? }. Call `containerStore.updateContainer(...)`.
- `DELETE /api/strategic/containers/:containerId` — Call `containerStore.deleteContainer(...)`. Return { orphanedDocumentIds }.
- `GET /api/strategic/containers/:containerId/documents` — Call `containerStore.getContainerDocuments(containerId)`. Return documents[].
- `PUT /api/strategic/documents/:documentId/containers` — Body: { containerIds: string[] }. Call `containerStore.assignDocumentToContainers(...)`.
- `DELETE /api/strategic/documents/:documentId/containers/:containerId` — Call `containerStore.removeDocumentFromContainer(...)`.
- `GET /api/strategic/environments/:envId/unorganized` — Call `containerStore.getUnorganizedDocuments(envId)`. Return documents[].
- `GET /api/strategic/documents/:documentId/containers` — Call `containerStore.getDocumentContainers(documentId)`.
- `POST /api/strategic/containers/:containerId/agents` — Body: { agentId, assignmentType?, autoProcessNew? }. Call `containerStore.assignAgentToContainer(...)`.
- `GET /api/strategic/containers/:containerId/agents` — Call `containerStore.getContainerAgentAssignments(containerId)`.
- `DELETE /api/strategic/containers/:containerId/agents/:agentId` — Call `containerStore.removeAgentFromContainer(...)`.

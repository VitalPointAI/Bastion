**design-skills.ts:**
- Export `createDesignTools()` returning an array of 4 `DynamicStructuredTool` instances (same pattern as `createTacticalTools()` in `tactical-skills.ts`)
- Each tool: name matches the skill .md `name`, description matches, schema matches inputSchema

**overlay_producer handler:**
- Accepts operational_approach, loes, ao_bounds
- Generates SVG string depicting phases as colored regions, LOEs as arrows/lines, decisive points as markers, boundaries as dashed lines
- Uses D3-like approach (construct SVG elements as template strings — no DOM needed on server)
- Returns `{ svg, layers }` where layers is an array of `{ name, svg }` for individual layer toggling

**resource_allocator handler:**
- Accepts operational_approach (with phases), resource_types filter
- Queries `getResourceRegistry().queryByCapability()` for available resources
- Maps resources to phases based on capability/type matching
- Calculates shortfalls (required minus available per phase — use simple heuristic: count required based on phase complexity)
- Returns `{ phases: [{phase_name, available_forces, required_forces, shortfalls}], summary }`

**campaign_visualizer handler:**
- Accepts complete OperationalDesign object + output_format
- If svg: Generates a one-page placemat SVG with layout regions for CoG tree (top-left), LOE arrows (center), phase timeline (bottom), problem statement (top-right), decision points (annotated on timeline)
- If markdown_spec: Generates detailed markdown describing the visual layout, element positions, colors, text content — suitable for image AI to generate polished output
- Returns `{ svg?, markdown_spec? }` based on output_format

**risk_visualizer handler:**
- Accepts operational_approach (with risks), display_format
- If matrix: 5x5 probability vs impact grid with risk dots
- If timeline: Risks plotted on phase timeline
- If heatmap: LOE x Phase grid with risk concentration coloring
- Annotates mitigations and residual risk levels
- Returns `{ svg, risks_summary }`

**skill-handler-registry.ts modifications:**
- Import `createDesignTools` from `./design-skills.js`
- In `initializeBuiltinHandlers()`, after the tactical tools block, add identical pattern:
  ```
  const designTools = createDesignTools();
  const designToolHandlerMap: Record<string, string> = {
    'overlay_producer': 'design/overlayProducer',
    'resource_allocator': 'design/resourceAllocator',
    'campaign_visualizer': 'design/campaignVisualizer',
    'risk_visualizer': 'design/riskVisualizer',
  };
  for (const tool of designTools) {
    const handlerId = designToolHandlerMap[tool.name];
    if (handlerId) {
      registerHandler(handlerId, async (args) => {
        const result = await tool.invoke(args);
        return typeof result === 'string' ? result : JSON.stringify(result);
      });
    }
  }
  ```

CRITICAL: Add the registration INSIDE `initializeBuiltinHandlers()` so skills use the fast path, not the slow `executeDynamicSkill()` fallback (Pitfall 7).

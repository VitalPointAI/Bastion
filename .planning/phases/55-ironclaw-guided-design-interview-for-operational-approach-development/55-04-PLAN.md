<task type="auto">
  <name>Task 1: Create useDesignInterview hook</name>
  <files>frontend/src/hooks/useDesignInterview.ts</files>
  <action>
Create a React hook `useDesignInterview(problemSetId: string)` that manages the full design interview lifecycle.

**State:**
- `interviewState`: DesignInterviewMeta | null (current interview progress)
- `isLoading`: boolean (API call in progress)
- `isActive`: boolean (interview has been started and not completed)
- `lastMessage`: string | null (last AI response text)
- `error`: string | null

**Actions (returned from hook):**
- `startInterview(mode?: 'new' | 'revision')`: Calls POST /start, updates state
- `sendMessage(message: string)`: Calls POST /continue, updates state
- `confirmSection()`: Calls POST /confirm-section, updates state
- `resetInterview()`: Calls DELETE, clears state
- `resumeInterview()`: Calls GET /state, restores state if interview exists

**Effects:**
- On mount, call `resumeInterview()` to check for existing interview state (enables page refresh resume)
- Listen on the Ironclaw WebSocket channel for `design.section_updated` events. When received, call back into the Design tab sections' data refresh (expose an `onSectionUpdate` callback that consumers can provide)
- Track `awaitingSectionConfirm` from state to determine if review gate should show

**Return type:**
```typescript
{
  interviewState: DesignInterviewMeta | null;
  isActive: boolean;
  isLoading: boolean;
  lastMessage: string | null;
  error: string | null;
  startInterview: (mode?: 'new' | 'revision') => Promise<void>;
  sendMessage: (message: string) => Promise<void>;
  confirmSection: () => Promise<void>;
  resetInterview: () => Promise<void>;
  awaitingConfirm: boolean;
}
```

Use the existing fetch pattern from the codebase (check other hooks for the API base URL pattern, likely relative URLs with `/api/` prefix). Handle errors with try/catch, set error state on failure.

Create an advanced Agent Builder with Eliza-like personalities, MCP tool integration, and team composition capabilities.

**Tech stack:**
- XState v5 for workflow orchestration (existing)
- Zod for schema validation
- @noble/hashes for DID key derivation
- react-hook-form with zod resolver
- Existing LLM provider abstraction layer

**Key architecture decisions:**
- Use Eliza-compatible character file format for agent personalities
- MCP tools are JSON Schema based (compatible with LLM tool calling)
- Teams are XState actor compositions with message passing
- All entities get DIDs: agents, tools, teams
- Tools can be shared across agents or team-scoped

**Reference: Eliza Character Structure**
```typescript
interface ElizaCharacter {
  name: string;
  bio: string[];              // Array of biography entries
  lore: string[];             // Backstory and history
  knowledge: string[];        // RAG-ready knowledge base
  messageExamples: MessageExample[][];  // Conversation examples
  postExamples: string[];     // Social media style examples
  topics: string[];           // Topics of interest
  style: {
    all: string[];           // Universal style traits
    chat: string[];          // Chat-specific style
    post: string[];          // Post-specific style
  };
  adjectives: string[];       // Personality descriptors
  modelProvider: string;      // LLM provider
  settings: {
    voice?: VoiceSettings;
    secrets?: Record<string, string>;
  };
  plugins: string[];          // Enabled plugins/tools
}
```

**Reference: MCP Tool Structure**
```typescript
interface MCPTool {
  toolId: string;
  toolDID: string;            // did:near:tool-{toolId}
  name: string;
  description: string;
  category: ToolCategory;     // 'data' | 'action' | 'integration' | 'analysis'
  inputSchema: JSONSchema;    // JSON Schema for parameters
  outputSchema?: JSONSchema;  // Expected output format
  handler: 'builtin' | 'webhook' | 'function';
  config?: {
    endpoint?: string;        // For webhook handlers
    timeout?: number;
    rateLimit?: number;
  };
  permissions: string[];      // Required ABAC permissions
  isEnabled: boolean;
  createdAt: string;
  createdBy: string;          // Admin DID
}
```

**Reference: Agent Team Structure**
```typescript
interface AgentTeam {
  teamId: string;
  teamDID: string;            // did:near:team-{teamId}
  name: string;
  description: string;
  purpose: string;            // Team's mission statement
  members: TeamMember[];
  workflow: TeamWorkflow;     // XState machine definition
  sharedContext: string[];    // Context keys shared between members
  escalationPolicy: EscalationPolicy;
  maxConcurrency: number;
  isEnabled: boolean;
  createdAt: string;
  createdBy: string;
}

interface TeamMember {
  agentId: string;
  role: 'coordinator' | 'specialist' | 'validator' | 'executor';
  responsibilities: string[];
  canInitiate: boolean;       // Can start workflows
  canEscalate: boolean;       // Can escalate to human
}

interface TeamWorkflow {
  type: 'sequential' | 'parallel' | 'consensus' | 'hierarchical';
  stages: WorkflowStage[];
  humanCheckpoints: string[]; // Stage IDs requiring human approval
}
```

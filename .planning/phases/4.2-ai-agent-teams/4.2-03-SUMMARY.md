2. **"Use Global Default" toggle** - When checked, agent uses system LLM config; when unchecked, custom provider/model/temperature/maxTokens can be set
3. **Separate tabs for agent creation** - Form-based creation for guided input, JSON upload for bulk/scripted agent definition

  <name>Fix UAT-001: Handle missing body in DELETE OSINT endpoint</name>
  <files>backend/src/api/admin.ts</files>
  <action>
Fix the DELETE /api/admin/osint-sources/:id endpoint to handle requests without a body.

The current code uses destructuring which fails when req.body is undefined:
```typescript
const { reason } = req.body;
```

Change to optional chaining:
```typescript
const reason = req.body?.reason;
```

This allows DELETE requests to work without a body (standard HTTP behavior) while still accepting an optional reason if provided.
  </action>

  <files>backend/src/strategic/agents/fusion-agent.ts</files>
  <action>
The fusion endpoint crashes with "Cannot read properties of undefined (reading 'toLowerCase')" when receiving manually crafted OSINT reports that are missing required fields.

The issue is in the `findCorrelations` method at line 313:
```typescript
const reportEntities = report.entities.map(e => e.name.toLowerCase());
```

When the API receives input without the `entities` array (or other required fields like `keywords`, `content`, `sentiment`), the code crashes.

**Fix approach:**
1. Add defensive null checks for all array fields accessed in `findCorrelations`:
   - `report.entities` (line 313)
   - `report.keywords` (line 346)
   - `indicator.associatedActors` (line 314)

2. Add defensive null checks in `buildOperationalEnvironment`:
   - `report.content` (line 418)
   - `report.sentiment` (line 427)
   - `report.keywords` (line 369)

3. Use optional chaining and nullish coalescing where appropriate:
   - `report.entities ?? []`
   - `report.keywords ?? []`
   - `report.content ?? ''`

4. Add early return or skip logic for reports missing critical data

**Do NOT change:**
- The API contract or types (OSINTReport interface)
- The full intelligence cycle behavior (works correctly with internal data)
- Any functionality for properly-formed inputs

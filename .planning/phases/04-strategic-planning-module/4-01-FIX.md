  <name>Fix UAT-001: Add file extension fallback for MIME type detection</name>
  <files>backend/src/api/strategic.ts</files>
  <action>
The multer file filter currently only checks `file.mimetype` to validate uploads. When clients like curl don't send the correct MIME type (sending `application/octet-stream` instead), valid DOCX/DOC files are rejected.

Modify the fileFilter in the multer configuration:

1. First check if mimetype is in allowedTypes (current behavior)
2. If mimetype is `application/octet-stream`, fall back to extension detection:
   - Extract file extension from `file.originalname`
   - Map extensions to allowed MIME types:
     - `.pdf` → `application/pdf`
     - `.docx` → `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
     - `.doc` → `application/msword`
     - `.pptx` → `application/vnd.openxmlformats-officedocument.presentationml.presentation`
     - `.ppt` → `application/vnd.ms-powerpoint`
   - Accept if extension maps to allowed type, reject otherwise

Create a helper function `getMimeTypeFromExtension(filename: string): string | null` that returns the MIME type based on file extension, or null if unrecognized.

Update the fileFilter:
```typescript
fileFilter: (_req, file, cb) => {
  const allowedTypes = [
    'application/pdf',
    'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    'application/msword',
    'application/vnd.openxmlformats-officedocument.presentationml.presentation',
    'application/vnd.ms-powerpoint',
  ];

  // Direct MIME type check
  if (allowedTypes.includes(file.mimetype)) {
    cb(null, true);
    return;
  }

  // Fallback: check extension when MIME is octet-stream or empty
  if (file.mimetype === 'application/octet-stream' || !file.mimetype) {
    const inferredMime = getMimeTypeFromExtension(file.originalname);
    if (inferredMime && allowedTypes.includes(inferredMime)) {
      // Override the mimetype for downstream processing
      file.mimetype = inferredMime;
      cb(null, true);
      return;
    }
  }

  cb(new Error(`Unsupported file type: ${file.mimetype}. Allowed: PDF, DOCX, DOC, PPTX, PPT`));
}
```

This allows curl and other clients that don't properly detect MIME types to still upload valid files.

**COPRobotLayer.tsx:**
- Follow `COPResourceLayer.tsx` pattern for a Leaflet map layer
- Props: `problemSetId: string`, `onRobotClick?: (robotId: string) => void`
- State: `robots` array fetched from `GET /api/robot/robots` on mount
- WebSocket subscription to `/ws/robot` for real-time updates (telemetry position changes, state changes). On each telemetry message, update the robot's position in state. On state_update, update the robot's state color.
- For each connected robot, render a Leaflet marker:
  - Position from latest telemetry (lat/lng — Bastion translates room coords to map coords before sending to frontend, OR the frontend does the transform using calibration config fetched from API)
  - Custom `DivIcon` with state-colored circle:
    - green (`#22c55e`): executing
    - yellow (`#eab308`): awaiting_auth
    - red (`#ef4444`): failed
    - grey (`#6b7280`): idle/connected (no active mission)
    - blue (`#3b82f6`): accepted (transitional)
  - Small label below icon showing mission name (e.g., "Find & Engage" or "Patrol Route") or robot_id if no active mission
  - Icon size: 24x24px circle with 2px border, pulsing animation for awaiting_auth state
- On marker click: call `onRobotClick(robotId)` to open status card
- Polling fallback: if WS not available, poll `/api/robot/robots` every 3 seconds
- Layer group wraps all markers for clean add/remove from map

**COPRobotStatusCard.tsx:**
- Follow `MissionStatusCard.tsx` / `MissionStatusDrilldown.tsx` pattern
- Props: `robotId: string`, `onClose: () => void`
- Fetch robot details + current mission from `GET /api/robot/missions/:missionId` and `GET /api/robot/robots`
- Display sections:
  1. **Header**: Robot ID, DID (if assigned), connection state indicator
  2. **Current Mission**: mission_id, command type, issued_by, timestamp
  3. **State Timeline**: vertical timeline of state transitions (accepted -> executing -> awaiting_auth -> ...) with timestamps. Each state gets the color dot from the state color map.
  4. **Telemetry Snapshot**: latest position (x, y room coords), heading, battery percentage with battery icon
  5. **Policy Summary**: autonomy_policy name, brief description of authority limits
- Styled with existing Tailwind classes matching the dark theme used in COP tab
- Close button in top-right corner
- If no active mission, show "Idle" state with last mission summary

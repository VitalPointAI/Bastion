<task type="auto">
  <name>Task 1: Create workspace member store with primary workspace management</name>
  <files>backend/src/workspace/workspace-member-store.ts</files>
  <action>
Create `WorkspaceMemberStore` following the singleton `ensureInitialized()` pattern.

1. `ensureInitialized()` creates `workspace_members` table (see 19-RESEARCH.md SQL). Include:
   - UNIQUE(workspace_id, user_did) constraint
   - Partial unique index for one primary per user: `CREATE UNIQUE INDEX IF NOT EXISTS idx_one_primary_per_user ON workspace_members(user_did) WHERE is_primary = true;`
   - Indexes on workspace_id, user_did, and (user_did, is_primary)

2. Methods:
   - `addMember(workspaceId: string, userDid: string, role: string, daoRole: string, invitedBy: string): Promise<WorkspaceMember>` — Generate `WM-${randomUUID()}`, INSERT. If this is the user's first workspace, auto-set `is_primary = true` (check count first).
   - `getMember(workspaceId: string, userDid: string): Promise<WorkspaceMember | null>` — SELECT by compound key.
   - `getMemberById(id: string): Promise<WorkspaceMember | null>` — SELECT by id.
   - `listMembers(workspaceId: string): Promise<WorkspaceMember[]>` — SELECT WHERE workspace_id, status = 'active'.
   - `listMemberships(userDid: string): Promise<WorkspaceMember[]>` — SELECT WHERE user_did (all workspaces for a user).
   - `updateRole(workspaceId: string, userDid: string, newRole: string, newDaoRole: string): Promise<WorkspaceMember>` — UPDATE role and dao_role.
   - `setPrimary(userDid: string, workspaceId: string): Promise<void>` — Transaction: clear old primary, set new primary.
   - `suspendMember(workspaceId: string, userDid: string, suspendedBy: string): Promise<WorkspaceMember>` — UPDATE status='suspended', set suspended_at and suspended_by.
   - `unsuspendMember(workspaceId: string, userDid: string): Promise<WorkspaceMember>` — UPDATE status='active', clear suspended fields.
   - `removeMember(workspaceId: string, userDid: string): Promise<void>` — DELETE.
   - `getMemberCount(workspaceId: string): Promise<number>` — SELECT COUNT.

3. Private `mapRow(row: any): WorkspaceMember` for snake_case to camelCase mapping.

4. Export: `export const workspaceMemberStore = new WorkspaceMemberStore();`

IMPORTANT: AI agents are first-class workspace members (locked decision). The `addMember` method accepts agent DIDs (format: `did:near:{agentAccountId}`) identically to human DIDs. No special handling in the store layer — agent vs. human distinction is enforced at the API layer via role `max_agent_tier` limits.

IMPORTANT: The `setPrimary` method MUST use a transaction to avoid race conditions — first `UPDATE workspace_members SET is_primary = false WHERE user_did = $1 AND is_primary = true`, then `UPDATE workspace_members SET is_primary = true WHERE workspace_id = $2 AND user_did = $1`.

<task type="auto">
  <name>Task 2: Create workspace invite store and activity store</name>
  <files>backend/src/workspace/workspace-invite-store.ts, backend/src/workspace/workspace-activity-store.ts</files>
  <action>
**workspace-invite-store.ts:** Create `WorkspaceInviteStore`:

1. `ensureInitialized()` creates `workspace_invites` table (see 19-RESEARCH.md SQL). Include indexes on workspace_id and token.

2. Token handling: Use exact pattern from `backend/src/mission/invite-store.ts`:
   - `import { randomBytes, createHash } from 'crypto';`
   - Generate: `randomBytes(32).toString('base64url')`
   - Hash: `createHash('sha256').update(token).digest('hex')`
   - Store ONLY the hash. Return raw token to caller (for invite link).

3. Methods:
   - `createInvite(workspaceId: string, role: string, daoRole: string, createdBy: string, options?: { inviteeEmail?: string; inviteeDid?: string; expiresInHours?: number }): Promise<{ invite: WorkspaceInvite; rawToken: string }>` — Default expiry: 72 hours. Generate `WI-${randomUUID()}`.
   - `getInviteByToken(rawToken: string): Promise<WorkspaceInvite | null>` — Hash the raw token, SELECT by hashed token WHERE NOT expired AND NOT accepted.
   - `getInviteById(id: string): Promise<WorkspaceInvite | null>`
   - `listInvitesForWorkspace(workspaceId: string): Promise<WorkspaceInvite[]>` — SELECT WHERE workspace_id, ordered by created_at DESC.
   - `listPendingInvites(workspaceId: string): Promise<WorkspaceInvite[]>` — SELECT WHERE workspace_id AND accepted_at IS NULL AND expires_at > NOW().
   - `markAccepted(id: string): Promise<void>` — UPDATE SET accepted_at = NOW().
   - `markApproved(id: string, approvedBy: string): Promise<void>` — UPDATE SET approved_at = NOW(), approved_by.
   - `cancelInvite(id: string): Promise<void>` — DELETE.
   - `cleanupExpired(): Promise<number>` — DELETE WHERE expires_at < NOW() AND accepted_at IS NULL. Returns count deleted.

4. Export: `export const workspaceInviteStore = new WorkspaceInviteStore();`

**workspace-activity-store.ts:** Create `WorkspaceActivityStore`:

1. `ensureInitialized()` creates `workspace_activity` table (see 19-RESEARCH.md SQL). Include indexes on workspace_id, created_at DESC, and actor_did.

2. Methods:
   - `log(workspaceId: string, activityType: string, actorDid: string, subjectDid: string | null, metadata?: Record<string, unknown>, txHash?: string): Promise<WorkspaceActivity>` — Generate `WA-${randomUUID()}`, INSERT.
   - `listActivities(workspaceId: string, options?: { limit?: number; offset?: number; types?: string[] }): Promise<WorkspaceActivity[]>` — SELECT with optional type filter, ORDER BY created_at DESC. Default limit 50.
   - `listActivitiesForUser(userDid: string, options?: { limit?: number }): Promise<WorkspaceActivity[]>` — SELECT WHERE actor_did = userDid OR subject_did = userDid.
   - `getUnreadCount(workspaceId: string, since: Date): Promise<number>` — SELECT COUNT WHERE workspace_id AND created_at > since.
   - `getUnreadCountsForUser(userDid: string, lastSeenMap: Record<string, string>): Promise<Record<string, number>>` — For each workspace the user belongs to, count activities since their last-seen timestamp. Uses a single query with CASE/WHEN.

3. Export: `export const workspaceActivityStore = new WorkspaceActivityStore();`

Activity types to document in a comment: 'workspace_created', 'member_joined', 'member_removed', 'member_suspended', 'member_unsuspended', 'role_changed', 'invite_sent', 'invite_accepted', 'invite_cancelled', 'mission_created', 'exercise_created', 'workspace_updated'.

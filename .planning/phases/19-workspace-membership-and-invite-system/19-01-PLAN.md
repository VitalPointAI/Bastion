**workspace-store.ts:** Create `WorkspaceStore` class following the singleton `ensureInitialized()` pattern from `backend/src/mission/invite-store.ts`.

1. `ensureInitialized()` creates the `workspaces` table (see 19-RESEARCH.md SQL schema). Include indexes on `parent_workspace_id` and `classification`. Additionally, run: `ALTER TABLE exercise_scenarios ADD COLUMN IF NOT EXISTS workspace_id TEXT REFERENCES workspaces(id);` — this adds the workspace FK to exercises per the locked decision "Missions AND exercises nest under workspaces."

2. Methods:
   - `createWorkspace(input: CreateWorkspaceInput, createdBy: string): Promise<Workspace>` — Generate `WS-${randomUUID()}` ID, generate `daoId = ws-${input.workspaceType.toLowerCase()}-${randomUUID()}`, INSERT into `workspaces` table, return workspace. Does NOT call on-chain (API route handles that).
   - `getWorkspace(id: string): Promise<Workspace | null>` — SELECT by id.
   - `getWorkspaceByDaoId(daoId: string): Promise<Workspace | null>` — SELECT by dao_id.
   - `listChildWorkspaces(parentId: string): Promise<Workspace[]>` — SELECT WHERE parent_workspace_id = parentId.
   - `listWorkspacesByType(type: WorkspaceType): Promise<Workspace[]>` — SELECT WHERE workspace_type = type.
   - `updateWorkspace(id: string, updates: Partial<Pick<Workspace, 'name' | 'description' | 'inviteMode' | 'discoverability'>>): Promise<Workspace>` — UPDATE with SET, return updated.
   - `getHierarchy(rootId: string): Promise<Workspace[]>` — Recursive CTE to get all descendants.

3. Export singleton: `export const workspaceStore = new WorkspaceStore();`

4. Use `getPool()` from `../lib/database.js`. Use `randomUUID` from `crypto`.

5. Map DB column names (snake_case) to TS property names (camelCase) in a private `mapRow` helper.

   ```typescript
   const COMMANDER_VISIBLE = ['workspace_created', 'member_joined', 'member_removed', 'member_suspended',
     'member_unsuspended', 'role_changed', 'invite_sent', 'invite_accepted', 'invite_cancelled',
     'mission_created', 'exercise_created', 'workspace_updated'];
   const STAFF_VISIBLE = ['member_joined', 'member_removed', 'mission_created', 'exercise_created', 'workspace_updated'];
   const OBSERVER_VISIBLE = ['workspace_updated', 'mission_created'];

   function getVisibleTypes(role: string | null): string[] {
     if (!role) return OBSERVER_VISIBLE;
     if (['commander', 'xo'].includes(role)) return COMMANDER_VISIBLE;
     if (role === 'observer') return OBSERVER_VISIBLE;
     return STAFF_VISIBLE; // s1-s9, team_lead, member
   }
   ```
   Filter fetched activities by visible types.

3. **Activity item rendering:**
   Each activity renders as a card/row with:
   - Icon: different icon per activity type (user-plus for join, user-minus for remove, shield for role change, etc.). Use simple SVG icons or emoji placeholders.
   - Description: Human-readable string built from activityType + metadata:
     - 'member_joined': "[actorDid] invited [subjectDid] as [metadata.role]"
     - 'role_changed': "[actorDid] changed [subjectDid]'s role from [metadata.oldRole] to [metadata.newRole]"
     - 'workspace_created': "[actorDid] created this workspace"
     - 'member_suspended': "[actorDid] suspended [subjectDid]"
     - etc. (build a map of activityType -> template string)
   - Timestamp: relative time ("2 hours ago", "yesterday") using a simple formatter.
   - TX hash link: if `txHash` is present, show a small "on-chain" link/badge (links to NEAR explorer).

4. **Pagination:** "Load more" button at bottom that increments offset.

5. **Empty state:** "No activity yet" message.

6. **Auto-refresh:** Poll for new activities every 15 seconds (lighter than notification polling).

7. Tailwind CSS. Vertical timeline-style layout with connecting line.

**WorkspaceSwitcher.tsx:**

Create a sidebar component using the Slack/Discord workspace selector pattern:

1. Uses `useWorkspace()` to get memberships, activeWorkspaceId, notificationCounts, setActiveWorkspace.
2. Uses `useNavigate()` from react-router-dom.
3. Renders a vertical column (fixed width ~64px) with:
   - Each workspace as a rounded square icon showing the first 2 characters of the name (abbreviation).
   - Active workspace has a highlighted border/background.
   - Notification badge: small red circle with count if `notificationCounts[ws.workspaceId] > 0`.
   - Primary workspace has a subtle star/dot indicator.
   - Tooltip on hover showing full workspace name and type.
4. On click: `setActiveWorkspace(ws.workspaceId)` then `navigate('/workspace/' + ws.workspaceId)`.
5. At bottom: a "+" button that opens CreateWorkspaceWizard in a modal/overlay.
6. Use Tailwind CSS classes for styling (the project uses Tailwind).
7. Sort: primary workspace first, then by name.
8. Show workspace type with a subtle icon or label (O/U/T for Org/Unit/Team).

**CreateWorkspaceWizard.tsx:**

Create a multi-step form for workspace creation:

1. Props: `{ onClose: () => void; onCreated: (workspaceId: string) => void; parentWorkspaceId?: string }`
2. Steps:
   - Step 1: Name, description, workspace type (radio: Organization/Unit/Team). If type is Unit or Team, show parent workspace dropdown (populated from user's memberships filtered to parent-eligible types).
   - Step 2: Classification (UNCLASSIFIED/SECRET/TOPSECRET radio), invite mode (open/gated toggle), discoverability (discoverable/private toggle). Show explanatory text for each.
   - Step 3: Review and confirm. Show all selected options. "Create Workspace" button.
3. On submit: call `workspaceService.createWorkspace(input)`, then `onCreated(workspace.id)`.
4. Show loading state during creation.
5. Show error state if creation fails (e.g., insufficient clearance, DAO creation failure).
6. Use Tailwind CSS. Modal overlay pattern.
7. Cancel button on every step.

Both components should be clean, functional React components using hooks. No class components.

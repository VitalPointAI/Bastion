  <action>
**WorkspaceInviteModal.tsx:**

Generalize from `frontend/src/components/mission/InviteModal.tsx`. Read that file first.

Props: `{ workspaceId: string; workspaceName: string; onClose: () => void }`

1. Fetch available roles for the workspace: `workspaceService.listRoles(workspaceId)`.
2. Form fields:
   - Role selection: dropdown populated from fetched roles (showing military labels).
   - Target type: radio buttons for "Anyone with link" / "Specific DID" / "Specific Email".
   - If DID: text input for DID (format: did:near:...).
   - If Email: email input.
   - Expiration: dropdown (24h / 72h / 7 days / 30 days).
3. On submit: call `workspaceService.createInvite(workspaceId, selectedRole.militaryLabel, selectedRole.daoRoleName, { inviteeEmail, inviteeDid, expiresInHours })`.
4. On success: Show the invite link (`window.location.origin + '/workspace/invite/' + rawToken`). Copy-to-clipboard button.
5. Show pending invites list below the form (fetched via `workspaceService.listPendingInvites`).
6. Each pending invite has a "Cancel" button.
7. For gated workspaces: pending invites that have been claimed but not approved show an "Approve" button.
8. Tailwind CSS styling. Modal overlay.

**InviteAcceptPage.tsx:**

A standalone page component for `/workspace/invite/:token` route.

1. Extract `token` from URL params (`useParams`).
2. On mount:
   - If user is NOT authenticated: show invite info (if possible to decode without auth) and a "Register / Login to join" button that stores the token in sessionStorage and redirects to `/login?redirect=/workspace/invite/{token}`.
   - If user IS authenticated: call `workspaceService.acceptInvite(token)`.
3. Handle responses:
   - Success (200): Show "You've joined [workspace name]!" with "Go to workspace" button.
   - Pending approval (202/null return): Show "Your request is pending approval."
   - Clearance error: Show "Insufficient clearance for this workspace" with workspace classification.
   - Invalid/expired: Show "This invite link is invalid or has expired."
   - Already a member: Show "You're already a member of this workspace."
4. After join: call `refreshMemberships()` from WorkspaceContext to update the sidebar.
5. Tailwind CSS styling. Full-page centered card layout.

Add the `/workspace/invite/:token` route to App.tsx (modify the file to add the route — this is a small addition to the existing route registration from 19-05).

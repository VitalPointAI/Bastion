**Frontend — Update RegistryStats mapping in `resource-registry-service.ts`:**
The frontend `RegistryStats` interface expects `totalResources` but backend returns `total`. Add a mapping in the `getRegistryStats()` method:
```typescript
async getRegistryStats(): Promise<RegistryStats> {
  const raw = await this.fetch<any>('/api/resources/registry/stats');
  return {
    totalResources: raw.total,
    byCategory: raw.byCategory,
    byStatus: raw.byStatus,
    withDID: raw.withDID ?? 0,
    autonomous: raw.autonomous,
    groupCount: raw.groupCount ?? 0,
  };
}
```

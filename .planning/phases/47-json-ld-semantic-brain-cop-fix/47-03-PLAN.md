1. Rewrite `actor-store.ts`:
   - Import `ACTOR_TYPE_TO_CCO_MAP` from `./types.js` and `ProvenanceProps` from `../provenance-types.js`
   - `createActor()`: Add JSON-LD fields to Cypher SET clause:
     - `a.jsonldType = $jsonldType` (lookup from ACTOR_TYPE_TO_CCO_MAP using actor.type, default 'cco:Agent')
     - `a.jsonldContext = 'https://bastion.vitalpoint.ai/ontology/context.jsonld'`
     - `a.assertedBy = $assertedBy` (default: 'system:unknown')
     - `a.assertedVia = $assertedVia` (default: 'manual_entry')
     - `a.derivedFrom = $derivedFrom` (default: '[]')
     - `a.confidence = $confidence` (default: SOURCE_WEIGHTS[assertedVia])
     - `a.sourceWeight = $sourceWeight` (from SOURCE_WEIGHTS)
     - `a.validFrom = datetime($validFrom)` (default: datetime())
     - `a.validTo = null`
     - `a.halfLifeDays = $halfLifeDays` (default: 180)
   - Promote queryable attributes to top-level: `a.attributes_affiliation`, `a.attributes_echelon`, `a.attributes_unitType`, `a.attributes_lat`, `a.attributes_lng`. Parse from existing `attributes` JSON blob if present.
   - `updateActor()`: Same JSON-LD fields. If `assertedVia` changes, recalculate `sourceWeight`. Update `updatedAt`.
   - `listActors()`: Keep existing behavior. Add optional `atTime?: Date` parameter — when provided, add temporal filter: `WHERE a.validFrom <= datetime($atTime) AND (a.validTo IS NULL OR a.validTo > datetime($atTime))`.
   - `getActor()`: No temporal filter needed (direct lookup by ID).
   - `deleteActor()`: Set `a.validTo = datetime()` instead of deleting node (soft delete for temporal history). Keep existing hard delete as `purgeActor()`.
   - All existing function signatures preserved. New optional parameters only.

   - `updateRelationship()`: Same fields
   - `listRelationships()`: Add optional `atTime` temporal filter
   - Soft delete pattern: set validTo instead of hard delete

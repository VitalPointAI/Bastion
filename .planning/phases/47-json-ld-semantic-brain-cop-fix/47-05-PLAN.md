<task type="auto">
  <name>Task 1: Create contradiction detector</name>
  <files>backend/src/graph/contradiction-detector.ts</files>
  <action>
1. Create `backend/src/graph/contradiction-detector.ts`:
   - Import `ContradictionRecord` from `./provenance-types.js`
   - Import `executeWriteQuery`, `executeReadQuery` from `./neo4j-client.js`
   - Import event bus from `../cop/messaging/event-bus.js` (for contradiction:detected events)

2. `detectContradiction(entityId: string, propertyKey: string, newValue: unknown, newValidFrom: string, newValidTo: string | null, workspaceId: string): Promise<ContradictionRecord | null>`:
   - Query existing assertions on same entity + property:
     ```
     MATCH (a {id: $entityId, workspaceId: $workspaceId})
     WHERE a[$propertyKey] IS NOT NULL AND a[$propertyKey] <> $newValue
     RETURN a
     ```
   - For each existing assertion, check temporal overlap:
     - Overlap exists if: `(existingValidFrom < newValidTo OR newValidTo IS NULL) AND (existingValidTo IS NULL OR existingValidTo > newValidFrom)`
     - If NO temporal overlap → return null (historical succession, not contradiction — per Pitfall 7)
   - If contradiction found:
     - Create `:CONTRADICTS` relationship in Neo4j between the two assertion contexts
     - Lower confidence on BOTH assertions by 20%: `SET a.confidence = a.confidence * 0.8`
     - Build `ContradictionRecord` with all fields
     - Emit `contradiction:detected` event on event bus with the record
     - Return the ContradictionRecord

3. `resolveContradiction(contradictionId: string, resolution: ContradictionRecord['resolution']): Promise<void>`:
   - Update the :CONTRADICTS relationship with `resolvedAt` and `resolution`
   - Based on resolution type:
     - `accept_a`: restore assertion A confidence (undo 20% penalty), mark B validTo = now
     - `accept_b`: restore assertion B confidence, mark A validTo = now
     - `both_valid`: restore both confidences (both are correct but different facets)
     - `flagged_for_intel`: keep lowered confidence on both, emit event for intel staff
   - Emit `contradiction:resolved` event

4. Export all functions.
  </action>

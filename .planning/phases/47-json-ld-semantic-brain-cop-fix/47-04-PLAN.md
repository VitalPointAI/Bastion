   - Import `executeWriteQuery`, `executeReadQuery` from `../neo4j-client.js`

3. `migrateActors(batchSize = 500)`:
   - Count unmigrated: `MATCH (a:Actor) WHERE a.migrationVersion IS NULL RETURN count(a)`
   - Loop in batches: Cypher SET per RESEARCH Pattern (migration script):
     - `a.jsonldType` from CASE on `a.type` matching ACTOR_TYPE_TO_CCO_MAP
     - `a.jsonldContext = 'https://bastion.vitalpoint.ai/ontology/context.jsonld'`
     - `a.assertedBy = coalesce(a.assertedBy, 'system:migration')`
     - `a.assertedVia = coalesce(a.assertedVia, 'manual_entry')`
     - `a.derivedFrom = coalesce(a.derivedFrom, '[]')`
     - `a.confidence = coalesce(a.confidence, 0.75)` (conservative default)
     - `a.sourceWeight = 0.75`
     - `a.validFrom = coalesce(a.validFrom, a.createdAt)`
     - `a.validTo = null`
     - `a.halfLifeDays = 180`
     - Promote attributes: parse `a.attributes` JSON blob, set `a.attributes_affiliation`, `a.attributes_echelon`, `a.attributes_unitType`, `a.attributes_lat`, `a.attributes_lng`
     - `a.migrationVersion = 47`
   - Log progress: `Migrated batch ${batch}: ${count} actors (${totalMigrated}/${totalCount})`
   - Return total migrated count

4. `migrateRelationships(batchSize = 500)`:
   - Same pattern. jsonldType = 'cco:ActOfRelating'. Set provenance defaults, temporal defaults, migrationVersion = 47.

5. `migrateTensions(batchSize = 500)`:
   - Same pattern. jsonldType = 'cco:InformationBearingEntity'. Set defaults, migrationVersion = 47.

6. `migrateDecisions(batchSize = 500)`:
   - Same pattern. jsonldType = 'cco:ActOfDecisionMaking'. Set defaults, migrationVersion = 47.

All functions are idempotent — they only touch nodes WHERE migrationVersion IS NULL.

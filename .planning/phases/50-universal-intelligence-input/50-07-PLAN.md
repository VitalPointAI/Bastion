    Create IngestionDrawer as a replacement for IngestionSidebar.

    **Drawer behavior:**
    - Renders as a fixed-position overlay on the left side of the brain canvas
    - Width: `min(33vw, 520px)` — enough for cards but not overwhelming
    - Backdrop: semi-transparent dark overlay behind drawer, click-to-close
    - Slide animation: CSS transform translateX(-100%) when closed, translateX(0) when open
    - Transition: 250ms ease-out open, 200ms ease-in close

    **Auto-open trigger:**
    - Accept an `isOpen` / `onOpen` / `onClose` prop pattern
    - Parent (BrainController) manages open state
    - Hook into useUniversalIngest — when items go from 0 to >0 (new submission), signal open
    - Drawer also opens on manual click of trigger button

    **Auto-close trigger:**
    - When all items reach terminal state (complete or error) AND no items are in
      classifying/routing/processing, start a 2s timer then signal close
    - If user submits new content during the timer, cancel the close
    - User can also close manually via X button or backdrop click

    **Trigger button (collapsed state):**
    - Small button fixed to left edge of brain canvas area: "+" icon or ingestion icon
    - Shows a badge count of active processing items when drawer is closed
    - Clicking opens the drawer

    **Content (simplified from IngestionSidebar):**
    - Header: "Intelligence Ingestion" + close button
    - UniversalInputZone (same component, just has more room now)
    - Processing cards (enlarged):
      - Each card shows: label, type badge, status with animated progress bar,
        classification result (inputType + confidence as percentage),
        entity count if available from SSE events, document summary preview
        (first 2-3 lines from report) if processing complete
      - Error cards: red border, error message, retry button
      - Complete cards: green checkmark, brief summary, dismiss button
    - Filter tags row (All / Documents / OSINT / Subscriptions / Research)
    - Unified feed below (same chronological merge as before)

    **Document & feed management section (below the feed):**
    - Collapsible "Ingested Documents" list — fetched from /api/strategic/documents
      - Each row: title, classification badge, date, objective count
      - Delete button with confirmation: "Delete X and remove its effects from the
        knowledge graph?" → calls DELETE /api/strategic/documents/:id (existing cascade endpoint)
      - Visual: compact rows, red delete icon on hover
    - Collapsible "OSINT Feeds" list — fetched from osintService.getFeeds()
      - Each row: feed name, source type badge, active/paused status dot, endpoint URL
      - Pause/resume toggle button per feed
      - Delete button with confirmation: removes feed subscription
      - No "Add Source" modal here — RSS URLs pasted into the input zone auto-create feeds

    **What is NOT in the drawer:**
    - No "Advanced options" wrapper section (the individual panels below replace it)
    - No DocIntelligencePanel (replaced by UniversalInputZone)
    - No AddOSINTSourceModal (RSS auto-detection replaces this)
    - No SubspaceSidebar (separate component, stays in the left grid column)

    **Tests:**
    - Drawer renders with correct overlay classes when open
    - Drawer has translateX(-100%) when closed
    - Trigger button shows active count badge
    - Backdrop click calls onClose
    - Close button calls onClose
    - Processing cards display classification details

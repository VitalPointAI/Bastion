    2. Create `frontend/src/components/brain/hooks/useUniversalIngest.ts`:

       Define frontend types (mirror backend types to avoid cross-project imports):
       ```typescript
       export type ItemStatus = 'queued' | 'classifying' | 'routing' | 'processing' | 'complete' | 'error';
       export type InputType = 'file' | 'rss_url' | 'article_url' | 'pdf_url' | 'api_url' | 'raw_text' | 'json_data' | 'xml_data' | 'unknown';

       export interface ClassificationResult {
         inputType: InputType;
         confidence: number;
         suggestedPipeline: 'doc-intelligence' | 'osint-subscribe' | 'text-ingest' | 'manual';
         metadata: { contentType?: string; title?: string; description?: string; feedUrl?: string; isRss?: boolean; };
       }

       export interface IngestItem {
         id: string;              // crypto.randomUUID()
         label: string;           // filename, URL, or first 60 chars of text
         status: ItemStatus;
         progress: number;        // 0-1
         processId?: string;      // backend processId for SSE tracking
         classification?: ClassificationResult;
         error?: string;
         retryCount: number;
         createdAt: string;       // ISO timestamp
       }
       ```

       Export `useUniversalIngest(problemSetId: string)` hook returning:
       ```typescript
       {
         items: IngestItem[];           // all tracked items, newest first
         submitText: (text: string) => Promise<void>;
         submitFiles: (files: File[]) => Promise<void>;
         retryItem: (itemId: string) => Promise<void>;
         dismissItem: (itemId: string) => void;
         clearCompleted: () => void;
         isInterviewRequired: boolean;  // true if backend returned interview_required
         handleSSEEvent: (event: string, data: unknown) => void;
       }
       ```

       Internal state: `useState<Map<string, IngestItem>>` keyed by item ID.

       `submitText(text: string)`:
       - Generate UUID, create IngestItem with status 'queued', label = text.slice(0, 60)
       - Set status to 'classifying'
       - POST to `${API_BASE}/api/ingest/classify` with `{ content: text, problemSetId }`
       - On response: update item with classification, set status to 'routing'
       - POST to `${API_BASE}/api/ingest/submit` with `{ content: text, problemSetId }`
       - On response: update item with processId, set status to 'processing'
       - If response.status === 'interview_required', set `isInterviewRequired = true`, set item status to 'error' with message "Complete scoping interview first"
       - If response.status === 'duplicate', set item status to 'error' with message "Already ingested"
       - On any fetch error: set item status to 'error' with error message

       `submitFiles(files: File[])`:
       - For each file: generate UUID, create IngestItem with label = file.name
       - Submit each independently via `Promise.allSettled` (not Promise.all — don't fail batch on single error)
       - For each file: POST to `/api/ingest/submit` as multipart FormData with file + problemSetId field
       - Track each item independently

       SSE integration via `handleSSEEvent(event: string, data: unknown)`:
       - `classify:result` — update matching item (by processId) with classification
       - `route:selected` — update item status to 'processing'
       - `route:error` — update item status to 'error' with error message
       - `processing:complete` — update item status to 'complete', progress to 1
       - `processing:error` — update item status to 'error'
       - Match events to items via processId field in event data

       `retryItem(itemId: string)`:
       - Get item from map, re-submit based on original content
       - Increment retryCount, reset status to 'queued'
       - Use exponential backoff: `3000 * Math.pow(2, item.retryCount)` delay before retry (copy from useBrainIngestion pattern)

       All API calls use `credentials: 'include'` (match existing fetch patterns).
